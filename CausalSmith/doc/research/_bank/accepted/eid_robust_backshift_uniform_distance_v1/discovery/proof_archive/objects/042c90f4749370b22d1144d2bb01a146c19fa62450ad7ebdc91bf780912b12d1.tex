The already-established \(\text{thm:certified-inference-representation-obstruction}\) proves the strongest available constructive part under only \(\Omega\in\mathbb S_+^p\): for every finitely rational-semialgebraically encoded nonempty region family, effective real quantifier elimination terminates and returns a rational-polynomial code whose realization is exactly \(\mathcal U^{(n)}_{\alpha}\); on simultaneous honest-slot coverage it gives \(D\in\mathcal U^{(n)}_{\alpha}\) and hence coverage at least \(1-\alpha\); its decidable universal audit releases the exact full-union code only when every feasible tuple satisfies the five prescribed margins and otherwise returns \(\mathsf{ABSTAIN}\), necessarily abstaining when a feasible tuple has \(\gamma=0\). That theorem also proves that finite membership-oracle access to arbitrary unencoded regions cannot compute every exact union. It proves no operator-norm contraction rate.
