For the class of arbitrary nonempty covariance regions \(\mathcal C^{(n)}_{e,\alpha}\subseteq\mathbb S_{++}^p\) without an effective code, no deterministic procedure that makes only finitely many membership queries can return the exact full confidence union \(\mathcal U^{(n)}_\alpha\) for every region family.  This is already true for \(p=2\), \(m=h=3\), and \(c=0\), using rational positive-definite matrices and a baseline design with \(\gamma_H=1\).
