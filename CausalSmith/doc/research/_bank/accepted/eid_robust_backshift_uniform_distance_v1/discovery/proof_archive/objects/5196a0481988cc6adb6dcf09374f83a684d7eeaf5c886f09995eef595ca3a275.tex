A rational semialgebraic region code in dimension \(p\) is a finite list of polynomials in the \(p(p+1)/2\) independent entries of a symmetric matrix \(G\), with coefficients in \(\mathbb Q\), together with a finite Boolean formula \(\rho(G)\) whose atoms are comparisons of those polynomials with zero. Its realization is
\[
\operatorname{Real}(\rho)
=\{G\in\mathbb S_{++}^p:\rho(G)\}.
\]
An encoded covariance-region family supplies, for every \(n\geq1\), \(\alpha\in(0,1)\), and \(e\in E\), such a finite code \(\rho^{(n)}_{e,\alpha}\) and requires
\[
\mathcal C^{(n)}_{e,\alpha}
=\operatorname{Real}\bigl(\rho^{(n)}_{e,\alpha}\bigr)\neq\varnothing.
\]
The code may be random through the sample, but after a sample outcome is fixed it is a finite rational string and its displayed equality with the region is exact, not an outer approximation or a membership oracle.
