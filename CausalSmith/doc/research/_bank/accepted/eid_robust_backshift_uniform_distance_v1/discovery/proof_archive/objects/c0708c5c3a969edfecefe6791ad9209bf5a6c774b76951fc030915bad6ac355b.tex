Fix \(n\geq1\) and \(\alpha\in(0,1)\), and suppose the nonempty regions \(\mathcal C^{(n)}_{e,\alpha}\subseteq\mathbb S_{++}^p\) are supplied through \(\operatorname{RegionCode}(\mathcal C^{(n)}_\alpha)\).  For rational thresholds \(\gamma_0>0\), \(\zeta_0>0\), \(\lambda_0>0\), \(\overline\kappa\geq1\), and \(\overline M\geq1\), the procedure \(\operatorname{CertificateInferenceHandle}\) terminates.  It either returns \(\mathsf{abstain}\), or returns a finite quantifier-free rational-polynomial code whose realization is exactly the full confidence union \(\mathcal U^{(n)}_\alpha\).  It returns the code precisely when every feasible witness in every cardinality-\(h\) subset branch satisfies
\[
 \widehat\gamma\geq\gamma_0,
 \qquad \widehat\zeta\geq\zeta_0,
 \qquad \widehat\lambda\geq\lambda_0,
 \qquad \widehat\kappa\leq\overline\kappa,
 \qquad \widehat M\leq\overline M,
\]
and otherwise abstains.  In particular, it abstains whenever a feasible witness has \(\widehat\gamma=0\).

For the causal BACKSHIFT instance, assume explicitly that \(\Omega\in\mathbb S_+^p\), in addition to \(\text{ass:backshift-normalization}\), \(\text{ass:nonnegative-shifts}\), and \(\text{ass:honest-covariance-model}\).  If
\[
 G_{n,\alpha,H}
 =\{\Sigma_e\in\mathcal C^{(n)}_{e,\alpha}
     \text{ for every }e\in H\},
\]
then
\[
 G_{n,\alpha,H}\subseteq\{D\in\mathcal U^{(n)}_\alpha\}.
\]
Consequently, \(\Pr(G_{n,\alpha,H})\geq1-\alpha\) implies \(\Pr\{D\in\mathcal U^{(n)}_\alpha\}\geq1-\alpha\).  Strict positive definiteness of \(\Omega\) is not required for this coverage conclusion.  The effective-code requirement cannot be replaced by finite membership-oracle access for arbitrary nonempty regions, by \(\text{lem:finite-membership-query-obstruction}\).  No operator-norm contraction rate is asserted: such a result for unrestricted candidates requires a separate coercivity argument or a compact candidate envelope.  The causal target remains \(B=I_p-D\); the confidence union is an observed-law compatibility construction whose coverage relation to \(D\) is proved here, not the definition of that target.
