For every \(n\geq1\) and \(\alpha\in(0,1)\), define
\[
 \mathcal U^{(n)}_\alpha
 =\bigcup\left\{
   \mathcal R_c(\Gamma):
   \Gamma_e\in\mathcal C^{(n)}_{e,\alpha}
   \text{ for every }e\in E
 \right\}.
\]
This definition uses the realized regions and is meaningful for arbitrary nonempty regions.  The additional code in \(\text{def:encoded-covariance-regions}\), when supplied, is an effective representation of the same realized sets and is the input used by \(\text{def:certificate-inference-handle}\).
