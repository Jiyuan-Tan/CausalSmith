Fix a realized encoded region family, \(n\geq1\), \(\alpha\in(0,1)\), and rational thresholds \(\gamma_0,\zeta_0,\lambda_0>0\) and \(\overline\kappa,\overline M\geq1\). For each \(K\subseteq E\) with \(|K|=h\), introduce a candidate tuple
\[
w=(K,A,\Psi,(t_e)_{e\in K},(\Gamma_e)_{e\in K}).
\]
The full feasibility formula \(F_K(w)\) is the conjunction of: each encoded region formula at \(\Gamma_e\); \(\Gamma_e\in\mathbb S_{++}^p\); \(A_{ii}=1\); \((\det A)^2>0\); \(1-\pi_C(A)>0\) and \(1+\pi_C(A)>0\) for every directed simple cycle \(C\), where \(\pi_C(A)\) is the corresponding entry product in \(I_p-A\); \(\Psi\in\mathbb S_+^p\); \(t_{ej}\geq0\); and
\[
A\Gamma_eA^{\mathsf T}=\Psi+\operatorname{diag}(t_e)
\qquad(e\in K).
\]
For such a tuple set \(\zeta(w)=1-\max_C|\pi_C(A)|\), \(\kappa(w)=\|A\|_{\mathrm{op}}\|A^{-1}\|_{\mathrm{op}}\),
\[
\lambda(w)=\min\left\{\lambda_{\min}(\Psi),\min_{e\in K}\lambda_{\min}(\Gamma_e)\right\},
\qquad
M(w)=1+\|\Psi\|_{\mathrm{op}}+\max_{e\in K}\|\Gamma_e\|_{\mathrm{op}}+\max_{e\in K}\|\operatorname{diag}(t_e)\|_{\mathrm{op}},
\]
and, writing
\[
\Delta^{k\ell}_{efg}(t)=
\det\begin{pmatrix}
1&t_{ek}&t_{e\ell}\\
1&t_{fk}&t_{f\ell}\\
1&t_{gk}&t_{g\ell}
\end{pmatrix},
\]
set \(\gamma(w)=0\) if \(h-c<3\), and otherwise set
\[
\gamma(w)=
\min_{1\leq k<\ell\leq p}
\min_{\substack{S\subseteq K\\|S|=h-c}}
\max_{e<f<g\in S}|\Delta^{k\ell}_{efg}(t)|.
\]
The certificate procedure forms
\[
\Phi_{\mathcal U}(A)
=\bigvee_{\substack{K\subseteq E\\|K|=h}}
\exists\Psi\,\exists(t_e)_{e\in K}\,\exists(\Gamma_e)_{e\in K} F_K(w),
\]
calls effective real quantifier elimination to obtain a quantifier-free rational-polynomial code in \(A\), and calls it again on the closed sentence asserting that some feasible tuple violates at least one of
\[
\gamma(w)\geq\gamma_0,\qquad
\zeta(w)\geq\zeta_0,\qquad
\lambda(w)\geq\lambda_0,\qquad
\kappa(w)\leq\overline\kappa,\qquad
M(w)\leq\overline M.
\]
It returns the code for \(\Phi_{\mathcal U}\) when that sentence is false and returns \(\mathsf{ABSTAIN}\) when it is true. This definition names the finite symbolic procedure and its candidate margins; exactness, termination, coverage, and the abstention guarantee are asserted only by the theorem.
