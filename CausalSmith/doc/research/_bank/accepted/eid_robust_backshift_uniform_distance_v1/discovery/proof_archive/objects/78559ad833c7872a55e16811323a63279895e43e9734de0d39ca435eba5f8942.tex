Now fix any realized encoded region family.  For each \(K\subseteq E\) with \(|K|=h\), expand \(F_K\) from \(\text{def:certificate-inference-handle}\).  All covariance equations are entrywise polynomial equations.  Invertibility is expressed by \((\det A)^2>0\).  \operatorname{CP}(I_p-A)<1

 1-\pi_C(A)>0\ \text{ and }\ 1+\pi_C(A)>0

 \{A:\Phi_{\mathcal U}(A)\}=\mathcal U^{(n)}_\alpha.
 \tag{21}

There are exactly \(\binom mh\) disjuncts.  Applying \(\text{lem:effective-real-quantifier-elimination}\) to (20) terminates and produces a finite quantifier-free rational-polynomial code whose realization is exactly (21).
