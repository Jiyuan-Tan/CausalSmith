Fix \(k<\ell\) and abbreviate \(P_e^{k\ell}=(x_e,y_e)\).  Type \(00\) gives the origin, types \(10\) and \(01\) give the two positive coordinate axes, and type \(11\) gives the open positive quadrant.  The horizontal axis, vertical axis, a line through the origin and one type \(11\) point when such a point exists, and a line through any two indexed points show
\[
 M_I^{k\ell}\ge
 \max\!\left\{
 N_{00}^{k\ell}+N_{10}^{k\ell},
 N_{00}^{k\ell}+N_{01}^{k\ell},
 N_{00}^{k\ell}+\mathbf 1\{N_{11}^{k\ell}>0\},
 \min(2,r)
 \right\}. \tag{22}
\]

For two nonzero-support points, collinearity with the origin is the polynomial equation
\[
 x_ey_f-x_fy_e=0. \tag{23}
\]
Unless both types are \(10\), or both are \(01\), this polynomial is not identically zero in the active coordinates: the mixed axis and axis--interior cases contain a nonzero product, while the interior--interior case contains two distinct monomials.  For three nonzero-support points, collinearity is the equation
\[
 \det\!\begin{pmatrix}
 1&x_e&y_e\\
 1&x_f&y_f\\
 1&x_g&y_g
 \end{pmatrix}=0. \tag{24}
\]
Except when all three types are \(10\), or all three are \(01\), this is not the zero polynomial.  To verify this, choose two distinct horizontal points and a vertical or interior point, use the coordinate-swapped construction, put one point off the line through the other two in the remaining mixed cases, and use \((1,1),(1,2),(2,1)\) for three interior points.  Equality of the active coordinates of two distinct type \(10\) points, and its type \(01\) analogue, is also the zero set of a nonzero linear polynomial.

The zero set of a nonzero polynomial in finitely many real variables has Lebesgue measure zero.  An induction proves this directly: a nonzero univariate polynomial has finitely many roots; after expansion in the last variable, the induction hypothesis removes the null set on which all coefficient polynomials vanish, every remaining section has finitely many roots, and integration of the null sections gives the result.  There are finitely many coordinate pairs and indexed pairs and triples.  Joint absolute continuity therefore gives a single probability-one event on which none of the non-forced equations (23)--(24) or coordinate equalities occurs, simultaneously for all \(k<\ell\).

On that event, a line through the origin containing type \(10\) is the horizontal axis, and the coordinate-swapped statement holds for type \(01\).  A line through the origin containing neither axis type has at most one type \(11\) point by (23).  A line not through the origin has no type \(00\) point; if it contained three indices, (24) would force all three to be type \(10\) or all three to be type \(01\), but the resulting coordinate axis passes through the origin.  Thus every line is bounded by one of the four quantities in (22), proving equality.
