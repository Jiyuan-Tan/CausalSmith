Fix \(D,\Omega,H,s\) satisfying the honest BACKSHIFT model with \(\Omega\in\mathbb S_{++}^{p}\), while the compatibility set permits positive-semidefinite invariant nuisances. The equality \(\mathcal R_c(\Sigma)=\{D\}\) holds for every assignment of arbitrary matrices from the positive-definite replacement domain to the \(c\) slots in \(E\setminus H\) if and only if \(\delta_H>c\), equivalently \(\gamma_H>0\). If \(\delta_H\le c\), there exist positive-definite values for all slots in \(E\setminus H\), a matrix \(D'\in\mathcal D\) with \(D'\ne D\), an invariant \(\Omega'\in\mathbb S_{++}^{p}\), and nonnegative shifts on a set \(H'\subseteq E\) with \(|H'|=h\) such that both \(D\) and \(D'\) belong to \(\mathcal R_c(\Sigma)\). At \(c=0\), the equivalence reduces to the BACKSHIFT pairwise noncollinearity criterion.
