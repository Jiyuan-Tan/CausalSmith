Fix an honest BACKSHIFT instance \(D,H,s,\Omega\) with \(D\in\mathcal D\), nonnegative shifts, \(\Omega\in\mathbb S_{+}^{p}\), and positive-definite honest covariances. If \(\delta_H>c\), equivalently \(\gamma_H>0\), then \(\mathcal R_c(\Sigma)=\{D\}\) for every assignment of matrices in \(\mathbb S_{++}^{p}\) to the \(c\) slots in \(E\setminus H\). If, in addition, this fixed instance has \(\Omega\in\mathbb S_{++}^{p}\) and \(\delta_H\le c\), then there are positive-definite values for all slots in \(E\setminus H\), a matrix \(D'\in\mathcal D\) with \(D'\ne D\), an invariant \(\Omega'\in\mathbb S_{++}^{p}\), and nonnegative shifts on a set \(H'\subseteq E\) with \(|H'|=h\) such that \(D,D'\in\mathcal R_c(\Sigma)\). Consequently, over the published class allowing \(\Omega\in\mathbb S_{+}^{p}\), the threshold \(\delta_H>c\) is minimax sharp: whenever \(\delta_H\le c\), the class contains an ambiguity witness in its positive-definite invariant-noise subclass. No ambiguity is asserted for every fixed singular boundary value of \(\Omega\). On the positive-definite invariant-noise interior and at \(c=0\), the equivalence is exactly the BACKSHIFT pairwise noncollinearity criterion.
