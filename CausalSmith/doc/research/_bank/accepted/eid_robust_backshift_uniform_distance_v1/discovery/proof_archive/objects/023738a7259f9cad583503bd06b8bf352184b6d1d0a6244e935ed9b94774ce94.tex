The definition-level coverage claim is valid, but the requested computable confidence-union construction has a negative answer for the region class stated in the question.  More precisely, if
\[
G_{n,\alpha,H}=\{\Sigma_e\in\mathcal C^{(n)}_{e,\alpha}\text{ for every }e\in H\},
\]
then \(G_{n,\alpha,H}\subseteq\{D\in\mathcal U^{(n)}_\alpha\}\), and consequently \(\Pr(G_{n,\alpha,H})\ge 1-\alpha\) implies \(\Pr\{D\in\mathcal U^{(n)}_\alpha\}\ge1-\alpha\).

For a rational population covariance family \(\Sigma\), the population compatibility set \(\mathcal R_c(\Sigma)\) has an exact rational semialgebraic description.  Effective real quantifier elimination therefore supplies finite rational-polynomial certificates for infeasibility, singleton output, and multiple-candidate output.  The affine minors of the fitted diagonal shifts can be included, without division, among the sign polynomials in each certificate.  These minors certify separation, but they cannot by themselves certify feasibility: the covariance equations, positive-semidefinite invariant nuisance, nonnegative shifts, invertibility, unit diagonal, and cycle-product inequalities are also necessary.  Normalization-chart changes are sound when pivot nonvanishing and all normalization and cycle inequalities are cleared to polynomial sign conditions before a chart certificate is accepted.

In contrast, when \(\mathcal C^{(n)}_{e,\alpha}\) is only an arbitrary nonempty subset of \(\mathbb S_{++}^p\), as in the frozen definition, no deterministic procedure making only finitely many membership queries to these sets can return the exact full set \(\mathcal U^{(n)}_\alpha\) for every region family.  This failure already occurs for \(p=2\), \(m=3\), and \(c=0\), with rational positive-definite matrices and a design having affine-minor separation \(\gamma_H=1\).  Hence the complete conjunction requested in the open question is false as stated: an exact computable confidence union, and thus a computable full-output-or-abstain rule at \(\gamma_H=0\), requires an additional effective representation of the regions.  The causal target remains \(B=I_p-D\); neither the coverage inclusion nor the semialgebraic description defines that target to equal an observable functional.
