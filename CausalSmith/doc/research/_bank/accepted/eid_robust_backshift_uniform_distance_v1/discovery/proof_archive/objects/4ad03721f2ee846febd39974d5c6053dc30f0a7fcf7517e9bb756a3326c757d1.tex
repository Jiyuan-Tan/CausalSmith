Let \(\bar Z\in\{0,1\}^{E\times p}\) be a planned full-environment support array and let \(\bar a\in(0,\infty)^{E\times p}\). Suppose the active subarray \((\bar a_{ek}:\bar Z_{ek}=1)\) has a joint density on its positive orthant, and put \(\bar s_{ek}=\bar Z_{ek}\bar a_{ek}\). For \(u,v\in\{0,1\}\), define \(N_{uv}^{k\ell}=\#\{e\in E:(\bar Z_{ek},\bar Z_{e\ell})=(u,v)\}\), and set \(T=\max_{k<\ell}\max\{N_{00}^{k\ell}+N_{10}^{k\ell},N_{00}^{k\ell}+N_{01}^{k\ell},N_{00}^{k\ell}+\mathbf 1\{N_{11}^{k\ell}>0\},\min(2,m)\}\). Almost surely, the following are equivalent: (i) for every failed set \(F\subseteq E\) with \(|F|=c\), the retained set \(H=E\setminus F\) and shifts \((\bar s_e:e\in H)\) give a design that guarantees \(\mathcal R_c(\Sigma)=\{D\}\) uniformly over all admissible \(D\in\mathcal D\), all \(\Omega\in\mathbb S_+^p\) producing positive-definite honest covariances, and all positive-definite replacements; (ii) \(T<m-2c\). If \(T<m\), condition (ii) is equivalent to \(c\le\lfloor(m-T-1)/2\rfloor\); if \(T=m\), no nonnegative corruption budget is certified. For the all-active design and \(m\ge3\), the largest certified budget is \(c_{\max}=\lfloor(m-3)/2\rfloor\).
