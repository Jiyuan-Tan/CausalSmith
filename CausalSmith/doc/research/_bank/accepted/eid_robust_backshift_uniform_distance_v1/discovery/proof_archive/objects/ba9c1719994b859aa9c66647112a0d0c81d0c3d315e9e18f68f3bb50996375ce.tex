For a coordinate pair \(k<\ell\), let \(T_{k\ell}\) denote the inner four-term maximum in the definition of \(T\).  Apply \(\text{lem:generic-affine-occupancy}\) with \(I=E\) and \(r=m\).  Its joint absolute-continuity premise is exactly the amplitude premise of the corollary, so on one probability-one event the full \((k,\ell)\)-cloud has maximum affine-line occupancy \(T_{k\ell}\), simultaneously for every pair.

Fix a pair \(k<\ell\).  For a retained set \(H\subseteq E\) of size \(m-c\), write \(M_{k\ell}(H)\) for the maximum line occupancy after restriction to \(H\).  We claim
\[
 \max_{H\subseteq E:\,|H|=m-c}M_{k\ell}(H)
 =\min\{T_{k\ell},m-c\}. \tag{31}
\]
The upper bound is immediate from restriction and cardinality.  For the reverse bound, choose a line attaining the full occupancy \(T_{k\ell}\), which exists because the finite cloud determines only finitely many relevant incidences.  If \(T_{k\ell}\ge m-c\), retain any \(m-c\) indices on that line.  If \(T_{k\ell}<m-c\), retain all its \(T_{k\ell}\) indices and add any \(m-c-T_{k\ell}\) other indices.  Both constructions are feasible and prove (31).

For each retained set, \(h=m-c\).  By the published-class sufficiency and strict-interior minimax converse in \(\text{thm:sharp-replacement-radius}\), this retained design gives a uniform guarantee over the positive-semidefinite invariant-noise class exactly when
\[
 M_{k\ell}(H)<h-c=m-2c
 \quad\text{for every }k<\ell. \tag{32}
\]
Indeed, sufficiency in (32) holds for every fixed positive-semidefinite instance; if (32) fails, choosing a positive-definite invariant covariance supplies the required class member witnessing ambiguity.  Since \(m-2c\le m-c\), equations (31)--(32) show that (32) holds for every retained set if and only if
\[
 T_{k\ell}<m-2c\quad\text{for every }k<\ell,
\]
which is equivalent to \(T<m-2c\).

Because \(c\) is an integer, when \(T<m\) the strict inequality is equivalent to
\[
 2c\le m-T-1
 \quad\Longleftrightarrow\quad
 c\le\left\lfloor\frac{m-T-1}{2}\right\rfloor. \tag{33}
\]
If \(T=m\), even \(c=0\) violates the strict inequality.  For the all-active design, \(N_{11}^{k\ell}=m\) and the other three support counts vanish.  Hence \(T=2\) when \(m\ge2\).  In particular, for \(m\ge3\), (33) gives
\[
 c_{\max}=\left\lfloor\frac{m-3}{2}\right\rfloor,
\]
as claimed.
