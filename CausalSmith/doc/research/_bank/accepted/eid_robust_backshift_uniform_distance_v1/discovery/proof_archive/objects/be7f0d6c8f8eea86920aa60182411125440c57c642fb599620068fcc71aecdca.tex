For a coordinate pair \(k<\ell\), let \(T_{k\ell}\) be the inner four-term maximum in the definition of \(T\).  Apply \(\text{lem:generic-affine-occupancy}\) with \(I=E\) and \(r=m\).  Its absolute-continuity premise is the stated joint-density premise.  Thus, on one probability-one event, the full \((k,\ell)\)-cloud has maximum indexed affine-line occupancy \(T_{k\ell}\), simultaneously for every pair.

Fix \(k<\ell\).  For a retained set \(H\subseteq E\) of size \(m-c\), write \(M_{k\ell}(H)\) for the maximum line occupancy after restriction to \(H\).  We claim
\[
 \max_{H\subseteq E:\,|H|=m-c}M_{k\ell}(H)
 =\min\{T_{k\ell},m-c\}. \tag{27}
\]
Restriction and cardinality give the upper bound.  For the reverse bound, choose a line attaining the full occupancy \(T_{k\ell}\).  If \(T_{k\ell}\ge m-c\), retain any \(m-c\) indexed points on that line.  If \(T_{k\ell}<m-c\), retain all its \(T_{k\ell}\) indices and add any \(m-c-T_{k\ell}\) other indices.  Both constructions are possible and prove (27).

For every retained set, \(h=m-c\).  By \(\text{thm:sharp-replacement-radius}\), that retained design gives a uniform guarantee over all positive-semidefinite invariant nuisances and covariance replacements exactly when
\[
 M_{k\ell}(H)<h-c=m-2c
 \quad\text{for every }k<\ell. \tag{28}
\]
Indeed, the forward implication of the theorem gives sufficiency for each member of the positive-semidefinite class.  If (28) fails, choose \(D=I_p\) and \(\Omega=I_p\); the theorem's strict-interior converse gives a positive-definite replacement assignment witnessing failure of the class-uniform guarantee.  Since \(m-2c\le m-c\), equation (27) and the interchange of the two finite universal quantifiers over \(H\) and \(k<\ell\) show that (28) holds for every retained set if and only if
\[
 T_{k\ell}<m-2c\quad\text{for every }k<\ell,
\]
which is equivalent to \(T<m-2c\).

Because \(c\) is an integer, when \(T<m\) the strict inequality is equivalent to
\[
 2c\le m-T-1
 \quad\Longleftrightarrow\quad
 c\le\left\lfloor\frac{m-T-1}{2}\right\rfloor. \tag{29}
\]
If \(T=m\), even \(c=0\) violates the strict inequality, so no nonnegative budget is certified.  For the all-active design, \(N_{11}^{k\ell}=m\) and \(N_{00}^{k\ell}=N_{10}^{k\ell}=N_{01}^{k\ell}=0\), so \(T=2\) when \(m\ge2\).  In particular, for \(m\ge3\), (29) gives
\[
 c_{\max}=\left\lfloor\frac{m-3}{2}\right\rfloor,
\]
as claimed.
