Let \(\widetilde U_i\) denote the oracle local-linear conditional-CDF estimator formed with the true responses \(L_i(X)\), true conditioning vectors \(L_{B_i}(X)\), and true query arguments.  On a first-stage event that controls \(\widehat L_\ell-L_\ell\) in \(C^1\) on the whole evaluation support, the kernel-neighborhood perturbation and threshold-crossing decomposition gives
\[
 \max_i\|\widehat U_i-\widetilde U_i\|_{\infty,K}
 =O_{\Pr}\!\left(
 \frac{b_N}{h_N}+b_N+\sqrt{\frac{b_N\log(\underline N)}{\underline N h_N^{d_\star}}}
 +\frac{\log(\underline N)}{\underline N h_N^{d_\star}}
 \right).
\]
Indeed, Lipschitz perturbation of a kernel argument is \(O(b_N/h_N)\); monotonicity with derivative margin \(c\) bounds the conditional density of \(L_i\), so response-indicator changes are confined to a band of conditional probability \(O(b_N)\); and Bernstein's inequality for the localized band supplies the last two displayed terms.  Under \(b_N=o(h_N)\) and \(\underline N h_N^{d_\star}/\log(\underline N)\to\infty\), this is
\[
 O_{\Pr}\!\left(\frac{b_N}{h_N}
 +\sqrt{\frac{\log(\underline N)}{\underline N h_N^{d_\star}}}\right).
\]
Thus an oracle bound of order \(h_N^2+\sqrt{\log(\underline N)/(\underline N h_N^{d_\star})}\) would imply the advertised \(r_N\) rate after the proposed support correction.  If a uniform first-stage linearization has remainder \(\varrho_N\) in the same \(C^1\) norm, its generated-conditioning contribution is \(O_{\Pr}(\varrho_N/h_N)\); consequently the transparent sufficient negligibility condition relative to the oracle scale \(s_N=h_N^2+\sqrt{\log(\underline N)/(\underline N h_N^{d_\star})}\) is \(\varrho_N=o(h_Ns_N)\).  A claim that this condition is weakest requires a precisely stated influence representation and second-stage weight convention, which the frozen handle does not yet provide.
