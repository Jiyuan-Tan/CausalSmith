By \(\mathrm{thm:matched-minimax-frontier}\), uniform consistency along a sequence is equivalent to
\[
 \frac{d}{n\log(ed)}\longrightarrow0.                                \tag{34}
\]
We show that this is equivalent to \(d=o(n\log(en))\).  Put \(t=d/n\) and \(L_n=\log(en)\).  Suppose first that \(t/L_n\to0\).  On a subsequence where \(d\geq n\), one has \(\log(ed)=L_n+\log t\geq L_n\), so \(d/[n\log(ed)]\leq t/L_n\to0\).  On a subsequence where \(d<n\), split again.  If \(d\geq\sqrt n\), then \(\log(ed)\geq L_n/2\) for all large \(n\), and \(d/[n\log(ed)]\leq2/L_n\to0\).  If \(d<\sqrt n\), then \(d/[n\log(ed)]\leq n^{-1/2}\).  Thus (34) holds.

Conversely assume (34).  If \(t<1\), then \(t/L_n\leq1/L_n\to0\).  If \(t\geq1\), then \(\log(ed)=L_n+\log t\), and (34) says \(\eta_n:=t/(L_n+\log t)\to0\).  Since \(\log t\leq t\) for \(t\geq1\), eventually \(\eta_n\log t\leq t/2\).  The identity \(t=\eta_nL_n+\eta_n\log t\) then gives \(t/L_n\leq2\eta_n\to0\).  This proves the first equivalence.

Multiplying the matched frontier by \(n\) shows that parametric mean-squared risk is equivalent, up to \(\epsilon\)-only constants, to boundedness above and away from zero of
\[
 n\min\left\{1,\frac d{n\log(ed)}\right\}.
\]
If \(d=O(1)\) and \(d\geq2\), this quantity is bounded above and away from zero for large \(n\), so \(\mathfrak R_{n,d,\epsilon}=\Theta_\epsilon(n^{-1})\) along a bounded-alphabet sequence.  If \(d\to\infty\) along any subsequence, then either the minimum is one, in which case its product with \(n\) diverges, or it is \(d/[n\log(ed)]\), in which case the product is \(d/\log(ed)\to\infty\).  Thus no unbounded sequence of alphabets has parametric MSE, proving the second equivalence.
