By \(\mathrm{thm:matched-minimax-frontier}\), uniform consistency is equivalent to
\[
 \frac d{n\log(ed)}\longrightarrow0.                                \tag{36}
\]
We prove that (36) is equivalent to \(d=o(n\log(en))\).  Put \(t=d/n\) and \(L_n=\log(en)\).  If \(t/L_n\to0\), then on a subsequence with \(d\geq n\), \(\log(ed)\geq L_n\), so \(d/[n\log(ed)]\leq t/L_n\to0\).  On a subsequence with \(d<n\), if \(d\geq\sqrt n\), then \(\log(ed)\geq L_n/2\) for all large \(n\), giving \(d/[n\log(ed)]\leq2/L_n\to0\); if \(d<\sqrt n\), the ratio is at most \(n^{-1/2}\).  Thus (36) follows.

Conversely assume (36).  If \(t<1\), then \(t/L_n\leq1/L_n\to0\).  If \(t\geq1\), define \(\eta_n=t/(L_n+\log t)\); equation (36) says \(\eta_n\to0\).  Since \(\log t\leq t\), eventually \(\eta_n\log t\leq t/2\).  The identity \(t=\eta_nL_n+\eta_n\log t\) then gives \(t/L_n\leq2\eta_n\to0\).  This proves the consistency equivalence.

Multiplying the matched frontier by \(n\) shows that parametric mean-squared risk is equivalent, up to \(\epsilon\)-only constants, to boundedness above and away from zero of
\[
 n\min\left\{1,\frac d{n\log(ed)}\right\}.                          \tag{37}
\]
If \(d=O(1)\) and \(d\geq2\), then \(d/\log(ed)\) is bounded above and away from zero, so (37) is bounded above and away from zero for large \(n\).  If \(d\to\infty\) along a subsequence, then either the minimum in (37) is one, in which case (37) equals \(n\to\infty\), or it is \(d/[n\log(ed)]\), in which case (37) equals \(d/\log(ed)\to\infty\).  Hence parametric risk holds exactly for bounded alphabets.  The causal version follows from the experiment and target equivalence proved by \(\mathrm{prop:identification-and-extension}\) and \(\mathrm{prop:causal-optimal-value-corollary}\).
