For \(\mathbb P\in\mathcal D_{d,\epsilon}^{\mathrm{obs}}\) with table \(\mathbf q=(q_x)_{x=1}^d\), define the observed-law optimal-regression functional by \(\Psi(\mathbb P)=\Psi(\mathbf q):=\sum_{x=1}^d p_x\max_{a\in\{0,1\}}\mu_{ax}\).  This value is independent of the permitted choice of \(\mu_{ax}\) on cells with \(p_x=0\).
