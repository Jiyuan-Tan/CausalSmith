Put \(r_{n,d}=\min\{1,d/[n\log(ed)]\}\) and \(a=d/[n\log(ed)]\).  Since \(\log(ed)\geq1\), a two-case check according as \(d\geq n\) or \(d<n\) gives \(r_{n,d}\leq d/n\).  Also
\[
 \frac{\sqrt d/n}{d/[n\log(ed)]}=\frac{\log(ed)}{\sqrt d}
\]
is bounded uniformly for integers \(d\geq2\).  If \(a>1\), the parent minimum is at most one, hence at most \(r_{n,d}=1\).  Suppose \(a\leq1\).  If \(n\geq d\), then \(\log(en)\geq\log(ed)\), so
\(d/[n\log(en)]\leq a\).  If \(n<d\), put \(t=d/n>1\).  The inequality \(a\leq1\) says \(t\leq\log(ed)=\log(en)+\log t\).  For \(t\geq2\), \(\log t\leq t/2\), and hence \(t\leq2\log(en)\); the case \(1<t<2\) has the same conclusion after changing the constant.  Thus \(\log(ed)=\log(en)+\log t\leq C\log(en)\), and \(d/[n\log(en)]\leq Ca\).  Hence, for a universal \(C\),
\[
 \min\left\{1,\frac{\sqrt d}{n}+\frac d{n\log(en)}\right\}
 \leq C r_{n,d}.                                                       \tag{33}
\]
Applying \(\mathrm{thm:matched-minimax-frontier}\) to these deterministic inequalities proves both comparisons with the banked bracket on the identical class.

The equality \(\widehat V_{n,d}^{\mathrm{JF}}=\widehat V_{n,d}^{\mathrm{ER}}\) for \(2\leq d<D_0\) is the first branch of \(\mathrm{def:jackson-factorial-estimator}\).  Finally, along any sequence with \(2\leq d\leq D<\infty\), the quantity \(d/\log(ed)\) is bounded above and bounded away from zero.  The matched frontier therefore gives \(c_{\epsilon,D}/n\leq\mathfrak R_{n,d,\epsilon}\leq C_{\epsilon,D}/n\) for all sufficiently large \(n\), which is the asserted bounded-alphabet parametric conclusion.
