Along arbitrary sequences \(n\to\infty\) with \(d=d_n\geq2\), uniform consistency for estimating \(\Psi(\mathbb P)\) over \(\mathcal D_{d,epsilon}^{\mathrm{obs}}\) is possible if and only if \(d=o(n\log(en))\).  Moreover, \(\mathfrak R_{n,d,epsilon}=\Theta_\epsilon(n^{-1})\) if and only if \(d=O(1)\).  By \(\mathrm{prop:causal-optimal-value-corollary}\) and observed-margin surjectivity, the same two equivalences hold for estimating \(V^\star(P)\) over \(\mathcal P_{d,epsilon}\).
