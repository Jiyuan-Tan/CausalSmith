Because \(a\) ranges over a finite discrete set, \(e_a(x)\) is measurable, and \(e_a(x)\ge\kappa>0\), the map \((a,x,t)\mapsto(t-1/e_a(x))_+\) is Borel measurable.  Each fiber has the stated convexity and continuity properties, and, with \(c_{a,x}=1/e_a(x)\),
\[
 B_{f_{a,x}}(e_a(x))
 =e_a(x)(c_{a,x}-c_{a,x})_++(1-e_a(x))(0-c_{a,x})_+=0. \tag{1}
\]

Fix an arm and a covariate value in the common conull set, and abbreviate \(P_a(x,\cdot),Q_a(x,\cdot)\) by \(P_x,Q_x\).  If \(P_x\ll Q_x\) and \(r_x=dP_x/dQ_x\), then
\[
 D_{f_{a,x}}(P_x\|Q_x)=\int(r_x-c_{a,x})_+\,dQ_x. \tag{2}
\]
The integrand is nonnegative.  Its integral is zero if and only if it is zero \(Q_x\)-almost surely: the reverse implication is immediate, and the forward implication follows because a positive-measure set \(\{(r_x-c_{a,x})_+\ge1/m\}\) for some integer \(m\) would make the integral positive.  Combining (1)--(2), the fiberwise divergence constraint is therefore equivalent to
\[
 r_x\le c_{a,x}=1/e_a(x),\qquad Q_x\text{-almost surely}. \tag{3}
\]
By conditional one-sided completeness, (3) is equivalent to the mixture identity and to global SCM realizability.

It remains to verify that this fiberwise equivalence can be imposed on one measurable conull set without jointly selecting the densities \(r_x\).  Choose a countable generating algebra \(\mathcal C\) for \(\mathcal Y\), and define
\[
 S_{\mathcal C}=\bigcap_{a=0}^1\bigcap_{C\in\mathcal C}
 \{x:Q_a(x,C)\ge e_a(x)P_a(x,C)\}. \tag{4}
\]
Each set in (4) is measurable, hence so is \(S_{\mathcal C}\).  For fixed \(x\), approximation in the finite measure \(Q_a(x,\cdot)+e_a(x)P_a(x,\cdot)\) extends the inequalities from \(\mathcal C\) to every Borel set, exactly as in the conditional completeness proof.  Thus \(S_{\mathcal C}\) is precisely a measurable carrier for the measure cap, which is fiberwise equivalent to (3) and hence to (2) being at most zero.  No density is chosen as a function of \(x\), and the divergence is never integrated over \(x\).  This proves the first displayed class equality.  Intersecting all three one-sided classes with the reverse-support class and applying the conditional mutual-support proposition and conditional mutual completeness proves the second equality.
