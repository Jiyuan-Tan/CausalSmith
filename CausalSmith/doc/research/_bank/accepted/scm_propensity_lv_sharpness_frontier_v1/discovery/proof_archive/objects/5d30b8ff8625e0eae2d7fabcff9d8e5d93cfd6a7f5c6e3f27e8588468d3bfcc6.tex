Because the arm set is finite, \(e_a(x)\) is measurable jointly in \((a,x)\).  Conditional overlap gives \(e_a(x)\ge\kappa>0\), so reciprocal, subtraction, and positive part show that
\[
 (a,x,t)\longmapsto f_{a,x}(t)=(t-1/e_a(x))_+
\]
is Borel measurable.  Each fiber is finite, continuous, and convex.  Since \(e_a(x)\le1-\kappa<1\), one has \(1<1/e_a(x)\), and hence \(f_{a,x}(1)=0\).  Writing \(c_{a,x}=1/e_a(x)\),
\[
 B_{f_{a,x}}(e_a(x))
 =e_a(x)(c_{a,x}-c_{a,x})_+
  +(1-e_a(x))(0-c_{a,x})_+=0. \tag{66}
\]

Fix an arm and a covariate value in the common conull set and abbreviate the two fiber laws by \(P_x,Q_x\).  If \(P_x\ll Q_x\) and \(r_x=dP_x/dQ_x\), then
\[
 D_{f_{a,x}}(P_x\|Q_x)
 =\int(r_x-c_{a,x})_+\,dQ_x. \tag{67}
\]
The integrand is nonnegative.  Its integral is zero if and only if it vanishes \(Q_x\)-almost surely: if it were positive on a set of positive measure, then for some integer \(m\) the set on which it is at least \(1/m\) would have positive measure and the integral would be positive.  Combining (66)--(67), the fiberwise divergence constraint is therefore equivalent to
\[
 r_x\le c_{a,x}=1/e_a(x),\qquad Q_x\text{-almost surely}. \tag{68}
\]
Equivalently, (68) says that the measure \(Q_a(x,\cdot)-e_a(x)P_a(x,\cdot)\) is nonnegative.

The conditional one-sided completeness theorem proves, on one common measurable conull set and simultaneously for both arms, that this measure cap is equivalent to the residual-kernel mixture identity and to global SCM realizability.  Therefore
\[
 \mathfrak B^{\mathrm{ad},\to}_{\mu_X,\boldsymbol e}(\boldsymbol P)
 =\mathfrak L^{\to}_{\mu_X,\boldsymbol e}(\boldsymbol P)
 =\mathfrak M^{\to}_{\mu_X,\boldsymbol e}(\boldsymbol P). \tag{69}
\]
No jointly measurable choice of Radon--Nikodym densities is needed: the equivalent measure inequalities can be synchronized using the countable generating algebra in the proof of conditional completeness, and the resulting carrier is measurable.

Finally intersect all three one-sided classes in (69) with \(\mathcal S_{\mu_X}(\boldsymbol P)\).  The conditional support-intersection proposition converts the divergence and SCM intersections to their mutual-support versions, and conditional bow-mixture completeness converts the mixture intersection.  Hence
\[
 \mathfrak B^{\mathrm{ad}}_{\mu_X,\boldsymbol e}(\boldsymbol P)
 =\mathfrak L_{\mu_X,\boldsymbol e}(\boldsymbol P)
 =\mathfrak M_{\mu_X,\boldsymbol e}(\boldsymbol P). \tag{70}
\]
All intersections involve only finitely many common carriers, so (69)--(70) hold on one measurable \(\mu_X\)-conull set and make no assertion about a prescribed version on its complement.
