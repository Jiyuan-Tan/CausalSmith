Fix \(0<e<1\), set \(c=1/e\), and let \(f\) be admissible.  If \(Q=eP+(1-e)R\) for an arbitrary probability law \(R\), then \(Q\ge eP\).  Therefore \(P\ll Q\), \(r=dP/dQ\le c\), and \(\int r\,dQ=1\).  The convex chord bound on \([0,c]\) gives
\[
 \begin{aligned}
 D_f(P\|Q)
 &\le\int\left\{\left(1-\frac rc\right)f(0)+\frac rc f(c)\right\}dQ\\
 &=(1-e)f(0)+ef(c)=B_f(e).
 \end{aligned} \tag{46}
\]
Hence \(\mathfrak L^{\to}_e(P)\subseteq\mathfrak B^{\to}_{f,e}(P)\), and the lawful-correction definition yields
\[
 \mathfrak B^{\mathrm{law},\to}_{f,e}(P)
 =\mathfrak B^{\to}_{f,e}(P)\cap\mathfrak L^{\to}_e(P)
 =\mathfrak L^{\to}_e(P)=\mathfrak M^{\to}_e(P), \tag{47}
\]
where the last equality is one-sided bow-mixture completeness.

On a finite alphabet, including cells with \(p_j=0\), a probability vector \(q=(q_j)_j\) is in \(\mathfrak L^{\to}_e(P)\) exactly when
\[
 q_j\ge ep_j\quad\text{for every }j. \tag{48}
\]
The forward implication is immediate from \(q_j=ep_j+(1-e)r_j\).  Conversely, (48) makes \(r_j=(q_j-ep_j)/(1-e)\) nonnegative and summing gives \(\sum_jr_j=1\), so \(Q=eP+(1-e)R\).  It also implies \(P\ll Q\).  Inequality (46) makes the divergence constraint redundant after (48) is imposed.  Thus the capped program has exactly the unrestricted lawful class.  Its feasible set is a nonempty compact subset of the probability simplex.  Restricting to it weakly lowers every linear maximum and weakly raises every linear minimum.  If an attained relaxed optimizer is unique and violates (48), equality of values would make an optimizer over the compact capped set a distinct relaxed optimizer, which is impossible.  The tightening is therefore strict.

For \(f\notin\mathfrak H_c\), \(\mathrm{thm:support\text{-}regime\text{-}open\text{-}illegal\text{-}dichotomy}\) gives a nonempty open set of full-support binary pairs satisfying \(q<ep\) while remaining feasible for the one-sided divergence ball.  Shrinking to a rectangle gives a nonempty open interval of observational probabilities \(p\), for each of which some feasible \(q<ep\) remains.  For the success indicator, (48) makes the lawful lower value \(ep\), while the relaxed lower value is at most \(q<ep\).  This is the claimed strict one-sided legality gap.
