Fix \(n\ge1\) and \(0<\alpha<1\).  Let
\[
 E_e=\{|\widehat e_n-e|\le\delta_e\}.
\]
Apply the already-established Hoeffding bounded-mean lemma \(\mathrm{lem:hoeffding\text{-}bounded\text{-}mean}\) to the independent indicators \(\mathbf 1\{A_i=a\}\in[0,1]\), whose common mean is \(e\).  Since \(\delta_e^2=\log(4/\alpha)/(2n)\),
\[
 \Pr(E_e^c)\le2\exp(-2n\delta_e^2)=\frac\alpha2. \tag{21}
\]
Because \(e,\widehat e_n\in[0,1]\), the event \(E_e\) implies \(e\in I_e\), even when the unclipped interval crosses zero or one.

On \(\{n_a>0\}\), define
\[
 E_F=\left\{\sup_{y\in\mathbb R}|\widehat F_{P,n}(y)-F_P(y)|\le\delta_F\right\}.
\]
Under independent observational sampling, conditional on the treatment indicators and on \(n_a=m>0\), the \(m\) outcomes with \(A_i=a\) are independent and have common distribution function \(F_P\).  The already-established Dvoretzky--Kiefer--Wolfowitz--Massart lemma \(\mathrm{lem:dkw\text{-}massart\text{-}cdf\text{-}band}\), applied conditionally, gives
\[
 \Pr(E_F^c\mid A_1,\ldots,A_n)
 \le2\exp(-2m\delta_F^2)=\frac\alpha2
 \quad\text{on }\{n_a=m>0\}. \tag{22}
\]
Summing over treatment-indicator configurations yields
\[
 \Pr(n_a>0,E_F^c)\le\frac\alpha2. \tag{23}
\]
On \(E_F\), clipping cannot remove any \(F_P(y)\in[0,1]\), so \(F_P(y)\in I_F(y)\) simultaneously for all \(y\).  The union bound applied to (21) and (23) gives
\[
 \Pr\bigl(E_e\cap(\{n_a=0\}\cup E_F)\bigr)\ge1-\alpha. \tag{24}
\]

On the event in (24), if \(n_a>0\), then simultaneously for every \(y\),
\[
 e\in I_e,\qquad F_P(y)\in I_F(y).
\]
Thus the generating set in \(\mathrm{def:honest\text{-}band}\) contains \((L_e(F_P(y)),U_e(F_P(y)))\), and so does its coordinatewise rectangular hull.  If \(n_a=0\), the same containment holds because the band is defined to be \([0,1]^2\).  Therefore
\[
 \Pr\left\{(L_e(F_P(y)),U_e(F_P(y)))\in
 \widehat{\mathcal C}_{n,\alpha}(y)\text{ for every }y\in\mathbb R\right\}
 \ge1-\alpha.
\]
By \(\mathrm{thm:cdf\text{-}endpoints\text{-}sharp}\), this pair is the exact causal CDF endpoint pair.  The conditional DKW bound is distribution-free and allows atoms.  Finally, the argument uses membership of the true point in the generating rectangle, not continuity of the piecewise endpoint map, so it remains valid at \(F_P(y)=0\), at \(F_P(y)=1\), and at all support-contact faces.
