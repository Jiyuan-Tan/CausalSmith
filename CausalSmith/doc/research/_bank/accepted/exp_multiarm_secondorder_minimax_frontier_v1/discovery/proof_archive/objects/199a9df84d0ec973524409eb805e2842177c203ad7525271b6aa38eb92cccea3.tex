\textbf{Proof.}
First take \(K=2\) and \(c=(1,-1)\).  Directly from the orbit target,
\[
 \tau_c(m)
 =\frac{1}{n}\sum_{t\in\{0,1\}^2}m_t(t_1-t_2)
 =\frac{m_{(1,0)}-m_{(0,1)}}{n}
 =\frac{p_+-p_-}{n},
\]
and \(r_0=m_{(0,0)}+m_{(1,1)}\), so \(p_++p_-+r_0=n\).  This aggregation is valid for the target only.  Indeed, in the orbit likelihood
\[
 P_m(x\mid r)
 =\frac{\prod_{a\in\mathcal A_2}r_a!}{n!}
 \sum_{h\in\mathcal H(m,r,x)}
 \prod_{t\in\mathcal T_2}\frac{m_t!}{\prod_{a\in\mathcal A_2}h_{t,a}!},
\]
the factorials \(m_t!\) and the row constraints
\(\sum_a h_{t,a}=m_t\) are still indexed separately by
\(t=(0,0),(0,1),(1,0),(1,1)\).  Hence neither the likelihood definition nor the exact-game theorem asserts that \(P_m(x\mid r)\) is determined by \((p_+,p_-,r_0)\).

The exact response-type game theorem gives
\[
 \rho_n((1,-1))=G_n((1,-1)).
\]
The embedded two-arm converse theorem applies with \(|S_c|=2\).  Its equality clause identifies this value with \(C_0(c)\rho_{n,2}\); here
\[
 L_c=|1|+|-1|=2,
 \qquad
 C_0(c)=\frac{L_c^2}{4}=1,
\]
so the value is exactly the unrestricted binary risk \(\rho_{n,2}\).  The published two-arm result incorporated in that established theorem identifies this minimax value with the scalar experiment
\[
 X_2=p_++\operatorname{Binomial}(r_0,1/2)
\]
for estimating \((p_+-p_-)/n\), and yields
\[
 \rho_n((1,-1))
 =\frac{1}{n}-C_A n^{-4/3}+o(n^{-4/3}).
\]
Therefore, from the definition \(d_n(c)=C_0(c)/n-\rho_n(c)\),
\[
 d_n((1,-1))=C_A n^{-4/3}+o(n^{-4/3}).
\]
This is a composition at the level of minimax values; it does not collapse the four-count orbit likelihood.

Now fix \(K\geq3\) and a nonzero zero-sum contrast \(c\).  The exact response-type game theorem applies without any restriction on dependence among assignments and without an unbiasedness restriction on the estimator.  It gives
\[
 \rho_n(c)=G_n(c),
\]
where nature ranges over \(m\in\mathcal M_{n,K}\), the count simplex generated by all \(|\mathcal T_K|=2^K\) binary response types, and where \(G_n(c)\) is the explicit orbit game using \(P_m(x\mid r)\).  The cited published theorem concerns only the two-arm scalar experiment, whereas this equality covers every fixed \(K\geq3\) and every such contrast.  Thus the exact response-type theorem is a strict extension in treatment-domain scope.  This conclusion neither rules out some other scalar representation of a multi-arm value nor asserts that one exists.

No positivity, overlap, rank, or inverse condition is used: the design class is unrestricted, allocation cells with \(r_a=0\) are permitted by the exact orbit game, and the all-zero and all-one response types remain in \(\mathcal T_K\).  This also supplies the relevant boundary check. \(\square\)
