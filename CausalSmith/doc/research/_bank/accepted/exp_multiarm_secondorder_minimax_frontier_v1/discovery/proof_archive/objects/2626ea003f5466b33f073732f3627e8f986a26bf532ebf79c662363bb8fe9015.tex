\textbf{Proved partial result (the multi-arm rate is exactly of order \(n^{-4/3}\)).}
Fix \(K\), a nonzero zero-sum contrast \(c\), and a fixed binary response schedule.  Put
\[
 h_c=\frac{L_c}{2}=\sqrt{C_0(c)}.
\]
Because \(c\neq0\), one has \(h_c>0\).  Under the independent contrast-weighted design, \(q_a^\star>0\) for every \(a\in S_c\).  Before projection, write the centered Horvitz--Thompson summand as
\[
 W_i=\sum_{a\in S_c}
 \frac{c_a\mathbf 1\{A_i=a\}}{q_a^\star}
 \left(Y_i^{\mathrm{obs}}-\frac12\right).
\]
On the event \(A_i=a\), the identities \(c_a/q_a^\star=L_c\operatorname{sign}(c_a)\) and \(Y_i^{\mathrm{obs}}-1/2\in\{-1/2,1/2\}\) imply \(W_i\in\{-h_c,h_c\}\).  Define
\[
 V_i=\frac{W_i}{h_c},\qquad
 \eta_i=\frac{1}{h_c}\sum_{a\in\mathcal A_K}c_at_{i,a},\qquad
 X_n=\frac1n\sum_{i=1}^nV_i,qquad
 \theta_n=\frac1n\sum_{i=1}^n\eta_i=\frac{\tau_c(z)}{h_c}.
\]
The assignments are independent, and the first-order Horvitz--Thompson identities give
\[
 V_i\in\{-1,1\},\qquad
 \mathbb E(V_i\mid z)=\eta_i,\qquad
 \mathbb E(X_n\mid z)=\theta_n.
\]
Every \(\eta_i\) belongs to the finite set
\[
 \left\{h_c^{-1}\sum_{a\in\mathcal A_K}c_at_a:t\in\mathcal T_K\right\}\subset[-1,1].
\]
This set has a nonzero element, since a response type supported on any one arm in \(S_c\) has score \(c_a/h_c\neq0\).  Hence
\[
 \lambda_c=\min\left\{\left|h_c^{-1}\sum_{a\in\mathcal A_K}c_at_a\right|:
 t\in\mathcal T_K,\ \sum_{a\in\mathcal A_K}c_at_a\neq0\right\}
\]
is well defined and satisfies \(0<\lambda_c\leq1\).  With \(Q_n=\sum_i\eta_i^2\), finiteness of the score set and the triangle inequality yield
\[
 Q_n\geq\lambda_c\sum_{i=1}^n|\eta_i|
 \geq\lambda_c\left|\sum_{i=1}^n\eta_i\right|
 =\lambda_c n|\theta_n|.
\]
Moreover,
\[
 \operatorname{Var}(X_n\mid z)
 =\frac1{n^2}\sum_{i=1}^n(1-\eta_i^2)
 =\frac1n-\frac{Q_n}{n^2}.
\]

We now construct an explicit improvement over the unshrunk rule.  Let
\[
 b_n=n^{-1/3},\qquad
 \varepsilon_n=\frac{\sqrt{\lambda_c}}4n^{-1/3},\qquad
 g_n(x)=\max\{-b_n,\min(x,b_n)\},
\]
and report
\[
 \widehat\tau_n^{\mathrm{sh}}
 =h_c\{X_n-\varepsilon_ng_n(X_n)\}.
\]
Since \(0<\varepsilon_n\leq1/4\), the map \(x\mapsto x-\varepsilon_ng_n(x)\) moves every \(x\in[-1,1]\) toward zero without crossing zero.  Thus \(\widehat\tau_n^{\mathrm{sh}}\in[-h_c,h_c]=[-L_c/2,L_c/2]\), so this is an admissible estimator based on the realized assignment and observed outcomes.

Set
\[
 C_n=\operatorname{Cov}\{X_n,g_n(X_n)\mid z\}.
\]
The function \(g_n\) is nondecreasing.  If \(X_n'\) is an independent copy of \(X_n\), then
\[
 2C_n=\mathbb E\left[(X_n-X_n')\{g_n(X_n)-g_n(X_n')\}\mid z\right]\geq0.
\]
If \(|\theta_n|\leq b_n/2\), then \(g_n(X_n)=X_n\) on \(|X_n|\leq b_n\).  Hoeffding's inequality for the independent variables \(V_i\in[-1,1]\) gives
\[
 \Pr\{|X_n-\theta_n|\geq b_n/2\mid z\}
 \leq2\exp\left(-\frac{nb_n^2}{8}\right).
\]
Since \(|X_n-\theta_n|\leq2\) and \(|g_n(X_n)-X_n|\leq1\), it follows that
\[
 C_n\geq\operatorname{Var}(X_n\mid z)-\Delta_n,
 \qquad
 \Delta_n=4\exp\left(-\frac{n^{1/3}}8\right).
\]

Define the normalized risk improvement
\[
 I_n(z)=\frac1n-
 \mathbb E\left[\{X_n-\varepsilon_ng_n(X_n)-\theta_n\}^2\mid z\right].
\]
Expanding the square and using \(\mathbb E g_n(X_n)^2\leq b_n^2\) gives the exact lower bound
\[
 I_n(z)\geq\frac{Q_n}{n^2}+2\varepsilon_nC_n-\varepsilon_n^2b_n^2.
\]
When \(|\theta_n|\leq b_n/2\), substitution of the local covariance bound yields
\[
 \begin{aligned}
 I_n(z)
 &\geq\frac{2\varepsilon_n}{n}
 +(1-2\varepsilon_n)\frac{Q_n}{n^2}
 -2\varepsilon_n\Delta_n-\varepsilon_n^2b_n^2\\
 &\geq
 \left(\frac{\sqrt{\lambda_c}}2-\frac{\lambda_c}{16}\right)n^{-4/3}
 -\frac{\sqrt{\lambda_c}}2n^{-1/3}\Delta_n.
 \end{aligned}
\]
When \(|\theta_n|>b_n/2\), use \(C_n\geq0\) and \(Q_n\geq\lambda_cn|\theta_n|\) to obtain
\[
 I_n(z)\geq
 \left(\frac{\lambda_c}{2}-\frac{\lambda_c}{16}\right)n^{-4/3}
 =\frac{7\lambda_c}{16}n^{-4/3}.
\]
Consequently, with
\[
 \kappa_c=\frac12\min\left\{
 \frac{\sqrt{\lambda_c}}2-\frac{\lambda_c}{16},
 \frac{7\lambda_c}{16}
 \right\}>0,
\]
the exponential remainder is absorbed for all sufficiently large \(n\), uniformly over every fixed schedule, and
\[
 \max_{z\in\mathcal T_K^n}
 R_n(\mathcal D^\star,\widehat\tau_n^{\mathrm{sh}};z)
 \leq C_0(c)\left\{\frac1n-\kappa_cn^{-4/3}\right\}.
\]
Since minimax risk is no larger than the risk of this explicit procedure,
\[
 d_n(c)\geq C_0(c)\kappa_cn^{-4/3}
\]
for all sufficiently large \(n\).  Combining this new lower bound with the established embedded-two-arm ceiling proves
\[
 0<C_0(c)\kappa_c
 \leq\liminf_{n\to\infty}n^{4/3}d_n(c)
 \leq\limsup_{n\to\infty}n^{4/3}d_n(c)
 \leq C_0(c)C_A.
\]
Thus \(d_n(c)=\Theta(n^{-4/3})\) for every fixed nonzero contrast, including every contrast with \(|S_c|\geq3\).  If a regularly varying sequence \(a_n\) satisfies \(a_nd_n(c)\to C\in(0,\infty)\), the two-sided display forces \(a_n/n^{4/3}\) to be bounded above and bounded away from zero.  The index of regular variation of \(a_n\) must therefore be exactly \(4/3\).  What remains unproved is convergence of \(n^{4/3}d_n(c)\), its multi-arm constant, and any limiting face--corner operator; the finite rational certificates evaluate the relevant sequence but do not supply the missing inter-\(n\) argument.
