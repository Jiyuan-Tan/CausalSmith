For every fixed \(n\), every \(K\ge 2\), and every nonzero zero-sum contrast \(c\), write \(\rho_{n,2}:=\rho_n((1,-1))\) for the unrestricted minimax risk in the two-arm problem. Then
\[
\rho_n(c)\ge C_0(c)\rho_{n,2}.
\]
If \(|S_c|=2\), equality holds. Moreover, for fixed \(c\),
\[
0\le d_n(c)\le C_0(c)\{n^{-1}-\rho_{n,2}\}
=C_0(c)C_A n^{-4/3}+o(n^{-4/3}).
\]
When \(|S_c|=2\), the first inequality comparing \(d_n(c)\) with \(C_0(c)\{n^{-1}-\rho_{n,2}\}\) is an equality, so the displayed Airy expansion is attained after multiplication by \(C_0(c)\).
