For every integer \(n\geq1\), every \(K\geq2\), and every nonzero zero-sum contrast \(c\), write \(\rho_{n,2}=\rho_n((1,-1))\) for the unrestricted two-arm minimax risk with the same population size. Then
\[
 \rho_n(c)\geq C_0(c)\rho_{n,2}.
\]
If \(|S_c|=2\), this inequality is an equality. Moreover,
\[
 0\leq d_n(c)\leq C_0(c)\{n^{-1}-\rho_{n,2}\}
 =C_0(c)C_A n^{-4/3}+o(n^{-4/3}).
\]
When \(|S_c|=2\), the upper bound in the last display is also an equality, so \(d_n(c)=C_0(c)\{n^{-1}-\rho_{n,2}\}\). The finite-sample lower bound permits arbitrary dependent assignment designs and arbitrary possibly biased estimators.
