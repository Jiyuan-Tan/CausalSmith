Let \(\mathcal I=\mathcal A_V\) be the finite observed-cell set and put \(K=|\mathcal I|\).  Every prescribed alphabet is finite and nonempty, so \(1\leq K<\infty\).  Also put \(\delta=\alpha/K\); the declared range \(0<\alpha<1\) gives \(0<\delta<1\).  For \(v\in\mathcal I\), define
\[
 N_v=\sum_{j=1}^n {\bf 1}\{O_j=v\}.
\]
By \(\mathrm{ass:iid\text{-}multinomial\text{-}sampling}\), marginally \(N_v\sim\operatorname{Bin}(n,p(v))\).  The counts need not be mutually independent in what follows.

We first verify the finite-sample property of the intervals used in \(\mathrm{def:branch\text{-}confidence\text{-}map}\).  The two-sided Clopper--Pearson interval of individual noncoverage \(\delta\) is the inversion of the two exact one-sided binomial tests with tail levels \(\delta/2\).  Thus, if \(B_r\sim\operatorname{Bin}(n,r)\), its acceptance set after observing \(x\in\{0,\ldots,n\}\) is
\[
 I_\delta(x)
 =\left\{r\in[0,1]:
       \Pr(B_r\geq x)\geq\delta/2
       \ \text{and}\ 
       \Pr(B_r\leq x)\geq\delta/2
   \right\}.
\]
This is an interval because the first displayed tail is nondecreasing in \(r\), whereas the second is nonincreasing in \(r\).  We give the coverage argument rather than invoke asymptotics.  Fix \(r\in[0,1]\), let \(B\sim\operatorname{Bin}(n,r)\), and set \(g(k)=\Pr(B\geq k)\).  Since \(g\) is nonincreasing in \(k\), the set
\[
 \{k:g(k)<\delta/2\}
\]
is either empty or is \(\{k_0,k_0+1,\ldots,n\}\) for its least element \(k_0\).  In the latter case,
\[
 \Pr\{g(B)<\delta/2\}=\Pr(B\geq k_0)=g(k_0)<\delta/2;
\]
in the former case the probability is zero.  Applying the same argument to the nondecreasing function \(h(k)=\Pr(B\leq k)\), the set \(\{k:h(k)<\delta/2\}\) is either empty or an initial set \(\{0,\ldots,k_1\}\); in the latter case its probability is \(\Pr(B\leq k_1)=h(k_1)<\delta/2\).  Thus
\[
 \Pr\{h(B)<\delta/2\}<\delta/2.
\]
Consequently, by the union bound,
\[
 \Pr_r\{r\notin I_\delta(B)\}
 \leq
 \Pr\{g(B)<\delta/2\}+\Pr\{h(B)<\delta/2\}
 \leq\delta.
\]
The weak final inequality also covers the empty-set cases.  Substituting \(r=p(v)\) and \(B=N_v\) therefore yields
\[
 \Pr_p\{p(v)\notin I_\delta(N_v)\}\leq\delta
 \qquad(v\in\mathcal I).
\]

Let
\[
 \mathcal E_n=\bigcap_{v\in\mathcal I}
 \{p(v)\in I_\delta(N_v)\}.
\]
No independence among the \(N_v\)'s is needed for the Bonferroni bound
\[
 \Pr_p(\mathcal E_n^c)
 \leq\sum_{v\in\mathcal I}
       \Pr_p\{p(v)\notin I_\delta(N_v)\}
 \leq K\delta=\alpha.
\]
Hence \(\Pr_p(\mathcal E_n)\geq1-\alpha\).

Write \(\mathcal R_n\) for the simultaneous cell region after the two intersections prescribed by \(\mathrm{def:branch\text{-}confidence\text{-}map}\):
\[
 \mathcal R_n=
 \left(\prod_{v\in\mathcal I}I_\delta(N_v)\right)
 \cap\Delta(\mathcal I)
 \cap\{p_{M'}:M'\in\mathfrak M(G,\mathcal A,V,W,T)\}.
\]
If \(\mathfrak F(p)=\varnothing\), then the asserted target image is empty and the desired inclusion is automatic.  Otherwise, take any \(M_0\in\mathfrak F(p)\).  By \(\mathrm{def:observed\text{-}fiber}\), \(p_{M_0}=p\), so \(p\) lies both in the simplex and in the feasible observed-law image.  On \(\mathcal E_n\), it also lies in every cell interval.  Therefore
\[
 p\in\mathcal R_n \qquad\text{on }\mathcal E_n.
\]

For clarity, the support branch of a model \(M'=(G,\mathcal A,\theta')\) is the row-support family
\[
 S(M')=\left(\{a\in\mathcal A_i:\theta'_i(a\mid u)>0\}\right)_{i\in D,\ u\in\mathcal A_{\operatorname{pa}_G(i)}}
\]
of \(\mathrm{def:support\text{-}stratum}\).  Each row is a probability vector, so every displayed support is nonempty; by qualitative functionality, its support is a singleton when \(i\in W\).  A branch \(S\) is compatible with \(\mathcal R_n\) precisely when there is a model \(M'\in\mathfrak M(G,\mathcal A,V,W,T)\) such that \(p_{M'}\in\mathcal R_n\) and \(S(M')=S\).  Now fix an arbitrary \(M\in\mathfrak F(p)\).  By \(\mathrm{def:observed\text{-}fiber}\), \(p_M=p\).  On \(\mathcal E_n\), we have proved that \(p\in\mathcal R_n\), and therefore \(S(M)\) is one of the compatible branches whose target images are unioned in \(\mathcal C_{n,\alpha}\).  In particular, \(M\) occurs in the target image attached to its own branch.  The definition of the confidence map therefore gives
\[
 q_M\in\mathcal C_{n,\alpha}.
\]
The event \(\mathcal E_n\) is common to all \(M\in\mathfrak F(p)\), so the preceding conclusion is simultaneous:
\[
 \{q_M:M\in\mathfrak F(p)\}
 \subseteq\mathcal C_{n,\alpha}
 \qquad\text{on }\mathcal E_n.
\]
Combining this inclusion with \(\Pr_p(\mathcal E_n)\geq1-\alpha\) proves the first assertion.  Notice that no equality between the observed law \(p\) and the causal target \(q_M\) has been assumed: the conclusion follows by retaining the target image of every causal model whose observed law remains in \(\mathcal R_n\).

It remains to verify the stated guard behavior.  If \(N_v=0\), the lower endpoint of \(I_\delta(0)\) is zero and its upper endpoint \(u\) is determined by
\[
 \Pr\{\operatorname{Bin}(n,u)\leq0\}
 =(1-u)^n=\delta/2,
\]
namely
\[
 u=1-(\delta/2)^{1/n}>0,
\]
where \(n\geq1\) and \(0<\delta/2<1\) justify the root and the strict inequality.  Thus an empirical zero does not by itself force the corresponding population cell to vanish.  After intersection with the simplex and the feasible observed-law image, suppose that some \(r\in\mathcal R_n\) has \(r(v)>0\).  Feasibility supplies a model \(M'\in\mathfrak M(G,\mathcal A,V,W,T)\) with \(p_{M'}=r\).  Its branch \(S(M')\) is compatible and is retained in the defining union for \(\mathcal C_{n,\alpha}\), while the observed-cell guard \(p_{M'}(v)=0\) is false on that retained branch.  Hence a structural-zero guard for cell \(v\) can hold across the confidence map only if
\[
 \forall r\in\mathcal R_n,\qquad r(v)=0.
\]
This is exactly the second assertion.  The argument uses neither division by an observed cell probability nor a limiting operation, so it requires no additional support, rank, overlap, boundary, or regularity condition beyond the stated finiteness, \(n\geq1\), and \(0<\alpha<1\).
