For a recursive causal model \(M\) represented by a latent-variable DAG \(G\), whenever \(\mathsf{ID}\) on the latent projection onto \(V\) returns \(\phi_{\mathrm{ID}}(p)\) for the query \(Q_M(t,y)\), its value equals \(Q_M(t,y)\).  Every successful return is a finite expression obtained from the observational law by marginalization, multiplication, and conditional-probability division.
