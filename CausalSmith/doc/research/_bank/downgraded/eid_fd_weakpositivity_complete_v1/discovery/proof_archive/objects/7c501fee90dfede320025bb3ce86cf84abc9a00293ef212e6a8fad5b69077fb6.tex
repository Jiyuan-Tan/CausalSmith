Let \(i_Z,i_A,i_X,i_Y\) be distinct vertices and suppose
\(D=\{i_Z,i_A,i_X,i_Y\}\), the edge set of \(G\) is exactly
\[
\{i_Z\mathbin{\to} i_A,\ i_A\mathbin{\to} i_X,
  \ i_A\mathbin{\to} i_Y,\ i_X\mathbin{\to} i_Y\},
\]
\(V=\{i_Z,i_X,i_Y\}\), \(W=\{i_A\}\), \(T=\{i_X\}\), and
\(Y=\{i_Y\}\).  Put
\(\mathcal Z=\mathcal A_{i_Z}\), \(\mathcal B=\mathcal A_{i_A}\),
\(\mathcal X=\mathcal A_{i_X}\), and \(\mathcal Y=\mathcal A_{i_Y}\).
Let \(p\) be a probability law on
\(\mathcal Z\times\mathcal X\times\mathcal Y\).  Put
\(p_X(x)=\sum_{z,y}p(z,x,y)\), and assume \(p_X(x)>0\) for every
\(x\in\mathcal X\).  Write
\(p(z)=\sum_{x,y}p(z,x,y)\) and \(p(z,x)=\sum_y p(z,x,y)\).  Under
the displayed guards define
\[
 e_z(x)=\frac{p(z,x)}{p(z)}\quad\text{when }p(z)>0,
 \qquad
 m_{zx}(y)=\frac{p(z,x,y)}{p(z,x)}\quad\text{when }p(z,x)>0.
\]
For each \(z\) with \(p(z)>0\), define its observed profile by
\[
 \rho_z=\bigl(e_z,(m_{zx})_{x:e_z(x)>0}\bigr).
\]
Thus \(\rho_z=\rho_{z'}\) means that \(e_z=e_{z'}\) and that
\(m_{zx}=m_{z'x}\) for every \(x\) in their common positive support.  Let
\(\mathcal R(p)=\{\rho_z:p(z)>0\}\), and define
\[
 L_x(y)=\sum_{z:p(z,x)>0}p(z)m_{zx}(y),
 \qquad
 M_x=\sum_{z:p(z)>0,\ p(z,x)=0}p(z).
\]
Then the following conclusions hold.
\begin{enumerate}
\item The law \(p\) is the observed marginal of a model in
\(\mathfrak M(G,\mathcal A,V,W,T)\) if and only if
\(\lvert\mathcal R(p)\rvert\leq\lvert\mathcal B\rvert\).  Given an
injection \(\kappa:\mathcal R(p)\to\mathcal B\), an explicit realizing
model sends every positive-mass \(z\) to
\(f(z)=\kappa(\rho_z)\), uses the root row
\(\theta_{i_Z}(z)=p(z)\), uses
\(\theta_{i_X}(\cdot\mid\kappa(\rho_z))=e_z\), and on reached treatment
rows uses \(\theta_{i_Y}(\cdot\mid\kappa(\rho_z),x)=m_{zx}\).  Zero-root-mass,
unused-state, and unreached outcome rows may be filled by arbitrary
probability vectors.  If \(p\) is rational, all arbitrary rows can be
chosen rational, giving a rational realizing model on the original
alphabets.
\item On every feasible law, the sharp identified set of the full
single-treatment intervention vector is
\[
 \mathcal Q(p)
 :=\left\{\bigl(Q_M(x,\cdot)\bigr)_{x\in\mathcal X}:
 M\in\mathfrak M(G,\mathcal A,V,W,T),\ p_M=p\right\}
 =\prod_{x\in\mathcal X}\bigl(L_x+M_x\Delta(\mathcal Y)\bigr),
\]
where \(L_x=(L_x(y))_{y\in\mathcal Y}\).  Simultaneous attainment is
obtained in the model above by setting, for every assigned profile whose
\(X\)-row misses \(x\), the common outcome row
\[
 s_x=\frac{q_x-L_x}{M_x}\quad\text{when }M_x>0
\]
for a desired \(q_x\in L_x+M_x\Delta(\mathcal Y)\); when \(M_x=0\), the
row is irrelevant and may be arbitrary.  The choices are independent
across \(x\).  If both \(p\) and the desired vector \(q\) are rational,
this attaining model can be chosen rational.
\item The full vector is point identified if and only if either
\(\lvert\mathcal Y\rvert=1\), or \(M_x=0\) for every
\(x\in\mathcal X\).  Hence, when \(\lvert\mathcal Y\rvert\geq2\), point
identification holds exactly when \(p(z,x)>0\) for every \(z\) with
\(p(z)>0\) and every \(x\in\mathcal X\).
\item After exact comparison of the profiles, feasibility, all
\(L_x(y)\) and \(M_x\), and the point-collapse test require
\(O(\lvert\mathcal Z\rvert\lvert\mathcal X\rvert
\lvert\mathcal Y\rvert)\) guarded arithmetic operations.  The region has
the linear-size half-space representation
\[
 q_x(y)\geq L_x(y)\quad(x\in\mathcal X,\ y\in\mathcal Y),
 \qquad
 \sum_{y\in\mathcal Y}q_x(y)=1\quad(x\in\mathcal X).
\]
\end{enumerate}
