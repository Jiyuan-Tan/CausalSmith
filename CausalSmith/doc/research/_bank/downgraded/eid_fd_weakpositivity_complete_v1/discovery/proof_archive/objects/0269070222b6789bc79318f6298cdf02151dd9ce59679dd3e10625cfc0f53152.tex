In the notation of
Definition \(\mathrm{def:profile\text{-}refinement\text{-}kernel\text{-}region}\),
put
\[
 C_\rho=\{z\in\mathcal Z_+:\rho_z=\rho\},
 \qquad
 H_\rho=\{x\in\mathcal X:e_z(x)=0\text{ for, equivalently every, }
 z\in C_\rho\}.
\]
The arbitrary-law saturation threshold is
\[
 B_{\mathrm{sat}}^0(p)
 =|\mathcal R(p)|+|\mathcal Z\setminus\mathcal Z_+|
 +\sum_{\rho\in\mathcal R(p):H_\rho\ne\varnothing}
 \bigl(|C_\rho|-1\bigr).
\]
It counts one baseline block for each positive-mass profile, one singleton
block for each zero-mass root state, and the additional singleton splits
needed inside every positive-mass profile class that has at least one
missing treatment row.
