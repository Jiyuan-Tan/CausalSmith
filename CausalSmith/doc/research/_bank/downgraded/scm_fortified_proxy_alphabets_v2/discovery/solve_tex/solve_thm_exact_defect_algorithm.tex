%%% FIELD exact-defect-narrowed
Given \(S\), \(u\), and access to the quotient-rank oracle \(\mathcal O_S\), there is an exact oracle-model algorithm that returns \(\kappa_0(S)\), \(\eta(S)\), \(r_{\mathrm{gen}}(S)\), and a subset \(I^*\subseteq\mathcal D_S\) attaining the maximum that defines \(\eta(S)\).  The submodular-minimization stage uses a strongly polynomial number of calls to \(\mathcal O_S\) as a function of \(|\mathcal D_S|\).  Every oracle value and the auxiliary computation of \(\kappa_0(S)\) are obtained by exact Gaussian elimination over \(\mathbb F_S\).  This is an exact oracle-call and field-operation reduction; it makes no polynomial, or strongly polynomial, bit-complexity claim for representing or manipulating rational functions.  The returned \(I^*\) is a witnessing deficient subset, with no claim of a separate succinct optimality certificate beyond the correctness of the submodular-minimization algorithm.
%%% FIELD exact-defect-proof
For an element \(e=(y,j)\in\mathcal D_S\), write \(W_e=W_y\).  For every \(I\subseteq\mathcal D_S\), define
\[
 U_I=\sum_{e\in I}W_e,
 \qquad
 \rho(I)=\dim_{\mathbb F_S}U_I=\mathcal O_S(I),
 \qquad
 F(I)=\rho(I)-|I|.
\]
These quantities are well defined because \(\mathcal D_S\) is finite and every \(W_e\) is a subspace of the finite-dimensional quotient \(\overline E_S/\overline N_S\).  For \(I,J\subseteq\mathcal D_S\), the dimension formula for two finite-dimensional subspaces gives
\[
 \rho(I)+\rho(J)
 =\dim_{mathbb F_S}(U_I+U_J)
  +\dim_{mathbb F_S}(U_I\cap U_J).
\]
By the definitions of the sums, \(U_I+U_J=U_{I\cup J}\), while \(U_{I\cap J}\subseteq U_I\cap U_J\).  Monotonicity of dimension therefore yields
\[
 \rho(I)+\rho(J)
 \geq \rho(I\cup J)+\rho(I\cap J).
\]
Thus \(\rho\) is an integer-valued submodular function.  Since
\[
 |I|+|J|=|I\cup J|+|I\cap J|,
\]
the function \(I\mapsto |I|\) is modular, and consequently \(F=\rho-|\cdot|\) is integer-valued and submodular.

Apply \(\textnormal{lem:schrijver-strongly-polynomial-sfm}\) to \(F\), using one call to \(\mathcal O_S\) to obtain \(\rho(I)\) at each value-oracle query and computing \(|I|\) directly.  It returns a minimizer \(I^*\) after a number of quotient-rank-oracle calls polynomial in \(|\mathcal D_S|\).  By \(\textnormal{def:hall-defect}\),
\[
 \eta(S)
 =\max_{I\subseteq\mathcal D_S}\bigl\{|I|-\rho(I)\bigr\}
 =-\min_{I\subseteq\mathcal D_S}F(I)
 =|I^*|-\mathcal O_S(I^*).
\]
Hence both \(\eta(S)\) and a subset attaining its defining maximum are returned exactly.  This equality is the asserted witness property of \(I^*\); no additional independently checkable optimality certificate is being asserted.

It remains to compute the constant-direction defect.  From the finite support \(S\), construct over \(\mathbb F_S\) the coordinate matrices for \(D_S\), the vectors \(r_c(x)\), and a basis of \(J_S\), as specified in \(\textnormal{def:rank-oracle}\).  Exact Gaussian elimination gives successively
\[
 H_S=\ker D_S,
 \qquad
 R_S(x)=\operatorname{span}_{\mathbb F_S}\{r_c(x):c\in\operatorname{proj}_C(S)\},
 \qquad
 L_S(x)=H_S+R_S(x),
\]
and then, by solving the homogeneous linear equations for the coordinate pairing,
\[
 N_S(x)=L_S(x)^\perp.
\]
The same exact elimination applied to concatenated bases for \(N_S(x)\) and \(J_S\) computes
\[
 \kappa_0(S)
 =\dim_{mathbb F_S}\bigl(N_S(x)\cap J_S\bigr)
 =\dim_{mathbb F_S}N_S(x)+\dim_{mathbb F_S}J_S
  -\dim_{mathbb F_S}\bigl(N_S(x)+J_S\bigr).
\]
All divisions made during elimination are by nonzero elements of the field \(\mathbb F_S\), so these ranks and dimensions are exact rational-function quantities rather than numerical specializations.

Finally, \(Q_S=u|\mathcal I_S|\) is obtained by counting the declared blocks, and \(\textnormal{thm:generic-rank-formula}\) gives
\[
 r_{\mathrm{gen}}(S)=Q_S-\kappa_0(S)-\eta(S).
\]
This computes every claimed output.  The cited submodular-minimization result controls only the number of value-oracle calls, while the remaining work consists of finitely many exact field operations and exact Gaussian eliminations over \(\mathbb F_S\).  Because the representation size and bit cost of rational-function arithmetic have not been bounded, the argument proves no polynomial bit-complexity statement.
