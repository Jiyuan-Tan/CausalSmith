If \(h\in V_m\), write \(h=\sum_c\gamma_cB_c^{(m)}\).  For every feasible \(b\) and every \(\nu\in\mathcal F_{m,\epsilon}(b)\),
\[
 \int h\,d\nu=\sum_c\gamma_c\int B_c^{(m)}\,d\nu
 =\sum_c\gamma_cb_c,
\]
so the functional is constant on every fiber.

Conversely, suppose \(h\notin V_m\).  Choose any \(b_0\in\operatorname{relint}(\mathcal B_{m,\epsilon})\), which is nonempty for every nonempty finite-dimensional convex set.  By lem:full-support-perturbation there is a full-support \(\nu_0\in\mathcal F_{m,\epsilon}(b_0)\).  Project \(h\) onto \(V_m\) in \(L^2(\nu_0)\) and write \(r=h-\Pi_{V_m}^{L^2(\nu_0)}h\).  Exactly as in that lemma,
\[
 \int B_c^{(m)}r\,d\nu_0=0,
 \qquad
 \int hr\,d\nu_0=\int r^2\,d\nu_0>0.
\]
The strict inequality follows because a continuous function that is zero \(\nu_0\)-almost surely is zero everywhere under full support.  For sufficiently small \(s>0\), the probability measures \((1\pm sr)\nu_0\) have the same moment vector \(b_0\) and different integrals of \(h\).  Therefore constancy on every feasible fiber implies \(h\in V_m\), proving the equivalence.

For \(h=f\), lem:finite-plate-nonpolynomial gives \(f\notin V_m\), so universal point identification fails.  Moreover, for each relative-interior \(b\), the two measures constructed in lem:full-support-perturbation belong to \(\mathcal F_{m,\epsilon}(b)\) and have distinct \(f\)-integrals.  Since \([L_m(b),U_m(b)]\) contains both values, \(L_m(b)<U_m(b)\).
