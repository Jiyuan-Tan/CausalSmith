Fix the declared ordered pair \(p\ne q\) and suppose that the deterministic margin event
\[
 \left\lvert\widehat\gamma_{pq}-\gamma_{pq}\right\rvert\le w_n
\]
holds. By the definition of absolute value, this event gives the two inequalities
\[
 \widehat\gamma_{pq}\le \gamma_{pq}+w_n
 \qquad\text{and}\qquad
 \widehat\gamma_{pq}\ge \gamma_{pq}-w_n.
\]
If \(\gamma_{pq}\le0\), the first inequality yields
\[
 \widehat\gamma_{pq}\le \gamma_{pq}+w_n\le w_n.
\]
Definition \(\mathrm{def:simultaneous\text{-}band}\) specifies the strict-threshold rule
\(\Psi_n=\mathbf 1\{\widehat\gamma_{pq}>w_n\}\). Therefore its indicator event is false and \(\Psi_n=0\).

If instead \(\gamma_{pq}\ge3w_n\), the second inequality gives
\[
 \widehat\gamma_{pq}
 \ge \gamma_{pq}-w_n
 \ge 3w_n-w_n
 =2w_n.
\]
The same definition gives
\[
 w_n=\left(\frac{2}{m}+\frac{2M}{m^2}\right)r_{H,n}.
\]
The declared ranges \(m>0\), \(M>m\), and \(r_{H,n}>0\) make the coefficient and hence \(w_n\) strictly positive. Consequently \(2w_n>w_n\), so \(\widehat\gamma_{pq}>w_n\), and the strict-threshold rule gives \(\Psi_n=1\). In particular, equality in the power premise \(\gamma_{pq}=3w_n\) still implies strict rejection, so no equality case remains unresolved.
