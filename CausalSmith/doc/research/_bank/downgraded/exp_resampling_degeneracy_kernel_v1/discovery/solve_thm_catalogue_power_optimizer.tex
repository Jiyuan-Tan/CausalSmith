The displayed matrix has nonnegative entries, every row sums to one, and its positive entries are exactly the six pairs listed in \(L\).  Hence it is a legal row-stochastic kernel.  We now inspect every nonempty subset, which is also the required smallest-instance stress test.  For a singleton,
\[
 d_K(\{i\})=K(i,i)=\frac23,\qquad i=1,2,3.
\]
For each two-point set \(A\), exactly one of its two directed cycle edges lies in \(L\).  If that edge is \((i,j)\), order the set as \((i,j)\).  The first prefix mass is \(K(i,\{i\})=2/3\), and the second is \(K(j,A)=2/3\), because the off-diagonal mass in row \(j\) points to the third state, outside \(A\).  Thus this ordering has maximum \(2/3\).  Conversely, the first prefix in either ordering is a diagonal mass \(2/3\), so
\[
 d_K(A)=\frac23\qquad (|A|=2).
\]
Finally, for \(A=\Omega\), the last prefix in every ordering is \(\Omega\), and row stochasticity gives \(K(i,\Omega)=1\); hence \(d_K(\Omega)=1\).  Since \(\pi(A)=|A|/3\), these calculations give
\[
 d_K(A)\geq \pi(A)\qquad\text{for every nonempty }A\subseteq\Omega.
\]
Theorem \(\texttt{thm:universal-validity-iff}\) therefore proves universal validity.

The strict score order gives the upper-tail sets \(\{1\}\), \(\{1,2\}\), and \(\Omega\) at states one, two, and three, respectively.  By \(\texttt{def:kernel-tail-value}\),
\[
 p_K(1;s^1)=K(1,\{1\})=\frac23,
 \qquad
 p_K(2;s^1)=K(2,\{1,2\})=\frac23,
 \qquad
 p_K(3;s^1)=K(3,\Omega)=1.
\]
Thus the rejection set at \(\alpha=2/3\) is exactly \(\{1,2\}\), and \(\texttt{def:catalogue-power}\) yields
\[
 \operatorname{Pow}(K)=\sum_{x\in\Omega}\pi(x)\mathbf 1\{p_K(x;s^1)\leq2/3\}=\frac23.
\]
For any universally valid legal kernel \(\widetilde K\), universal validity applied to this fixed score and level gives
\[
 \operatorname{Pow}(\widetilde K)
 =\Pr_{X\sim\pi}\{p_{\widetilde K}(X;s^1)\leq2/3\}
 \leq\frac23.
\]
The displayed \(K\) attains this upper bound, so it is globally catalogue-power optimal.

It remains to calculate the partition benchmark.  If two distinct states \(i\) and \(j\) belonged to the same partition cell, positivity of \(\pi\) would imply that its conditional-design kernel assigns both \(K(i,j)>0\) and \(K(j,i)>0\).  The directed three-cycle contains at most one direction for each unordered pair, contradicting legal support.  Consequently every legal partition has only singleton cells and its kernel is the identity.  All its upper-tail values equal one, so its power at \(\alpha=2/3<1\) is zero.  Therefore
\[
 \Delta_{\mathrm{part}}
 =\operatorname{Pow}(K)-\max_{\widetilde K\in\mathcal P_L}\operatorname{Pow}(\widetilde K)
 =\frac23-0=\frac23.
\]

For each catalogue member \(h\) and observed state \(x\), define the fixed coefficients and the corresponding linear row-tail mass
\[
 a_{hxy}=\mathbf 1\{s^h(y)\geq s^h(x)\},
 \qquad
 Q_{hx}(K)=\sum_{y\in\Omega}a_{hxy}K(x,y).
\]
The catalogue is fixed before outcomes by \(\texttt{ass:prespecified-catalogue}\), and \(\texttt{def:kernel-tail-value}\), as used through \(\texttt{def:catalogue-power}\), gives \(Q_{hx}(K)=p_K(x;s^h)\).  In addition to the continuous entries \(K(x,y)\), introduce rejection variables \(z_{hx}\in\{0,1\}\).  Impose
\[
 Q_{hx}(K)\leq \alpha+1-z_{hx}
 \qquad(h=1,\ldots,q,\ x\in\Omega)
\]
and maximize
\[
 \sum_{h=1}^{q}w_h\sum_{x\in\Omega}\pi(x)z_{hx}.
\]
Because row stochasticity and nonnegativity imply \(0\leq Q_{hx}(K)\leq1\), the constraint is vacuous when \(z_{hx}=0\), while \(z_{hx}=1\) is feasible exactly when the closed rejection inequality \(Q_{hx}(K)\leq\alpha\) holds.  Hence every feasible choice satisfies
\[
 z_{hx}\leq\mathbf 1\{p_K(x;s^h)\leq\alpha\},
\]
and, for every fixed \(K\), equality can be chosen for all \((h,x)\).  This remains true at \(Q_{hx}(K)=\alpha\), so threshold equality is handled without a strict inequality.  Terms with \(w_h=0\) are immaterial to the objective and may also be set equal to their indicators.  The optimized linear objective is therefore exactly \(\max_K\operatorname{Pow}(K)\), not a relaxation.

We next encode universal validity.  For every nonempty \(A\subseteq\Omega\), every ordering \(\sigma\in\operatorname{Ord}(A)\), and every \(j\in\{1,\ldots,|A|\}\), introduce \(y_{A\sigma j}\in\{0,1\}\) and impose
\[
 \sum_{j=1}^{|A|}y_{A\sigma j}\geq1,
 \qquad
 K(\sigma_j,P_j(\sigma))
 \geq \pi(A)-\bigl(1-y_{A\sigma j}\bigr).
\]
If \(y_{A\sigma j}=0\), the latter inequality follows from nonnegativity because \(\pi(A)-1\leq0\).  If it equals one, the selected half-space is
\(K(\sigma_j,P_j(\sigma))\geq\pi(A)\).  Thus the first constraint selects at least one valid prefix for every pair \((A,\sigma)\).  By \(\texttt{thm:polyhedral-description}\), these finitely many constraints are equivalent to \(d_K(A)\geq\pi(A)\) for every nonempty \(A\).  Adding
\[
 0\leq K(x,y)\leq1,
 \qquad
 \sum_{y\in\Omega}K(x,y)=1,
 \qquad
 K(x,y)=0\quad\text{when }(x,y)\notin L
\]
therefore gives an exact finite mixed-integer linear formulation of the program in \(\texttt{def:power-optimal-kernel}\).  Finiteness follows from finiteness of \(\Omega\), its nonempty subsets, their orderings, and the catalogue.

For completeness, consider a branch-and-cut solution of this formulation.  At a proposed kernel, \(\texttt{thm:subset-recursion}\) computes all \(d_K(A)\) in \(O(m2^m)\) arithmetic operations.  If \(d_K(A)<\pi(A)\), a stored minimizing ordering \(\sigma\) satisfies
\[
 \max_{1\leq j\leq|A|}K(\sigma_j,P_j(\sigma))<\pi(A),
\]
so the disjunction indexed by \((A,\sigma)\) is violated and is added.  No indexed disjunction need be added twice, and only finitely many exist.  Consequently the separation phase terminates; exhaustive branching over the finitely many \(z\)- and \(y\)-variables is a finite fallback.

We spell out the promised exact certificate.  After fixing all binary variables in one branch, the remaining problem is a bounded system of linear inequalities in the finitely many entries of \(K\) and one objective variable.  Eliminating a variable is exact: every pair of bounds
\[
 a v\leq b\quad(a>0),
 \qquad
 -c v\leq d\quad(c>0)
\]
implies and is feasible over \(v\) exactly when the retained variables satisfy \(cb+ad\geq0\), together with the inequalities not containing \(v\).  Repeating this finite Fourier--Motzkin step either produces a contradictory constant inequality or projects the branch onto an objective interval with an exact upper endpoint.  The elimination trace is respectively an infeasibility certificate or an upper-bound certificate.  Taking the largest certified branch endpoint and exhibiting an incumbent attaining it certifies global optimality.  The chosen \(y\)-variables identify active validity disjuncts, and direct evaluation of the closed \(z\)-conditions returns the exact rejection probability.

For inputs represented by rational or real-algebraic numbers, all coefficient comparisons and elimination operations above are terminating exact computations.  If arbitrary real constants are admitted, the same finite derivation is an ideal exact-real-arithmetic procedure rather than a Turing-algorithm claim.  This distinction does not change the finite mixed-integer representation or its mathematical certificate.

It remains to certify the partition comparison.  First, every legal partition kernel satisfies the validity inequalities.  Indeed, fix a nonempty \(A\) and any ordering \(\sigma\).  For a partition \(\mathcal G\), positivity gives \(\pi(G)>0\) for each nonempty cell, and
\[
 \pi(A)=\sum_{G\in\mathcal G}\pi(G)\frac{\pi(A\cap G)}{\pi(G)}.
\]
Therefore some cell \(G\) meeting \(A\) obeys \(\pi(A\cap G)/\pi(G)\geq\pi(A)\).  Let \(i\) be the last element of \(A\cap G\) in \(\sigma\), at position \(j\).  Then \(P_j(\sigma)\cap G=A\cap G\), and the partition-kernel formula gives
\[
 K(i,P_j(\sigma))=\frac{\pi(A\cap G)}{\pi(G)}\geq\pi(A).
\]
This holds for every ordering, so \(d_K(A)\geq\pi(A)\).  Thus every member of \(\mathcal P_L\) is feasible for the unrestricted program.

If that program is feasible, its singleton constraint gives
\[
 K(i,i)=d_K(\{i\})\geq\pi(i)>0
\]
for every \(i\).  Legal support then forces every self-loop \((i,i)\) to lie in \(L\), so the singleton partition kernel belongs to \(\mathcal P_L\); the benchmark is nonempty.  There are only finitely many partitions of a finite set, and each legal one can be evaluated by the same exact arithmetic.  Since each is feasible,
\[
 \max_{K\in\mathcal P_L}\operatorname{Pow}(K)
 \leq \operatorname{Pow}(K^\star),
 \qquad
 \Delta_{\mathrm{part}}\geq0.
\]
The globally certified optimum of the full mixed-integer program and the finite certified maximum over legal partitions therefore certify strict dominance over every partition kernel exactly when \(\Delta_{\mathrm{part}}>0\).  Finally, \(\texttt{ass:outcome-free-kernel}\) ensures that optimizing this prespecified catalogue selects a design-stage kernel and does not adapt the test to the observed outcomes.

Suppose every self-loop belongs to \(L\), and suppose there are distinct \(x,y\in\Omega\) such that \((x,y)\in L\) and, for every \(z\neq x\), at least one of \((x,z)\) and \((z,x)\) is absent from \(L\).  Take \(q=1\), \(w_1=1\), \(\alpha=\pi(x)\), and a score satisfying \(s^1(x)>s^1(z)=s^1(z')\) for all \(z,z'\in\Omega\setminus\{x\}\).  Define
\[
 K(x,x)=\pi(x),\qquad K(x,y)=1-\pi(x),\qquad K(z,z)=1\ (z\neq x),
\]
with all other entries zero.  Then \(K\in\mathcal K_L\) is a nonpartition kernel,
\[
 d_K(\{x\})=\pi(x),
 \qquad
 d_K(A)=1\quad\text{for every nonempty }A\neq\{x\},
\]
and it is universally valid.  It rejects exactly at \(x\), has \(\operatorname{Pow}(K)=\pi(x)=\alpha\), and is globally catalogue-power optimal.  Every legal partition kernel has power zero, so \(\Delta_{\mathrm{part}}=\pi(x)>0\).  In particular, the uniform three-state directed-cycle support in \(\texttt{prop:worked-nonpartition-power-gap}\) satisfies the premise at each vertex and is a corollary of this support criterion (with the kernel and level constructed here).

Because \(x\neq y\), positivity and \(\sum_{z\in\Omega}\pi(z)=1\) give \(0<\pi(x)<1\).  The displayed row at \(x\) sums to \(\pi(x)+1-\pi(x)=1\), and every other row is an identity row.  All entries are nonnegative.  Its only positive off-diagonal entry is the assumed legal pair \((x,y)\), while every positive diagonal entry uses an assumed legal self-loop.  Thus \(K\in\mathcal K_L\).

For \(A=\{x\}\), the only ordering has prefix mass \(K(x,\{x\})=\pi(x)\), so \(d_K(\{x\})=\pi(x)\).  Now let \(A\neq\{x\}\) be nonempty and fix any ordering \(\sigma\) of \(A\).  If \(x\notin A\), every \(i\in A\) is an identity row, and at the position of any such \(i\),
\[
 K(i,P_j(\sigma))=K(i,i)=1.
\]
If \(x\in A\), then \(A\) contains some \(i\neq x\), and the same equality holds at the position of that \(i\).  Since no row mass can exceed one, every ordering consequently satisfies
\[
 \max_j K(\sigma_j,P_j(\sigma))=1.
\]
Minimizing over orderings proves \(d_K(A)=1\).  Hence \(d_K(A)\geq\pi(A)\) for every nonempty \(A\), and \(\texttt{thm:universal-validity-iff}\) proves universal validity.

Under the stated tied score, the upper-tail set at \(x\) is \(\{x\}\), whereas the upper-tail set at every \(z\neq x\) is all of \(\Omega\).  Therefore
\[
 p_K(x;s^1)=K(x,\{x\})=\pi(x)=\alpha,
 \qquad
 p_K(z;s^1)=K(z,\Omega)=1>\alpha\quad(z\neq x).
\]
The rejection set is exactly \(\{x\}\), and its design probability and catalogue power are both \(\pi(x)=\alpha\).  Universal validity bounds the rejection probability of every universally valid competitor at this score and level by \(\alpha\), so this \(K\) attains the global optimum.

For any partition kernel supported on \(L\), the cell containing \(x\) cannot contain a state \(z\neq x\): if it did, positivity would make both conditional transitions \(x\to z\) and \(z\to x\) positive, contrary to the no-mutual-neighbor premise.  Thus \(x\) is a singleton cell.  The partition upper-tail value at \(x\) is consequently one.  At every other state the upper-tail set is \(\Omega\), so its value is also one.  Since \(\alpha<1\), every legal partition kernel has power zero.  Moreover, the constructed kernel has \(K(x,y)=1-\pi(x)>0\), while every legal partition kernel has zero at \((x,y)\); hence it is not a partition kernel.  It follows that \(\Delta_{\mathrm{part}}=\pi(x)>0\).

Finally, on the uniform three-state directed cycle every self-loop is legal, no distinct pair has both directions legal, and one may take, for example, \(x=1\) and \(y=2\).  Substitution into the displayed construction proves the stated corollary.
