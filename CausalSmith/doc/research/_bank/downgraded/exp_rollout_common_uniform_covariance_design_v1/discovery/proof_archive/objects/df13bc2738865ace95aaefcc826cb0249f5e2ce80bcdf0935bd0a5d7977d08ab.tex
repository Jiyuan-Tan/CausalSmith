Fix a finite \(n\in\mathbb N\), an order \(1\leq\beta\leq n\), a radius \(B>0\), and weights \(\omega_r>0\) for \(r=1,\ldots,\beta\).  If \((Y,c)\in\mathcal C_{n,\beta}(B,\omega)\), Definition~\(\mathrm{def{:}ellipsoidal\text{-}coefficient\text{-}class}\) directly requires \((Y,c)\in\mathcal C^{\mathrm{CEY}}_{n,\beta}\).  Therefore
\[
\mathcal C_{n,\beta}(B,\omega)
\subseteq
\mathcal C^{\mathrm{CEY}}_{n,\beta}.
\]

We now construct an element for which the inclusion is strict.  The inequalities \(1\leq\beta\leq n\) imply that \(1\in I_n\) and \(\{1\}\in\mathcal S_{n,\beta}\).  For each \(i\in I_n\), set
\[
c^*_{i,\{1\}}=2B\sqrt{\frac{\omega_1}{n}},
\qquad
c^*_{i,R}=0
\quad
\text{for every }R\in\{\varnothing\}\cup\mathcal S_{n,\beta}
\text{ with }R\neq\{1\},
\]
and define, for every \(z\in\{0,1\}^n\),
\[
Y_i^*(z)
=c^*_{i,\varnothing}
+\sum_{R\in\mathcal S_{n,\beta}}c^*_{i,R}
  \prod_{j\in R}z_j.
\]
This is exactly the bounded-order polynomial representation in Assumption~\(\mathrm{ass{:}low\text{-}order\text{-}schedule}\).  Hence Definition~\(\mathrm{def{:}published\text{-}low\text{-}order\text{-}class}\) gives
\[
(Y^*,c^*)\in\mathcal C^{\mathrm{CEY}}_{n,\beta}.
\]

For every \(R\in\mathcal S_{n,\beta}\), the definition \(a_R=n^{-1}\sum_{i\in I_n}c_{i,R}\) yields
\[
a_R^*
=\frac{1}{n}\sum_{i\in I_n}c^*_{i,R}
=
\begin{cases}
2B\sqrt{\omega_1/n},&R=\{1\},\\
0,&R\neq\{1\}.
\end{cases}
\]
Because every \(\omega_r\) is positive, the diagonal matrix \(\Omega\), whose diagonal entry indexed by \(R\) is \(\omega_{|R|}\), is invertible and has inverse diagonal entry \(\omega_{|R|}^{-1}\).  It follows that
\[
(a^*)^{\mathsf T}\Omega^{-1}a^*
=\sum_{R\in\mathcal S_{n,\beta}}
  \frac{(a_R^*)^2}{\omega_{|R|}}
=\frac{4B^2\omega_1/n}{\omega_1}
=\frac{4B^2}{n}.
\]
Since \(B>0\) and \(n\geq1\),
\[
\frac{4B^2}{n}>\frac{B^2}{n}.
\]
Thus the witness fails the aggregate ellipsoid condition stated in Assumption~\(\mathrm{ass{:}aggregate\text{-}coefficient\text{-}ellipsoid}\), which is the additional membership condition in Definition~\(\mathrm{def{:}ellipsoidal\text{-}coefficient\text{-}class}\).  Consequently
\[
(Y^*,c^*)\notin\mathcal C_{n,\beta}(B,\omega).
\]
We have exhibited an element of \(\mathcal C^{\mathrm{CEY}}_{n,\beta}\) outside \(\mathcal C_{n,\beta}(B,\omega)\), proving
\[
\mathcal C_{n,\beta}(B,\omega)
\subsetneq
\mathcal C^{\mathrm{CEY}}_{n,\beta}.
\]
