Fix a finite \(n\in\mathbb N\), an order \(1\leq\beta\leq n\), a radius
\(B>0\), and order weights \(\omega_r>0\) for
\(r=1,\ldots,\beta\).  If
\((Y,c)\in\mathcal C_{n,\beta}(B,\omega)\),
Definition~\(\mathrm{def{:}ellipsoidal\text{-}coefficient\text{-}class}\)
requires \((Y,c)\in\mathcal C^{\mathrm{CEY}}_{n,\beta}\).  Therefore
\[
\mathcal C_{n,\beta}(B,\omega)
\subseteq
\mathcal C^{\mathrm{CEY}}_{n,\beta}.
\]

It remains to prove strictness with the stated schedule.  Because
\(1\leq\beta\leq n\), one has \(1\in I_n\) and
\(\{1\}\in\mathcal S_{n,\beta}\).  For each \(i\in I_n\), set
\[
c^*_{i,\{1\}}=2B\sqrt{\frac{\omega_1}{n}},
\qquad
c^*_{i,R}=0
\quad
\text{for every }R\in\{\varnothing\}\cup\mathcal S_{n,\beta}
\text{ with }R\neq\{1\},
\]
and, for every \(z\in\{0,1\}^n\), define
\[
Y_i^*(z)
=c^*_{i,\varnothing}
+\sum_{R\in\mathcal S_{n,\beta}}c^*_{i,R}
  \prod_{j\in R}z_j
=2B\sqrt{\frac{\omega_1}{n}}\,z_1.
\]
Thus \((Y^*,c^*)\) belongs to the unrestricted algebraic class
\(\mathcal A_{n,\beta}\) of
Lemma~\(\mathrm{lem{:}cey\text{-}envelope\text{-}union\text{-}equivalence}\).
That lemma gives
\(\mathcal A_{n,\beta}=\mathcal U_{n,\beta}\), and the reverse-inclusion
proof there supplies the explicit complete-graph certificate
\(E^{\mathrm{all}}=I_n\times I_n\), with
\(\mathcal N_i(E^{\mathrm{all}})=I_n\).  Hence the schedule satisfies both
equivalent descriptions of the zero-noise CEY class: its unrestricted
degree-at-most-\(\beta\) expansion is the frozen algebraic description in
Definition~\(\mathrm{def{:}published\text{-}low\text{-}order\text{-}class}\),
and the complete graph certifies the graph-union description.  Therefore
\[
(Y^*,c^*)\in\mathcal C^{\mathrm{CEY}}_{n,\beta}.
\]

For every \(R\in\mathcal S_{n,\beta}\), the aggregate-coefficient definition
\(a_R=n^{-1}\sum_{i\in I_n}c_{i,R}\) gives
\[
a_R^*
=\frac{1}{n}\sum_{i\in I_n}c^*_{i,R}
=
\begin{cases}
2B\sqrt{\omega_1/n},&R=\{1\},\\
0,&R\neq\{1\}.
\end{cases}
\]
Every \(\omega_r\) is positive, so the diagonal matrix \(\Omega\) is
invertible and its inverse has diagonal entry \(\omega_{|R|}^{-1}\) at
index \(R\).  Hence
\[
\begin{aligned}
(a^*)^{\mathsf T}\Omega^{-1}a^*
&=\sum_{R\in\mathcal S_{n,\beta}}
  \frac{(a_R^*)^2}{\omega_{|R|}}\\
&=\frac{4B^2\omega_1/n}{\omega_1}\\
&=\frac{4B^2}{n}.
\end{aligned}
\]
Since \(B>0\) and \(n\geq1\),
\[
\frac{4B^2}{n}>\frac{B^2}{n}.
\]
The witness therefore violates the aggregate ellipsoid condition in
Assumption~\(\mathrm{ass{:}aggregate\text{-}coefficient\text{-}ellipsoid}\),
which is the additional membership requirement in
Definition~\(\mathrm{def{:}ellipsoidal\text{-}coefficient\text{-}class}\).
Consequently
\[
(Y^*,c^*)\notin\mathcal C_{n,\beta}(B,\omega).
\]
Together with the first inclusion, this explicit witness proves
\[
\mathcal C_{n,\beta}(B,\omega)
\subsetneq
\mathcal C^{\mathrm{CEY}}_{n,\beta}.
\]
