The barrier \(\Psi_\beta(q)\) quantifies the unavoidable extrapolation cost created jointly by the rollout budget and the number of polynomial moments that must be reproduced.  For \(\beta=1\), every feasible node vector with the endpoint readout is optimal.  For \(\beta\ge2\) and \(q<1\), no finite step readout can attain the continuous Riesz-representer relaxation, so the attained exact-covariance optimum lies strictly above the barrier.  At \(q=1\), every node vector is optimal only with the unique endpoint difference readout.
