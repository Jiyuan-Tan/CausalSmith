Put \(D=|\mathcal S_{n,\beta}|\), and, for fixed \(p\in\mathcal P_{k,q,\delta}\), form the \((k+1)D\)-by-\((k+1)D\) block matrix
\[
 \mathsf C(p)_{st}
 =\Omega^{1/2}\bigl[K_{st}(S,T)\bigr]_{S,T\in\mathcal S_{n,\beta}}\Omega^{1/2}.
\]
By \(\mathrm{lem{:}common\text{-}uniform\text{-}monomial\text{-}covariance}\), this is the covariance matrix of the stacked, centered, order-weighted monomial vectors at the \(k+1\) stages; hence \(\mathsf C(p)\succeq0\).  Choose any square root \(L_pL_p^{\mathsf T}=\mathsf C(p)\), and define
\[
 B_p(w)=(w^{\mathsf T}\otimes I_D)L_p,
 \qquad
 A_p(w)=\Omega^{1/2}G(p,w)\Omega^{1/2}.
\]
Block multiplication and the definition of \(G\) give, entry by entry,
\[
 A_p(w)
 =(w^{\mathsf T}\otimes I_D)\mathsf C(p)(w\otimes I_D)
 =B_p(w)B_p(w)^{\mathsf T}.
\]
Let \(E(p)\in\mathbb R^{(\beta+1)\times(k+1)}\) have entries \(E(p)_{d,t}=p_t^d\) for \(0\le d\le\beta\), and let \(b=(0,1,\ldots,1)^{\mathsf T}\).  The spacing restriction gives \(p_0<\cdots<p_k\), while \(k\ge\beta\); therefore the first \(\beta+1\) columns contain a nonsingular Vandermonde matrix and \(E(p)\) has row rank \(\beta+1\).  Thus \(\mathcal W_\beta(p)=\{w:E(p)w=b\}\) is nonempty.  For this fixed \(p\), its exact optimal weight value is the semidefinite program
\[
 \begin{aligned}
 \rho(p)=\min_{\rho\in\mathbb R,\,w\in\mathbb R^{k+1}}\quad&\rho\\
 \text{subject to}\quad&E(p)w=b,\\
 &\begin{bmatrix}
 \rho I_D&B_p(w)\\
 B_p(w)^{\mathsf T}&I_{(k+1)D}
 \end{bmatrix}\succeq0.
 \end{aligned}
\]
Indeed, the lower-right block is positive definite, so the Schur-complement identity makes the displayed matrix inequality equivalent to
\[
 \rho I_D-B_p(w)B_p(w)^{\mathsf T}\succeq0,
\]
which in turn is equivalent to \(\rho\ge\lambda_{\max}\{A_p(w)\}\).  Consequently, using \(\mathrm{lem{:}subset\text{-}lattice\text{-}block\text{-}reduction}\),
\[
 V^*_{n,\beta,k,q,\delta}
 =\frac{B^2}{n}\min_{p\in\mathcal P_{k,q,\delta}}\rho(p),
 \qquad
 \rho(p)=\min_{w\in\mathcal W_\beta(p)}
 \max_{0\le h\le\beta}\lambda_{\max}\{H_h(p,w)\}.
\]
Joint attainment follows from \(\mathrm{thm{:}exact\text{-}covariance\text{-}saddle}\).  The boundary pieces are already exact: \(\mathrm{prop{:}rollout\text{-}budget\text{-}elbow}\) gives all minimizers when \(q=1\), all minimizers and the value when \(\beta=1\), and, for \(0<q<1\), the computable lower bound
\[
 V^*_{n,\beta,k,q,\delta}
 \ge \frac{B^2\omega_1}{n}\Psi_\beta(q)
 \ge \frac{B^2\omega_1}{n}\frac{1-q}{q}.
\]
Finally, \(\mathrm{prop{:}quadratic\text{-}witness}\) proves that at \((n,\beta,k,q)=(3,2,2,1/2)\) one legal schedule has interpolation risk \(4(1-x)/\{9(1-2x)\}\), with values \(14/27\) at \(x=1/8\) and \(2/3\) at \(x=1/4\).  This last comparison concerns one member of the schedule class and therefore is not, by itself, a comparison of the robust values \(\rho(p)\).
