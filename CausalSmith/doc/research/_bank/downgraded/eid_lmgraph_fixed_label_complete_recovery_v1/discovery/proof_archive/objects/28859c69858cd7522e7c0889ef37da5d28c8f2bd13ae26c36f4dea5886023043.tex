On formal input \((\mathcal G,A,Y,\mathbf p)\), start from every observed-trace kernel written as a rational expression in \(\mathbf p\) and recursively apply ancestral marginalization, district decomposition, licensed \(\Phi_v^{\lambda}\) updates, and delayed \(\Sigma_c\) updates. Canonicalize states modulo admissible adjacent swaps and memoize \((\mathcal H,F,c,\Lambda)\). At each terminal state append the symbolic formulas \(\mathsf C_{\mathcal G}(\theta;\mathbf p)\), \(\mathsf I_{a,y}(\mathcal G;\mathbf p)\), and \(\mathsf V_{a,y}(\mathbf p,z)\). One common signed-subresultant CAD refines these outputs into \(\mathscr P_{\mathcal G,A,Y}\), with a rational trace expression or unique-value graph on identifying cells and \(\mathsf W_j\) on negative cells. The notation \(\operatorname{TCF}(\mathcal G,A,Y,P_{\mathrm{obs}})\) means this symbolic object with the formal names \(p_o=P_{\mathrm{obs}}(o)\); selecting a numerical cell is only the separate exact specialization. The procedure neither names nor returns a colored hedge.
