On formal input \((\mathcal G,A,Y,\mathbf p)\), enumerate at most \(2^n c\) supported initial observed-trace kernels, indexed by an observed margin and a partial missingness context, each written as a rational expression in \(\mathbf p\). From an initial kernel, a recursive transition must be strict: ancestral marginalization or passage to one child of a nontrivial district decomposition strictly decreases the current random-vertex set; a licensed \(\Phi_v^{\lambda}\) update moves one random vertex to the fixed set; and a delayed \(\Sigma_c\) update strictly extends the current partial context. No no-op transition is enumerated. The termination-certified implementation retains distinct initial-trace and operation-word histories. As an optional optimization, when \(\operatorname{Swap}_{\kappa}(u,v)\) holds, the two suffixes may be replayed in a fixed canonical order from their common pre-swap state, but the branches are merged only if the replayed complete tuples \((\mathcal H,F,c,q,\pi,\Lambda)\) are literally equal; otherwise both histories are retained. At each terminal state append one package containing the feasible-projection and constancy formulas in the free coordinates \(\mathbf p\), together with the stored relation \(\mathsf V_{a,y}(\mathbf p,z)\) or \(\mathsf W_j\), for each \((a,y)\). One common signed-subresultant CAD refines only the concatenated partition-generating formulas in \(\mathbf p\) into \(\mathscr P_{\mathcal G,A,Y}\); the value and witness relations are attached to the resulting cells and do not add CAD coordinates. Identifying cells carry a rational trace expression or unique-value graph, and negative cells carry \(\mathsf W_j\). The notation \(\operatorname{TCF}(\mathcal G,A,Y,P_{\mathrm{obs}})\) means this symbolic object with the formal names \(p_o=P_{\mathrm{obs}}(o)\); selecting a numerical cell is only the separate exact specialization. The procedure neither names nor returns a colored hedge.
