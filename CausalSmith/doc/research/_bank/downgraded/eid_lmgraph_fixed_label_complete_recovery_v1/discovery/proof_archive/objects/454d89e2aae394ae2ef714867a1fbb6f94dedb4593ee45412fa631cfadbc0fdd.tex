For \((n,\ell,c,t,h,g,K_{\mathcal G},p,s)\), set \(t=2n\) and \(L_{\mathrm{op}}=2^{n+1}+n(\ell+1)+c+1\), and define
\[
\begin{aligned}
B_{\mathrm{state}}&=2^n c\sum_{j=0}^{t}L_{\mathrm{op}}^j,\\
N_{\mathrm{term}}&=|\mathcal X_A||\mathcal X_Y|B_{\mathrm{state}},\\
S_{\mathrm{tot}}&=N_{\mathrm{term}}(s+1),\\
B_{\mathrm{tot}}&=B_{\mathrm{state}}+\operatorname{CAD}(p,S_{\mathrm{tot}}).
\end{aligned}
\]
The initial factor \(2^n c\) bounds observed margins and partial contexts. A complete initial-trace and operation-word history determines its literal full state, including \(q\), \(\pi\), and the order-sensitive list \(\Lambda\); no quotient that erases provenance is used in this count. The partition-generating portion of each terminal package has at most \(p=2\{g+hK_{\mathcal G}\}+|\mathcal X_{\mathcal O}|\) quantified-plus-free variable slots and encoding length at most \(s\). Scoped response variables use the same two slots in every package. Concatenating all package formulas with at most one separator or Boolean connective per package has length at most \(S_{\mathrm{tot}}\). The stored value variable \(z\) is not a CAD partition coordinate. The fixed CAD eliminates only the response variables, retains the observed-cell parameters, and uses at most \(\operatorname{CAD}(p,S_{\mathrm{tot}})\) projection, root-isolation, sign-evaluation, and output-cell steps. This is a symbolic bound; exact point specialization is a separate finite sign computation under \(\operatorname{Exact}(P_{\mathrm{obs}})\).
