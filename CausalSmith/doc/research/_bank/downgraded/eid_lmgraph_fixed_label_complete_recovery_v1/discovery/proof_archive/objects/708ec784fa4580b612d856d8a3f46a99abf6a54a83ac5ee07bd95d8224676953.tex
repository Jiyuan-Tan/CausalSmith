On formal input \((\mathcal G,A,Y,\mathbf p)\), first construct the trace-independent base formulas
\[
\exists\theta\,\mathsf C_{\mathcal G}(\theta;\mathbf p)
\quad\text{and}\quad
\mathsf I_{a,y}(\mathcal G;\mathbf p),
\qquad (a,y)\in\mathcal X_A\times\mathcal X_Y,
\]
eliminate only the response variables, and form their single common sign-invariant CAD. This produces the canonical partition \(\mathscr P_{\mathcal G,A,Y}\) before any colored trace is enumerated; its identifying cells retain \(\mathsf V_{a,y}(\mathbf p,z)\), and its negative cells retain \(\mathsf W_j\).

After the canonical partition is fixed, enumerate colored traces solely to discover rational annotations. Start from every observed margin and partial-context trace kernel written as a rational expression in \(\mathbf p\). Recursively branch only by strict ancestral marginalization, restriction to a proper child of a nontrivial district decomposition, a licensed \(\Phi_v^{\lambda}\) update, or a delayed \(\Sigma_{c'}\) update that strictly extends the partial context. Retain the complete operation word and memoize only literal complete tuples \(\kappa=(\mathcal H,F,c,q,\pi,\Lambda)\), including the syntax of \(q\), \(\pi\), and every provenance entry in \(\Lambda\). An adjacent-swap optimization may merge two branches only after replaying both license orders from their common pre-swap state in a fixed canonical order and verifying literal equality of the complete resulting tuples; fixing and selection are never commuted.

For each terminal rational candidate \(r(\mathbf p)=n(\mathbf p)/d(\mathbf p)\), each coordinate \((a,y)\), and each already-constructed identifying cell \(\psi_j\), use real-closed-field elimination to verify both
\[
\forall\mathbf p\,[\psi_j(\mathbf p)\Rightarrow d(\mathbf p)\neq0]
\]
and
\[
\forall\mathbf p\,\forall\theta\,
\bigl[\psi_j(\mathbf p)\wedge\mathsf C_{\mathcal G}(\theta;\mathbf p)
\Rightarrow d(\mathbf p)q_{a,y}(\theta)=n(\mathbf p)\bigr].
\]
Annotate the cell by that rational expression only if both sentences are true. If no candidate validates on the whole cell, retain the unique-value graph; trace validation never refines or changes the canonical cells. The notation \(\operatorname{TCF}(\mathcal G,A,Y,P_{\mathrm{obs}})\) denotes this symbolic partition and its annotations with formal names \(p_o=P_{\mathrm{obs}}(o)\). Numerical cell selection and witness extraction are separate exact-specialization operations. The procedure neither names nor returns a colored hedge.
