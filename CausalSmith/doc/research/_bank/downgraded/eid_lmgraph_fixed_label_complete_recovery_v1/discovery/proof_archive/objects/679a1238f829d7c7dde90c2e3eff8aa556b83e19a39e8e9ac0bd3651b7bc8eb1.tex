On formal input \((\mathcal G,A,Y,\mathbf p)\), enumerate at most \(2^n c\) supported initial observed-trace kernels, indexed by an observed margin and a partial missingness context, each written as a rational expression in \(\mathbf p\). From an initial kernel, every recursive transition is strict: ancestral marginalization or passage to one child of a nontrivial district decomposition strictly decreases the current random-vertex set; a licensed \(\Phi_v^{\lambda}\) update moves one random vertex to the fixed set; and a delayed \(\Sigma_c\) update strictly extends the current partial context. No no-op transition is enumerated. Retain the initial trace and complete operation word, and after every update memoize only the literal complete tuple \((\mathcal H,F,c,q,\pi,\Lambda)\); no quotient may erase \(q\), \(\pi\), or an ordered provenance snapshot. As an optional optimization, when \(\operatorname{Swap}_{\kappa}(u,v)\) holds, return to the common pre-swap state and replay the two licenses in a fixed canonical order. Merge the branches only if the two replayed complete tuples \((\mathcal H,F,c,q,\pi,\Lambda)\) are literally equal; otherwise retain both histories. At each terminal state, append for each \((a,y)\) one package containing the feasible-projection and constancy formulas in the free coordinates \(\mathbf p\), together with the stored relation \(\mathsf V_{a,y}(\mathbf p,z)\) or \(\mathsf W_j(\mathbf p,a,y,\theta^0,\theta^1)\). One common signed-subresultant CAD refines only the concatenated partition-generating formulas in \(\mathbf p\) into \(\mathscr P_{\mathcal G,A,Y}\); scoped response-variable names are reused across packages, and the stored value and witness relations do not add partition coordinates. An identifying cell carries either a rational trace expression verified against its unique-value relation or that unique-value graph itself; a negative cell carries \(\mathsf W_j\). The notation \(\operatorname{TCF}(\mathcal G,A,Y,P_{\mathrm{obs}})\) denotes this symbolic object with formal names \(p_o=P_{\mathrm{obs}}(o)\); selecting a numerical cell is the separate exact specialization. The procedure neither names nor returns a colored hedge.
