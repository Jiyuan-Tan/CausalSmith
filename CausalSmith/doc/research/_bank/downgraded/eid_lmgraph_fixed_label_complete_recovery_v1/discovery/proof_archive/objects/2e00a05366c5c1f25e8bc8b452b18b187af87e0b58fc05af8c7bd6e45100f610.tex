Given an exact specialized witness \(\omega=(a,y,\theta^0,\theta^1)\) and any associated finite colored-recursion trace \(\mathcal T\), first decode \(\theta^0,\theta^1\) through their selected tables and independent factor weights to obtain \(\mathcal M_0,\mathcal M_1\). Then scan \(\mathcal T\) in a fixed prefix order. At each prefix, test the finite graphical and trace-polynomial predicates appearing in the definition of \(\Delta(\omega,\mathcal T)\), clearing only denominators whose support is recorded in that trace. If a qualifying record exists, choose the first one, perform the stated ancestor pruning and edge coloring, and return \((\mathtt{candidate},H,\mathcal M_0,\mathcal M_1)\). If none exists, return \((\mathtt{no\mbox{-}colored\mbox{-}record},\mathcal M_0,\mathcal M_1)\). This scan is a partial diagnostic: the construction does not assert that a candidate belongs to \(\operatorname{CH}(\mathcal G,A,Y)\), that the decoded models realize it, or that a qualifying record exists whenever the response fiber is non-singleton.
