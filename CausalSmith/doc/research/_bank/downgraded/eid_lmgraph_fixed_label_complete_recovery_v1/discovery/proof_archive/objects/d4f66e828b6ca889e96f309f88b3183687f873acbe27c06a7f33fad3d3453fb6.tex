Fix \(\mathcal M\in\mathfrak M_{+}^{\mathrm{rm}}(\mathcal G_\star)\).  Apply \(\text{lem:eipfd-frontdoor-identification}\) with \(H=\{C\}\) and \(m=1\).  Membership in the displayed positive class supplies the lemma's strict-positivity premise, so every conditioning event in the following finite sums has a positive denominator.  The lemma gives
\[
\begin{aligned}
Q_a^{\mathcal M}(y)
&=\sum_{c\in\mathcal X_C}P_{\mathrm{obs}}(c)
\sum_{b\in\mathcal X_{B_1}}P_{\mathrm{obs}}(b\mid a,c,R_W=0)\\
&\qquad\times\sum_{a'\in\mathcal X_A}
P_{\mathrm{obs}}(y\mid b,a',c,R_W=0)
P_{\mathrm{obs}}(a'\mid c,R_W=0)\\
&=f_a^\star(P_{\mathrm{obs}})(y),
\end{aligned}
\tag{1}
\]
where the last equality is \(\text{def:eipfd-star-functional}\).  The derivation encoded by that definition first records the interventional kernel conditional on \(R_W\), then selects \(R_W=0\), applies front-door adjustment through \(B_1\) conditional on \(C\), and finally averages against the unselected marginal \(P_{\mathrm{obs}}(C)\).  Thus (1) proves both the functional and its stated operation order.

We next check the two comparator premises.  By \(\text{def:endogenous-proxy-frontdoor-class}\), the edge \(A\leftrightarrow Y\) occurs in \(\mathcal G_\star\).  Deleting directed arrows out of \(A\) does not delete this bidirected edge, so in every candidate \(\mathcal H_r[\underline A]\) the length-one path \(A\leftrightarrow Y\) remains open.  It has no nonendpoint at which an admissible set can block it.  Therefore condition \(\mathrm{(v)}\) in \(\text{def:da4-certificate-functional}\) fails for every candidate certificate, and
\[
\operatorname{DA4}(\mathcal G_\star,A,Y)=\varnothing.
\tag{2}
\]
The same graph contains \(C\to R_W\), while \(R_W\) is the context variable of the label on \(W\to A\).  Hence that context variable is not parentless, so the root premise in \(\text{def:root-control-functional}\) fails:
\[
\neg\operatorname{RC}(\mathcal G_\star,A,Y).
\tag{3}
\]

The right side of (1) depends only on \(P_{\mathrm{obs}}\) and equals the causal coordinate for every model in its fiber.  Hence the coordinate is constant on the fiber.  By \(\text{lem:semialgebraic-fiber-dichotomy}\), the unique TCF coordinate cell is identifying, and by \(\text{thm:tcf-soundness}\) its carried value is the common value in (1).  Together, (1)--(3) prove every assertion.
