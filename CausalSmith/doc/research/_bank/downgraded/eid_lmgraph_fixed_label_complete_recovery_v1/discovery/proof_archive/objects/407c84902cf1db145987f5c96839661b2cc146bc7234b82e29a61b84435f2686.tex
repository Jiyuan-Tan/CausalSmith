On formal input \((\mathcal G,A,Y,\mathbf p)\), first construct the response-polynomial feasibility formula \(\exists\theta\,\mathsf C_{\mathcal G}(\theta;\mathbf p)\) and the coordinate-constancy formulas \(\mathsf I_{a,y}(\mathcal G;\mathbf p)\) for all \((a,y)\). Run one common signed-subresultant CAD on this base family alone, retaining \(\mathbf p\), to obtain the canonical cells \(\psi_j\) and their unique-value or witness relations. This base partition is independent of every fixing trace.

After the base cells have been fixed, enumerate expression-discovery traces. Start from every supported observed margin and partial-context trace kernel written as a rational expression in \(\mathbf p\). Recursively branch only by strict ancestral marginalization, restriction to a proper child of a nontrivial district decomposition, a licensed \(\Phi_v^{\lambda}\) update, or a delayed \(\Sigma_{c'}\) update that strictly extends the partial context. Retain the complete operation word and memoize only literal complete tuples \(\kappa=(\mathcal H,F,c,q,\pi,\Lambda)\), including the syntax of \(q\), \(\pi\), and every provenance entry in \(\Lambda\). An adjacent-swap optimization may merge branches only after replaying both license orders from their common pre-swap state in a fixed canonical order and verifying literal equality of the complete resulting tuples. Fixing and selection are never commuted.

For a candidate trace expression \(r(\mathbf p)=N(\mathbf p)/D(\mathbf p)\), a base cell \(\psi_j\), and a coordinate \((a,y)\) whose cell relation is unique, use real-closed-field quantifier elimination to decide the whole-cell implication
\[
\forall\mathbf p\,\forall z\,
\left[
\psi_j(\mathbf p)\wedge\mathsf V_{a,y}(\mathbf p,z)
\ \Longrightarrow\ D(\mathbf p)\neq0\ \wedge\ D(\mathbf p)z=N(\mathbf p)
\right].
\]
Annotate \(\psi_j\) by \(r\) only if this implication is true. If no candidate passes, retain the unique-value graph \(\mathsf V_{a,y}\); on a nonconstant cell retain \(\mathsf W_j\). Trace enumeration and annotation never split, merge, or otherwise alter the base CAD cells.
