Apply \(\text{lem:eipfd-frontdoor-identification}\) with \(H=\{C\}\) and \(m=1\). Proxy consistency changes each probability on its right-hand side to the corresponding observed-law probability, and the resulting expression is exactly the construction of \(f_a^\star\). This proves the displayed causal equality for every model in the observed-law fiber. The trace order is the one used in that lemma: the intervention kernel is retained before \(R_W=0\) is selected, the ordinary front-door steps are applied in the selected graph, and the outer weight remains the unselected marginal \(P_{\mathrm{obs}}(C)\).

For the de Aguas certificate, condition \(\mathrm{(v)}\) requires \(A\) and \(Y\) to be d-separated in the graph with outgoing arrows from \(A\) removed, conditional only on variables that exclude the endpoints. The edge \(A\leftrightarrow Y\) remains in every such graph and is an open length-one path; no conditioning on a third vertex blocks it. Hence every proposed certificate fails condition \(\mathrm{(v)}\). The root-control certificate requires every context variable to be parentless, whereas \(C\to R_W\) is an arrow into the context variable. Thus that certificate also fails. Finally, the proved observed functional is constant over the whole fiber, so \(\text{lem:semialgebraic-fiber-dichotomy}\) places every compatible law on an identifying cell, and \(\text{thm:tcf-soundness}\) shows that its value is \(f_a^\star\).
