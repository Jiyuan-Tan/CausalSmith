For an instance in \(\mathfrak I_{\mathrm{CTFTR}}\), map every observational or atomic hard-interventional descriptor to the identical DCTFTR descriptor, retaining the graph, domain labels, declared alphabets, supplied cell laws, and causal query. The restriction defining \(\mathfrak I_{\mathrm{CTFTR}}\) excludes every constructor not representable in the DCTFTR grammar, so this map is well typed. It is injective because all retained fields and descriptors can be read back unchanged.

The embedding is proper. In \(\mathfrak I_{\mathrm{bin}}\), the supplied quantity
\[
p=P^s(Y_0=1,Y_1=1)\tag{1}
\]
is a joint two-world response cell. It is admitted by the declared partial-copy grammar, but it is neither observational nor an atomic hard-interventional distribution; hence it is outside the stated CTFTR restriction.

For an instance in \(\mathfrak I_{\mathrm{CTFIDU+}}\), set
\(\mathcal S=\{\star\}\) and apply the constructor map required in the definition of that intersection. Again the map is injective and type preserving because the intersection contains exactly the actions for which this declared conversion exists. It is proper because the binary instance has two domains and satisfies
\[
P^\star(Z=1)=0,\qquad P^s(Z=1)=1.\tag{2}
\]
One SCM cannot induce both marginal laws in (2), so this instance is not in the one-SCM image.

On the first embedded restriction, published CTFTR soundness and DCTFTR recursion soundness show that every successful expression from either calculus equals the same transported causal query in every compatible model. The corresponding conclusion on the second restriction follows from published CTFIDU+ soundness and DCTFTR recursion soundness. Equality through the common semantic query does not imply equality of syntax or transition traces. Since conditional and stochastic-policy CTFTR constructors and undeclared Layer-2.5 CTFIDU+ actions were excluded from the two source-class definitions, the proof makes no claim about them.
