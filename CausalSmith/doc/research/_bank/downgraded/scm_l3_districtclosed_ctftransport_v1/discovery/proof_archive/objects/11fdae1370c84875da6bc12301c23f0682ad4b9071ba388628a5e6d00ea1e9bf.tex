For every transport-admissible complete supplied cell \(C_{a,v}\) whose exhaustive support check is local to \(D\), set
\[
r^{\mathrm{raw}}_{s,a,D,v}(\omega_D)=\mathbf1\{C_{a,v}(\omega_D,\omega_{-D}^0)\}.
\]
For an accepted \(\mathsf{RowEligible}_{s,a,D}(h,c)\), set
\[
u_{s,a,D,h,c}=\operatorname{row}_D(A_{h,c}),\qquad
v_{s,a,D,h}=\operatorname{row}_D(H_h),\qquad
r_{s,a,D,h,c}=u_{s,a,D,h,c}.
\]
All these rows lie in \(\{0,1\}^{\Omega_D}\).  The last equality only preserves the generic incidence-row name; it does not assert that the conditional kernel equals a linear response-law functional.
