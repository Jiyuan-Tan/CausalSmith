Put \(J=D\cap\Delta_s\) and \(I=D\setminus\Delta_s\).  The displayed
partial-selection hypothesis gives
\[
J\ne\varnothing,
\qquad
I\ne\varnothing,
\qquad
D\cap\Delta_s\ne\varnothing.
\]
The last inequality makes the antecedent in district-kernel invariance false
for the pair \((s,D)\).  Thus, after district closure is omitted, that
assumption yields no equation between \(q_D^s\) and \(q_D^\star\).  In
particular, neither equality of the full district response law nor equality
of a marginal response law on \(I\) follows from the frozen graph-only
assumptions.

We first give a paired-model certificate for an arbitrary nonconstant binary
row.  Let \(\ell:\Omega_D\to\{0,1\}\) be nonconstant.  By nonconstancy there
are \(\omega_0,\omega_1\in\Omega_D\) such that
\[
\ell(\omega_0)=0,
\qquad
\ell(\omega_1)=1.
\]
For \(i\in\{0,1\}\), we construct a source-labelled family
\(\mathbf M^{(i)}\).  In the partially selected source and in the target set
\[
q_D^{s,(i)}=\delta_{\omega_0},
\qquad
q_D^{\star,(i)}=\delta_{\omega_i}.
\tag{1}
\]
For every additional domain \(t\notin\{s,\star\}\), set
\[
q_D^{t,(i)}=
\begin{cases}
\delta_{\omega_i},&D\cap\Delta_t=\varnothing,\\
\delta_{\omega_0},&D\cap\Delta_t\ne\varnothing.
\end{cases}
\tag{2}
\]
Equation \((2)\) copies the target law precisely in every domain for which
district-kernel invariance has a true antecedent.  For each district
\(D'\ne D\), choose one deterministic response profile
\(\bar\omega_{D'}\) and use \(\delta_{\bar\omega_{D'}}\) in every domain and
in both families.

It remains to verify that these probability vectors are realized on the
declared state spaces rather than on enlarged alphabets.  By the canonical
district-response-profile definition, every coordinate of
\(\omega_i\) is a deterministic structural response map with codomain
\(\mathcal X_V\).  For a parent configuration not visited by the target or
menu, choose a fixed element \(x_V^\circ\in\mathcal X_V\), which exists
because every declared alphabet is nonempty, and extend the response map by
the value \(x_V^\circ\).  Use these completed deterministic tables as the
structural equations.  Give every exogenous variable a one-point law.  Since
\(G\) is acyclic, recursive evaluation in a topological order defines a
finite SCM; since every table uses only graph-allowed parents and has values
in \(\mathcal X_V\), recursive compatibility holds.  The exogenous response
blocks are degenerate, hence their joint law is the product of their
marginals, so district factorization holds.  The common choices outside
\(D\), together with \((2)\), verify every instance of district-kernel
invariance whose antecedent is true.  Its antecedent is false for \((s,D)\),
as observed above.  Thus both \(\mathbf M^{(0)}\) and
\(\mathbf M^{(1)}\) satisfy all retained frozen assumptions on the original
alphabets.

The source SCMs in the two families are identical, not merely
observationally equivalent:
\[
M^{s,(0)}=M^{s,(1)}.
\tag{3}
\]
Consequently every observational, interventional, or declared partial-copy
law supplied from this source is identical in the two families.  In
particular, for the source-row-only information configuration in the
statement,
\[
\sum_{\omega\in\Omega_D}
 \ell(\omega)q_D^{s,(0)}(\omega)
=
\sum_{\omega\in\Omega_D}
 \ell(\omega)q_D^{s,(1)}(\omega)
=\ell(\omega_0)=0.
\tag{4}
\]
No target-domain law, nor a law from an additional wholly unselected source
that would copy the target district law by district-kernel invariance, is
part of a source-row-only information configuration.  Such extra information
would be an additional statistical premise rather than a graph-only
replacement for district closure.

By contrast, the two target row values are
\[
\begin{aligned}
\sum_{\omega\in\Omega_D}
 \ell(\omega)q_D^{\star,(0)}(\omega)
 &=\ell(\omega_0)=0,\\
\sum_{\omega\in\Omega_D}
 \ell(\omega)q_D^{\star,(1)}(\omega)
 &=\ell(\omega_1)=1.
\end{aligned}
\tag{5}
\]
Equations \((3)\)--\((5)\) are the required same-source-law,
different-target certificate.  Conversely, if \(\ell\equiv c\) is constant,
then for every probability law \(q\in\Delta(\Omega_D)\), normalization gives
\[
\sum_{\omega\in\Omega_D}\ell(\omega)q(\omega)
=c\sum_{\omega\in\Omega_D}q(\omega)
=c.
\tag{6}
\]
Hence every constant row transports, while \((1)\)--\((5)\) refute universal
transport of every nonconstant row.  This proves that, from a source row
alone, the universally transportable rows are exactly the constant rows.

We next prove the asserted characterization under the additional marginal
invariance premise.  Let
\[
\pi_I:\Omega_D\longrightarrow\pi_I(\Omega_D)
\]
be coordinate restriction to the complete response maps of vertices in
\(I\), and assume
\[
(\pi_I)_\#q_D^s=(\pi_I)_\#q_D^\star.
\tag{7}
\]
Suppose first that \(\ell\) is constant on every fiber of \(\pi_I\).  Then
the rule
\[
\widetilde\ell(u)=\ell(\omega)
\quad\text{for any }\omega\text{ with }\pi_I(\omega)=u
\]
is well defined on \(\pi_I(\Omega_D)\), and
\(\ell=\widetilde\ell\circ\pi_I\).  Grouping the finite sum by fibers and
then using \((7)\) yields
\[
\begin{aligned}
\sum_{\omega\in\Omega_D}\ell(\omega)q_D^s(\omega)
&=\sum_{u\in\pi_I(\Omega_D)}
 \widetilde\ell(u)(\pi_I)_\#q_D^s(u)\\
&=\sum_{u\in\pi_I(\Omega_D)}
 \widetilde\ell(u)(\pi_I)_\#q_D^\star(u)\\
&=\sum_{\omega\in\Omega_D}\ell(\omega)q_D^\star(\omega).
\end{aligned}
\tag{8}
\]
Thus fiber constancy is sufficient.

For necessity, suppose that \(\ell\) is not constant on the fibers.  Then
there are \(\omega_0,\omega_1\in\Omega_D\) with
\[
\pi_I(\omega_0)=\pi_I(\omega_1),
\qquad
\ell(\omega_0)\ne\ell(\omega_1).
\tag{9}
\]
Set the source and target district laws to
\(q_D^s=\delta_{\omega_0}\) and
\(q_D^\star=\delta_{\omega_1}\), and complete the SCM exactly as in
\((1)\)--\((2)\).  Because the two profiles in \((9)\) have identical
response maps on \(I\), this construction satisfies the added premise:
\[
(\pi_I)_\#\delta_{\omega_0}
=\delta_{\pi_I(\omega_0)}
=\delta_{\pi_I(\omega_1)}
=(\pi_I)_\#\delta_{\omega_1}.
\tag{10}
\]
Nevertheless its source and target row values are respectively
\(\ell(\omega_0)\) and \(\ell(\omega_1)\), which differ by \((9)\).
Therefore a row that transports for every compatible pair must be constant
on every projection fiber.  Together with \((8)\), this proves the
if-and-only-if claim.

The characterization is computable because \(\Omega_D\) is finite.  Enumerate
all ordered pairs \((\omega,\omega')\in\Omega_D^2\); reject and return the
pair as a leakage certificate exactly when
\[
\pi_I(\omega)=\pi_I(\omega')
\quad\text{and}\quad
\ell(\omega)\ne\ell(\omega').
\tag{11}
\]
If no pair is returned, the exhaustive test proves fiber constancy; if a
pair is returned, equations \((9)\)--\((10)\) give the promised two-point
original-alphabet certificate.

As a smallest exact stress check, take the binary two-vertex ADMG
\(X\leftrightarrow Y\), let \(D=\{X,Y\}\), and let
\(\Delta_s=\{X\}\).  With no directed parents, use the profiles
\(\omega_0=(X=0,Y=0)\) and \(\omega_1=(X=1,Y=0)\), and the row
\(\ell(\omega)=\mathbf 1\{X(\omega)=1\}\).  The two source laws are both
\(\delta_{\omega_0}\), whereas the target laws
\(\delta_{\omega_0}\) and \(\delta_{\omega_1}\) give row values \(0\) and
\(1\).  They also have the same \(I=\{Y\}\) marginal, so this is the
two-point failure certificate for a non-fiber-constant row.  Restoring
district closure excludes this partial selection set because neither
\(D\subseteq\Delta_s\) nor \(D\cap\Delta_s=\varnothing\) holds.  This check
also confirms that district closure is load-bearing for the graph-only
transport claim.
