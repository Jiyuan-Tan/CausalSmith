The rational fast path has a unique finite run by recursion soundness.  If it returns \(\operatorname{ID}\), relabelling it \(\operatorname{ID\_RAT}\) preserves its derivation, and recursion soundness proves both \(F\in\mathscr R(\mathcal P)\) and equality with the causal query throughout \(\mathcal C(\mathcal P)\).  If it certifies an identically zero evidence denominator, the relabelled zero-evidence terminal is sound.  Every other fast-path failure triggers, rather than terminates, the canonical phase.

By exact global canonical frontier, nonempty \(\mathcal C(\mathcal P)\) implies that \(S=\Theta_G^{\mathrm{can}}(\mathcal P)\) is a nonempty compact semialgebraic set and that its target-cell ranges equal the ranges over compatible SCMs.  All defining polynomials have rational coefficients except for the supplied cell values, which are effectively real algebraic by hypothesis.

We first adapt effective cylindrical decomposition to exact optimization on this particular fiber.  For polynomials \(p,q\) with \(q>0\) on \(S\), form the first-order formula
\[
\varphi_{p/q}(t)\;\Longleftrightarrow\;
\exists x\,[x\in S\ \wedge\ q(x)>0\ \wedge\ q(x)t-p(x)=0].
\tag{1}
\]
The cited cylindrical decomposition result terminates, eliminates \(x\), and returns an exact sign-cell description of the image \(I_{p/q}=\{p(x)/q(x):x\in S\}\).  Compactness of \(S\) and positivity of \(q\) make this image compact.  Its least and greatest cells are therefore closed point cells, each represented by an isolated real-algebraic root of a projection polynomial.  Lifting those two cells through the existential formula in (1) returns algebraic samples \(x_-,x_+\in S\) attaining the endpoints.  Projection polynomials, sign tables, isolating intervals, and the lifted samples constitute the advertised independently checkable certificate.  Equality, strict inequality, and positivity of all resulting algebraic values are decided by the same exact sign calculus.

For an unconditional target, use (1) with \(p=\Phi_{T,\mathrm{can}}^\star\) and \(q=1\).  Let the attained extrema be \(L\leq U\).  Exactly one of \(L=U\) and \(L<U\) holds.  If \(L=U\), exact range equality makes the target constant on \(\mathcal C(\mathcal P)\), so \(\operatorname{ID\_CAN}(L,\zeta)\) is sound.  Conversely, identification forces every compatible value, hence both extrema, to agree.  If \(L<U\), the returned parameters \(\vartheta_-\) and \(\vartheta_+\) attain those values.  The canonical realization direction of the frontier theorem converts them into two compatible SCM families on the original observed alphabets with identical supplied laws and unequal target probabilities.  This proves both soundness and exhaustiveness for the unconditional branch.

For a conditional query, apply the same procedure first to the nonnegative polynomial \(D(\vartheta)=\Phi_{E,\mathrm{can}}^\star(\vartheta^\star)\), obtaining attained extrema \(0\leq e_-\leq e_+\).  If \(e_+=0\), nonnegativity implies \(D=0\) throughout the fiber, so the conditional is nowhere defined.  If \(e_-=0<e_+\), endpoint samples give \(\vartheta_0,\vartheta_+\) with \(D(\vartheta_0)=0\) and \(D(\vartheta_+)>0\); canonical realization gives the claimed original-alphabet witnesses, and no functional can represent a conditional on the entire fiber because its causal target is undefined at the first witness.

The remaining case is \(e_->0\).  This strict inequality is the required uniform positivity certificate.  Set
\[
N(\vartheta)=\Phi_{B_\rho\cap E,\mathrm{can}}^\star(\vartheta^\star).
\]
Using (1) with \(p=N\) and \(q=D\) returns attained algebraic extrema \(L_Q\leq U_Q\).  Exact canonical range equality identifies this ratio with \(P_{M^\star}(B_\rho\mid E)\) for every compatible realization.  Thus \(L_Q=U_Q\) is equivalent to identification and yields \(\operatorname{ID\_CAN}\); if \(L_Q<U_Q\), endpoint parameters yield two original-alphabet same-menu SCM families with unequal conditional values and hence a sound \(\operatorname{PAIR\_CAN}\) terminal.

The cases \(e_+=0\), \(e_-=0<e_+\), and \(e_->0\) are mutually exclusive and exhaustive because \(0\leq e_-\leq e_+\).  In the last case, equality or strict inequality of the ratio extrema is likewise exhaustive.
