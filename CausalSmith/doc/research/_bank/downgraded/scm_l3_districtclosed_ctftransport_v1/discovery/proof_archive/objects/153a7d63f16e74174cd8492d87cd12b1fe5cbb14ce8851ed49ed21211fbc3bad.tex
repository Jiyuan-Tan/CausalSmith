For each complete supplied cell \(C_{a,v}\) in domain \(s\), first prove transport admissibility, namely \(s=\star\) or \(D\cap\Delta_s=\varnothing\).  If recursive evaluation of \(C_{a,v}\) depends only on \(\omega_D\), retain the raw row
\[
r^{\mathrm{raw}}_{s,a,D,v}(\omega_D)
=\mathbf 1\{C_{a,v}\text{ is true under }\omega_D\}
\]
with value \(P_a^s(v)\).  Next, for every successful extraction with the same admissibility proof, retain a conditional cell only when its derivation contains
\(\operatorname{ROW\_ELIGIBLE}(h,c;u_{h,c},v_h,N_{h,c},H_h,\delta_N,\delta_H,\pi_H)\).  In that case retain the two literal linear equalities
\[
u_{h,c}^{\mathsf T}q_D^\star=N_{h,c},
\qquad
v_h^{\mathsf T}q_D^\star=H_h,
\]
and never stack the quotient \(K_{s,a,D}(c\mid h)=N_{h,c}/H_h\) as a row value.  Prepend \(\mathbf 1^{\mathsf T}q_D^\star=1\), canonically de-duplicate identical row--value pairs, and stack all retained raw, numerator, and context rows into \(A_D\), with the corresponding values stacked into \(m_D\).  Failed extraction, failed row eligibility, a changed-district source cell, and a cross-district cell create no local row.  Their complete supplied-cell equalities remain in \(\Theta(\mathcal P)\) or \(\Theta_G^{\mathrm{can}}(\mathcal P)\); failure of a derived extraction never deletes an independently certified raw district-local row.
