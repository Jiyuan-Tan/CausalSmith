The finite extraction calculus has event syntax
\[
\mathsf{XEvent}::=\operatorname{Cell}(s,a,y)\mid\top\mid\bot\mid
\neg\mathsf{XEvent}\mid\bigsqcup_{j\in J}\mathsf{XEvent}_j
\mid\operatorname{Fix}(\mathsf{FixTrace},\mathsf{XEvent}),
\]
where \(J\) is finite and the disjoint-union constructor carries a pointwise disjointness table.  If \(a\) is a postprocessed descriptor with base returned tuple \(T_a\), then
\[
\operatorname{Cell}(s,a,y)=\bigsqcup_{t:f_a(t)=y}\{T_a=t\};
\]
this is a definitional preimage expansion, not an additional causal assumption or an additional supplied law.  Menu expressions have syntax
\[
\mathsf{XExpr}::=\operatorname{CellProb}(s,a,y)\mid\operatorname{Rat}(r)
\mid\sum_{j\in J}\mathsf{XExpr}_j\mid\mathsf{XExpr}-\mathsf{XExpr}
\mid\prod_{j\in J}\mathsf{XExpr}_j
\mid\operatorname{Quot}(F,H,\pi_H),
\]
where \(r\in\mathbb Q\) and \(\pi_H\) is a separately checkable strict-positivity certificate on its declared compatibility fiber.  A derivation \(\delta:A\Downarrow F\) is generated only by source-cell lookup, deterministic-preimage expansion, finite disjoint additivity or marginalization, complementation from the sure event, and a fixing constructor.  A fixing constructor records all finite response-profile sums before and after fixing, every quotient and its positivity certificate, and a cleared-denominator polynomial identity checked coefficient by coefficient; it contains no field asserting the semantic equality it is meant to prove.

For an event \(A\) and district \(D\), \(\operatorname{SupportLocal}_D(A)\) enumerates the finite table
\[
(\omega_D,\omega_{-D})\longmapsto
\mathbf 1\{A\text{ is true under recursive evaluation of }(\omega_D,\omega_{-D})\}.
\]
It accepts exactly when every two entries with the same \(\omega_D\) agree, and then returns the row \(\operatorname{row}_D(A)\in\{0,1\}^{\Omega_D}\) consisting of that common value.  Otherwise it returns a displayed disagreeing pair.  All syntax trees, tables, rational identities, and searches are finite and canonically ordered.
