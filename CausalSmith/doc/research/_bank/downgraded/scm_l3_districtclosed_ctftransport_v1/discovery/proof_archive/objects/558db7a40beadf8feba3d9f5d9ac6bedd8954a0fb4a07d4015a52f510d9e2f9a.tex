Initialize roots \(\operatorname{Raw}(\mathrm{num},B_\rho\cap E)\) and \(\operatorname{Raw}(\mathrm{den},E)\).  Apply the following deterministic priority rules to the least applicable node.  \(\mathsf{NORM}\) computes checked disjoint normal form.  \(\mathsf{ANCESTOR}\) inserts the checked complete-alphabet marginalization over omitted ancestors.  \(\mathsf{SPLIT}\) enumerates full response tuples over the original districts \(\mathcal D(G)\), compiles the exact sum of products in \(\mathrm{def:dctftr\text{-}grammar}\), and creates a local leaf only when \(\mathsf{Local}_D(C)\) accepts; otherwise it returns the typed nonlocal split failure.  \(\mathsf{EXTRACT}\) enumerates supplied complete cells, accepts a raw row only after transport admissibility and exhaustive support locality, accepts derived information only through \(\mathsf{RowEligible}\), and stacks \((u,N)\) and \((v,H)\) separately.  It never stacks \(N/H\), substitutes an unproved kernel identity, or suppresses nonfocal context.  Its certificate \(\kappa_{\mathrm{all}}\) literally verifies every row of \(A_Dq_D^\star=m_D\).

\(\mathsf{FACE\_ID}\) computes \(Z_D(m_D)\) by exact linear programming and accepts only a decomposition
\[
b_D=\lambda^{\mathsf T}A_D+
\sum_{\omega\in Z_D(m_D)}\zeta_\omega e_\omega,
\]
then resolves the node to \(\lambda^{\mathsf T}m_D\).  A failed membership test returns only a local row-face witness.  \(\mathsf{MARGINALIZE}\) and \(\mathsf{PRODUCT}\) combine ready resolved children, the latter only according to the original-district split.  \(\mathsf{CONDITION}\) returns \(\operatorname{ZERO\_EVIDENCE}\) under an independently checked uniform zero certificate, returns \(\operatorname{ID}(F_B/F_E)\) only under an independently checked uniform strict-positivity certificate for \(F_E\), and otherwise returns the appropriate zero witness or positivity-uncertified failure without division.

Priority is \(\mathsf{NORM}>\mathsf{ANCESTOR}>\mathsf{SPLIT}>\mathsf{EXTRACT}>\mathsf{FACE\_ID}>\mathsf{MARGINALIZE}>\mathsf{PRODUCT}>\mathsf{CONDITION}\).  The first seven rules decrease the corresponding first changeable coordinate of \(\operatorname{rank}_{\mathrm{lex}}\), and condition decreases its last flag.  Every partial-operation rejection has an explicit failure branch.
