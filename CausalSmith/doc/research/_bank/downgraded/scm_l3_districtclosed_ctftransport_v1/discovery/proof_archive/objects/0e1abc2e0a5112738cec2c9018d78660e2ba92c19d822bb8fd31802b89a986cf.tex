Initialize one finite acyclic work DAG with roots \(\operatorname{Raw}(\mathrm{num},B_\rho\wedge E)\) and \(\operatorname{Raw}(\mathrm{den},E)\); its denotation at \(\mathbf M\in\mathcal C(\mathcal P)\) is \((P_{M^\star}(B_\rho\wedge E),P_{M^\star}(E))\). The deterministic transition system \(\mathsf{DCTFTR}\) has these eight rules. \(\mathsf{NORM}\): replace the least \(\operatorname{Raw}(\tau,e)\) by \(\operatorname{Normed}(\tau,\operatorname{nf}(e),\nu)\), where the total finite-state checker applies consistency, unnesting, contradiction removal, and disjoint-normal-form rewriting and returns a derivation \(\nu:P(e)=P(\operatorname{nf}(e))\); append \(\operatorname{NORM}(v,e,\operatorname{nf}(e),\nu)\). \(\mathsf{ANCESTOR}\): for the least normalized node, enumerate its counterfactual ancestors \(H\), the assignments summed out, and a checked finite marginalization derivation \(\alpha\), then replace it by \(\operatorname{AncClosed}(\tau,H,e|_H,\alpha)\) and append \(\operatorname{ANCESTOR}(v,H,\alpha)\). \(\mathsf{SPLIT}\): for the least ancestor-closed node, the compiler mechanically enumerates \(G[H]\), its districts, and all finite summation assignments and builds an acyclic sum-product DAG with leaves \(\operatorname{NeedRows}(\tau,D,b)\); its checker constructs \(\sigma\) from finite marginalization and district-factorization rules, the DAG is spliced in, and \(\operatorname{SPLIT}(v,D_1,\ldots,D_k,\sigma)\) is appended. If enumeration or typing is undefined, return \(\operatorname{FAIL}(\operatorname{SPLIT\_UNDEFINED}(v,\mathrm{reason},t))\). \(\mathsf{EXTRACT}\): at the least \(\operatorname{NeedRows}(\tau,D,b)\), enumerate all supplied \((s,a)\) and their complete cells canonically.  After a checked proof of \(s=\star\) or \(D\cap\Delta_s=\varnothing\), first retain every complete cell whose recursive indicator visits only \(D\) as the raw equality \(P_a^s(v)=r^{\mathrm{raw}}_{s,a,D,v}q_D^\star\).  Then retain a derived context and cell only when \(\operatorname{Extract}_{s,a,D}(P_a^s)\Downarrow(K_{s,a,D},\kappa)\) succeeds with the same admissibility proof; the recomputed extraction tree must prove \(K_{s,a,D}(c\mid h)=r_{s,a,D,h,c}q_D^\star\). Record every failed derived extraction, changed-district rejection, and cross-district raw cell without turning it into a district row. Prepend the normalization row, stack accepted raw and derived rows and values canonically as \((A_D,m_D)\), even if no non-normalization row survives, replace the node by \(\operatorname{NeedFace}(\tau,D,b,A_D,m_D,Z_D(m_D),\kappa_{\mathrm{all}})\), and append the accepted rows, rejected candidates, admissibility proofs, and derivations; \(\kappa_{\mathrm{all}}\) checks \(A_Dq_D^\star=m_D\). \(\mathsf{FACE\_ID}\): for the least face node, compute \(Z=\{\omega:q(\omega)=0\text{ for every }q\ge0\text{ with }Aq=m\}\), with an exact LP or Farkas certificate for every coordinate, and test \(b\in\operatorname{row}(A)+\operatorname{span}\{e_\omega:\omega\in Z\}\). If membership holds, fixed-pivot reduced row echelon form chooses \(b=\lambda^\top A+\sum_{\omega\in Z}\zeta_\omega e_\omega\); replace the node by \(\operatorname{Resolved}(\lambda^\top m,\delta_{\mathrm{face}})\), where the checker verifies \(bq=\lambda^\top Aq+\sum_{\omega\in Z}\zeta_\omega q(\omega)=\lambda^\top m\), and append the certificates. If membership fails, return \(\operatorname{FAIL}(\operatorname{FACE\_NOT\_IDENTIFIED}(D,b,A,m,Z,w_{\mathrm{local}},t))\); \(w_{\mathrm{local}}\) witnesses only variation in the district row relaxation.  It is not a pair of globally compatible SCMs unless district saturation and the district-separated one-district projection hypotheses have been checked. If no non-normalization raw or derived row succeeded, use \(\operatorname{NO\_ADMISSIBLE\_FACTOR}\) instead only after this normalization-only face test fails. \(\mathsf{MARGINALIZE}\): replace the least ready \(\operatorname{Sum}(J,\mathrm{children})\), all of whose children are resolved, by \(\operatorname{Resolved}(\sum_{j\in J}F_j,\delta_{\mathrm{sum}})\), using finite additivity and child derivations. \(\mathsf{PRODUCT}\): replace the least ready product node by \(\operatorname{Resolved}(\prod_jF_j,\delta_{\mathrm{prod}})\), using district factorization and child derivations. \(\mathsf{CONDITION}\): when both roots are \(\operatorname{Resolved}(F_B,\delta_B)\) and \(\operatorname{Resolved}(F_E,\delta_E)\), append a condition record and return \(\operatorname{ZERO\_EVIDENCE}(F_E,z)\) if the independent zero calculus proves \(F_E=0\) throughout \(\mathcal C(\mathcal P)\); return \(\operatorname{ID}(\operatorname{Quot}(F_B,F_E,\pi),\delta_B,\delta_E,\pi)\) if the independent positivity calculus proves \(F_E>0\) throughout that fiber; return \(\operatorname{FAIL}(\operatorname{DENOMINATOR\_MAY\_VANISH}(E,\mathbf M,t))\) if an explicitly checked \(\mathbf M\in\mathcal C(\mathcal P)\) has \(F_E=0\); otherwise return \(\operatorname{FAIL}(\operatorname{DENOMINATOR\_POSITIVITY\_UNCERTIFIED}(E,t))\). Rule priority is \(\mathsf{NORM}>\mathsf{ANCESTOR}>\mathsf{SPLIT}>\mathsf{EXTRACT}>\mathsf{FACE\_ID}>\mathsf{MARGINALIZE}>\mathsf{PRODUCT}>\mathsf{CONDITION}\); within a rule choose the least applicable node, where applicability includes readiness. No rule creates an earlier-phase node. For nonterminals, \(\operatorname{rank}_{\mathrm{lex}}=(r_N,r_A,r_S,r_X,r_F,r_{\Sigma},r_{\Pi},r_C)\): the rules respectively decrease the indicated first still-changeable coordinate, with \(\mathsf{CONDITION}\) changing \(r_C=1\) to zero after the first seven coordinates vanish; later coordinates may increase. If no rule applies to a nonterminal, return \(\operatorname{FAIL}(\operatorname{STUCK}(\mathrm{phase},\mathrm{reason},t))\).
