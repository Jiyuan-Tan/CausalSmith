For a checked \(\operatorname{ROW\_ELIGIBLE}\) constructor, define
\[
u_{h,c}(\omega_D)=r_{s,a,D,h,c}(\omega_D)
=\mathbf 1\{\text{the extracted numerator event for }(h,c)\text{ is true under }\omega_D\},
\]
and
\[
v_h(\omega_D)
=\mathbf 1\{\text{the extracted context event }h\text{ is true under }\omega_D\},
\qquad \omega_D\in\Omega_D.
\]
These are joint-event incidence rows, not the conditional kernel value.  The kernel is the certified quotient \((u_{h,c}^{\mathsf T}q_D^s)/(v_h^{\mathsf T}q_D^s)\).  No such district row is defined when the corresponding indicator depends on a nonfocal random response profile.
