For \(P_a^s\in\Delta(\mathcal Y_a)\), write
\[
\operatorname{Extract}_{s,a,D}(P_a^s)
\Downarrow(K_{s,a,D},\kappa)
\]
exactly when the finite extraction calculus constructs, for every retained \(h\in H_{s,a,D}\) and \(c\in C_{s,a,D}\), a numerator event \(A_{h,c}\), a context event \(H_h\), derivations
\[
\delta_N:A_{h,c}\Downarrow N_{s,a,D,h,c},
\qquad
\delta_H:H_h\Downarrow H_{s,a,D,h},
\]
two accepting \(\operatorname{SupportLocal}_D\) traces, the rows those traces construct,
\[
r_{s,a,D,h,c}=\operatorname{row}_D(A_{h,c}),
\qquad
v_{s,a,D,h}=\operatorname{row}_D(H_h),
\]
and an independently checkable certificate \(\pi_h\) that \(H_{s,a,D,h}>0\) on the declared fiber.  The returned kernel entry is the typed expression
\[
K_{s,a,D}(c\mid h)=
\operatorname{Quot}(N_{s,a,D,h,c},H_{s,a,D,h},\pi_h).
\]
The record \(\kappa\) contains only the event and expression derivations, locality tables, constructed rows, and positivity certificates.  It contains neither \(N=r^{\mathsf T}q\), nor \(H=v^{\mathsf T}q\), nor any equivalent semantic equality.  An unavailable cell, undefined fixing, rejected locality table, or uncertified denominator has no successful judgment and creates no row-eligibility record.
