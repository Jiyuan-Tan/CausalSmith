Fix a checked local-arm instance \(\mathfrak L_D\) whose finite arm set is \(\mathcal R_{\mathrm{arm}}\), so every arm has a numerator row and the common evidence row has the certified lower bound \(\varepsilon_D>0\) on \(\mathcal K_D(m_D)\).  Each realizable experiment \(e\in\mathcal U\) jointly reveals a rational or real-algebraic block \((R_e,p_e)\) at cost \(c_e>0\).  Require joint realizability, so \(\mathcal K_{\mathcal U}\ne\varnothing\), and define
\[
\mathcal K_S=\{q\in\mathcal K_D(m_D):R_eq=p_e\text{ for every }e\in S\},
\]
\[
\operatorname{PO}(S)=\{\rho\in\mathcal R_{\mathrm{arm}}:\exists q\in\mathcal K_S\ \forall\sigma\in\mathcal R_{\mathrm{arm}},\ (n_{\rho,D}-n_{\sigma,D})^{\mathsf T}q\ge0\}.
\]
Because the denominator is common and strictly positive, this is equivalent to comparison by the defined values \(Q_\rho(q)\).  Set
\[
\mathcal P_{\mathrm{full}}=\operatorname{PO}(\mathcal U),\qquad
f(S)=|\mathcal R_{\mathrm{arm}}|-|\operatorname{PO}(S)|,
\]
and solve
\[
\min_{S\subseteq\mathcal U}\sum_{e\in S}c_e
\quad\text{subject to}\quad
\operatorname{PO}(S)=\mathcal P_{\mathrm{full}}.
\]
An arm without a checked numerator row or with uncertified common evidence is outside this acquisition problem rather than assigned a numerical value.
