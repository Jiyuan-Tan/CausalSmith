Fix a supplied complete law \(P_a^s\) and its finite outcome carrier.  The extraction-event grammar is
\[
\mathsf{ExtractEvent}::=\operatorname{SourceCell}(s,a,v)\mid\bot\mid\top\mid A^c\mid\bigsqcup_{j\in J}A_j\mid\operatorname{Marg}_{x\in\mathcal X_W}A_x\mid\operatorname{FixEv}(A,\delta_{\mathrm{fix}}),
\]
where the disjoint-union constructor carries a decidable disjointness proof, marginalization enumerates a complete finite declared alphabet, and \(\operatorname{FixEv}\) may be formed only by applying a named already-proved sound fixing identity through its checked substitution \(\delta_{\mathrm{fix}}\).  The menu-expression grammar is
\[
\mathsf{MenuExpr}::=0\mid1\mid P_a^s(v)\mid 1-F\mid\sum_{j\in J}F_j,
\]
where every finite index set is explicitly enumerated.  A derivation \(\delta:A\Downarrow F\) is a finite tree whose source-cell, complement, disjoint-sum, and marginalization nodes mirror these constructors; at a fixing-event node it additionally checks the named sound fixing identity and its substitution before deriving the reconstructed event into the same quotient-free grammar.  Its evaluator \(\operatorname{Eval}_{s,a}\) substitutes the supplied complete-cell probabilities and performs the displayed finite arithmetic.  Thus every derived event probability is an explicit finite affine sum of supplied complete-cell probabilities.  A kernel quotient \(N/H\) is formed only after separate derivations of \(N\) and \(H\) and an independently checked certificate \(\pi_H:H>0\); the quotient is not a \(\mathsf{MenuExpr}\), event-probability derivation, or linear row.  The verifier recursively checks typing, disjointness, complete enumeration, every referenced fixing theorem, and every positivity certificate.  In particular, no constructor is an unverified assertion that an event probability equals an expression.

For an event \(A\) and a district \(D\), the total checker \(\operatorname{SupportLocal}_D(A)\) enumerates all
\[
(\omega_D,\omega_{-D},\omega'_{-D})\in
\Omega_D\times\prod_{D'\ne D}\Omega_{D'}\times\prod_{D'\ne D}\Omega_{D'}
\]
and accepts exactly when recursive evaluation gives
\[
\mathbf 1\{A(\omega_D,\omega_{-D})\}
=\mathbf 1\{A(\omega_D,\omega'_{-D})\}
\]
for every enumerated triple.  On acceptance it constructs the unique row
\[
\operatorname{row}_D(A)(\omega_D)
=\mathbf 1\{A(\omega_D,\omega_{-D}^0)\}\in\{0,1\}^{\Omega_D},
\]
where \(\omega_{-D}^0\) is the first canonical nonfocal profile; exhaustive equality makes the choice immaterial.  On rejection it returns a displayed triple with unequal truth values.  Thus event reconstruction, numerical expression evaluation, support locality, and positivity are four independently checked judgments.
