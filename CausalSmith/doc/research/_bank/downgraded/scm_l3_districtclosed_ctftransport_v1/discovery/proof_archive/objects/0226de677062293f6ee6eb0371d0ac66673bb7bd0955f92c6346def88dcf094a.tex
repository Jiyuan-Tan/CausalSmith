Initialize a finite work DAG with roots \(\operatorname{Raw}(\mathrm{num},B_\rho\wedge E)\) and \(\operatorname{Raw}(\mathrm{den},E)\), denoting
\[
\bigl(P_{M^\star}(B_\rho\cap E),P_{M^\star}(E)\bigr)
\quad\text{for }\mathbf M\in\mathcal C(\mathcal P).
\]
The priority transition system \(\mathsf{DCTFTR}\) uses the following rules.

\(\mathsf{NORM}\) replaces the least raw node by a canonical disjoint normal form after checking consistency, unnesting, contradiction removal, and Boolean identities.  \(\mathsf{ANCESTOR}\) explicitly enumerates each eliminated variable over its complete finite alphabet and records the corresponding marginalization identity.

At \(\mathsf{SPLIT}\), first run \(\operatorname{SupportLocal}_D\) for each original district in canonical order.  If one accepts, create the corresponding \(\operatorname{NeedRows}(\tau,D,C,\ell,b)\).  Otherwise enumerate the entire product \(\prod_{D\in\mathcal D(G)}\Omega_D\), recursively evaluate \(C\), and splice in the exact finite expansion
\[
\sum_{\omega:C(\omega)=1}
\prod_{D\in\mathcal D(G)}e_{\omega_D}^{\mathsf T}q_D^\star.
\]
Its leaves are local coordinate-row goals with the accepting singleton-row certificates.  This is a total-probability expansion over the original districts of \(G\); the rule never factorizes over districts of \(G[H]\).  An independently proved fixing theorem may simplify this expansion only through an explicit cited derivation.  Failed typing or enumeration returns \(\operatorname{SPLIT\_UNDEFINED}\).

At \(\mathsf{EXTRACT}\), enumerate all supplied complete cells.  After checking \(s=\star\) or \(D\cap\Delta_s=\varnothing\), retain a raw pair only when the total support-local checker accepts.  For a successful extraction retain a context--cell pair only when \(\mathsf{RowEligible}_{s,a,D}(h,c)\) supplies independent event-expression derivations, two accepting locality traces, their constructed rows \(u\) and \(v\), and the independent certificate \(H>0\).  The checker for \(\mathrm{lem:district\text{-}cell\text{-}linearity}\), rather than the row-eligibility record, derives
\[
N=u^{\mathsf T}q_D^\star,
\qquad H=v^{\mathsf T}q_D^\star.
\]
The rule stacks \((u,N)\) and \((v,H)\) separately, together with accepted raw pairs and normalization.  It never stacks \((r,N/H)\).  Rejected, changed-district, or nonlocal cells assert no local equality and remain constraints only in the global fibers.  The resulting proof \(\kappa_{\mathrm{all}}\) checks every row of \(A_Dq_D^\star=m_D\), after which the node becomes \(\operatorname{NeedFace}(\tau,D,C,\ell,b,A_D,m_D,Z_D(m_D),\kappa_{\mathrm{all}})\).

At \(\mathsf{FACE\_ID}\), exact rational LP certificates compute the forced-zero set and decide
\[
b\in\operatorname{row}(A)+\operatorname{span}\{e_\omega:\omega\in Z\}.
\]
If \(b=\lambda^{\mathsf T}A+\sum_{\omega\in Z}\zeta_\omega e_\omega\), replace the node by \(\operatorname{Resolved}(\lambda^{\mathsf T}m,\delta_{\mathrm{face}})\) after checking the equality on the active face.  Otherwise return \(\operatorname{FACE\_NOT\_IDENTIFIED}\), typed only as local row-face variation.  When normalization is the sole retained equality, failure is labelled \(\operatorname{NO\_ADMISSIBLE\_FACTOR}\).

\(\mathsf{MARGINALIZE}\) and \(\mathsf{PRODUCT}\) resolve ready nodes by checked finite addition and the original-district product identity.  \(\mathsf{CONDITION}\) runs only after both roots resolve.  It returns \(\operatorname{ZERO\_EVIDENCE}\) if an independent certificate proves \(F_E=0\) throughout \(\mathcal C(\mathcal P)\), returns \(\operatorname{ID}(\operatorname{Quot}(F_B,F_E,\pi),\delta)\) only if \(\pi\) proves \(F_E>0\) throughout that fiber, returns \(\operatorname{DENOMINATOR\_MAY\_VANISH}\) with a checked zero-evidence model when available, and otherwise returns \(\operatorname{DENOMINATOR\_POSITIVITY\_UNCERTIFIED}\).  No failure branch divides.

Priority is \(\mathsf{NORM}>\mathsf{ANCESTOR}>\mathsf{SPLIT}>\mathsf{EXTRACT}>\mathsf{FACE\_ID}>\mathsf{MARGINALIZE}>\mathsf{PRODUCT}>\mathsf{CONDITION}\), with the least applicable node chosen canonically.  The corresponding rule decreases the first still-changeable coordinate of
\[
\operatorname{rank}_{\mathrm{lex}}=(r_N,r_A,r_S,r_X,r_F,r_\Sigma,r_\Pi,r_C)
\]
and creates no earlier-phase node.  If a partial operation fails it takes its typed failure branch; a residual nonterminal would be labelled \(\operatorname{STUCK}\).
