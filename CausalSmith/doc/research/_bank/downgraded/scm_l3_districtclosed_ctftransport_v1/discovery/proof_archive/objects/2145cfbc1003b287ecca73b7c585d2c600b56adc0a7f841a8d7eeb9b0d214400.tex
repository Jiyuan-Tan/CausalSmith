For every finite instance, all minimum-cost Layer-3 regime-block solutions are characterized by enumerating \(S\subseteq\mathcal U\) and, for each arm, solving the finite linear program consisting of the equations defining \(\mathcal K_S\), the common-denominator positivity test, and the pairwise numerator-gap inequalities. This is an algorithmic computation whenever all matrix entries, menu values, and costs are effectively presented rational or real algebraic numbers. In general the elimination function \(f\) is not submodular. In particular, there is a realizable one-domain binary one-district instance with two unit-cost Layer-3 cell experiments for which
\[
\operatorname{PO}(\varnothing)=\operatorname{PO}(\{e_1\})
=\operatorname{PO}(\{e_2\})=\{\rho,\sigma\},
\qquad
\operatorname{PO}(\{e_1,e_2\})=\mathcal P_{\mathrm{full}}=\{\sigma\}.
\]
Consequently the marginal gain of \(e_2\) is zero at \(S=\varnothing\) and one at \(T_{\mathrm{exp}}=\{e_1\}\), violating diminishing returns. For this instance the exact acquisition problem is
\[
\min_{x_1,x_2\in\{0,1\}}x_1+x_2
\quad\text{subject to}\quad x_1+x_2\geq2,
\]
whose unique solution is \((1,1)\) with cost two. The multiplier \(y=1\) for the covering inequality is a matching dual lower-bound certificate for the continuous relaxation.
