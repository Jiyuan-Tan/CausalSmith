For every accepted row-eligibility record, define
\[
r_{s,a,D,h,c}(\omega_D)=\mathbf 1\{A_{h,c}\text{ is true at the common value certified by }\operatorname{SupportLocal}_D\},
\qquad
v_{s,a,D,h}(\omega_D)=\mathbf 1\{H_h\text{ is true at that common value}\}.
\]
Thus \(r_{s,a,D,h,c},v_{s,a,D,h}\in\{0,1\}^{\Omega_D}\).  For a complete supplied output cell \(C_{a,y}\) whose exhaustive locality table accepts, define independently
\[
r^{\mathrm{raw}}_{s,a,D,y}(\omega_D)=
\mathbf 1\{C_{a,y}\text{ is true at its certified common value}\}.
\]
For a deterministic-postprocessing descriptor, this last indicator is evaluated through the finite preimage \(\{t:f_a(t)=y\}\).
