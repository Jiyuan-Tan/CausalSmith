Consider a finite acquisition instance in which checked locality judgments reduce every arm numerator and a common evidence event to the same district \(D\), and the common denominator is strictly positive on every nonempty face \(\mathcal K_S\) considered.  All minimum-cost Layer-3 regime-block solutions are characterized by enumerating \(S\subseteq\mathcal U\) and deciding, for each arm, the linear feasibility system comprising the equations for \(\mathcal K_S\) and all pairwise numerator-gap inequalities.  This is effective for rational or real-algebraic data.  The elimination function \(f\) is not submodular in general: there is a realizable one-domain binary one-district instance with two unit-cost declared Layer-3 cell experiments such that
\[
\operatorname{PO}(\varnothing)=\operatorname{PO}(\{e_1\})
=\operatorname{PO}(\{e_2\})=\{\rho,\sigma\},
\qquad
\operatorname{PO}(\{e_1,e_2\})=\mathcal P_{\mathrm{full}}=\{\sigma\}.
\]
Its exact acquisition program is
\[
\min_{x_1,x_2\in\{0,1\}}x_1+x_2
\quad\text{subject to}\quad x_1+x_2\ge2,
\]
with unique solution \((1,1)\), cost two, and continuous-relaxation dual multiplier \(y=1\).
