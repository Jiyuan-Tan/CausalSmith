For a query tag \(\tau\in\{\operatorname{Uncond}(T),\operatorname{Cond}(B_\rho\cap E,E)\}\), define
\[
\begin{split}
\mathsf{HybridResult}::={}&
\operatorname{ID\_RAT}(F,\delta)
\mid\operatorname{ID\_CAN}(\alpha,\zeta)
\mid\operatorname{PAIR\_CAN}(\alpha_-,\alpha_+,\vartheta_-,\vartheta_+,\zeta)\\
&\mid\operatorname{ZERO\_EVIDENCE}(z)
\mid\operatorname{NOT\_UNIFORMLY\_DEFINED}(\vartheta_0,\vartheta_+,\zeta)
\mid\operatorname{INCONSISTENT\_MENU}(z).
\end{split}
\]
Here \(F\in\mathscr R(\mathcal P)\); \(\alpha,\alpha_-,\alpha_+\) are exactly represented real-algebraic numbers; \(\vartheta_-,\vartheta_+,\vartheta_0\in\Theta_G^{\mathrm{can}}(\mathcal P)\) are exact canonical parameters; and \(\zeta\) and \(z\) are checkable real-closed-field certificates consisting of projection polynomials, isolated algebraic roots, sign tables, lifted sample points, and a quantifier-free certificate for the asserted universal or existential formula.

The proof-producing hybrid algorithm \(\mathsf{DCTFTR\text{-}CAN}\) takes an effectively presented rational or real-algebraic typed menu.  For a conditional query it first runs \(\mathsf{DCTFTR}\).  A successful rational identification terminal is relabelled \(\operatorname{ID\_RAT}\), and a certified identically zero denominator is relabelled \(\operatorname{ZERO\_EVIDENCE}\).  After every unresolved fast-path failure it constructs \(\Theta_G^{\mathrm{can}}(\mathcal P)\) and applies finite sign-invariant cylindrical decomposition.

For \(\operatorname{Uncond}(T)\), it computes the attained minimum and maximum of \(\Phi_{T,\mathrm{can}}^\star\).  Equality returns \(\operatorname{ID\_CAN}\); strict inequality returns \(\operatorname{PAIR\_CAN}\) with endpoint parameters.  For \(\operatorname{Cond}(B_\rho\cap E,E)\), it first computes
\[
e_- =\min_{\vartheta\in\Theta_G^{\mathrm{can}}(\mathcal P)}
\Phi_{E,\mathrm{can}}^\star(\vartheta^\star),
\qquad
e_+ =\max_{\vartheta\in\Theta_G^{\mathrm{can}}(\mathcal P)}
\Phi_{E,\mathrm{can}}^\star(\vartheta^\star).
\]
If \(e_+=0\), it returns \(\operatorname{ZERO\_EVIDENCE}\).  If \(e_-=0<e_+\), it returns \(\operatorname{NOT\_UNIFORMLY\_DEFINED}\) with zero- and positive-evidence witnesses.  Only when \(e_->0\) does it optimize
\[
\frac{\Phi_{B_\rho\cap E,\mathrm{can}}^\star(\vartheta^\star)}
{\Phi_{E,\mathrm{can}}^\star(\vartheta^\star)}.
\]
Equal endpoints return \(\operatorname{ID\_CAN}\), and unequal endpoints return \(\operatorname{PAIR\_CAN}\).  An empty canonical fiber returns \(\operatorname{INCONSISTENT\_MENU}\).  No constructor divides before strict positivity has been certified.
