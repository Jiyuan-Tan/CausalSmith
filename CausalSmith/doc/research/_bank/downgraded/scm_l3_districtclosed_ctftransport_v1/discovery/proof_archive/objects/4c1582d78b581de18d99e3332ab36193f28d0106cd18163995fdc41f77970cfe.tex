Put \(\Omega=\prod_{D\in\mathcal D(G)}\Omega_D\), with every factor finite.  The finite extraction calculus has the following syntax and no other constructors.
\[
\begin{split}
\mathsf{FEvent}::={}&\top\mid\bot\mid\operatorname{Cell}(s,a,v)\mid
\operatorname{And}(A,H)\mid\operatorname{Compl}_H(A)\mid
\operatorname{Disj}_{i\in I}A_i\mid
\operatorname{Marg}_{X}(A),\\
\mathsf{FExpr}::={}&\operatorname{Rat}(r)\mid\operatorname{CellVal}(s,a,v)\mid
\operatorname{Add}_{i\in I}F_i\mid F-G\mid
\operatorname{Mul}_{i\in I}F_i\mid
\operatorname{Quot}(F,H,\pi_H).
\end{split}
\]
Here \(I\) and every alphabet are finite, \(r\in\mathbb Q\), \(\operatorname{Marg}_{X}(A)\) is the checked disjoint union of the events \(A\wedge\{X=x\}\) over the complete alphabet \(\mathcal X_X\), and \(\operatorname{Compl}_H(A)\) is admitted only with a truth-table certificate that \(A\subseteq H\).  The evaluator is
\[
\begin{gathered}
\llbracket\operatorname{Rat}(r)\rrbracket=r,\qquad
\llbracket\operatorname{CellVal}(s,a,v)\rrbracket=P_a^s(v),\\
\llbracket\operatorname{Add}_{i\in I}F_i\rrbracket=\sum_{i\in I}\llbracket F_i\rrbracket,\quad
\llbracket F-G\rrbracket=\llbracket F\rrbracket-\llbracket G\rrbracket,\quad
\llbracket\operatorname{Mul}_{i\in I}F_i\rrbracket=\prod_{i\in I}\llbracket F_i\rrbracket,\\
\llbracket\operatorname{Quot}(F,H,\pi_H)\rrbracket
=\llbracket F\rrbracket/\llbracket H\rrbracket,
\end{gathered}
\]
where \(\pi_H\) is checked independently and proves \(\llbracket H\rrbracket>0\) on its declared compatibility fiber.

A fixing trace \(\delta:A\Downarrow F\) is generated only by: \(\mathsf{CELL}\), which maps \(\operatorname{Cell}(s,a,v)\) to \(\operatorname{CellVal}(s,a,v)\); \(\mathsf{ZERO}\) and \(\mathsf{ONE}\); \(\mathsf{DISJOINT\_SUM}\), carrying a complete truth-table certificate that \(A=\biguplus_{i\in I}A_i\); \(\mathsf{MARGINALIZE}\), carrying the displayed complete-alphabet partition; \(\mathsf{COMPLEMENT}\), which maps \(H\setminus A\) to \(F_H-F_A\) after checking \(A\subseteq H\); \(\mathsf{PRODUCT}\), carrying a registry entry that its event factors depend on disjoint original districts of \(G\); \(\mathsf{CONDITION}\), which maps a numerator--context pair to \(\operatorname{Quot}(F_N,F_H,\pi_H)\); \(\mathsf{REGISTRY}\), which uses one entry from the finite allowed identity registry; \(\mathsf{SUBST}\), which substitutes already accepted child traces into such an identity; and \(\mathsf{TRANS}\), which composes traces.

The allowed identity registry contains exactly finite counterfactual consistency and recursive substitution, unnesting, contradiction and sure-event identities, Boolean associativity and distributivity used to form disjoint normal form, complete-alphabet marginalization, complement inside a checked context, and the product identity for events measurable with respect to mutually independent original district blocks.  Every registry entry is stored as two \(\mathsf{FEvent}\) trees and is accepted only when exhaustive recursive evaluation gives the same Boolean value at every \(\omega\in\Omega\); the sole non-Boolean product entry additionally stores the original-district partition and checks it against \(\mathcal D(G)\).  There is no semantic probability equality in a registry premise.

For every expression identity, the checker lists all quotient denominators \(g_1,\ldots,g_k\), checks their separate strict-positivity certificates, multiplies both sides by a common positive denominator \(G=\prod_{j=1}^kg_j^{m_j}\), expands in a fixed monomial order over the effectively presented coefficient field, and accepts exactly when the two finite coefficient vectors agree.  Thus every conditional or fixing identity is checked by an explicit cleared-denominator polynomial identity; division by zero has no constructor.

For an event \(A\) and district \(D\), \(\operatorname{SupportLocal}_D(A)\) enumerates every \((\omega_D,\omega_{-D})\in\Omega_D\times\prod_{D'\ne D}\Omega_{D'}\), recursively evaluates \(\mathbf1_A\), and accepts exactly when, for each fixed \(\omega_D\), the value is constant over all \(\omega_{-D}\).  On acceptance it returns the row
\[
\operatorname{row}_D(A)(\omega_D)=\mathbf1_A(\omega_D,\omega_{-D}^0),
\]
where \(\omega_{-D}^0\) is the first canonical nonfocal profile.  On rejection it returns two enumerated nonfocal profiles giving different values at a common \(\omega_D\).

\mathsf{RowEligible}_{s,a,D}(h,c)
=(A_{h,c},H_h,\delta_N,\delta_H,\tau_u,\tau_v,u_{s,a,D,h,c},v_{s,a,D,h},\pi_H)
\]
is well formed exactly when \(\delta_N:A_{h,c}\Downarrow F_N\) and \(\delta_H:H_h\Downarrow F_H\), the two support-local traces \(\tau_u,\tau_v\) accept and construct the displayed rows, and \(\pi_H\) proves \(\llbracket F_H\rrbracket>0\).  It defines
\[
N_{s,a,D,h,c}=\llbracket F_N\rrbracket,\qquad
H_{s,a,D,h}=\llbracket F_H\rrbracket,\qquad
K_{s,a,D}(c\mid h)=N_{s,a,D,h,c}/H_{s,a,D,h}.
\]
Neither \(N=u^{\mathsf T}q\), \(H=v^{\mathsf T}q\), nor any equivalent response-law equality is a field or premise of \(\mathsf{RowEligible}\).
