For a fixed district \(D\), a total record \(\mathsf{CheckedLocalArms}_D\) consists of: a finite nonempty arm set \(\mathcal R_{\mathrm{arm}}\); for every \(\rho\in\mathcal R_{\mathrm{arm}}\), an accepting \(\operatorname{SupportLocal}_D(B_\rho\cap E)\) trace and its constructed row \(n_{\rho,D}\); one accepting \(\operatorname{SupportLocal}_D(E)\) trace and its constructed row \(d_D\); a rational or real-algebraic number \(\varepsilon_D>0\); and an exact certificate that
\[
d_D^{\mathsf T}q\geq\varepsilon_D
\qquad\text{for every }q\in\mathcal K_D(m_D).
\]
Only from such a record define, for \(q\in\mathcal K_D(m_D)\),
\[
Q_\rho(q)=\frac{n_{\rho,D}^{\mathsf T}q}{d_D^{\mathsf T}q},
\qquad
g_{\rho,\sigma,D}=n_{\sigma,D}-n_{\rho,D}.
\]
Separately, for any target cell \(C\), an accepting \(\operatorname{SupportLocal}_D(C)\) trace constructs the generic target row \(b_D=\operatorname{row}_D(C)\).  If a required locality trace rejects, the corresponding row, comparison, or target value is undefined rather than silently assigned a row.
