The DCTFTR typed-menu grammar permits observational, hard-interventional, and declared partial-copy descriptors.  Restricting each \(\mathcal A_s\) to its observational and hard-interventional constructors is therefore an injective type-preserving map from \(\mathfrak I_{\mathrm{CTFTR}}\) into \(\mathfrak I_{\mathrm{DCTFTR}}\).  Likewise, imposing \(\mathcal S=\{\star\}\) removes source labels and selection changes but retains every one-specification Layer-3 descriptor, giving an injective type-preserving map from \(\mathfrak I_{\mathrm{CTFIDU+}}\).

For either embedding, recursion soundness proves that every successful DCTFTR expression equals the causal target in every compatible model.  The cited CTFTR and CTFIDU+ soundness results give the same semantic equality for a successful expression returned by the corresponding published calculus.  Equality to the same target is all that is claimed; the respective syntaxes and traces need not coincide.

Both embeddings are proper.  In \(\mathfrak I_{\mathrm{bin}}\), the supplied quantity
\[
 p=P^s(Y_0=1,Y_1=1)=\frac38
\]
is a joint cross-world cell, so it is not generated by the observational or hard-interventional descriptor constructors of CTFTR.  Thus the first embedding is not surjective.  For the second, a one-specification instance has one SCM law for the factual variable \(Z\).  The complete binary family instead requires simultaneously
\[
 P^\star(Z=1)=0,
 \qquad P^s(Z=1)=1.
\]
No single probability law can satisfy both equalities.  The family is a valid two-domain DCTFTR instance because \(Z\) is selected in the source domain, but it is not a one-specification CTFIDU+ instance.  Hence the second embedding is proper as well.
