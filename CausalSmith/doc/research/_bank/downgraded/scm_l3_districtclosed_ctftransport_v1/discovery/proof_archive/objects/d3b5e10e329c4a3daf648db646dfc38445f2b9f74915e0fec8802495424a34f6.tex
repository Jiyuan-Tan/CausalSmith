For every \(s\in\mathcal S\) and \(D\in\mathcal D(G)\), all mechanisms on \(D\) are generated by one finite latent variable \(U_D^s\in\Omega_D^{\mathrm{all}}\), where \(\Omega_D^{\mathrm{all}}\) contains the deterministic response maps at every parent configuration: if \(U_D^s=\omega_D=(f_V:V\in D)\), then the structural equation of each \(V\in D\) reads the component \(f_V\); the variables \((U_D^s:D\in\mathcal D(G))\) are mutually independent.
