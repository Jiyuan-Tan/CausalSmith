For effectively presented rational or real-algebraic menu values, define
\[
\begin{split}
\mathsf{HybridResult}::={}&
\operatorname{ID\_RAT}(F,\delta)
\mid\operatorname{ID\_CAN}(\alpha,\zeta)
\mid\operatorname{PAIR\_CAN}(\vartheta_-,\vartheta_+,\zeta)\\
&\mid\operatorname{ZERO\_EVIDENCE}(\xi,\zeta)
\mid\operatorname{NOT\_UNIFORMLY\_DEFINED}(\vartheta_0,\vartheta_+,\zeta).
\end{split}
\]
Here \(F\in\mathscr R(\mathcal P)\); \(\alpha\) is an isolated real-algebraic target value; \(\vartheta_-\) and \(\vartheta_+\) are graph-compatible canonical endpoint parameters on the original alphabets; \(\xi\) is either a fast-path pair \((F_E,z)\) proving identically zero evidence or a canonical zero-evidence sample \(\vartheta_0\); and \(\zeta\) is a finite verifier record.  A verifier record contains the input polynomial list and variable order, projection polynomials, isolating intervals or Thom encodings for algebraic coordinates, sign-invariant cells, lifted sample points, exact evaluations of every defining constraint, and the sign or equality comparisons establishing the advertised endpoint or evidence case.

The hybrid procedure \(\mathsf{DCTFTR\text{-}CAN}\) first runs \(\mathsf{DCTFTR}\).  A successful rational identification is returned as \(\operatorname{ID\_RAT}\), and a proved identically zero evidence expression is returned as \(\operatorname{ZERO\_EVIDENCE}\).  Every other local terminal invokes a genuine cylindrical algebraic decomposition of \(\Theta_G^{\mathrm{can}}(\mathcal P)\): projection is performed to one target coordinate, lifting constructs sign-invariant cells and algebraic samples, and the verifier checks the result by exact real-algebraic arithmetic.  For an unconditional target, equal attained extrema return \(\operatorname{ID\_CAN}\) and unequal extrema return \(\operatorname{PAIR\_CAN}\).  For a conditional target, write
\[
e_-^{\mathrm{can}}=\min_{\vartheta\in\Theta_G^{\mathrm{can}}(\mathcal P)}
\Phi_{E,\mathrm{can}}^\star(\vartheta^\star),
\qquad
e_+^{\mathrm{can}}=\max_{\vartheta\in\Theta_G^{\mathrm{can}}(\mathcal P)}
\Phi_{E,\mathrm{can}}^\star(\vartheta^\star).
\]
The case \(e_+^{\mathrm{can}}=0\) returns \(\operatorname{ZERO\_EVIDENCE}\); \(e_-^{\mathrm{can}}=0<e_+^{\mathrm{can}}\) returns \(\operatorname{NOT\_UNIFORMLY\_DEFINED}\) with zero- and positive-evidence samples; and only when \(e_-^{\mathrm{can}}>0\) does the procedure decompose the graph of the ratio, returning \(\operatorname{ID\_CAN}\) for equal ratio extrema and \(\operatorname{PAIR\_CAN}\) otherwise.  Legal CAD projection and lifting choices need not be unique, but every legal run terminates and every returned record must pass the same exact verifier.
