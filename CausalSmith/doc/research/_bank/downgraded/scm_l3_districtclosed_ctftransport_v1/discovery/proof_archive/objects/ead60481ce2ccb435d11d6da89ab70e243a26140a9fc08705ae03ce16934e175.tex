Fix \(s\in\mathcal S\setminus\{\star\}\) and \(D\in\mathcal D(G)\) with \(0<|D\cap\Delta_s|<|D|\).  Omit district closure, retain recursive compatibility, district factorization, and district-kernel invariance exactly as stated, and restrict the available information to the complete laws supplied from this designated partially selected source \(s\).  For a scalar row \(\ell\in\mathbb R^{\Omega_D}\), its target value is universally determined by those source laws if and only if \(\ell\) is constant on \(\Omega_D\).  More strongly, every nonconstant \(\ell\) admits two finite source-labelled SCM families on the original declared alphabets \(\mathcal X\) that satisfy all retained assumptions, induce identical complete supplied laws in domain \(s\), and have unequal target values of \(\ell\).  If one additionally requires invariance of the marginal response law on \(I=D\setminus\Delta_s\), then universal transport holds if and only if \(\ell\) is constant on every fiber of the coordinate projection \(\pi_I:\Omega_D\to\pi_I(\Omega_D)\).  For every finite real matrix, componentwise universal transport holds if and only if every row has the corresponding constancy property.  For rational rows, and for real-algebraic rows given by effective representations supporting exact equality comparison, the criterion is decidable by finite enumeration; failure returns a row index and two response profiles giving an original-alphabet two-Dirac certificate.  Thus binary incidence and event rows, \(\{-1,0,1\}\)-valued arm-gap rows, finite real reward rows, and linear-certificate rows are all covered.  The result is only a designated-source-information limitation: it makes no claim after adding target-domain data or data from a wholly unselected source whose district law is tied to the target.
