For \(P_a^s\in\Delta(\mathcal X_{W_a})\), write
\[
\operatorname{Extract}_{s,a,D}(P_a^s)\Downarrow(K_{s,a,D},\kappa)
\]
exactly when consistency, unnesting, ancestor restriction, fixing, and marginalization define a kernel \(K_{s,a,D}:H_{s,a,D}\to\Delta(C_{s,a,D})\), and the checked derivation \(\kappa\) records every context lookup, marginal, and nonzero divisor used.  A locally retainable conditional cell additionally requires a checked constructor
\[
\operatorname{ROW\_ELIGIBLE}(h,c;u_{h,c},v_h,N_{h,c},H_h,\delta_N,\delta_H,\pi_H)
\]
inside \(\kappa\).  It exhibits \(u_{h,c},v_h\in\{0,1\}^{\Omega_D}\), identified menu functionals \(N_{h,c},H_h\in\mathscr R(\mathcal P)\), derivations
\[
N_{h,c}=u_{h,c}^{\mathsf T}q_D^s,
\qquad
H_h=v_h^{\mathsf T}q_D^s,
\qquad
\pi_H:H_h>0,
\qquad
K_{s,a,D}(c\mid h)=\frac{N_{h,c}}{H_h},
\]
and syntactic certificates that the recursively evaluated numerator event and context event depend only on \(\omega_D\).  For a fixed nondistrict context the checker may use \(v_h=\mathbf 1\) and \(H_h=1\).  If either event depends on a random response profile outside \(D\), the extraction may still be recorded for the exact global constraints, but no \(\operatorname{ROW\_ELIGIBLE}\) constructor is issued and no local row is retained.  An undefined fixing, unavailable context, or uncertified quotient has no successful extraction judgment.
