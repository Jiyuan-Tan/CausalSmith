%%% FIELD theorem-statement
There exists a well-typed explicit instance \(I\) with \(V=\{W,Y\}\), \(\mathcal X_W=\{0,1,2\}\), \(\mathcal X_Y=\{0,1\}\), permitted directed edges \(W\to Y\to W\), no bidirected edge, and three independent binary private sources incident only to \(Y\), having the following properties relative to the instance family \(\mathfrak M(I)=\{\mathcal M_\theta:\theta\in\Theta_{\mathcal L}\}\).  For source success probabilities \((x,y,z)\), the supplied complete-law coordinates contain \(a=xy\), \(b=xz\), and \(c=yz\); for \(A=\{Y_{\operatorname{do}(W=0)}=1\}\) and \(B=\{Y_{\operatorname{do}(W=2)}=1\}\), one has \(H=xyz\), \(K=yz=c\), and, whenever \(K>0\),
\[
 q=\frac{H}{K}=x=\sqrt{\frac{ab}{c}}.
\]
Thus the ratio is constant on every \(\mathcal F_+(p)\) for \(p\in\mathcal P_{\mathrm{feas}}\) with \(\mathcal F_+(p)\neq\varnothing\), but no rational arithmetic circuit \(C\) in the supplied regime probabilities represents it on that full positive feasible image.  Consequently no total sound procedure on the declared explicit source-decoder input class can be complete if its only positive output is such a rational circuit and its only negative output is a pair of positive-denominator models in the same \(\mathfrak M(I)\) that agree on all supplied laws and disagree on the query: on this \(I\), neither output is possible.  The procedure \(\mathsf{SC\mbox{-}CTFID}(I)\) terminates and returns \(O\), so a third outcome such as \(O\), or an enlargement of the positive expression language, is unavoidable for a total sound procedure.  This is an instance-relative restricted-submodel conclusion: it does not assert identification over all of \(\mathfrak M_{sc}(G,\operatorname{inc},\mathcal X)\) and does not refute acyclic CTFID completeness.  The permitted edge \(Y\to W\) is inactive in the witness, so cyclic feedback is not load-bearing for the obstruction.
%%% FIELD instance-family-construction
\[
 \mathfrak M(I):=\{\mathcal M_\theta:\theta\in\Theta_{\mathcal L}\}.
\]
Here \(I\) fixes the endogenous alphabets, the permitted graph, every labeled source alphabet \(\Omega_s\), the incidence map, and every structural decoding table.  For \(\theta=(\lambda_{s,u})\in\Theta_{\mathcal L}\), the model \(\mathcal M_\theta\) uses those fixed objects and gives the labeled sources the independent law \(\bigotimes_{s\in S}(\lambda_{s,u})_{u\in\Omega_s}\).  Thus only the source masses vary inside \(\mathfrak M(I)\); neither the source alphabets nor the decoder varies.  Every member is required to pass the legality test encoded by \(\Theta_{\mathcal L}\), and hence \(\mathfrak M(I)\subseteq\mathfrak M_{sc}(G,\operatorname{inc},\mathcal X)\) for a well-typed instance.
%%% FIELD theorem-proof
Let \(V=\{W,Y\}\), ordered as in the input, and set
\[
 \mathcal X_W=\{0,1,2\},\qquad \mathcal X_Y=\{0,1\}.
\]
Let the permitted directed graph \(G\) have exactly the edges \(W\to Y\) and \(Y\to W\), and let it have no bidirected edge.  Its only nontrivial directed strongly connected component is therefore the induced chordless two-cycle \(W\to Y\to W\), which verifies assumption \texttt{ass:chordless-cycle-scc}.  The equivalence relation generated by directed-SCC membership and bidirected adjacency has one class, and that class contains exactly this one original cycle, verifying assumption \texttt{ass:one-cycle-per-district}.

Take \(S=\{s_1,s_2,s_3\}\), let \(\Omega_{s_i}=\{0,1\}\), write the corresponding source states as \(U_i\), and put
\[
 \operatorname{inc}(s_i)=\{Y\},\qquad i=1,2,3.
\]
This is exact private-source incidence and satisfies \(1\leq |\operatorname{inc}(s_i)|\leq2\), as required by assumption \texttt{ass:sparse-source-incidence}.  Give the sources the product law in assumption \texttt{ass:source-independence}, and write
\[
 x=P(U_1=1),\qquad y=P(U_2=1),\qquad z=P(U_3=1).
\]
Define the fixed decoder by the structural equations
\[
 W=0,
 \qquad
 Y=
 \begin{cases}
 U_1U_2,&W=0,\\
 U_1U_3,&W=1,\\
 U_2U_3,&W=2,
 \end{cases}
\]
where multiplication is Boolean conjunction.  The graph is an upper bound on functional dependence in \texttt{def:model-class}; hence the equation for \(W\) may ignore the permitted parent \(Y\).

We verify assumption \texttt{ass:subset-unique-solvability} pointwise in the source tuple, so the common exceptional set is empty.  If both endogenous equations are retained, the first forces \(W=0\), after which the second forces \(Y=U_1U_2\).  If only the equation for \(W\) is retained, it uniquely gives \(W=0\) for either boundary value of \(Y\).  If only the equation for \(Y\) is retained, each boundary value \(W\in\{0,1,2\}\) selects exactly one displayed Boolean value.  If neither equation is retained, there is no endogenous coordinate to solve.  These are all subsets of \(V\).  Therefore every decoded deterministic response profile passes \texttt{def:legal-profiles}, and
\[
 \Theta_{\mathcal L}=[0,1]^3.
\]
Together with the preceding graph and incidence checks, this proves that every \(\mathcal M_\theta\in\mathfrak M(I)\) belongs to \(\mathfrak M_{sc}(G,\operatorname{inc},\mathcal X)\).  Take \(\mathcal T\) to be the explicitly enumerated deterministic response-table set, take \(\mathcal L\) to be exactly the subset passing the exhaustive legality check just verified, and define \(\Phi,H,K\) by direct source-tuple enumeration from this decoder.  All response tables have entries in \(\{0,1\}\), and the resulting probability polynomials have integer coefficients.  Thus every finite table is explicit over the rationals and the resulting decoder input \(I\) is well typed.

Supply the three complete regimes
\[
 \mathcal R=\bigl\{(\varnothing,\varnothing),\ (\{W\},1),\ (\{W\},2)\bigr\}
\]
and abbreviate
\[
 a=xy,\qquad b=xz,\qquad c=yz.
\]
Under the observational regime, \(W=0\) surely and source independence gives
\[
 P(W=0,Y=1)=P(U_1=1,U_2=1)=xy=a,
 \qquad P(W=0,Y=0)=1-a,
\]
while all cells with \(W\neq0\) have probability zero.  Under the other two regimes,
\[
 P(Y=1\mid\operatorname{do}(W=1))=P(U_1=1,U_3=1)=xz=b,
\]
and
\[
 P(Y=1\mid\operatorname{do}(W=2))=P(U_2=1,U_3=1)=yz=c,
\]
with complementary cells \(1-b\) and \(1-c\).  Hence the full menu vector \(p=\Phi(\theta)\) consists only of \(0,1,a,1-a,b,1-b,c,1-c\), and \(a,b,c\) themselves are supplied coordinates.

Take the unnested events
\[
 A=\{Y_{\operatorname{do}(W=0)}=1\},
 \qquad
 B=\{Y_{\operatorname{do}(W=2)}=1\}.
\]
The decoder gives
\[
 A=\{U_1=1,U_2=1\},
 \qquad
 B=\{U_2=1,U_3=1\}.
\]
Using source independence once more,
\[
 H(x,y,z)=P(A\cap B)=xyz,
 \qquad
 K(x,y,z)=P(B)=yz=c.
\]
On the domain specified by assumption \texttt{ass:positive-query-denominator}, \(K=c>0\), so division by \(K\) is valid and
\[
 q(\mathcal M_\theta)=\frac{H(\theta)}{K(\theta)}=x. \tag{1}
\]

We next establish uniform identification relative to the fixed instance family.  Let \(\theta=(x,y,z)\) and \(\theta'=(x',y',z')\) lie in the same fiber \(\mathcal F_+(p)\) of \texttt{def:source-fiber}.  Equality of their supplied laws yields
\[
 xy=x'y'=a,\qquad xz=x'z'=b,\qquad yz=y'z'=c,
\]
and membership in the positive fiber yields \(c>0\).  Therefore
\[
 x^2=\frac{(xy)(xz)}{yz}=\frac{ab}{c}
     =\frac{(x'y')(x'z')}{y'z'}=(x')^2. \tag{2}
\]
Both \(x\) and \(x'\) are probabilities and hence are nonnegative.  Equation (2) implies \(x=x'\).  By (1), the two conditional targets are equal.  Equivalently, since \(H=xK\), \(H'=x'K'\), and \(K=K'=c\),
\[
 H(\theta)K(\theta')=xc^2=x'c^2=H(\theta')K(\theta). \tag{3}
\]
This proves the advertised fiber constancy for every feasible \(p\) whose positive fiber is nonempty.  Notice that \(x=0\) is allowed; the only division in (2) is by the expressly positive quantity \(c\).  On the strictly positive subimage, (2) and nonnegativity select the positive algebraic branch
\[
 q=x=\sqrt{\frac{ab}{c}}, \tag{4}
\]
with the nonnegative value \(0\) at points where \(x=0\).

Source independence is load-bearing.  To check this on the smallest displayed alphabet, first take the three sources to be independent fair bits.  Then \(a=b=c=1/4\), \(H=1/8\), \(K=1/4\), and \(q=1/2\).  Now leave the graph, alphabets, decoder, regimes, and subset-solvability property unchanged, but replace the product source law by the uniform law on
\[
 \{000,011,101,110\}.
\]
Each pairwise conjunction still has probability \(1/4\), so all three complete supplied laws, including their complementary cells, remain unchanged.  However the triple conjunction has probability zero, while \(K=P(U_2=1,U_3=1)=1/4>0\), and hence \(q=0\).  This second law violates assumption \texttt{ass:source-independence}; it shows directly that (4) and fiber constancy fail when that assumption is removed.

We now prove that no rational arithmetic circuit in the supplied probabilities represents this value on the full positive feasible image.  Suppose, to the contrary, that such a circuit \(C\) exists.  Substituting the displayed menu cells into its finitely many rational operations and recursively clearing its intermediate denominators produces polynomials \(P,Q\in\mathbb Q[a,b,c]\) such that
\[
 C(p)=R(a,b,c):=\frac{P(a,b,c)}{Q(a,b,c)}.
\]
The nonvanishing requirement in the definition of \(C\) ensures that this representation can be chosen with \(Q(xy,xz,yz)\neq0\) at every \((x,y,z)\in(0,1)^3\).  Correctness of the circuit and (1) would give
\[
 P(xy,xz,yz)-xQ(xy,xz,yz)=0
 \qquad\text{for every }(x,y,z)\in(0,1)^3. \tag{5}
\]
The left side of (5) is a polynomial in \(\mathbb Q[x,y,z]\).  A polynomial that vanishes on an open box is identically zero: for one variable this follows because a nonzero univariate polynomial has only finitely many roots; fixing two coordinates in the box and applying that fact to the remaining coordinate, then repeating for the other coordinates, proves the three-variable assertion.  Thus (5) is an identity in \(\mathbb Q(x,y,z)\), and so
\[
 R(xy,xz,yz)=x \tag{6}
\]
as a rational-function identity.

For completeness, the substitution homomorphism
\[
 \iota:\mathbb Q(a,b,c)\longrightarrow\mathbb Q(x,y,z),
 \qquad (a,b,c)\longmapsto(xy,xz,yz),
\]
is injective.  Indeed, the monomial \(a^ib^jc^k\) maps to \(x^{i+j}y^{i+k}z^{j+k}\), and the original exponents are recovered from an image exponent triple \((r,s,t)\) by
\[
 i=\frac{r+s-t}{2},\qquad
 j=\frac{r+t-s}{2},\qquad
 k=\frac{s+t-r}{2}.
\]
Distinct monomials therefore have distinct images, proving injectivity first on polynomial rings and then on their fraction fields.  Consider the field automorphism
\[
 \sigma:\mathbb Q(x,y,z)\longrightarrow\mathbb Q(x,y,z),
 \qquad \sigma(x,y,z)=(-x,-y,-z).
\]
It fixes \(xy,xz,yz\), so it fixes the image of \(\iota\) pointwise.  The left side of (6) is in that fixed image, whereas \(\sigma(x)=-x\).  Applying \(\sigma\) to (6) would imply both \(R(xy,xz,yz)=x\) and \(R(xy,xz,yz)=-x\), which is impossible in the characteristic-zero field \(\mathbb Q(x,y,z)\).  This contradiction proves the claimed nonrationality.

There can also be no genuine negative output for this same explicit instance.  Such an output would consist of \(\mathcal M_{\theta^-},\mathcal M_{\theta^+}\in\mathfrak M(I)\) with \(K(\theta^-)K(\theta^+)>0\), equal supplied menu vectors, and unequal target ratios.  Equal menu vectors place \(\theta^-\) and \(\theta^+\) in a common positive fiber, and (3) forces their ratios to be equal, a contradiction.  Therefore, on this input, a sound positive output in the prescribed rational language does not exist and a sound negative same-instance countermodel output does not exist.  Any procedure defined on every legal explicit input and restricted to those two sound output types must fail on this \(I\); equivalently, no such total sound formula-or-countermodel procedure is complete.  A total sound procedure must either admit a third outcome or enlarge its positive expression language, for example to describe the branch in (4).

Finally, apply the already-established \texttt{thm:sc-ctfid-output-soundness}.  It gives termination of \(\mathsf{SC\mbox{-}CTFID}(I)\).  The input checks above exclude \(\mathsf{invalid}\).  A returned verified circuit would contradict nonrationality, and a returned verifier-accepted negative certificate would, by output soundness, give the impossible same-instance pair just excluded.  The exhaustive final-output clause of \texttt{def:algorithm-handle} leaves only \(O\).  Hence \(\mathsf{SC\mbox{-}CTFID}(I)\) returns \(O\).

All identification and nonidentification quantifiers in this argument range over \(\mathfrak M(I)\), whose source alphabets and decoder are fixed.  Although \(\mathfrak M(I)\subseteq\mathfrak M_{sc}(G,\operatorname{inc},\mathcal X)\), constancy on fibers of a subclass does not imply constancy after mechanisms outside that subclass are added.  Thus no graph-wide identification conclusion transfers upward.  Moreover, the equation \(W=0\) ignores the permitted edge \(Y\to W\); deleting that inactive dependence does not change any calculation.  Cyclic feedback is therefore not load-bearing, and the result makes no assertion against acyclic CTFID completeness on its own unrestricted model class.
