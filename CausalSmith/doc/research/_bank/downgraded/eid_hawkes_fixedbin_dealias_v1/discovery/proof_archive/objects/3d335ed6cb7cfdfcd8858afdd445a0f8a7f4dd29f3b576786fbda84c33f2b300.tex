On \(\mathcal V_n\), let \(\widehat z\) be the vector of upper-triangular entries of the recovered signed jump \(Z^\star=K^\star-(K^\star)^{\mathsf T}\); on \(\mathcal V_n^c\), set \(\widehat z=0\). With the sentinel in \(\text{def:rank-adaptive-estimator}\), this gives the total identity \(\widehat z=\zeta(\widehat\theta_n)\). Let \(\widehat W_n\) be the total positive-semidefinite signed-score covariance in \(\text{def:hac-estimator}\). Conditional on \(\widehat W_n\), let \(c_{n,1-\alpha}\) be the \((1-\alpha)\)-quantile of \(\max_{i<j}|\mathcal Z_{ij}|\) for \(\mathcal Z\sim\mathcal N(0,\widehat W_n)\). On \(\mathcal V_n\), set \(I_{ij,n}=[\widehat z_{ij}-c_{n,1-\alpha}/\sqrt n,\widehat z_{ij}+c_{n,1-\alpha}/\sqrt n]\), and let \(\mathcal C_n(1-\alpha)\) be the set of labeled acyclic graphs which, for every \(i<j\), use no edge only if \(0\in I_{ij,n}\), use \(j\to i\) only if \(I_{ij,n}\cap(0,\infty)\neq\varnothing\), and use \(i\to j\) only if \(I_{ij,n}\cap(-\infty,0)\neq\varnothing\). On \(\mathcal V_n^c\), set every \(I_{ij,n}=\mathbb R\) and let \(\mathcal C_n(1-\alpha)\) be the set of all labeled acyclic graphs. Define \(\mathcal T_n^{\mathrm{fm}}(1-\alpha)\) as the full-parameter Wald ellipsoid only on \(\mathcal V_n\) when the full positive-part derivative exists and \(\widehat V_n\) makes that ellipsoid well defined; on every other sample set \(\mathcal T_n^{\mathrm{fm}}(1-\alpha)=\overline\Theta_{\Delta,p}\). This optional parameter benchmark is not used in signed-edge or graph coverage.
