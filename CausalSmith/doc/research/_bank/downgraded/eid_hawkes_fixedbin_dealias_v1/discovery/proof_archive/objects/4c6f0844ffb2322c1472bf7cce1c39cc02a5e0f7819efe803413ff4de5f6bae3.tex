For the Bartlett kernel \(w(x)=(1-|x|)_+\), set \(\overline Y_n=(n-2)^{-1}\sum_{k=0}^{n-3}Y_k=\widehat\xi_n\) and \(\widehat\Omega_n=\widehat\Xi_0+\sum_{h=1}^{b_n}w(h/b_n)(\widehat\Xi_h+\widehat\Xi_h^{\mathsf T})\), where \(\widehat\Xi_h=(n-2)^{-1}\sum_{k=0}^{n-h-3}(Y_k-\overline Y_n)(Y_{k+h}-\overline Y_n)^{\mathsf T}\), with an empty inner sum interpreted as zero. This Bartlett matrix is positive semidefinite for every sample. On \(\mathcal V_n\), define \(\widehat W_n=D(\zeta\circ\Phi_{\Delta,\widehat r_n}\circ\mathcal C)_{\widehat\xi_n}\widehat\Omega_nD(\zeta\circ\Phi_{\Delta,\widehat r_n}\circ\mathcal C)_{\widehat\xi_n}^{\mathsf T}\), evaluating the derivative through the smooth representative \(Z^\star=K^\star-(K^\star)^{\mathsf T}\) before positive parts, and set \(\widehat W_n=0\) on \(\mathcal V_n^c\). On \(\mathcal V_n\) and only where the full derivative \(D(\Phi_{\Delta,\widehat r_n}\circ\mathcal C)_{\widehat\xi_n}\) exists, define \(\widehat V_n\) by its corresponding sandwich with \(\widehat\Omega_n\); otherwise set \(\widehat V_n=0\) as a numerical placeholder. The optional \(\widehat V_n\) is not used to define \(\widehat W_n\) or any graph interval.
