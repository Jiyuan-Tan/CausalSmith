The present local-polynomial claim cannot be closed from the current class without laundering an occupancy assumption. Standard boundary-local-polynomial results require thickness of the retained design support or an explicit Gram lower bound; neither follows from the normal-link certificate. ## 2. Faithful construction and bound

Use three-fold rotations: one fold estimates Γ, one provides retained donor scores, and one supplies the target empirical distribution and directly truncated scores.

Let F_Σ,s be the unit ball of functions on S admitting the already-assumed original-coordinate C^{s−1,1} Whitney extension. For cutoff C define, on the target fold,

    L̂_C(f) = n_V⁻¹ Σ_{r∈V, X_r≠0} 1{H_k(X_r)>C} f(X_r).

For retained donor observations D_C = `{i∈D:X_i≠0,H_k(X_i)≤C}`, define

    I_C(γ) = sup_{f∈F_Σ,s} |L̂_C(f) − Σ_{i∈D_C} γ_i f(X_i)|.

Choose the lexicographically least minimizer

    γ̂_C ∈ argmin_{|γ_i|≤Λ_Σ/|D|}
      { L_s² I_C(γ)² + c_Σ Σ_i γ_i²(1+H_k(X_i)²) }.

Here Λ_Σ is a fixed signature/envelope constant. The box constraint is important: under the existing unconditional q-moment assumption it gives

    E Σ_i γ̂_i² |Z_i−μ_k(X_i)|²
      ≲ G⁻¹ {1 + E[H_k² 1{H_k≤C}]},

without adding a uniform conditional moment assumption. If D_C is empty, set γ̂_C=0. Compactness, strict coercivity, and deterministic tie-breaking make the estimator total and measurable.

The fold estimator is

    τ̂_k^ML(C)
      = n_V⁻¹ Σ_{r∈V} 1{X_r≠0,H_k(X_r)≤C} Z_r
        + Σ_{i∈D_C} γ̂_{C,i} Z_i,

then average fold rotations. This uses only Σ, the declared constants, observed X and outcomes, and Γ̂. It receives neither μ_k, Γ, a dominating stratum, nor any tail/bias index. It uses no chartwise bandwidth, local Gram, or occupancy test and automatically pools tangential directions.

Define the honest empirical extrapolation modulus

    Ω_G,Σ,k,s(C)
      = sup_{P∈P_Σ} E_P [
          min_{|γ_i|≤Λ_Σ/|D|}
          { L_s² I_C(γ)²
            + c_Σ Σ_i γ_i²(1+H_k(X_i)²) }
        ].

Then the standard minimax-linear decomposition, the weight cap, and `lem:regular-gamma` give

    sup_P ||τ̂_k^ML(C)−τ_k||₂
      ≤ C_Σ,q [
          {V̄_Σ,k(C)/G}¹ᐟ²
          + Ω_G,Σ,k,s(C)¹ᐟ²
          + G⁻¹ᐟ²
        ].

The already-proved deterministic statement remains valid:

    B̄_Σ,k,s(C)
      ≤ C_Σ,s L_s D_Σ,k,s(C)
      ≤ C′_Σ,s L_s J_Σ,k,s(C).

What is not justified is

    Ω_G,Σ,k,s(C*) ≲ R*_G,Σ,k.

That comparison is exactly the missing higher-rank/boundary transport theorem. Audibert–Tsybakov and Gaïffas show why it cannot be replaced by a generic local-polynomial citation; Sasaki–Ura likewise requires an explicit series Gram condition.

Define, if an attained oracle is desired,

    R†_G,Σ,k(C)
      = V̄_Σ,k(C)/G
        + B̄_Σ,k,s(C)²
        + Ω_G,Σ,k,s(C)
        + G⁻¹,

and let C† be its least minimizer on the existing finite grid. Then the displayed estimator attains R† up to constants without any new assumption. Keep the pole-derived R* as a deterministic geometric oracle and state that R†≲R* is open.
