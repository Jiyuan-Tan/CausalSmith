Use a fixed positive number of deterministic folds and the frozen partition. For a validation mover set \(Z_{gk}=e_k'M(X_g)^+(\Delta Y_g-\widehat\Gamma_{I^c})\), and set \(Z_{gk}=0\) when \(X_g=0\). Let \(v_s(u)=(u^\beta)_{|\beta|\le s-1}\), \(K_d(u)=c_d\prod_{a=1}^d(1-u_a^2)_+\), and, for finite \(C\), \(h_{G,C,\Sigma}=\min\{\delta_0/8,[(1+C^2)\log(G+1)/G]^{1/(2s+d)}\}\). At each query \(x\) and chart \(j\), put \(a=p_{jC}(x)\), \(u_g=(X_g-a)/h_{G,C,\Sigma}\), and \(w_{gjC}(a)=\mathbf 1\{g\in I^c,X_g\ne0,H_k(X_g)\le C\}\omega_j(X_g)K_d(u_g)\). Define \[\widehat\theta_{kjC}(a)=\left\{\sum_gw_{gjC}(a)v_s(u_g)v_s(u_g)'+G^{-2}I\right\}^{-1}\sum_gw_{gjC}(a)v_s(u_g)Z_{gk}.\] The ridge makes every normal equation total; if the weighted cell is empty its right-hand side and coefficient vector are zero. Put \(\widehat m_{kj,C}(x)=v_s((x-a)/h_{G,C,\Sigma})'\widehat\theta_{kjC}(a)\). If \(A_C=\varnothing\), set every finite-cutoff fitted extension to zero. Average \(\mathbf 1\{H_k(X_g)\le C\}Z_{gk}+\mathbf 1\{H_k(X_g)>C\}\sum_j\omega_j(X_g)\widehat m_{kj,C}(X_g)\) over validation movers and folds, returning zero if every validation fold has no mover. For \(C=\infty\), omit fitting and average the globally defined Moore--Penrose scores. This defines zero movers, empty cells, singular polynomial Gram matrices, singular history matrices, and every cutoff event.
