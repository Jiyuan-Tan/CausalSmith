Use a fixed positive number of deterministic folds and the frozen partition. For a validation mover set \(Z_{gk}=e_k'M(X_g)^+(\Delta Y_g-\widehat\Gamma_{I^c})\), and set \(Z_{gk}=0\) when \(X_g=0\). Let \(v_s(u)=(u^\beta)_{|\beta|\le s-1}\) and \(K_d(u)=c_d\prod_{a=1}^d(1-u_a^2)_+\). For finite \(C\), a query \(x\), chart \(j\), and anchor \(a=p_{jC}(x)\), let \(r_{jC}(a)\) be the supremum of \(r_0\in[0,\delta_0/8]\) for which \(B(a,r_0)\cap S\cap\operatorname{supp}\omega_j\cap\{Q>0\}\subseteq\{H_k\le a_0C\}\). Define the total query bandwidth \[h_{G,C,\Sigma,j}(a)=\min\left\{\frac{\delta_0}{8},\ \max\left\{\frac{\delta_0}{8G^2},\ \min\left\{\frac{r_{jC}(a)}4,\left[\frac{(1+C^2)\log(G+1)}G\right]^{1/(2s+d)}\right\}\right\}\right\}.\] Put \(u_g=(X_g-a)/h_{G,C,\Sigma,j}(a)\) and \(w_{gjC}(a)=\mathbf 1\{g\in I^c,X_g\ne0,H_k(X_g)\le C\}\omega_j(X_g)K_d(u_g)\). Define \[\widehat\theta_{kjC}(a)=\left\{\sum_gw_{gjC}(a)v_s(u_g)v_s(u_g)'+G^{-2}I\right\}^{-1}\sum_gw_{gjC}(a)v_s(u_g)Z_{gk}.\] The ridge makes every normal equation total; if the weighted cell is empty its right-hand side and coefficient vector are zero. Put \(\widehat m_{kj,C}(x)=v_s((x-a)/h_{G,C,\Sigma,j}(a))'\widehat\theta_{kjC}(a)\). If \(A_C=\varnothing\), set every finite-cutoff fitted extension to zero. Average \(\mathbf 1\{H_k(X_g)\le C\}Z_{gk}+\mathbf 1\{H_k(X_g)>C\}\sum_j\omega_j(X_g)\widehat m_{kj,C}(X_g)\) over validation movers and folds, returning zero if every validation fold has no mover. For \(C=\infty\), omit fitting and average the globally defined Moore--Penrose scores. This defines zero movers, empty cells, singular polynomial Gram matrices, singular history matrices, and every cutoff event.
