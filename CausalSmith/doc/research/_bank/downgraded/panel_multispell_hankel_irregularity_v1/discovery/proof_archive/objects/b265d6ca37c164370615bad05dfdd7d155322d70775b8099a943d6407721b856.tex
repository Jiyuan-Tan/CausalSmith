For each fixed certified \(\Sigma\), there is \(C<\infty\), depending only on \(\Sigma,\mathbf c,s,q,\eta\), such that for all large \(G\), \[\operatorname{Risk}_{G,k}(\Sigma)\le C R_{G,\Sigma,k}^{\star},\qquad\operatorname{Len}_{G,k}(\Sigma,\eta)\le C\sqrt{R_{G,\Sigma,k}^{\star}}.\] The upper risk is attained by \(\widehat\tau_k(C_{G,\Sigma,k}^{\star})\), and a bias-aware interval using the uniform bias envelope attains the length bound. For \(0<\alpha_{\Sigma,k}<2\), write \(v_{\Sigma,k}=2-\alpha_{\Sigma,k}\). The oracle upper-bound scale is \[R_{G,\Sigma,k}^{\star}\asymp\begin{cases}G^{-1},&2<\alpha_{\Sigma,k}\le\infty,\\G^{-1}(\log G)^{m_{\Sigma,k}+1},&\alpha_{\Sigma,k}=2,\\G^{-2\zeta_{\Sigma,k,s}/(v_{\Sigma,k}+2\zeta_{\Sigma,k,s})}(\log G)^{2\{\zeta_{\Sigma,k,s}m_{\Sigma,k}+\ell_{\Sigma,k,s}v_{\Sigma,k}\}/(v_{\Sigma,k}+2\zeta_{\Sigma,k,s})},&0<\alpha_{\Sigma,k}<2.\end{cases}\] The equality case \(\alpha_{\Sigma,k}=2\), every logarithmic multiplicity, and the bounded-score branch are retained. No tail or bias index, active stratum, \(\Gamma\), or \(\mu_k\) is supplied to the estimator.
