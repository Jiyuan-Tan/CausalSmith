Put \(c_{n,d}=n^{-1/2}d^{-1/4}\) and \(g(h)=Lh^2+c_{n,d}h^{-3/2}\).  For \(L>0\), the definition of \(h_0\) is equivalent to
\[
 Lh_0^2=c_{n,d}h_0^{-3/2}.
\]
Let \(\ell=d^{-1}\) and \(u=d^{-1/2}\).  If \(h_0\leq\ell\), then
\[
 L\ell^2\leq\inf_{h\in[\ell,u]}g(h)\leq g(\ell)\leq2L\ell^2,
\]
where the last inequality uses \(c_{n,d}\ell^{-3/2}\leq L\ell^2\).  Thus \(\inf g\asymp Ld^{-2}\).  If \(\ell<h_0<u\), then \(g(h_0)=2Lh_0^2\).  For every \(h\), either \(h\geq h_0\), in which case \(Lh^2\geq Lh_0^2\), or \(h\leq h_0\), in which case \(c_{n,d}h^{-3/2}\geq c_{n,d}h_0^{-3/2}=Lh_0^2\).  Hence
\[
 \inf g\asymp Lh_0^2=L^{3/7}(n^2d)^{-1/7}.
\]
If \(h_0\geq u\), then
\[
 c_{n,d}u^{-3/2}=\sqrt{d/n},
 \qquad Lu^2\leq c_{n,d}u^{-3/2},
\]
and monotonicity of the stochastic term gives \(\inf g\asymp\sqrt{d/n}\).  Adding the graph floor in \({\rm def:frontier-envelope}\) proves all three phase displays.

By \({\rm thm:honest-upper}\), the displayed estimator has worst-case absolute risk at most \(\mathfrak u_{n,d,L}\), so the infimum in \({\rm def:minimax-criteria}\) is no larger.  The same theorem bounds worst-case expected interval length by \(2\max\{1,\alpha^{-1/2}\}\mathfrak u_{n,d,L}\), proving the second upper inequality.  Finally, \({\rm thm:conditional-isolate-wall}\) proves the pointwise isolate assertion.  The closing sentence records that none of these upper or conditional statements supplies the missing minimax converse.
