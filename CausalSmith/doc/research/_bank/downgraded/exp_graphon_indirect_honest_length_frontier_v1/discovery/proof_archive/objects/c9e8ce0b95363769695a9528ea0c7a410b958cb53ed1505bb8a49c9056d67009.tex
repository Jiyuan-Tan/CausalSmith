For every parameter tuple satisfying the displayed model conditions for which \(\mathcal M_{n,d,L}\) is nonempty, but which need not satisfy \(\max\{r/\kappa,r\underline\lambda\}\leq\kappa\) and \(b_\psi\geq(r-1)/\sqrt r\), does there exist a constant \(c>0\) such that
\[
 R^*_{n,d,L}\geq c\mathfrak r^{\mathrm{sup}}_{n,d,L},
 \qquad
 \Lambda^*_{n,d,L}(\alpha)\geq c\mathfrak r^{\mathrm{sup}}_{n,d,L}
\]
for all sufficiently large \(n\)?  The handle is to characterize enough of the compatibility region for bounded nonnegative exact-rank graphons, then build within each compatible class analogues of the linear, smooth-bump, and exposure-lattice experiments from \({\rm thm:minimax\text{-}lower}\).  The block construction proves the result only on its explicit sufficient region; it does not characterize nonemptiness outside that region.
