At every index for which \(\mathcal H_{n,d}\ne\varnothing\), put \(\ell=d^{-1}\), \(u=\min\{d^{-1/2},1/2\}\), and, for each realized graph \(A\), define the finite nonempty candidate set
\[
 \mathcal K(A)=\{\ell,u\}\cup
 \left\{\left|\frac m{N_i}-\frac12\right|:
 i\in\mathcal V_n,\ N_i>0,\ 0\leq m\leq N_i,\
 \ell\leq\left|\frac m{N_i}-\frac12\right|\leq u\right\}.
\]
The graph-adaptive operational bandwidth is
\[
 \widehat h(A)=\min\operatorname*{argmin}_{h\in\mathcal K(A)}
 \{\overline b_h(A)+\overline s_h(A)\}.
\]
All ties are therefore resolved deterministically toward the smallest candidate.  The construction uses only the observed graph, the known constants, and the finite-lattice certificates; it does not use \(Z\) or the observed outcomes.
