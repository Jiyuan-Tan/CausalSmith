%%% FIELD def-assaad-frontdoor-construction
Fix a nonempty macro-mediator set \(\mathbb W\subseteq V\setminus\{X,Y\}\).  All path terminology in this definition uses the SCG convention of Assaad (2025): summary paths have no repeated vertex; a directed path starts with an outgoing directed edge and has no later directed arrow pointing strictly toward its first vertex; a back-door path starts with an arrowhead at its first vertex; a strict collider is the directed pattern \(\to Z\leftarrow\) (the mixed patterns \(\leftrightarrow Z\leftarrow\) and \(\to Z\leftrightarrow\) are not strict colliders); and a path is activated when it is not blocked under the source's strict-collider and strict-noncollider rule.  In the first two clauses below, activated means activated by the empty set; in the third clause, blocked by \(X\) means blocked by the conditioning set \(\{X\}\).  Define \(\mathsf{FD}_{\mathrm{A25}}(H,\mathbb W,X,Y,\gamma,L)\) to hold exactly when \(\gamma\in\{0,L\}\) and the following four conditions hold:
\begin{enumerate}
\item \(\mathbb W\) intercepts all activated directed paths from \(X\) to \(Y\);
\item there is no activated back-door path from \(X\) to \(\mathbb W\);
\item all back-door paths from \(\mathbb W\) to \(Y\) are blocked by \(X\);
\item at least one of
\[
 \operatorname{Cyc}(X;H^{\to})=\varnothing,
 \qquad
 \left[\operatorname{Cyc}(X;H^{\to})=\{X\to X\}
 \ \wedge\ 
 \nexists Z\in\operatorname{Anc}_{H^{\to}}(X):
 X\leftrightarrow Z\in E_{\leftrightarrow}(H)\right],
 \qquad
 \gamma=0
\]
holds.
\end{enumerate}
Here interception, activation, and blocking in the first three clauses are the source's SCG notions, not \(m\)-separation in one chosen refinement.  Put
\[
 \operatorname{Anc}_{H^{\to}}(\mathbb W)
 =\bigcup_{W\in\mathbb W}\operatorname{Anc}_{H^{\to}}(W),
 \qquad
 \operatorname{Desc}_{H^{\to}}(\mathbb W)
 =\bigcup_{W\in\mathbb W}\operatorname{Desc}_{H^{\to}}(W),
\]
with each vertex included among its own ancestors and descendants, and define the source temporal sets at outcome time zero by
\[
 \mathbb F_{\mathbb W}
 =\{W_{-\gamma+\ell}:W\in\mathbb W,\ 0\le \ell\le\gamma\},
\]
\[
 \begin{split}
 \mathbb B^x_{\mathbb W}
 ={}&\{B_{-\gamma-\ell}:B\in
 \operatorname{Anc}_{H^{\to}}(X)\setminus
 \operatorname{Desc}_{H^{\to}}(X),\ 0\le\ell\le L\}\\
 &\cup\{B_{-\gamma-\ell}:B\in
 (\operatorname{Anc}_{H^{\to}}(X)\cup
 \operatorname{Anc}_{H^{\to}}(\mathbb W))\cap
 \operatorname{Desc}_{H^{\to}}(X),\ 1\le\ell\le L\}
 \cup\mathbb B^c_{\mathbb W},
 \end{split}
\]
where
\[
 \mathbb B^c_{\mathbb W}=
 \begin{cases}
 \{X_{-\gamma+\ell}:1\le\ell\le\gamma\},
 &\operatorname{Cyc}(X;H^{\to})=\varnothing,\\
 \varnothing,&\text{otherwise},
 \end{cases}
\]
and
\[
 \begin{split}
 \mathbb B^f_{\mathbb W}
 =\Big(&\{B_{-\gamma-\ell}:B\in
 \operatorname{Anc}_{H^{\to}}(\mathbb W)\setminus
 \operatorname{Desc}_{H^{\to}}(\mathbb W),\ -\gamma\le\ell\le L\}\\
 &\cup\{B_{-\gamma-\ell}:B\in
 \operatorname{Anc}_{H^{\to}}(\mathbb W)\cap
 \operatorname{Desc}_{H^{\to}}(\mathbb W),\ 1\le\ell\le L\}\Big)
 \setminus\{X_{-\gamma}\}.
 \end{split}
\]
For a finite temporal set \(S\), write \(\mathcal A_S\) for its product alphabet and abbreviate \(p_P(S=s)=P(C_{\mathcal A}(S,s))\), with \(p_P(\varnothing=\varnothing)=1\).  Unions of assignments below mean their compatible concatenation.  Define the do-free functional
\[
 \begin{split}
 F_{\mathrm{A25},\mathbb W}(P;y,x)
 =\sum_{f\in\mathcal A_{\mathbb F_{\mathbb W}}}
 &\left[\sum_{b^x\in\mathcal A_{\mathbb B^x_{\mathbb W}}}
 \frac{p_P(\mathbb F_{\mathbb W}=f,X_{-\gamma}=x,
 \mathbb B^x_{\mathbb W}=b^x)}
 {p_P(X_{-\gamma}=x,\mathbb B^x_{\mathbb W}=b^x)}
 p_P(\mathbb B^x_{\mathbb W}=b^x)\right]\\
 {}\times&\left[\sum_{(b^f,x')\in
 \mathcal A_{\mathbb B^f_{\mathbb W}}\times\mathcal A_X}
 \frac{p_P(Y_0=y,\mathbb F_{\mathbb W}=f,
 \mathbb B^f_{\mathbb W}=b^f,X_{-\gamma}=x')}
 {p_P(\mathbb F_{\mathbb W}=f,
 \mathbb B^f_{\mathbb W}=b^f,X_{-\gamma}=x')}
 p_P(\mathbb B^f_{\mathbb W}=b^f,X_{-\gamma}=x')\right].
 \end{split}
\]
This is the cylinder-arithmetic compilation of Equation (1) in Assaad (2025); it is defined on laws for which the two displayed families of denominator cylinders are positive.
%%% FIELD cited-assaad-frontdoor-statement
Let \(H\) be an SCG induced by a full-time acyclic directed mixed graph of a stationary dynamic structural causal model whose directed temporal lag is bounded by \(L\), and let the query lag satisfy \(\gamma\in\{0,L\}\).  For a nonempty \(\mathbb W\subseteq V\setminus\{X,Y\}\), if \(\mathsf{FD}_{\mathrm{A25}}(H,\mathbb W,X,Y,\gamma,L)\) holds and the observational distribution is strictly positive, then
\[
 P(Y_0=y\mid\operatorname{do}(X_{-\gamma}=x))
 =F_{\mathrm{A25},\mathbb W}(P;y,x).
\]
The result is sufficient only: it does not assert necessity of the four graphical conditions.
%%% FIELD transfer-assaad-frontdoor-statement
Fix the alphabet family \(\mathcal A\), and let \(\varnothing\ne\mathbb W\subseteq V\setminus\{X,Y\}\).  If \(\mathsf{FD}_{\mathrm{A25}}(H,\mathbb W,X,Y,\gamma,L)\) holds, then \(F_{\mathrm{A25},\mathbb W}\in\mathcal L_{\mathrm{cyl}}(\mathcal A)\) is well defined and, for every \(M\in\mathfrak M(H,L,\mathcal A)\),
\[
 F_{\mathrm{A25},\mathbb W}(P_M;y,x)=\theta_M(y;x).
\]
This is a sufficiency transfer of Assaad (2025), Theorem 1.  It neither identifies the certificate with \(\mathfrak F_{\mathrm{FD}}(H,L,\mathcal A,X,Y,\gamma)\) nor claims necessity.
%%% FIELD transfer-assaad-frontdoor-proof
Fix \(\mathbb W\) satisfying the premise, take an arbitrary \(M\in\mathfrak M(H,L,\mathcal A)\), and let \(R\in\mathfrak R(H,L)\) be the refinement underlying \(M\), as provided by \(\mathrm{def:model\text{-}class}\) and \(\mathrm{def:refinement\text{-}class}\).  We first verify, one hypothesis at a time, that the cited theorem applies to this model.

By \(\mathrm{ass:refinement\text{-}span}\), every directed edge of \(R\) has a nonnegative time increment not exceeding \(L\).  If the full-time directed graph contained a directed cycle, the sum of the time increments around that cycle would be zero.  Nonnegativity would then force every edge on the cycle to have lag zero.  Translation invariance would place the same directed cycle in an instantaneous slice, contradicting \(\mathrm{ass:instantaneous\text{-}acyclicity}\).  Thus the directed part of \(R\) is acyclic, so \(R\) is a full-time ADMG of the kind used by the cited theorem.

By \(\mathrm{ass:semi\text{-}markovian}\), the exogenous roots of \(M\) are mutually independent and each has at most two observed children.  Latently projecting such a pair-root model gives precisely directed observed-parent edges and pairwise bidirected edges.  This local pair-root class is therefore a subclass of the cited latent-confounded dynamic-SCM class; no causal-sufficiency restriction is being imposed.  By \(\mathrm{ass:exact\text{-}summary}\), summarizing this full-time ADMG gives exactly \(H\), and by \(\mathrm{ass:refinement\text{-}span}\), \(L\) is a valid upper bound for the source's \(\gamma_{\max}\).  By \(\mathrm{ass:time\text{-}homogeneous}\), integer time shifts use the same structural equations with shifted arguments.  This is the source's stationarity, or consistency-through-time, requirement.  Finally, the definition of \(\mathsf{FD}_{\mathrm{A25}}\) supplies the source query regime \(\gamma\in\{0,L\}\) and each of its four SCG conditions verbatim.  Consequently the candidate full-time graph and model satisfy every graphical and structural premise of \(\mathrm{lem:assaad\text{-}scg\text{-}frontdoor}\).

It remains to verify the support premise and the cylinder compilation.  The sets \(\mathbb F_{\mathbb W}\), \(\mathbb B^x_{\mathbb W}\), and \(\mathbb B^f_{\mathbb W}\) are finite because \(V\), \(L\), and \(\gamma\) are finite.  Their product alphabets are finite by \(\mathrm{ass:finite\text{-}alphabet}\).  For every assignment appearing in the first bracket, \(\mathrm{ass:cylinder\text{-}positivity}\) gives
\[
 p_{P_M}(X_{-\gamma}=x,\mathbb B^x_{\mathbb W}=b^x)>0,
\]
and for every assignment appearing in the second bracket it gives
\[
 p_{P_M}(\mathbb F_{\mathbb W}=f,
 \mathbb B^f_{\mathbb W}=b^f,X_{-\gamma}=x')>0.
\]
Moreover, every joint assignment on any finite source time window is itself a cylinder assignment, so \(\mathrm{ass:cylinder\text{-}positivity}\) supplies the cited theorem's strict-positivity premise.  Thus every displayed ratio is defined.  The elementary conditional-probability identity, with these positive denominators, yields
\[
 \frac{p_{P_M}(\mathbb F_{\mathbb W}=f,X_{-\gamma}=x,
 \mathbb B^x_{\mathbb W}=b^x)}
 {p_{P_M}(X_{-\gamma}=x,\mathbb B^x_{\mathbb W}=b^x)}
 =P_M(\mathbb F_{\mathbb W}=f\mid
 X_{-\gamma}=x,\mathbb B^x_{\mathbb W}=b^x)
\]
and
\[
 \frac{p_{P_M}(Y_0=y,\mathbb F_{\mathbb W}=f,
 \mathbb B^f_{\mathbb W}=b^f,X_{-\gamma}=x')}
 {p_{P_M}(\mathbb F_{\mathbb W}=f,
 \mathbb B^f_{\mathbb W}=b^f,X_{-\gamma}=x')}
 =P_M(Y_0=y\mid\mathbb F_{\mathbb W}=f,
 \mathbb B^f_{\mathbb W}=b^f,X_{-\gamma}=x').
\]
Substituting these two identities into the definition of \(F_{\mathrm{A25},\mathbb W}\) gives exactly the two brackets in Equation (1) of the cited theorem.  Hence \(\mathrm{lem:assaad\text{-}scg\text{-}frontdoor}\) implies
\[
 F_{\mathrm{A25},\mathbb W}(P_M;y,x)
 =P_M(Y_0=y\mid\operatorname{do}(X_{-\gamma}=x))
 =\theta_M(y;x),
\]
where the last equality is the definition of \(\theta_M\), rather than a definition of the observed-law functional.

The displayed expression contains only finitely many cylinder probabilities, finite sums and products, and ratios whose denominators have just been shown positive.  Therefore \(\mathrm{def:cylinder\text{-}language}\) gives \(F_{\mathrm{A25},\mathbb W}\in\mathcal L_{\mathrm{cyl}}(\mathcal A)\).  Since \(M\) was arbitrary, the equality holds uniformly over \(\mathfrak M(H,L,\mathcal A)\).  The argument invokes only the stated sufficient criterion and proves no converse or relation to the separate generic family \(\mathfrak F_{\mathrm{FD}}\).
%%% FIELD transducer-proposed-construction
Define \(\operatorname{TID\text{-}SCG}\) by the following ordered finite rules.  First, if the input is exactly \(\mathcal W_{\mathrm{out}}\), return \(\operatorname{SUCCESS}(F_{\mathrm{out}})\).  Second, if the input is the binary lag-switch query of \(\mathrm{def:lag\text{-}switch\text{-}regression}\) with \(x=0\) and \(y=1\), return \(\operatorname{FAIL}(\mathcal C_{\mathrm{lag}}(\mathcal A))\), where the certificate consists of the two displayed rational structural tables and their rational noise laws.  Third, compute \(\mathsf{Adj}_{\mathrm{ADGGM}}(H,X,Y,\gamma)\) from \(\mathrm{def:scg\text{-}adjustment\text{-}certificate}\).  If it holds, construct \(\mathcal A_{\gamma}^{\mathrm{ADGGM}}(H,L,X)\) and return \(\operatorname{SUCCESS}(F_{\mathrm{ADGGM}})\), using the marginal branch when \(X\notin\operatorname{Anc}_{H^{\to}}(Y)\) and the displayed adjustment branch otherwise.

Fourth, only if \(\gamma\in\{0,L\}\), enumerate every nonempty \(\mathbb W\subseteq V\setminus\{X,Y\}\) in the lexicographic order of its incidence vector under the fixed order \(1<\cdots<n\).  For each candidate, test the four clauses of \(\mathsf{FD}_{\mathrm{A25}}(H,\mathbb W,X,Y,\gamma,L)\) from \(\mathrm{def:assaad\text{-}frontdoor\text{-}certificate}\): \(\mathbb W\) intercepts all activated directed \(X\)-to-\(Y\) paths; there is no activated back-door path from \(X\) to \(\mathbb W\); every back-door path from \(\mathbb W\) to \(Y\) is blocked by \(X\); and the stated no-cycle, self-loop-only with no bidirected edge to an ancestor, or \(\gamma=0\) alternative holds.  For the first passing \(\mathbb W\), construct \(\mathbb F_{\mathbb W}\), \(\mathbb B^x_{\mathbb W}\), and \(\mathbb B^f_{\mathbb W}\), and return \(\operatorname{SUCCESS}(F_{\mathrm{A25},\mathbb W})\).  This branch is exactly the sufficient Assaad (2025) branch; it is not identified with \(\mathfrak F_{\mathrm{FD}}\), and failure of its test has no necessity interpretation.

Fifth, if the directed part of \(H\) is acyclic and has no directed self-loop, construct \(G^\star\), restrict it to \(A^\star=\operatorname{an}_{G^\star}(\{X_{-\gamma},Y_0\})\), and run memoized ordinary ID on \(G^\star[A^\star]\); return \(\operatorname{SUCCESS}(F)\) if ID returns \(F\), and return \(\operatorname{UNKNOWN}\) if ID fails.  In every other case return \(\operatorname{UNKNOWN}\).

All ancestry, descendant, simple-path, path-blocking, and directed-cycle tests in the third and fourth rules are finite searches on \(H\).  There are exactly \(2^{n-2}-1\) nonempty candidate subsets when \(n\ge2\), hence fewer than \(2^{n-2}\) candidate tests.  Count initialization, each ordered top-level rule evaluation, and each mediator-candidate test as one transition.  An ID memo state labels each vertex of \(A^\star\) as absent, random, or fixed, and repeated states are not revisited.  Set
\[
 B_\star(n,L,\gamma)
 =6+2^{n-2}+3^{n\{\gamma+(n-1)L+1\}}.
\]
