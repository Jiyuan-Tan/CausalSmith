The first two lag-one special branches of \(\operatorname{TID\text{-}SCG}(H,0,\mathcal A,X,Y,0,x,y)\) cannot match.  If \(\mathsf{Adj}_{\mathrm{ADGGM}}(H,X,Y,0)\) holds, the procedure returns \(\operatorname{SUCCESS}(F_{\mathrm{ADGGM}})\), which is uniformly valid.  Otherwise the procedure enumerates the nonempty sets \(\mathbb W\subseteq V\setminus\{X,Y\}\); if one satisfies \(\mathsf{FD}_{\mathrm{A25}}(H,\mathbb W,X,Y,0,0)\), it returns the uniformly valid \(\operatorname{SUCCESS}(F_{\mathrm{A25},\mathbb W})\) for the first such set.  If no such set passes, it makes one ordinary-ID call on the relevant ancestral subgraph.  If ID succeeds, it returns \(\operatorname{SUCCESS}(F)\), where \(F\) is the ordinary-ID functional on the common product alphabet and satisfies \(F(P_M)=\theta_M(y;x)\) for every \(M\in\mathfrak M(H,0,\mathcal A)\); if ID fails, it returns \(\operatorname{UNKNOWN}\).  No fixed-alphabet stationary hedge lift is claimed on the ID-failure branch.

%%% FIELD proof-static-reduction
Assume \(L=0\).  Since \(0\leq\gamma\leq L\), necessarily
\[
 \gamma=0.
\]
Let \(R\in\mathfrak R(H,0)\).  By \(\mathrm{ass:refinement\text{-}span}\), every directed edge has the form \(i_t\to j_t\), and every bidirected edge has the form \(i_t\leftrightarrow j_t\).  Translation invariance of the stationary refinement gives, for every \(k\in\mathbb Z\),
\[
 i_t\to j_t\in E_{\to}(R)
 \iff i_{t+k}\to j_{t+k}\in E_{\to}(R),
\]
and the analogous equivalence for bidirected edges.  Hence \(R\) is the translation closure of its time-zero mixed graph.  By \(\mathrm{ass:exact\text{-}summary}\), that time-zero graph has exactly the coordinate edges of \(H\).  It is a finite static ADMG by \(\mathrm{ass:instantaneous\text{-}acyclicity}\).

The same argument shows that \(H^{\to}\) is acyclic and loop-free.  Indeed, a directed cycle through distinct summary vertices, or a directed self-loop, would appear in the time-zero slice and contradict \(\mathrm{ass:instantaneous\text{-}acyclicity}\).

The first two rules of \(\mathrm{def:transducer\text{-}handle}\) require their displayed lag-one inputs, so neither can match when \(L=0\).  If \(\mathsf{Adj}_{\mathrm{ADGGM}}(H,X,Y,0)\) holds, the next rule returns \(\operatorname{SUCCESS}(F_{\mathrm{ADGGM}})\), and \(\mathrm{prop:scg\text{-}adjustment\text{-}transfer}\) gives
\[
 F_{\mathrm{ADGGM}}\in\mathcal L_{\mathrm{cyl}}(\mathcal A),
 \qquad
 F_{\mathrm{ADGGM}}(P_M;y,x)=\theta_M(y;x)
 \quad(M\in\mathfrak M(H,0,\mathcal A)).
\]

If the adjustment test fails, the condition \(\gamma=0\in\{0,L\}\) makes the Assaad enumeration eligible.  There are finitely many nonempty \(\mathbb W\subseteq V\setminus\{X,Y\}\).  For the first set passing \(\mathsf{FD}_{\mathrm{A25}}(H,\mathbb W,X,Y,0,0)\), \(\mathrm{def:transducer\text{-}handle}\) returns \(\operatorname{SUCCESS}(F_{\mathrm{A25},\mathbb W})\), while \(\mathrm{prop:assaad\text{-}frontdoor\text{-}transfer}\) proves
\[
 F_{\mathrm{A25},\mathbb W}\in\mathcal L_{\mathrm{cyl}}(\mathcal A),
 \qquad
 F_{\mathrm{A25},\mathbb W}(P_M;y,x)=\theta_M(y;x)
 \quad(M\in\mathfrak M(H,0,\mathcal A)).
\]

Suppose no candidate passes.  The acyclic and loop-free property proved above activates the saturated ordinary-ID rule.  With \(L=\gamma=0\), \(\mathrm{prop:acyclic\text{-}summary\text{-}reduction}\) gives
\[
 A^\star\subseteq V\times[0,0].
\]
Thus the saturated ancestral graph is exactly the relevant ancestral subgraph of the common static ADMG.  If ordinary ID returns \(F\), the same proposition gives
\[
 F\in\mathcal L_{\mathrm{cyl}}(\mathcal A),
 \qquad
 F(P_M)=\theta_M(y;x)
 \quad(M\in\mathfrak M(H,0,\mathcal A)).
\]
If ID fails, the definition returns \(\operatorname{UNKNOWN}\).  Neither the definition nor \(\mathrm{thm:tid\text{-}dichotomy}\) converts that failure into a fixed-alphabet stationary pair, so no hedge-lift claim follows.

%%% FIELD proof-easyrca-abstention
Let the successful queries in the fixed finite collection be indexed by \(1\leq j\leq m\), with returned functionals \(F_j\).  A collection with at most one successful query has a trivial ordering, so suppose \(m\geq2\).  By \(\mathrm{thm:tid\text{-}dichotomy}\), each is a finite-cylinder observed-law functional and satisfies
\[
 \theta_j=F_j(p_{F_j})
\]
throughout its compatible model class.  Under the hypotheses of \(\mathrm{thm:cylinder\text{-}hac}\), each plug-in estimator is consistent.  Equivalently, \(\mathrm{prop:finite\text{-}margin\text{-}plugin\text{-}ranking}\) applies and gives the desired ordering.  Explicitly, for every \(j\),
\[
 \widehat\theta_{F_j}-\theta_j\overset p\longrightarrow0.
\]
Because \(m\) is fixed and finite, the union bound gives
\[
 \max_{1\leq j\leq m}|\widehat\theta_{F_j}-\theta_j|
 \overset p\longrightarrow0.
\]
If
\[
 \Delta=\min_{j\ne k}|\theta_j-\theta_k|>0,
\]
then on the event where the preceding maximum is smaller than \(\Delta/2\), every pairwise sign is preserved:
\[
 \operatorname{sign}(\widehat\theta_{F_j}-\widehat\theta_{F_k})
 =\operatorname{sign}(\theta_j-\theta_k).
\]
The probability of this event tends to one, proving consistency of the ranking restricted to successes.

On a \(\operatorname{FAIL}\) output, \(\mathrm{thm:tid\text{-}dichotomy}\) supplies two directly constructed final models on the fixed alphabet family with the same entire observed-process law and unequal causal scores.  Hence the observed law cannot select a unique causal rank for that query.  An \(\operatorname{UNKNOWN}\) output carries neither an identifying functional nor a nonidentification certificate.  Excluding both tags therefore ranks exactly the certified causal scores and preserves the distinct meanings of certified failure and unresolved abstention.
