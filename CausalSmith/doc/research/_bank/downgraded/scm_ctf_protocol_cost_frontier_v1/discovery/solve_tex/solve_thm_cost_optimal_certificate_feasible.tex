 q=\left\lceil\log_2(n+L+M+2)\right\rceil.

bits.  Indeed, the masks use at most \(3n(n+1)\) bits and the remaining count and framing data use at most \((n+1)q+2(n+1)\) bits, whose sum is bounded by the left side of (9). %%% FIELD switching-cover-proof
Write \(m=|\mathcal A|\), \(L=|\mathrm{LIT}|\), and let \(E\) be accepted by \(\operatorname{Acc}_{\mathrm{sw}}\).  Let \(\mathcal P(E)\) be the distinct protocols occurring in its nonempty records.  Each \(\alpha\in\Omega\) occurs in exactly one such record, and the record passes \(\mathsf{Succ}_{\alpha}\).  Definition~\(\mathrm{Switching\ protocol\mbox{-}to\mbox{-}branch\ cover\ incidence}\) therefore gives
\[
 \Omega\subseteq\bigcup_{S\in\mathcal P(E)}K_{\mathrm{sw}}(S).
 \tag{13}
\]
Every incidence set is contained in \(\Omega\), so equality holds in (13).  After deleting any index-zero marker, Definition~\(\mathrm{Distinct\mbox{-}protocol\ cost}\) gives
\[
 \operatorname{Cost}(E)
 =\sum_{S\in\mathcal P(E)}\sum_{a\in S}c(a)
 =\sum_{S\in\mathcal P(E)}w(S).
 \tag{14}
\]
Without deletion the right side of (14) is no larger, because marker-only protocols have nonnegative weight.

Conversely, let \(\mathcal P\subseteq\Pi\) cover \(\Omega\).  For each \(\alpha\), choose the first \(S\in\mathcal P\) with \(\alpha\in K_{\mathrm{sw}}(S)\), and then the first tuple \((\ell,T,\tau)\) witnessing the existential definition of this incidence.  Make one singleton-index record for \(\alpha\).  Every local legality, oracle, event-local support, measured-ancestry, and transcript check holds because \(\mathsf{Succ}_{\alpha}=1\).  Since every branch occurs exactly once, the exhaustive factor-and-branch search on the decoded source collection finds a successful witness in every branch and returns nonfailure.  Definition~\(\mathrm{Sparse\ switching\ operational\ acceptance}\) therefore accepts the resulting certificate.  Protocols in \(\mathcal P\) unused by the chosen records may be omitted; by nonnegativity this does not increase cost.  Taking minima in the two constructions, and using finiteness of \(\Pi\), proves the derived identity
\[
 \operatorname{Opt}_{\mathrm{sw}}
 =\min_{\mathcal P\subseteq\Pi:\,\bigcup_{S\in\mathcal P}K_{\mathrm{sw}}(S)=\Omega}
   \sum_{S\in\mathcal P}w(S),
 \tag{15}
\]
with value \(+\infty\) when the cover family is empty.  This is a consequence of operational acceptance and distinct-protocol charging, not a definition of the causal query.

We next construct the incidence relation.  Enumerate the \(2^m\) protocol masks.  The explicit catalogue decides SELECT cardinality, fresh-unit typing, at-most-once mechanism use, precedence, and conflicts by scans of the input; Lemma~\(\mathrm{Published\ CTF\mbox{-}REALIZE\ runtime}\) decides physical compatibility in polynomial time.  Query each legal protocol at most once and cache its immutable reply.  A \(\bot\) reply gives empty incidence.  For every other reply, enumerate the \(2^L\) literal masks, reject inconsistent or uncatalogued labels, and consult the exact support table only for the event actually used by that label.  A zero-mass used event is rejected; zero mass at an unused cell has no effect.  The ancestral and district decomposition of each surviving slice yields at most \(|V|\) canonical single-district source factors, and measured ancestry is decided from the READ endpoints and action-fixed vertices.

Suppose the free request positions of factor \(C_j\) have domain sizes \(h_1,\ldots,h_r\).  The equality type is induced by the assignment, not chosen independently.  The literal table has one request literal for each value at each such position.  Hence
\[
 |\Omega_j|=\prod_{u=1}^{r}h_u
 \leq 2^{\sum_{u=1}^{r}h_u}
 \leq 2^L,
 \qquad
 M=\sum_{j=1}^{k}|\Omega_j|\leq k2^L.
 \tag{16}
\]
For each enumerated \((\alpha,S,\ell,T)\), instantiate the value matches and apply the ancestor--district recursion.  Proposition~\(\mathrm{Connected\mbox{-}ancestor\ obstruction}\) decides failure on each fixed connected factor call; on success Lemma~\(\mathrm{Fixed\ transcript\ size}\) produces its canonical finite transcript.  Thus the enumeration records exactly the true incidence bits.  Since \(k\leq |V|\leq N_{\mathrm{in}}\), the number of branch checks is bounded by
\[
 2^m2^L|V|M
 \leq 2^{O(m+L)}\operatorname{poly}(N_{\mathrm{in}}).
 \tag{17}
\]
Reading all queried handles and support tables contributes their actual total length \(N_{\mathcal O}\).  Consequently complete incidence construction uses at most \(2^m\) distinct oracle queries and
\[
 2^{O(m+L)}\operatorname{poly}(N_{\mathrm{in}}+N_{\mathcal O})
 \tag{18}
\]
work.

List the protocols with nonempty incidence as \(S_1,\ldots,S_p\), where \(p\leq2^m\).  For \(U\subseteq\Omega\), initialize \(D_0(\varnothing)=0\), \(D_0(U)=+\infty\) for \(U\ne\varnothing\), and define
\[
 D_i(U)=\min\{D_{i-1}(U),\ D_{i-1}(U\setminus K_{\mathrm{sw}}(S_i))+w(S_i)\}.
 \tag{19}
\]
Induction on \(i\) shows that \(D_i(U)\) is the least weight of a subcollection of the first \(i\) protocols covering \(U\): an optimum either omits \(S_i\), giving the first term, or contains it, leaving \(U\setminus K_{\mathrm{sw}}(S_i)\) for earlier protocols and giving the second.  Thus (19) evaluates (15) in \(O(p2^M)\) exact rational operations.  Alternatively enumerate the \(2^p\) protocol subsets and test their unions.  Choosing the faster method and adding (18) gives
\[
 2^{O(m+L+\min\{M,2^m\})}
 \operatorname{poly}(N_{\mathrm{in}}+N_{\mathcal O}).
 \tag{20}
\]

Finally, run weighted greedy on the explicit incidence.  First include every zero-cost protocol that covers a new branch.  If \(r>0\) branches remain, fix an optimum cover \(\mathcal P^{\star}\).  If \(t_S\) is the number of remaining branches covered by \(S\in\mathcal P^{\star}\), then
\[
 \sum_{S\in\mathcal P^{\star}}t_S\geq r,
 \qquad
 \sum_{S\in\mathcal P^{\star}}w(S)=\operatorname{Opt}_{\mathrm{sw}}.
 \tag{21}
\]
Therefore some \(S\in\mathcal P^{\star}\) with \(t_S>0\) has
\[
 \frac{w(S)}{t_S}\leq\frac{\operatorname{Opt}_{\mathrm{sw}}}{r}.
 \tag{22}
\]
Greedy chooses a ratio no larger than (22).  Charge its ratio to each newly covered branch.  Ordering branches by the time they are covered makes the successive denominators at least \(M,M-1,\ldots,1\), and the charges sum to the greedy cost.  Hence
\[
 \operatorname{Cost}(E_{\mathrm{greedy}})
 \leq \operatorname{Opt}_{\mathrm{sw}}\sum_{r=1}^{M}\frac1r
 =H_M\operatorname{Opt}_{\mathrm{sw}}.
 \tag{23}
\]
If the optimum is zero, the initial zero-cost phase covers all branches and the same inequality holds.  The cover-to-certificate construction preceding (15) turns the greedy cover into an accepted certificate.  Greedy is polynomial in the explicit incidence size, so its total construction time is (18).  This proves all asserted equalities, resource bounds, and qualifications.

%%% FIELD cost-optimal-proof
Operational feasibility and Lemma~\(\mathrm{Sparse\ canonical\ certificate\ bound}\) give a nonempty finite set of accepted canonical certificates of length at most \(B_{\mathrm{sw}}\).  Their costs are finite sums of input binary rationals.  Therefore that cost set has a minimum, and lexicographic order selects the unique first minimizer \(E_{\mathrm{sw}}^{\star}\).  The same lemma gives
\[
 \operatorname{Cost}(E_{\mathrm{sw}}^{\star})=\operatorname{Opt}_{\mathrm{sw}},
 \qquad
 N_{E_{\mathrm{sw}}^{\star}}\leq B_{\mathrm{sw}}.
 \tag{24}
\]

Theorem~\(\mathrm{Switching\ weighted\mbox{-}cover\ frontier}\) constructs the complete relation \(K_{\mathrm{sw}}(S)\) using at most \(2^{|\mathcal A|}\) source-oracle queries and proves that its minimum-weight cover value equals \(\operatorname{Opt}_{\mathrm{sw}}\).  Its branch-mask recurrence or protocol-subset enumeration therefore computes that value in
\[
 2^{O(|\mathcal A|+|\mathrm{LIT}|+\min\{M,2^{|\mathcal A|}\})}
 \operatorname{poly}(N_{\mathrm{in}}+N_{\mathcal O})
 \tag{25}
\]
time.  Exact addition and comparison are polynomial-time operations in the total bit length of the binary-rational costs.

We explain why the same bound returns the stipulated lexicographically first certificate rather than only its cost.  During incidence construction retain, in encoding order, every canonical successful record witnessing each pair \((S,\alpha)\).  There are at most \(2^{|\mathcal A|+|\mathrm{LIT}|}\operatorname{poly}(N_{\mathrm{in}})\) such records: for fixed \((S,\ell)\), the district decomposition yields at most \(|V|\) source factors, and the branch universe has \(M\leq k2^{|\mathrm{LIT}|}\).  A normalized certificate chooses exactly one such record for each \(\alpha\), and its cost is the weight of the union of the protocols appearing in those choices.

Augment recurrence (19) in the weighted-cover proof with predecessor pointers and lexicographic tie-breaking among equal-cost states.  Equivalently, for any proposed prefix of the sorted sparse-certificate encoding, discard records incompatible with that prefix, force the records already completed by it, and rerun the same cover recurrence on the remaining branch indices and admissible protocol incidences.  This test returns the minimum possible total protocol-union cost of a completion: the induction used for (19) remains valid after replacing each incidence by the branches having at least one prefix-compatible record, and forced protocol weights are charged once before the recurrence.  Trying the next bit, including the self-delimiting end decision, in increasing order while retaining the first prefix whose completion cost is \(\operatorname{Opt}_{\mathrm{sw}}\) preserves the invariant that an optimal completion exists.  At termination the resulting string is optimal.  If a lexicographically smaller optimum existed, its first differing bit would have passed the same test, a contradiction.

The number of prefix tests is polynomial in the explicit record universe and the output bound.  By Definition~\(\mathrm{Sparse\ canonical\ switching\mbox{-}certificate\ bound}\), \(B_{\mathrm{sw}}\) is polynomial in \(M\), \(|\mathcal A|\), \(|\mathrm{LIT}|\), \(|V|\), and their logarithms; since \(M\leq k2^{|\mathrm{LIT}|}\), that extra factor is absorbed in (25).  Decoding the selected records outputs the protocol masks, exact literal masks, labelled source masks, \(q_M\)-bit singleton branch indices, and canonical finite transcripts asserted in the theorem.

The incidence construction caches the immutable reply to each protocol mask.  Thus each mask is queried at most once, every handle and every support-table bit actually returned is included in \(N_{\mathcal O}\), and none is hidden in \(N_{\mathrm{in}}\) or in the certificate length.  The greedy part of Theorem~\(\mathrm{Switching\ weighted\mbox{-}cover\ frontier}\) supplies, from the same table, an accepted certificate satisfying
\[
 \operatorname{Cost}(E_{\mathrm{greedy}})
 \leq H_M\operatorname{Opt}_{\mathrm{sw}}
 \tag{26}
\]
within \(2^{O(|\mathcal A|+|\mathrm{LIT}|)}\operatorname{poly}(N_{\mathrm{in}}+N_{\mathcal O})\) time.  Every support test in these constructions concerns an event actually used in a record.  Finally, (24)--(26) optimize only \(\operatorname{Acc}_{\mathrm{sw}}\); no semantic completeness theorem, scalar evaluation of \(Q\), or positivity of an unused cell is used.

  \left(\prod_{v\in B(S)\setminus D}|\mathfrak X_v|^{-1}\right)
  P_{(b_D,b_{B(S)\setminus D})}(R=r)}.
\end{aligned}
\tag{41}
\]
If there is no READ conditioning, take the denominator in (41) to be one.  Otherwise it is strictly positive because the accepted record actually uses that conditioning event and the support check is a clause of \(\operatorname{Acc}_{\mathrm{sw}}\).  Thus (41) is a finite composition of marginals, mixtures, and a conditional formed from members of
\(\mathcal Q_{\mathbf B(E_{\mathrm{batch}})}\), exactly within the deterministic preprocessing allowed by Definition~\(\mathrm{Ordinary\ full\mbox{-}kernel\ source\ family}\).  It requires no positivity at any unasserted READ cell.

Every used source factor is consequently available to the ordinary recursion.  Applying Lemma~\(\mathrm{Single\mbox{-}world\ operational\ specialization}\) to each accepted component proves ordinary acceptance at every \((x,s)\).  Hence \(\mathbf B(E_{\mathrm{batch}})\) identifies the complete ordinary kernel.  Coalescing duplicate sets (40) and adding only zero-cost READs give
\[
 \sum_{B\in\mathbf B(E_{\mathrm{batch}})}\sum_{v\in B}\kappa_v
 \leq \sum_{S\in\mathcal P}\sum_{a\in S}c(a).
 \tag{42}
\]
Taking infima in (39) gives
\(\operatorname{Opt}_{\mathrm{batch}}\leq\operatorname{Opt}_{\mathrm{ord}}\),
and taking infima in (42) gives the reverse inequality.  The two constructions also preserve existence.  Therefore
\[
 \operatorname{Opt}_{\mathrm{batch}}=\operatorname{Opt}_{\mathrm{ord}},
 \tag{43}
\]
and batch feasibility agrees in both representations.

It remains to transfer the stated lower bounds with the promised qualifications.  Lemma~\(\mathrm{Published\ minimum\mbox{-}weight\ hitting\mbox{-}set\ reduction}\) supplies a polynomial, cost-preserving reduction to the ordinary full-kernel intervention problem.  Lemma~\(\mathrm{Published\ ordinary\ NP\mbox{-}completeness}\) gives NP-hardness, and Lemma~\(\mathrm{Published\ ordinary\ logarithmic\ inapproximability}\) gives the \((1-o(1))\ln|V|\) threshold unless \(\mathrm{NP}\) has quasi-polynomial-time algorithms.  To replace any prohibitive auxiliary weight in the cited reduction by a finite rational one, let \(W\) be the sum of the original nonnegative rational weights and let \(N\) be the number of vertices in the constructed graph.  Set
\[
 C_{\mathrm{aux}}=(N+1)(W+1).
 \tag{44}
\]
Its binary encoding length is polynomial in the weighted input length.  On every feasible hard instance, an all-original hitting set has cost at most \(W<C_{\mathrm{aux}}\), so no exact optimum chooses an auxiliary vertex.  Moreover, any solution within a factor smaller than \(\ln N\) has cost below \(NW<C_{\mathrm{aux}}\) when \(W>0\); when \(W=0\), any finite approximation to the zero optimum also cannot pay the positive cost (44).  Thus the exact and logarithmic gaps of the cited construction persist with finite binary-rational costs.  The obstruction used by the reduction is graphical, so finite binary observed domains suffice for its finite-discrete image.

Equations~(39)--(43) are cost-preserving maps between this ordinary class and the SELECT--RAND--READ batch image.  The structural catalogue is polynomially encoded, but a complete source-law handle and support reply may be exponentially long and is supplied through \(\mathcal O_{\mathrm{src}}\).  Hence the transferred hardness and threshold are relative to that oracle convention, with every returned bit charged to \(N_{\mathcal O}\).  Nothing above is a batch-to-scalar reduction or an approximation theorem for the unrestricted physical catalogue.

Let \(m=|\mathcal A|\) and \(L=|\mathrm{LIT}|\).  Exact minimum-cost optimization over the restricted uniform acquisition certificates \(E\) accepted by \(\operatorname{Acc}\) has a deterministic algorithm that makes at most \(2^m\) distinct queries to \(\mathcal O_{\mathrm{src}}\), runs in
\[
 2^{O(m+L)}\operatorname{poly}(N_{\mathrm{in}}+N_{\mathcal O}),
\]
and uses
\[
 2^{O(m+L)}\operatorname{poly}(N_{\mathrm{in}}+N_{\mathcal O})
\]
oracle-answer space.  It returns the lexicographically first optimum restricted uniform certificate when \(\operatorname{Opt}<+\infty\), and otherwise certifies \(\operatorname{Opt}=+\infty\).  Thus the positive algorithmic alternative in the oracle-search question holds for the explicitly restricted uniform-certificate problem; no oracle lower bound is asserted.

%%% FIELD oracle-answer-proof
Put \(m=|\mathcal A|\), \(L=|\mathrm{LIT}|\), and \(n=|V|\).  We construct the finite search universe and prove that it is exactly the universe relevant to \(\operatorname{Acc}\).

Enumerate all \(2^m\) protocol masks in canonical order.  Definition~\(\mathrm{Legal\ protocol\ class}\) makes legality decidable from the explicit SELECT, mechanism-use, precedence, conflict, and ownership records, together with the physical compatibility check.  Lemma~\(\mathrm{Published\ CTF\mbox{-}REALIZE\ runtime}\) makes the latter polynomial in the finite graph and protocol encoding.  Query each legal mask once and cache the immutable answer, so the number of distinct oracle queries is at most
\[
 |\{0,1\}^m|=2^m.
 \tag{45}
\]
A \(\bot\) reply, or a malformed support index, supplies no candidate source.

For every remaining protocol enumerate the \(2^L\) literal masks.  Definition~\(\mathrm{Canonical\ literal\ and\ label\ encoding}\) rejects inconsistent and uncatalogued masks.  The exact support table decides whether the particular event \(H_{\mathrm{slice}}(S,\ell)\) used by the mask has positive mass.  Only this event can be a denominator; Assumption~\(\mathrm{Event\mbox{-}local\ positive\ source\ law}\) imposes no test on unused cells.  Apply the finite ancestral-set and district decomposition to each surviving slice.  It yields at most \(n\) canonical single-district source factors, and the measured-ancestry assumption removes exactly those whose required ancestors are neither READ nor action-fixed.

Fix a surviving tuple \((S,\ell,T)\) and a target factor \(C_j\).  Enumerate every branch in \(\Omega_j\).  If its free request positions have domain sizes \(h_1,\ldots,h_r\), the equality type is induced by their assignment and
\[
 |\Omega_j|=\prod_{u=1}^{r}h_u
 \leq 2^{\sum_{u=1}^{r}h_u}
 \leq2^L.
 \tag{46}
\]
For each branch, instantiate the value matches and run the finite ancestor--district recursion.  Proposition~\(\mathrm{Connected\mbox{-}ancestor\ obstruction}\) decides failure of a fixed connected factor call, and Lemma~\(\mathrm{Fixed\ transcript\ size}\) supplies the canonical successful transcript otherwise.  Compare the canonical restriction schemas after replacing concrete request values by their request-position identifiers.  The tuple is a uniform witness for \(C_j\) exactly when one common schema verifies after substitution for every enumerated branch in \(\Omega_j\).  Necessity is the cross-branch clause of Definition~\(\mathrm{Uniform\ acquisition\ certificate}\); sufficiency follows by the exhaustive substitution check.  Thus no exchange of \(\forall\) and \(\exists\) occurs.

For each base \((S,\ell,T)\), let \(J(S,\ell,T)\subseteq[k]\) be the factors for which the preceding comparison produced a verified uniform schema.  Enumerate one canonical uniform record for every subset \(J\subseteq J(S,\ell,T)\), attaching the corresponding schemas.  This includes every locally valid ownership mask that can occur in an accepted uniform certificate.  Since \(k\leq L\), the extra ownership enumeration has size at most \(2^L\) per base.  For each protocol \(S\), define
\[
 K_{\mathrm{unif}}(S)
 =\{j\in[k]:\text{some enumerated }(\ell,T,\tau_j)
 \text{ is a uniform witness for }C_j\}.
 \tag{47}
\]
Because separate records using the same protocol share its charge, an accepted uniform certificate yields a protocol cover
\[
 \bigcup_{S\in\operatorname{Prot}(E)}K_{\mathrm{unif}}(S)=[k].
 \tag{48}
\]
Conversely, from a cover in (48), assign every factor to the first covering protocol and its first enumerated uniform witness, merge records with identical protocol--slice--source bases when permitted, and sort.  The ownership masks partition \([k]\); every local support, ancestry, and uniform-transcript check has already passed; and the decoded complete source collection supplies a successful source for every factor and branch.  Hence \(\operatorname{Acc}(Q,E;G)=1\).  Nonnegative distinct-protocol charging therefore gives the derived optimization identity
\[
 \operatorname{Opt}
 =\min_{\mathcal P\subseteq\Pi:\,\bigcup_{S\in\mathcal P}K_{\mathrm{unif}}(S)=[k]}
   \sum_{S\in\mathcal P}\sum_{a\in S}c(a),
 \tag{49}
\]
with \(+\infty\) for an empty cover family.

The candidate generation is within the claimed size.  Every nonempty factor contributes at least one request literal with first coordinate \(j\), so \(k\leq L\).  By (46), the number of branch checks is at most
\[
 2^m2^Lnk2^L
 =2^{O(m+L)}\operatorname{poly}(N_{\mathrm{in}}).
 \tag{50}
\]
The additional \(2^k\) ownership masks per record base merely adds another exponential factor in \(L\).  Reading and caching the actual oracle replies adds \(N_{\mathcal O}\).  All candidate records, canonical transcripts, and incidence bits consequently occupy
\[
 2^{O(m+L)}\operatorname{poly}(N_{\mathrm{in}}+N_{\mathcal O})
 \tag{51}
\]
space and are constructed in the same time bound.

List the protocols with nonempty incidence as \(S_1,\ldots,S_p\), \(p\leq2^m\).  For \(U\subseteq[k]\), set \(D_0(\varnothing)=0\), \(D_0(U)=+\infty\) for \(U\ne\varnothing\), and
\[
 D_i(U)=\min\{D_{i-1}(U),
 D_{i-1}(U\setminus K_{\mathrm{unif}}(S_i))+w(S_i)\}.
 \tag{52}
\]
Induction on \(i\) proves that (52) is the least cost of protocols among the first \(i\) covering \(U\).  It therefore computes (49) in \(O(2^m2^k)\) exact rational operations, which is within (51) because \(k\leq L\).  If the final value is infinite, (48) certifies that no accepted restricted uniform certificate exists and hence \(\operatorname{Opt}=+\infty\).

If the value is finite, retain the ordered canonical record universe during candidate generation.  We give an exact completion test for lexicographic self-reduction.  For a proposed prefix of the self-delimiting certificate encoding, delete incompatible records and force every record completed by the prefix.  Reject immediately if two forced nonempty ownership masks intersect or if a forced record fails a local check.  For the remaining records of a fixed protocol, scan them in encoding order and maintain the family \(A_r\) of disjoint factor sets attainable from the first \(r\) records:
\[
 A_0=\{\varnothing\},\qquad
 A_{r+1}=A_r\cup
 \{U\cup J:U\in A_r,\ U\cap J=\varnothing\},
 \tag{53}
\]
where \(J\) is the ownership set of record \(r+1\); records excluded by the prefix contribute only the omission transition.  Induction on \(r\) proves that (53) lists exactly the locally attainable ownership sets.  A second dynamic program over protocols and factor masks chooses one set from each resulting family and charges \(w(S)\) exactly once when a nonempty set from protocol \(S\) is used, while accounting first for every forced protocol.  Its terminal value is therefore exactly the least cost of an accepted completion of the prefix.  It has at most \(2^k\) states per layer and at most \(3^k\) disjoint-union transitions, hence remains within (51) because \(k\leq L\).

Starting from the empty prefix, choose the smaller next bit or end decision that still permits a completion of value \(\operatorname{Opt}\).  The maintained invariant is existence of an optimum completion.  The process terminates because the candidate universe is finite; if a lexicographically smaller optimum existed, its first differing choice would have passed the constrained test.  The output is therefore the lexicographically first optimum accepted uniform certificate.

The number of prefix tests is polynomial in the finite candidate universe and maximum canonical record length, so (51) still bounds time and oracle-answer space.  Equations~(45)--(53) establish the positive alternative in the open-ended question.  The construction proves only an upper bound for the explicitly restricted uniform acceptance predicate and makes no adversarial lower-bound or scalar-functional claim.
