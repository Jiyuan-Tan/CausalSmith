Let \(m=|\mathcal A|\) and \(L=|\mathrm{LIT}|\).  Exact minimum-cost optimization over the restricted uniform acquisition certificates \(E\) accepted by \(\operatorname{Acc}\) has a deterministic algorithm that makes at most \(2^m\) distinct queries to \(\mathcal O_{\mathrm{src}}\), runs in
\[
 2^{O(m+L)}\operatorname{poly}(N_{\mathrm{in}}+N_{\mathcal O}),
\]
and uses
\[
 2^{O(m+L)}\operatorname{poly}(N_{\mathrm{in}}+N_{\mathcal O})
\]
oracle-answer space.  It returns the lexicographically first optimum restricted uniform certificate when \(\operatorname{Opt}<+\infty\), and otherwise certifies \(\operatorname{Opt}=+\infty\).  Thus the positive algorithmic alternative in the oracle-search question holds for the explicitly restricted uniform-certificate problem; no oracle lower bound is asserted.

Let \(m=|\mathcal A|\) and \(L=|\mathrm{LIT}|\).  Theorem~\(\mathrm{Explicit\ oracle\ enumeration\ frontier}\), the sole dependency of this corollary, applies to exactly the restricted uniform certificates \(E\) accepted by \(\operatorname{Acc}\).  It supplies a deterministic algorithm with at most
\[
 2^m
\]
distinct queries to \(\mathcal O_{\mathrm{src}}\), and with both running time and oracle-answer space bounded by
\[
 2^{O(m+L)}\operatorname{poly}(N_{\mathrm{in}}+N_{\mathcal O}).
\]
The same theorem states the exhaustive output dichotomy: if \(\operatorname{Opt}<+\infty\), the algorithm returns the lexicographically first optimum certificate, while if no accepted restricted uniform certificate exists, it certifies \(\operatorname{Opt}=+\infty\).  These are precisely all clauses of the present statement.  Therefore the positive alternative posed by the oracle-search question holds, without any appeal to or assertion of an adversarial oracle lower bound.
