%%% FIELD proof-sharp-one-row
Under \(\texttt{ass:one-unsupported-row}\) and
\(\texttt{ass:binary-free-row}\), the generalized unsupported-row objects
specialize to
\[
 \mathcal R_{\mathrm{free}}=\{rstar\},
 \qquad
 \mathcal P_{\mathrm{free}}
 =\{(1-q,q):0\leq q\leq 1\}.
\]
Comparing \(\texttt{def:model-class}\) with
\(\texttt{def:finite-unsupported-model-class}\), all their other
membership requirements agree in this specialization: both use the same
finite schema and graph, induce the same source and target groundings,
require mutually independent distinct exogenous variables, exclude
exogenous relational parents, exclude any non-relational exogenous parent
shared by distinct ground endogenous variables, require type-shared finite
mechanisms, reproduce \(Psrc\), and use \(K\) at every
positive-source-support key.  The comparator-only uniform bound in
\(\texttt{ass:bounded-relational-parent-multisets}\) is not a membership
condition of either structural class and is not used in this comparison.
Consequently
\[
 \mathcal M_{\mathrm{fin}}=Mone.
\]
The definitions of the two queries then give
\(Q_{\mathrm{fin}}=Q\).  Replaying
\(\texttt{def:multivariate-target-polynomial}\) at
\(p_{rstar}=(1-q,q)\) performs exactly the substitutions defining \(F\).
Equivalently, this is the reduction proved in
\(\texttt{lem:polynomial-reduction}\).  Hence, for every \(q\in[0,1]\),
\[
 \Phi\bigl((1-q,q)\bigr)=F(q).
\]
Applying \(\texttt{thm:sharp-finite-unsupported-rows}\) to this
specialization proves
\[
 \Theta=F([0,1])
 =\left[\min_{q\in[0,1]}F(q),\max_{q\in[0,1]}F(q)\right].
\]
In particular, the reverse inclusion is witnessed by compatible
finite-noise, type-shared models; the displayed set is not merely an outer
bound.

It remains to identify these two extrema with the declared algebraic
candidates.  If \(F\) is nonconstant and \(c\in(0,1)\) is a minimizer,
then for all sufficiently small \(h>0\),
\[
 \frac{F(c+h)-F(c)}{h}\geq0,
 \qquad
 \frac{F(c)-F(c-h)}{h}\leq0.
\]
Both quotients converge to \(F'(c)\), so \(F'(c)=0\).  Reversing the two
inequalities gives the same conclusion for an interior maximizer.  Thus
every optimizer is \(0\), \(1\), or a feasible distinct real root of
\(F'\), and therefore lies in \(Ccrit\) by
\(\texttt{def:critical-candidates}\).  Since \(Ccrit\subseteq[0,1]\) and
the global optimizers belong to \(Ccrit\),
\[
 \min_{q\in[0,1]}F(q)=\min_{c\in Ccrit}F(c)=L,
 \qquad
 \max_{q\in[0,1]}F(q)=\max_{c\in Ccrit}F(c)=U.
\]
If \(F\) is constant, \(Ccrit\) contains the boundary candidates and all
its values equal that same constant, so the two equalities still hold.
This proves the unconditional structural assertion
\[
 \Theta=F([0,1])=[L,U].
\]

We now prove only the conditional comparator consequences stated in the
theorem.  By
\(\texttt{lem:ejaz-bareinboim-rho-markovian-scope}\), Definition 3.2 and
the Section 5 domain impose different requirements: the former gives the
\(\rho\)-Markovian exogenous-parent restrictions, whereas assumptions
(I)--(III) specify the domain on which Algorithm 1 and Corollary D.7 have
their soundness and completeness guarantee.  In particular, the global
relational-parent bound is not inferred from the finiteness of the listed
source and target groundings.

Fix an instance satisfying the two explicit comparator hypotheses in the
statement, and write \(\mathcal E\) for its compatible
Ejaz--Bareinboim class in the intersection with the Section 5 domain.
The second hypothesis is precisely the same-data, same-query inclusion
\[
 Mone\subseteq\mathcal E.
\]
If \(F\) is nonconstant, choose \(q_1,q_2\in[0,1]\) with
\(F(q_1)\neq F(q_2)\).  The already proved equality
\(\Theta=F([0,1])\) supplies \(M_1,M_2\in Mone\), both reproducing the
fixed source laws, such that
\[
 Q(M_1)=F(q_1)\neq F(q_2)=Q(M_2).
\]
The inclusion places both witnesses in \(\mathcal E\), so the causal query
is not point identified in \(\mathcal E\).  This is the claimed upward
transfer of nonidentification.  If Algorithm 1 reports
\(\mathsf{FAIL}\) on such an instance, that report does not change the
structural equality already proved for \(Mone\).  Conversely, inclusion
alone gives no upper or lower restriction on values attained by elements
of \(\mathcal E\setminus Mone\); it therefore gives neither sharpness of
\([L,U]\) nor equality of the two identified sets.

If \(F\) is constant, the structural part gives \(L=U\) on \(Mone\).
When the compatible classes coincide, substitution of that equality of
classes transfers the singleton conclusion.  When the inclusion is
strict, constancy on \(Mone\) says nothing about the query values of the
additional models in \(\mathcal E\setminus Mone\), so no such transfer is
valid.

Finally, unsupportedness alone does not force
\(\mathsf{FAIL}\).  Consider a finite, acyclic, two-node instance in the
Section 5 domain for which the supplied graph excludes every additional
shared-exogenous structure, so that the comparator and fully Markovian
compatible classes coincide.  Let \(A\) be a supported fair binary node,
let \(X\) use the single unsupported binary row with success probability
\(q\), take the intervention assignment to be empty, and set
\(B=\{A=X\}\).  Independence gives
\[
 P(B\mid\operatorname{do}(a))
 =P(A=0)P(X=0)+P(A=1)P(X=1)
 =(1-q)\frac{1}{2}+q\frac{1}{2}=\frac{1}{2}.
\]
Thus the row is target relevant but cancels from the query, and the
sound-and-complete identified-case procedure on this comparator-domain
instance cannot return \(\mathsf{FAIL}\).

As a load-bearing check on the shared-coordinate reduction, take two
independent target nodes using the same unsupported binary key and let
the event be exactly one success.  Type sharing gives the map
\[
 2q(1-q)\leq\frac{1}{2}.
\]
If type sharing is removed while the remaining finite acyclic structure
is retained, occurrence-specific choices \(q_1=1\) and \(q_2=0\) make
the event probability \(1\).  Hence the common coordinate \(q\) is
essential to the proved structural image.
