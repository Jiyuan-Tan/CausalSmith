%%% FIELD proof-coordinate-alignment
Fix \((G,P)\in\mathcal M_{\mathrm{cert}}^{(q)}(K,J)\).  Membership in the certified class invokes the measurement-model factorization, positive latent support, measurement nondegeneracy, third-view coverage, the subset condition, faithfulness, and \(\Delta_{\mathrm{DT}}\ne0\).  By Theorem~\(\textnormal{thm:certificate-frontier}\),
\[
 \operatorname{rank}(M_1)=\operatorname{rank}(M_2)=q^K.
\]
Let \(\tau:\mathscr L(P_X)\to\mathcal Q^K\) denote the unknown bijection between the labels returned by the assumed three-view decomposition and the true latent configurations.  This bijection is used only to prove that the observable construction below returns the true coordinate structure; it is not an input to that construction.  For a label \(\ell\), write
\[
 Q_j^\ell(x)=P\!\left(X_j=x\mid H=\tau(\ell)\right)
\]
for the recovered conditional column of observed coordinate \(j\).

First, the component weights are themselves determined by the observed law and the recovered columns.  Define the observable matrix
\[
 \widetilde M_1(x,\ell)=\prod_{j\in S_1}Q_j^\ell(x_j),
 \qquad x\in\prod_{j\in S_1}\mathcal X_j,
\]
and let \(v_1(x)=P_X(X_{S_1}=x)\).  The Markov factorization in the definition of the certified class makes the observed coordinates conditionally independent given \(H\), so \(\widetilde M_1\) is \(M_1\) with its columns permuted by \(\tau\).  Hence it has column rank \(q^K\).  If \(\omega_\ell=\pi_{\tau(\ell)}\), finite marginalization gives the observable mixture equation
\[
 v_1=\widetilde M_1\omega.
\]
Full column rank makes \(\widetilde M_1^{\mathsf T}\widetilde M_1\) positive definite: for \(z\ne0\),
\[
 z^{\mathsf T}\widetilde M_1^{\mathsf T}\widetilde M_1z
 =\lVert\widetilde M_1z\rVert_2^2>0.
\]
Thus the weights are recovered uniquely by the explicit observable formula
\[
 \omega
 =\left(\widetilde M_1^{\mathsf T}\widetilde M_1\right)^{-1}
   \widetilde M_1^{\mathsf T}v_1.
\]

We next recover the product coordinates without using \(\tau\).  For each observed coordinate set
\[
 A_j=\{k\in\{1,\ldots,K\}:H_k\to X_j\text{ in }G\}.
\]
For every \(A\subseteq\{1,\ldots,K\}\), define an equivalence relation on \(\mathcal Q^K\) by
\[
 h\mathrel{E_A}h'
 \quad\Longleftrightarrow\quad h_A=h'_A.
\]
The measurement-model factorization gives
\[
 P(X_j=\mathord\cdot\mid H=h)
 =P(X_j=\mathord\cdot\mid H_{A_j}=h_{A_j}).
\]
Consequently, \(h_{A_j}=h'_{A_j}\) implies equality of the two conditional columns.  Conversely, Assumption~\(\textnormal{ass:measurement-nondegeneracy}\) says that distinct configurations of \(H_{A_j}\) induce distinct conditional distributions of \(X_j\).  Therefore
\[
 Q_j^\ell=Q_j^{\ell'}
 \quad\Longleftrightarrow\quad
 \tau(\ell)\mathrel{E_{A_j}}\tau(\ell').
\]
Thus the observable relation \(E_j\) is exactly the pullback \(\tau^{-1}E_{A_j}\tau\).

Order equivalence relations by inclusion, so their meet is intersection and their join is the smallest equivalence relation containing their union.  For all \(A,B\subseteq\{1,\ldots,K\}\),
\[
 E_A\wedge E_B=E_{A\cup B},
 \qquad
 E_A\vee E_B=E_{A\cap B}.
\]
The meet identity follows directly from simultaneous agreement on \(A\) and \(B\).  For the join identity, every \(E_A\)- or \(E_B\)-step preserves the coordinates in \(A\cap B\), so \(E_A\vee E_B\subseteq E_{A\cap B}\).  Conversely, if \(h_{A\cap B}=h'_{A\cap B}\), choose \(z\in\mathcal Q^K\) with
\[
 z_A=h_A,
 \qquad z_B=h'_B;
\]
the prescriptions agree on \(A\cap B\), and the remaining coordinates may be chosen arbitrarily because \(\mathcal Q\ne\varnothing\).  Then \(h\mathrel{E_A}z\mathrel{E_B}h'\), proving the reverse inclusion.  Induction over lattice expressions now shows that every element of the finite lattice generated by \(\{E_j:1\le j\le J\}\) is the pullback of some \(E_A\).  Moreover,
\[
 \#(\mathcal Q^K/E_A)=q^{|A|}.
\]
The map \(A\mapsto E_A\) is injective: if \(k\in A\setminus B\), two configurations which differ only at coordinate \(k\) are \(E_B\)-equivalent but not \(E_A\)-equivalent.

For each latent coordinate define its observed-child set
\[
 C_k=\{j:k\in A_j\}=\operatorname{ch}_X(H_k).
\]
Third-view coverage makes \(C_k\) nonempty.  For \(\ell\ne k\), the subset condition gives \(C_k\nsubseteq C_\ell\), so there is a \(j\in C_k\setminus C_\ell\).  Equivalently, \(k\in A_j\) and \(\ell\notin A_j\).  It follows coordinate by coordinate that
\[
 \bigcap_{j\in C_k}A_j=\{k\}.
\]
Repeated use of the join identity therefore yields
\[
 E_{\{k\}}=\bigvee_{j\in C_k}E_{A_j}.
\]
Hence every one-coordinate relation occurs in the observable generated lattice.  Conversely, because \(q\ge3\), an element \(E_A\) of this lattice has exactly \(q\) equivalence classes if and only if \(|A|=1\).  The observable operation ``generate the finite relation lattice and retain its elements with exactly \(q\) classes'' therefore returns precisely
\[
 \{E_{\{1\}},\ldots,E_{\{K\}}\}
\]
transported to \(\mathscr L(P_X)\), without using the unknown map \(\tau\).

Choose any ordering \(R_1,\ldots,R_K\) of these \(K\) observable relations and, independently for each \(r\), choose a bijection
\[
 \lambda_r:\mathscr L(P_X)/R_r\longrightarrow\mathcal Q.
\]
Define
\[
 \varphi_{\mathrm{coord}}(\ell)_r
 =\lambda_r\!\left([\ell]_{R_r}\right).
\]
Because the \(R_r\)'s are exactly the one-coordinate relations,
\[
 \bigwedge_{r=1}^KR_r=E_{\{1,\ldots,K\}},
\]
which is the equality relation.  Thus \(\varphi_{\mathrm{coord}}\) is injective.  Its domain and codomain both have cardinality \(q^K\), so it is bijective.  Changing the order of the \(R_r\)'s permutes the \(K\) coordinates, and changing their class labels independently permutes the \(q\) states within each coordinate.  Conversely, any two choices differ in exactly this way.  Thus the bijection is unique modulo
\[
 \mathfrak G=\mathfrak S_K\ltimes(\mathfrak S_q)^K.
\]

All remaining recovery maps are now explicit.  In the chosen coordinate labeling,
\[
 \Gamma_{jk}=1
 \quad\Longleftrightarrow\quad
 k\in A_j
 \quad\Longleftrightarrow\quad
 E_j\subseteq R_k,
\]
because agreement on \(A_j\) implies agreement on coordinate \(k\) exactly when \(k\in A_j\).  Hence \(\Gamma\) is recovered from observable relation inclusion.  For \(h\in\mathcal Q^K\), let \(\ell=\varphi_{\mathrm{coord}}^{-1}(h)\) and set
\[
 \pi_h=\omega_\ell,
 \qquad
 p_j(x\mid h)=Q_j^\ell(x).
\]
The preceding mixture equation and conditional-column equivalence prove that these observable formulas equal the true latent weights and measurement tables after the chosen coordinate and state relabeling; they do not define the causal target by fiat.

It remains to identify the latent Markov equivalence class.  Positive latent support gives \(\pi_h>0\) for every \(h\), so every conditioning event formed from latent coordinates has positive probability.  The recovered \(\pi\) decides every latent conditional-independence statement by finite marginalization: for pairwise disjoint coordinate sets \(U,V,W\),
\[
 H_U\mathbin{\perp\!\!\!\perp}H_V\mid H_W
\]
holds if and only if, for every \((u,v,w)\),
\[
 \pi_{U\cup V\cup W}(u,v,w)\,\pi_W(w)
 =\pi_{U\cup W}(u,w)\,\pi_{V\cup W}(v,w),
\]
where each term is the corresponding marginal sum of \(\pi\).  This equivalence follows by multiplying the defining conditional-probability equality by the positive quantity \(\pi_W(w)^2\).

The measurement assumption makes every observed vertex a sink and forbids observed--observed edges.  Consequently, a trail between latent vertices that enters an observed vertex has that observed vertex as a collider; because an observed sink has no descendants and the conditioning set contains only latent vertices, such a trail is blocked.  Hence, for latent endpoints and latent conditioning sets, d-separation in \(G\) is exactly d-separation in the latent subgraph \(\Lambda\).  Assumption~\(\textnormal{ass:faithfulness}\) therefore identifies the recovered conditional-independence pattern with the d-separation pattern of \(\Lambda\).

For a terminating recovery map, enumerate the finite set of directed acyclic graphs on the recovered \(K\) coordinate labels, compute each graph's d-separation relations, and retain exactly those whose relations equal the recovered pattern.  The true \(\Lambda\) is retained by faithfulness.  Lemma~\(\textnormal{lem:dag-markov-equivalence-characterization}\) says that equality of d-separation patterns is equivalent to equality of skeletons and unshielded colliders, so the retained set is exactly \([\Lambda]_{\mathrm{MEC}}\).  Every operation above is finite and determined by \(P_X\) and the assumed recovered component columns.  It recovers \(\Gamma\), \(\pi\), \(p\), and \([\Lambda]_{\mathrm{MEC}}\) modulo \(\mathfrak G\), which proves the theorem and exhibits the coordinate-alignment step beyond anonymous three-view label recovery.
