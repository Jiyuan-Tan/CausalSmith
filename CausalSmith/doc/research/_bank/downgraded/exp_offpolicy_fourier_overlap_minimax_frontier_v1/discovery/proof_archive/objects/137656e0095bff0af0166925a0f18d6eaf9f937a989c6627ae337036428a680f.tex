Fix \(\mathfrak A\in\mathsf{Adm}\). Applying \(\mathrm{thm:instance-adaptive-minimax-frontier}\) to each row gives
\[
 0\le R_n^{\star}\le F_n\le\kappa_nR_n^{\star},
 \qquad n\ge1,
\]
where \(\kappa_n\ge1\) is finite by \(\mathrm{def:adaptive-rank-fiber-complexity}\) and the cardinality bound in the instance-adaptive theorem.

If \(F_n\to0\), the first two terms and the squeeze theorem give \(R_n^{\star}\to0\), proving \(\mathrm{(a)}\). For a fixed row, if \(F_n=0\), then \(0\le R_n^{\star}\le F_n=0\), so \(R_n^{\star}=0\). Conversely, if \(R_n^{\star}=0\), then \(0\le F_n\le\kappa_nR_n^{\star}=0\), so \(F_n=0\). This proves \(\mathrm{(b)}\) without any limit or uniformity assumption.

If \(\kappa_nR_n^{\star}\to0\), the rowwise inequality \(0\le F_n\le\kappa_nR_n^{\star}\) gives \(F_n\to0\), proving \(\mathrm{(c)}\). Finally, suppose an array belongs to a subfamily for which \(\sup_n\kappa_n=C<\infty\). Then \(R_n^{\star}\to0\) implies
\[
 0\le F_n\le\kappa_nR_n^{\star}\le C R_n^{\star}\longrightarrow0.
\]
Together with \(\mathrm{(a)}\), this proves the equivalence in \(\mathrm{(d)}\). No reverse implication is asserted on all of \(\mathsf{Adm}\), because the proved factors \(\kappa_n\) may diverge.
