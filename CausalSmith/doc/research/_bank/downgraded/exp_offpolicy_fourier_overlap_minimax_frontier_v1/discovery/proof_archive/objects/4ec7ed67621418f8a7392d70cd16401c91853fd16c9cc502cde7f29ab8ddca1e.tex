Fix \(\mathfrak A\in\mathsf{Adm}\). Applying the instance-adaptive minimax frontier theorem to each row gives
\[
 0\le R_n^{\star}\le F_n\le\kappa_nR_n^{\star},
 \qquad n\ge1,
\]
where \(\kappa_n\ge1\) is finite by \(\mathrm{def:adaptive-rank-fiber-complexity}\) and the cardinality bound in that theorem.

If \(F_n\to0\), then for every \(\eta>0\) there is \(N\) such that \(n\ge N\) implies \(F_n<\eta\); the displayed inequality then gives \(0\le R_n^{\star}<\eta\). Hence \(R_n^{\star}\to0\), proving \(\mathrm{(a)}\). For a fixed row, if \(F_n=0\), then \(0\le R_n^{\star}\le F_n=0\), so \(R_n^{\star}=0\). Conversely, if \(R_n^{\star}=0\), then \(0\le F_n\le\kappa_nR_n^{\star}=0\), so \(F_n=0\). This proves \(\mathrm{(b)}\) without any limit or uniformity assumption.

If \(\kappa_nR_n^{\star}\to0\), then for every \(\eta>0\) the displayed inequality eventually gives \(0\le F_n<\eta\), proving \(F_n\to0\) and hence \(\mathrm{(c)}\). Finally, suppose an array belongs to a subfamily for which \(\sup_n\kappa_n=C<\infty\). Then \(R_n^{\star}\to0\) implies
\[
 0\le F_n\le\kappa_nR_n^{\star}\le C R_n^{\star}\longrightarrow0.
\]
Together with \(\mathrm{(a)}\), this proves the equivalence in \(\mathrm{(d)}\). No reverse implication is asserted on all of \(\mathsf{Adm}\), because the proved factors \(\kappa_n\) may diverge.
