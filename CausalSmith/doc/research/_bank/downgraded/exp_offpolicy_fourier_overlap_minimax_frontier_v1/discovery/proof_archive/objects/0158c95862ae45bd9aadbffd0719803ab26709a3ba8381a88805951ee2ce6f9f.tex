By \texttt{lem:selector-reduction-and-dual}, the finite selector experiment has a minimizing weight rule and satisfies \(F=\mathcal D\).  For any fixed rule \(a\), define
\[
 Q_a(v)=\sum_{z\in\Omega_n}p_{\pi}(z)
 \bigl(a_z^{\mathsf T}N_zv-\theta(v)\bigr)^2.
\]
Each summand is the square of a linear functional of \(v\), and each coefficient \(p_{\pi}(z)\) is nonnegative by \texttt{ass:source-product-design} and \texttt{ass:source-overlap}; hence \(Q_a\) is convex.  By \texttt{def:bounded-fourier-class}, \(K\) is a compact finite-dimensional polytope.  If \(v=\sum_e\lambda_e e\) is a convex decomposition over \(e\in\operatorname{vert}(K)\), then convexity gives
\[
 Q_a(v)\le \sum_e\lambda_e Q_a(e)
 \le \max_{e\in\operatorname{vert}(K)}Q_a(e).
\]
The reverse inequality is immediate because every vertex belongs to \(K\).  Therefore the exact finite epigraph formulation is
\[
 F=\min_{a,t}t
 \quad\text{subject to}\quad
 \sum_{z\in\Omega_n}p_{\pi}(z)
 \bigl(a_z^{\mathsf T}N_ze-\theta(e)\bigr)^2\le t
 \quad\text{for every }e\in\operatorname{vert}(K).
\]
This is an exact computable program for every fixed finite instance, but its explicit assignment and vertex index sets can be exponential in \(L_{\mathrm{in}}\), so it is not the algorithm requested by the OEQ.

The proved node \texttt{prop:raw-incidence-bag-moment-obstruction} supplies the complementary negative partial result.  For every even \(r\ge2\) and admissible \(q\ne1/2\), it constructs an additive-star instance with \(\operatorname{tw}(\mathcal I)=1\) and two genuine finitely supported priors having identical ordinary edge-bag coefficient laws but target second moments \((2q-1)^2/r^2\) and \(0\).  Consequently, ordinary bag moments on a raw incidence-tree decomposition do not determine the term \(\langle\ell,M\ell\rangle_E\) in \texttt{def:moment-dual}.  Its \(r=2\) witness is the smallest star exhibiting that particular ambiguity.  This rules out only the unaugmented raw-bag lift: carrying the full leaf-coefficient vector restores the missing information at dimension growing with \(r\), while a compressed running target-sum state is not excluded.  Thus neither optimizer nonlocality nor failure of every \(\operatorname{poly}(L_{\mathrm{in}})2^{O(w)}\) exact algorithm has been proved.
