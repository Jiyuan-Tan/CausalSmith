The exact selector reduction is already available: \texttt{lem:selector-reduction-and-dual} proves \(F=\mathcal D\) and existence of minimizing weights after quotienting null coefficient directions.  There is also an exact finite epigraph formulation.  For a fixed weight rule \(a\), the map
\[
 v\longmapsto Q_a(v):=\sum_{z\in\Omega_n}p_\pi(z)
 \bigl(a_z^{\mathsf T}N_zv-\theta(v)\bigr)^2
\]
is convex because it is a nonnegative weighted sum of squares of linear functionals.  The bounded Fourier class \(K\) is a compact finite-dimensional polytope.  If \(v=\sum_e\lambda_e e\) is a convex decomposition into vertices, convexity gives \(Q_a(v)\le\sum_e\lambda_eQ_a(e)\le\max_eQ_a(e)\).  Hence
\[
 F=\min_{a,t}t
 \quad\text{subject to}\quad
 \sum_{z\in\Omega_n}p_\pi(z)
 \bigl(a_z^{\mathsf T}N_ze-\theta(e)\bigr)^2\le t
 \quad\text{for every }e\in\operatorname{vert}(K).
\]
This is an exact finite convex program, but its assignment and vertex indices are not bounded by \(\operatorname{poly}(L_{\mathrm{in}})2^{O(w)}\).

The new proved obstruction is \texttt{prop:raw-incidence-bag-moment-obstruction}.  Already when \(\operatorname{tw}(\mathcal I)=1\), two genuine priors have identical full edge-bag coefficient laws but different target second moments.  The target-square polynomial contains every cross-leaf monomial and its canonical coefficient-interaction graph contains an arbitrarily large clique.  Thus raw incidence treewidth does not justify the proposed ordinary junction-tree moment lift.  The result is deliberately narrower than a nonexistence theorem: carrying the complete hub coefficient vector repairs this particular loss but uses a state whose dimension grows with the hub degree, while a running target-sum state might compress that vector.  What remains open is whether such a compressed state simultaneously represents the bounded-schedule moment body, the assignment-indexed weight dependence, and the pseudoinverse residual with polynomial bit-size and bounded piece complexity, or whether an exact value gap or complexity lower bound rules this out.
