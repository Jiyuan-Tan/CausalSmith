For each row with \(F_n>0\), apply the preceding ellipsoidal-prior construction to a maximizer \(M_n^{\star}\) of \(\mathcal D_n=F_n\), and let \(r_n=\operatorname{rank}(M_n^{\star})\).  Row by row it gives
\[
 \frac{F_n}{r_n}\le R_n^{\star}\le F_n.
\]
For a row with \(F_n=0\), set \(r_n=1\); then the same display remains valid because \(R_n^{\star}=0\).  Hence
\[
 F_n\longrightarrow0\quad\Longrightarrow\quad R_n^{\star}\longrightarrow0
\]
for every \(\mathfrak A\in\mathsf{Adm}\).  The reverse implication follows on every admissible subfamily for which \(\sup_n r_n<\infty\), since then
\[
 0\le F_n\le\left(\sup_k r_k\right)R_n^{\star}\longrightarrow0.
\]
More generally, the proved rank-dependent converse shows that \(r_nR_n^{\star}\to0\) is sufficient for \(F_n\to0\).  The definition of \(\mathsf{Adm}\) imposes no uniform bound on \(r_n\), so \(R_n^{\star}\to0\) alone cannot be converted to \(F_n\to0\) by this argument.  A dimension-free genuine-prior rounding inequality, with one constant preceding the quantifiers over \(n\) and \(\mathfrak A\), is precisely the residual needed for the stated equivalence.
