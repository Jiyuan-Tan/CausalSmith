Along any sequence or subsequence with limiting mixture parameters \((p_j^\infty,V_j^\infty)_{j\in\mathcal J_\infty}\) as in Theorem 3, a single deterministic positive-definite matrix \(\Sigma\) gives asymptotic coverage \(1-\alpha\) for every \(\alpha\in(0,1)\) and every nonzero contrast \(c\in\mathbb R^d\) if and only if \(V_j^\infty=\Sigma\) for every \(j\in\mathcal J_\infty\). Equivalently, the limiting selected covariance that equals \(V_j^\infty\) with probability \(p_j^\infty\) is almost surely the deterministic matrix \(\Sigma\). In the fixed-parameter special case this is equivalent to \(V_J=\Sigma\) almost surely. The implication from all projected equalities to matrix equality follows by polarization.
