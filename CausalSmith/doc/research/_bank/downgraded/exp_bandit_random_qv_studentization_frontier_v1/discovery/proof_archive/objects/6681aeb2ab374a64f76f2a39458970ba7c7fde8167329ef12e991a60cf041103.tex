Suppose first that one deterministic positive-definite \(\Sigma\) gives the asserted subsequential coverage for every nonzero \(c\) and every nominal level. The contrastwise theorem gives
\[
 c^\top(V_j^\infty-\Sigma)c=0
 \qquad\text{for every }c\ne0\text{ and every }j\in\mathcal J_\infty.
\]
Fix \(j\) and set \(A=V_j^\infty-\Sigma\), which is symmetric. Taking \(c=e_r\) gives \(A_{rr}=0\). For \(r\ne s\), taking \(c=e_r+e_s\) and using the diagonal equalities gives
\[
 0=(e_r+e_s)^\top A(e_r+e_s)=2A_{rs}.
\]
Thus every entry of \(A\) vanishes and \(V_j^\infty=\Sigma\).

Conversely, if \(V_j^\infty=\Sigma\) for every \(j\in\mathcal J_\infty\), then \(c^\top V_j^\infty c=c^\top\Sigma c\) for every nonzero \(c\). The contrastwise theorem gives coverage \(1-\alpha\) for every such \(c\) and every \(\alpha\in(0,1)\).

Let \(V_\infty\) denote the random matrix taking value \(V_j^\infty\) with probability \(p_j^\infty\). If all \(V_j^\infty\) equal \(\Sigma\), then \(V_\infty=\Sigma\) almost surely. Conversely, if \(V_\infty=A\) almost surely for a deterministic matrix \(A\), then each event selecting \(j\in\mathcal J_\infty\) has positive probability and forces \(V_j^\infty=A\). In the fixed-parameter case, the definition \(V_J=\sum_j\mathbf 1\{J=j\}V_j\) gives the same argument with \(V_\infty\) replaced by \(V_J\).
