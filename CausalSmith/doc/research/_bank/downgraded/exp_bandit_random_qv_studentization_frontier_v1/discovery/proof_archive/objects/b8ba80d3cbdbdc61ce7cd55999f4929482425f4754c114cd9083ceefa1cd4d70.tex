For the finite law in the statement and every Borel set \(B\),
\[
 \mu(B)=\sum_{j=1}^rp_j\mathbf1\{W_j\in B\}.
\tag{1}
\]
Because every \(p_j\) is strictly positive, a scalar equality \(c^\top Vc=c^\top\Sigma c\) holds \(\mu\)-almost surely if and only if it holds at every \(W_j\). Theorem \(\mathrm{thm:contrastwise\text{-}deterministic\text{-}sandwich\text{-}iff}\) therefore gives the first equivalence. Likewise, \(V=\Sigma\) holds \(\mu\)-almost surely if and only if every \(W_j=\Sigma\); Theorem \(\mathrm{thm:matrixwise\text{-}deterministic\text{-}sandwich\text{-}iff}\) gives the second equivalence. Thus the finite-support conclusion is a corollary of the covariance-law characterization.
