For the finite law in the statement and every Borel set \(D\),
\[
 \mu(D)=\sum_{j=1}^rp_j\mathbf1\{W_j\in D\}.
\tag{1}
\]
Since every \(p_j\) is strictly positive, \(c^\top Vc=c^\top\Sigma c\) holds \(\mu\)-almost surely if and only if \(c^\top W_jc=c^\top\Sigma c\) for every \(j\).  The contrastwise deterministic-sandwich theorem gives the first equivalence.  Likewise, \(V=\Sigma\) holds \(\mu\)-almost surely if and only if \(W_j=\Sigma\) for every \(j\); the matrixwise theorem gives the second equivalence.
