Suppose first that one deterministic positive-definite matrix \(\Sigma\) gives the asserted coverage for every nonzero \(c\) and every nominal level. The contrastwise theorem gives
\[
 c^\top(V_j-\Sigma)c=0
 \qquad\text{for every }c\ne0\text{ and every }j\in\mathcal J.
\]
Fix \(j\) and write \(A=V_j-\Sigma\), which is symmetric. Taking \(c=e_r\) gives \(A_{rr}=0\). Taking \(c=e_r+e_s\) and using the diagonal equalities gives
\[
 0=(e_r+e_s)^\top A(e_r+e_s)=2A_{rs}
\]
for \(r\ne s\). Thus every entry of \(A\) is zero and \(V_j=\Sigma\). This is the polarization step written coordinatewise.

Conversely, if \(V_j=\Sigma\) for every \(j\in\mathcal J\), then \(c^\top V_jc=c^\top\Sigma c\) for every nonzero \(c\); the contrastwise theorem gives coverage \(1-\alpha\) for every \(c\) and every \(\alpha\in(0,1)\).

Finally, if all \(V_j\) equal \(\Sigma\), the definition of \(V_J\) gives \(V_J=\Sigma\) almost surely. Conversely, if \(V_J=A\) almost surely for a deterministic matrix \(A\), then on the event \(\{J=j\}\), which has probability \(p_j>0\), the definition gives \(V_J=V_j\). Hence \(V_j=A\) for every \(j\in\mathcal J\). This proves the stated equivalence with almost-sure determinism.
