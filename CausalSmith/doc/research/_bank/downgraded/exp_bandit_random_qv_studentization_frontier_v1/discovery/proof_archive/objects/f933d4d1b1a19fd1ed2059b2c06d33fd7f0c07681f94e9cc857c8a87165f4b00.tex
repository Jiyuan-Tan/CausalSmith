Fix nonzero \(c\) and deterministic \(\Sigma\). Under any finite centered Gaussian-mixture limit supplied by Theorem 1 with \(p_j>0\), \(\lim_{T\to\infty}P\{\tau\in C_T^{\Sigma}(c,\alpha)\}=1-\alpha\) for every \(\alpha\in(0,1)\) if and only if \(c^\top V_jc=c^\top\Sigma c\) for every \(j\in\mathcal J\). The necessity is an equality-of-laws result for the finite centered Gaussian scale mixture, not a variance-matching argument at one nominal level.
