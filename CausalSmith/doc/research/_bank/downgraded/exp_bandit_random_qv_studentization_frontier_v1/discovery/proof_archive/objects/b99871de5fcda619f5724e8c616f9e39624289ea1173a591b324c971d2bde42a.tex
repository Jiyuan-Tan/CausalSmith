For \(\eta\in\mathsf H\), define
\[
 \Gamma_P(\eta)=E_P\!\left[\sum_{a\in\mathcal A}
 \frac{g(a,X_t,Y_t(a);\theta^*)g(a,X_t,Y_t(a);\theta^*)^\top}
 {\Pi(a\mid X_t,\eta)}\right].
\]
For each \(j\in\{1,\ldots,m\}\), set \(p_j=P(J=j)\), \(\Omega_j=\Gamma_P(\bar\eta_j)\), and \(V_j=H^{-1}\Omega_jH^{-\top}\). Define \(\mathcal J=\{1,\ldots,m\}\), \(\Omega_J=\sum_{j=1}^m\mathbf 1\{J=j\}\Omega_j\), and \(V_J=\sum_{j=1}^m\mathbf 1\{J=j\}V_j\). Because \(\eta_\infty=\bar\eta_J\) almost surely in the finite-tail-attractor class, set \(\Omega_\infty=\Gamma_P(\eta_\infty)=\Omega_J\) and \(V_\infty=H^{-1}\Omega_\infty H^{-\top}=V_J\) almost surely. The mass floor \(p_j\ge p_->0\) makes every listed attractor an attained basin.
