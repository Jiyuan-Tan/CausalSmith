For \(\eta\in\mathsf H\), define
\[
 \Gamma_P(\eta)=E_P\!\left[\sum_{a\in\mathcal A}
 \frac{g(a,X_t,Y_t(a);\theta^*)g(a,X_t,Y_t(a);\theta^*)^\top}
 {\Pi(a\mid X_t,\eta)}\right].
\]
Set \(\Omega_\infty=\Gamma_P(\eta_\infty)\) and \(V_\infty=H^{-1}\Omega_\infty H^{-\top}\). For any auxiliary finite-support representation \(\eta_\infty=\bar\eta_J\) almost surely with \(\mathcal J=\{j:P(J=j)>0\}\), set \(p_j=P(J=j)\), \(\Omega_j=\Gamma_P(\bar\eta_j)\), \(V_j=H^{-1}\Omega_jH^{-\top}\), \(\Omega_J=\sum_{j\in\mathcal J}\mathbf 1\{J=j\}\Omega_j\), and \(V_J=\sum_{j\in\mathcal J}\mathbf 1\{J=j\}V_j\). These finite-support objects are auxiliary specializations and are not restrictions on the class.
