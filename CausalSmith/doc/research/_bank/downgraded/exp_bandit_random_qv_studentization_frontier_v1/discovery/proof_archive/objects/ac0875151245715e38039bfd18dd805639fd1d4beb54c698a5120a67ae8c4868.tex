For \(\eta\in\mathsf H\), define
\[
 \Gamma_P(\eta)=E_P\!\left[\sum_{a\in\mathcal A}
 \frac{g(a,X_t,Y_t(a);\theta^*)g(a,X_t,Y_t(a);\theta^*)^\top}
 {\Pi(a\mid X_t,\eta)}\right].
\]
For \(j\in\mathcal J=\{1,\ldots,m\}\), set \(p_j=P(J=j)\), \(\Omega_j=\Gamma_P(\bar\eta_j)\), and \(V_j=H^{-1}\Omega_jH^{-\top}\). Set
\[
 \Omega_J=\sum_{j=1}^m\mathbf1\{J=j\}\Omega_j,\qquad
 V_J=\sum_{j=1}^m\mathbf1\{J=j\}V_j,
\]
and set \(\Omega_\infty=\Gamma_P(\eta_\infty)\) and \(V_\infty=H^{-1}\Omega_\infty H^{-\top}\).
