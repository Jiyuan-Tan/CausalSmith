Write \(Z^{\mathrm{GX}}_t=(\beta_1,\beta_2,q_1,q_2)^\top\) for a current augmented state. Its induced armwise update is \(q_a^+=q_a/(1+\mathbf 1\{A=a\}q_aX^2)\) and \(\beta_a^+=(\beta_a+\mathbf 1\{A=a\}q_aXY(a))/(1+\mathbf 1\{A=a\}q_aX^2)\). The next clipped-UCB action uses \(\beta_aX+|X|\sqrt{q_a}\), so \(Z^{\mathrm{GX}}_t\), rather than its two-dimensional slope projection, is the time-homogeneous Markov state. Analyze this augmented chain on \(\mathsf E_{\mathrm{GX}}\): the set is invariant because an updated slope is a convex combination of its preceding value and \(Y(a)/X\), while an unupdated slope is fixed and every inverse-Gram coordinate stays in \([0,1]\). Classify projected almost-sure limit sets directly from the augmented transition kernel; any stochastic-approximation ODE used in this classification must be derived for the augmented chain. If the projected limits are finitely many isolated deterministic states, combine compact containment in relative basin interiors with a finite-cover argument to seek the common Cesaro moduli \(r_T(K_0)\) and \(\delta_T(K_0)\).
