For the finite law in the statement and every Borel set \(D\),
\[
 \mu(D)=\sum_{j=1}^rp_j\mathbf1\{W_j\in D\}.
\tag{1}
\]
Because every \(p_j\) is strictly positive, the equality
\(c^\top Vc=c^\top\Sigma c\) holds \(\mu\)-almost surely if and only if
\(c^\top W_jc=c^\top\Sigma c\) for every \(j\).  Theorem
\(\mathrm{thm:contrastwise\text{-}deterministic\text{-}sandwich\text{-}iff}\)
therefore gives the first equivalence.  Likewise, \(V=\Sigma\) holds
\(\mu\)-almost surely if and only if \(W_j=\Sigma\) for every \(j\);
Theorem
\(\mathrm{thm:matrixwise\text{-}deterministic\text{-}sandwich\text{-}iff}\)
gives the second equivalence.
