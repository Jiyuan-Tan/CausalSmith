Write \(d_W=\lvert\mathcal X_W\rvert\leq r\) for each \(W\in V\).  To specify a scalar key, each vertex is either absent, assigned to \(A\) with one of \(d_W\) cell values, assigned to \(B\) with one of \(d_W\) values, or assigned to \(C\) with one of \(d_W\) values.  Requiring \(A\neq\varnothing\) subtracts the assignments having no \(A\)-vertex, and the two source tags contribute a factor of two.  Hence Definition \(\mathrm{def{:}extid\text{-}state\text{-}machine}\) and the inventory definition give
\[
 \begin{aligned}
 \lvert\mathscr K_{\mathcal G}\rvert
 &=2\left\{\prod_{W\in V}(1+3d_W)-\prod_{W\in V}(1+2d_W)\right\}\\
 &\leq2\left\{(1+3r)^{\lvert V\rvert}-(1+2r)^{\lvert V\rvert}\right\}.
 \end{aligned}
\]
The first equality is also obtained by partitioning according to the disjoint sets \(A,B,C\) and then counting their cells.

The ordered instance universe \(\mathscr U\) is finite because \(V\), \(\mathscr K_{\mathcal G}\), and the move-tag set are finite.  Every enabled nonterminal transition is, by definition, an instance in \(\mathscr U\) whose output is a key in \(\mathscr K_{\mathcal G}\), and the absent-output condition gives
\[
 K_{\sigma'}=K_\sigma\cup\{\xi_{\mathrm{out}}\},
 \qquad \xi_{\mathrm{out}}\notin K_\sigma.
\]
Therefore
\[
 \mu(\sigma')
 =\lvert\mathscr K_{\mathcal G}\setminus K_{\sigma'}\rvert
 =\mu(\sigma)-1.
\]
The nonnegative integer \(\mu\) can decrease only finitely many times.  Each intervening scan is over the finite ordered set \(\mathscr U\), so a scan either adds such a key, returns a present target, or returns \(\operatorname{FAIL}\).  Thus the procedure terminates and never has more than \(\lvert\mathscr K_{\mathcal G}\rvert\) keys present.

Now fix a compatible input and a model \(M\) in its exact fiber.  By Proposition \(\mathrm{prop{:}extid\text{-}storage\text{-}invariant}\), every annotation at every reachable state equals the interventional-kernel cell named by its key.  Finite sums and products preserve membership in \(\mathcal A(q_S,q_0)\), and a division is performed only when its denominator is positive; induction on the transition count therefore also shows that every annotation is in \(\mathcal A(q_S,q_0)\).  If the target key is present, its key is
\[
 (Y,X,\varnothing,\mathrm{pop},y,x,\ast),
\]
so its annotation satisfies
\[
 F_{x,y}(q_S,q_0)
 =P_M(Y=y\mid\operatorname{do}(X=x))
 =\psi_{x,y}(M).
\]
The input tables are common to every \(M\) in the exact fiber, so the same equality holds simultaneously for every such model.  Applying the cell argument in the finite lexicographic order on \(\mathcal I\) and using Definition \(\mathrm{def{:}full\text{-}kernel\text{-}collection}\) gives, whenever all runs succeed,
\[
 \mathbf F(q_S,q_0)=\{\psi_{x,y}(M):(x,y)\in\mathcal I\}
 =\boldsymbol\psi(M)
\]
for every model in the fiber.
