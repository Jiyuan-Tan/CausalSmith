We first prove the necessary condition by contraposition. Suppose \(\psi_{x,y}\) is not identifiable from \(P_N(V)\) on the positive finite substantive model class compatible with \(G_V\). Choose any common strictly positive terminal selection kernel, for example
\[
 \pi_S(1\mid r)=\frac12
 \quad\text{for every parent cell }r.
\]
Theorem \(\mathrm{thm{:}positive\text{-}ordinary\text{-}hedge\text{-}selection\text{-}lift}\) constructs two terminal-unconfounded extensions \(M_1,M_2\) with
\[
 \operatorname{Obs}_{T_0}(M_1)=\operatorname{Obs}_{T_0}(M_2)
 \quad\text{and}\quad
 \psi_{x,y}(M_1)\ne\psi_{x,y}(M_2).
\]
Therefore no single functional of the selected law and the \(T_0\)-margin can equal the causal cell for every model in that extension class. This is exactly the contrapositive of the first assertion.

Now take \(T_0=V\). The necessary direction has just been proved. For the converse, the second observed table is
\[
 q_0(v)=P_M(V=v).
\]
If ordinary identification supplies a functional \(f\) satisfying
\[
 \psi_{x,y}(M)=f(P_M(V))
\]
for every positive substantive model compatible with \(G_V\), then the two-source functional
\[
 F(q_S,q_0)=f(q_0)
\]
has the same value for every terminal-unconfounded extension and ignores the selected table. Thus ordinary identification implies two-law identification, proving the equivalence.

Finally, Lemma \(\mathrm{lem{:}ordinary\text{-}do\text{-}calculus\text{-}completeness}\) gives a finite ordinary do-calculus and probability derivation for every ordinarily identifiable cell. Proposition \(\mathrm{prop{:}boundary\text{-}reductions}\) states that when \(T_0=V\), initialization stores every cell of \(q_0=P_M(V)\) and the saturation replays any such finite derivation. Hence \(\operatorname{EXT\text{-}ID}\) returns an arithmetic functional. The soundness conclusion of that proposition, equivalently Theorem \(\mathrm{thm{:}extid\text{-}sound\text{-}termination}\), gives
\[
 F_{x,y}(q_S,q_0)=\psi_{x,y}(M)
\]
for every \(M\) in the exact compatible fiber. This proves the final claim without asserting anything about a bare \(\operatorname{FAIL}\) outside the stated boundary.
