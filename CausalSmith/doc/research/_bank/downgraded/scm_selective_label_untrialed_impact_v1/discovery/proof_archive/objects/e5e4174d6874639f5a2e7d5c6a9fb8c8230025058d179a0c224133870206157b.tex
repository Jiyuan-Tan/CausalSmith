Use throughout the row and column orders fixed by \(\text{def:complete-32-type-table}\).  We first verify legality and completeness of the observable--target cover.  For a displayed row with \(z=0\), its neutral-outcome triple is \(111\), while its \(r=1\) triple is one of
\[
000,\qquad 100,\qquad 110,\qquad 111.
\tag{1}
\]
Thus the neutral outcome is constant, the incorrect \(r=1\) outcome is nonincreasing in \(q\), and the correct neutral outcome is at least every incorrect outcome.  These are respectively neutral invariance, incorrect-performance order, and counterfactual correctness in \(\text{def:legal-response-types}\); correct-performance order holds because the correct neutral path is constant.  For a displayed row with \(z=1\), the neutral triple is \(000\), while its correct \(r=1\) triple is one of
\[
000,\qquad 001,\qquad 011,\qquad 111.
\tag{2}
\]
Now the neutral outcome is constant, the correct \(r=1\) outcome is nondecreasing, and every correct outcome is at least the incorrect neutral outcome.  Hence all four restrictions again hold.  Actions are unrestricted by \(\text{def:legal-response-types}\).  The displayed labels and full arrays differ for distinct row indices, so the thirty-two rows are distinct members of \(\mathcal T_{\mathrm{SLCC}}\).

Let \(t\) be any legal type in the specialized design.  Since \(\mathcal S^{32}=\{s_0\}\), its stratum is \(s_0\).  By \(\text{def:32-design-specialization}\) and the incidence definition, \(B^{32}_{\cdot,t}\) reads only
\[
\bigl(A_{(1,q_\ell)},Y_{(1,q_\ell)}\bigr),
\qquad
\bigl(A_{(1,q_h)},Y_{(1,q_h)}\bigr),
\tag{3}
\]
together with \(z\) whenever an endpoint action equals one.  The target \(h^{32}(t)\) reads only \(Y_{(1,q_m)}\).  In particular, neither object reads \(A_{(1,q_m)}\).  Indeed, \(e_{32}\notin J^{32}_0\), so no trial row uses that action, and the target is outcome-only.  The same argument applies to every action coordinate at any other nontrialed configuration.  Since legality restricts outcomes but imposes no cross-coordinate action restriction, these unread action coordinates may be fixed to the table values without changing \(B^{32}_{\cdot,t}\), \(h^{32}(t)\), or \(K^{32}B^{32}_{\cdot,t}\).

It remains to cover the outcomes read in (3) and at \(q_m\).  If \(z=0\), neutral invariance makes the correct neutral triple constant.  If that constant is zero, correctness forces the incorrect \(r=1\) triple to be \(000\); if it is one, incorrect-performance order permits exactly the four paths in (1).  The neutral-zero case has the same read coordinates as the displayed representative with \(r=1\) path \(000\).  If \(z=1\), the incorrect neutral triple is constant.  If that constant is one, correctness forces the correct \(r=1\) triple to be \(111\); if it is zero, correct-performance order permits exactly the four paths in (2).  The neutral-one case has the same read coordinates as the displayed representative with \(r=1\) path \(111\).  Finally, the four displayed endpoint-action patterns exhaust
\[
\bigl(A_{(1,q_\ell)},A_{(1,q_h)}\bigr)\in\{0,1\}^2.
\tag{4}
\]
Thus every legal full response type has the same \((B^{32}_{\cdot,t},h^{32}(t))\), and consequently the same \((K^{32}B^{32}_{\cdot,t},h^{32}(t))\), as at least one displayed row.  This proves a complete quotient-generating cover; it does not assert injectivity or minimality of the quotient map.  For example, rows \(1\) and \(17\) have the same observable column and target.  Inspection also shows that every one of the six feasible observable cells in each trial arm occurs.  Hence the twelve displayed cells are exactly the feasible rows, and the table generates the full observable polytope without omitting any column capable of changing one of the four endpoint optima.

Coarsening revealed labels gives

For every displayed column \(i\), the monotone paths (1)--(2) give

\lambda_L^{\top}B^{32}_{\cdot,i}\leq h^{32}_i
\leq\lambda_U^{\top}B^{32}_{\cdot,i}.
\tag{8}

For the lower inequality, the left side is the indicator of the low-arm cell \((1,1,1)\) plus the indicator of the high-arm cell \((1,1,0)\).  Only the summand whose revealed label matches the unit's label can be nonzero, and the relevant endpoint monotonicity then forces the middle outcome to one.  For the upper inequality, when \(z=0\) the right side is
\(1-\mathbf 1\{A_{(1,q_\ell)}=1,Y_{(1,q_\ell)}=0\}\), and when \(z=1\) it is
\(1-\mathbf 1\{A_{(1,q_h)}=1,Y_{(1,q_h)}=0\}\).  In either case, a middle outcome equal to one forces the relevant endpoint outcome to one by the corresponding performance order.  Likewise, column by column,
\[
\mu_L^{\top}K^{32}B^{32}_{\cdot,i}
=Y_{(1,q_\ell)}(t_i^{32})+Y_{(1,q_h)}(t_i^{32})-1

\leq1

\tag{9}

The left inequality in (9) holds for every binary monotone three-point path: if both endpoint values are one, its middle value is one, and otherwise the left side is nonpositive.  The quotient-generating cover shows that (8)--(9) also hold for every omitted legal full type.  With simplex multiplier zero, these are therefore feasible dual certificates.
