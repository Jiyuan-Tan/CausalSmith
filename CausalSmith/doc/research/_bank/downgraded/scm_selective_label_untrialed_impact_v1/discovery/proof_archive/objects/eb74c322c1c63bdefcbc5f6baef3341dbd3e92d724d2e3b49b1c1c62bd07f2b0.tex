For a direction \(g\), put \(z=\Pi_{T_{\mathfrak O}(p)}g\).  Using the full unnormalized dual faces, define
\[
\Gamma'_p(g)=\left(
\max_{(\alpha,\lambda)\in\Lambda_L(p)}\lambda^{\top}z,
\min_{(\alpha,\lambda)\in\Lambda_U(p)}\lambda^{\top}z
\right).
\]
Only the slope coordinate acts on \(z\); no normalized representative is selected.
