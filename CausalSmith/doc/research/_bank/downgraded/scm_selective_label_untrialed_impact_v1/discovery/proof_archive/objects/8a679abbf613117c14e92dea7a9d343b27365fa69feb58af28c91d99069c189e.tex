Fix \(p\in\mathfrak O\) and let
\[
F(p)=\{v\in\Delta_{\mathrm{SLCC}}:Bv=p\}.
\]
This fiber is nonempty, convex, and compact.  By \(\text{thm:finite-response-converse}\), its compatible causal values are exactly
\[
\{\tau_e(M):P_M(O_i)=p,\ M\in\mathfrak M_{\mathrm{SLCC}}\}
=\{h_e^{\top}v:v\in F(p)\}.
\]
The continuous linear image of a compact convex set in \(\mathbb R\) is a compact interval.  Its attained endpoints are \(L(p)\) and \(U(p)\) by \(\text{def:sharp-endpoint-programs}\).  If \(v_L,v_U\) attain them, then, for \(0\leq\gamma\leq1\),
\[
v_\gamma=(1-\gamma)v_L+\gamma v_U\in F(p),\qquad
h_e^{\top}v_\gamma=(1-\gamma)L(p)+\gamma U(p).
\]
The converse theorem constructs an SCM for every \(v_\gamma\), so the identified set is exactly \([L(p),U(p)]\).
