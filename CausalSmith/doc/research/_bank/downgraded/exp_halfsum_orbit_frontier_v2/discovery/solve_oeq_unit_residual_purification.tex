The proved catalog machinery supplies a finite, computable substitute for the unresolved purification.  Specifically, \(\textnormal{thm:affine-frontier}\) gives, for every \(R\ge 4\) and \(n_B,n_S\ge 4R\),
\[
\Phi_{n_B,n_S}(R)=\max_{c\in\mathcal C_R} f_c(n_B,n_S).
\]
It also identifies the optimizing profiles with the catalog argmax profiles, modulo common block permutation and simultaneous complementation, and records every tie through the affine phase inequalities.  The set \(\mathcal C_R\) is finite: its definition bounds \(m,A,D\) by \(2R\), positivity leaves only finitely many integer vectors \(u,v\), and \(p\in\{0,\ldots,A\}\), \(q\in\{0,\ldots,D\}\).  Thus both the frontier and all catalog equality cases are exactly enumerable for each fixed \(R\).  This result neither constructs a map from \(\mathcal C_R\) to \(\mathcal U_R\) nor proves simultaneous support and score dominance by a unit-residual entry.
