There is an exact rational support-deficient separating pair, which verifies the intervention-before-conditioning algebra but not the target's strict selected-cell positivity.  Let \(U,W,Z_1\) be independent fair bits and let selection satisfy
\[
 P(S=1\mid Z_1=z_1,Z_2=0)=\frac35,
 \qquad
 P(S=1\mid Z_1=z_1,Z_2=1)=1.
\]
In model zero set \(B=U\), \(D=B\), \(Z_2=U\oplus W\), and \(Y=W\).  In model one set \(B=U\), \(D=B\), \(Z_2=W\), and \(Y=D\oplus W\).  In both models \((B,Z_2)\) is uniform, \(D=B\), and \(Y=B\oplus Z_2\), so their selected observational laws agree on their common support.  At \(x_\star=(0,0)\), model zero has \(Z_2=U\oplus W\), which is independent of \(W=Y\), and hence its selected target is \(1/2\).  Model one has \(Z_2=W=Y\), and hence
\[
 P(Y=1\mid\operatorname{do}(B=0,D=0),S=1)
 =\frac{(1/2)\cdot1}{(1/2)\cdot1+(1/2)\cdot(3/5)}=\frac58.
\]
Constant-coordinate exactification supplies every syntactic edge of \(G_\star^S\) without changing these laws.  However, the equations \(D=B\) and \(Y=B\oplus Z_2\) leave zero selected cells, so this is not a proof of the positive-fiber target.
