In the following legal raw response family for the early-kill graph, independent smoothing cannot preserve a target contrast. Let \(U,W,Z_1\) be independent fair bits, let \(E\) be an independent bit with \(0<P(E=1)<1\), and use the same strictly positive selection probabilities given \((Z_1,Z_2)\) in two models. Both models set \(B=U\) and \(D=B\oplus E\). Model zero sets \(Z_2=U\oplus W\), model one sets \(Z_2=W\), and model \(j\) uses a Bernoulli outcome kernel \(P_j(Y=1\mid D=d,W=w)=\kappa_j(d,w)\). If their selected observational laws agree, then for each \(d\), \(\kappa_0(d,0)=\kappa_0(d,1)=\kappa_1(d,0)=\kappa_1(d,1)\); consequently their selected targets under \(\operatorname{do}(B=0,D=d)\) are equal. Coordinate-constant exactification cannot change this conclusion.
