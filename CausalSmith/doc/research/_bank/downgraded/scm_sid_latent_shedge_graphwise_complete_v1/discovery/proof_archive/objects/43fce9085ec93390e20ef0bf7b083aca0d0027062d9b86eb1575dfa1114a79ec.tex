Fix a finite signature \(\sigma\), a member \(D_i\in\mathcal D_S(D)\), and the call chain in the statement.  We work under the exact-graph convention in \texttt{ass:augmented-scm-compatibility} and \texttt{def:model-class}.

First consider the trace of the single-component recursion.  By the operational specification in \texttt{def:success-or-certificate-algorithm}, the target argument is unchanged along this call chain, so at a terminal failure
\[
 C=D_i.
\]
The same specification says that the current enclosure \(T\) remains inside its initial enclosure \(T_i^{(0)}\), that both the target and the current enclosure are single S-components, and that the terminal failure test is equality of the current enclosure with the ancestor set of the target.  Consequently,
\[
 C\subsetneq T\subseteq T_i^{(0)},\qquad
 \operatorname{SComp}_{G^S}(C)=\{C\},\qquad
 \operatorname{SComp}_{G^S}(T)=\{T\},
\]
and
\[
 \operatorname{An}_{G^S[T]}(C)=T.
\]
These are exactly the four conditions in \texttt{def:s-hedge}; hence
\[
 \operatorname{SHedge}_{G^S}(C,T)
\]
holds.

Apply \texttt{lem:projection-components} with \(H=C\) and with \(H=T\).  The two singleton S-component identities just obtained imply, respectively, that \(\Pi_S(G^S)[C]\) and \(\Pi_S(G^S)[T]\) each have one district.  By \texttt{def:suppression-projection}, the directed part of \(\Pi_S(G^S)\) is precisely the directed part of \(G^S[N_S]\).  Since \(T\subseteq N_S\), the directed induced graphs on \(T\) coincide.  Directed ancestry therefore coincides as well, and the preceding terminal equality gives
\[
 \operatorname{An}_{\Pi_S(G^S)[T]}(C)
 =\operatorname{An}_{G^S[T]}(C)
 =T.
\]

We next construct the claimed forests.  Regard the bidirected edges of \(\Pi_S(G^S)[C]\) as undirected edges.  This finite graph is connected because \(\Pi_S(G^S)[C]\) has one district.  Repeatedly add an edge joining the vertices already reached to a new vertex until every vertex is reached; deleting no chosen edge, this procedure constructs a bidirected spanning tree \(K_0\) on \(C\).  Starting from \(K_0\), perform the same finite procedure in the connected bidirected graph \(\Pi_S(G^S)[T]\): whenever the current vertex set \(U\) is a proper subset of \(T\), connectedness supplies a bidirected edge across the cut \((U,T\setminus U)\), and we add that edge and its endpoint outside \(U\).  Cardinality increases strictly at each step, so after at most \(|T\setminus C|\) steps the result is a bidirected spanning tree \(K_1\) on \(T\).  Every edge added after \(K_0\) has, at the moment it is added, an endpoint outside the current vertex set and hence an endpoint outside \(C\).  Thus
\[
 K_1[C]=K_0.
\]

Set \(R=C\), which is nonempty because \(D_i\) is a member of a partition.  For each \(t\in T\), define
\[
 \delta(t)=\min\bigl\{\ell\in\mathbb N:
 t=v_0\to v_1\to\cdots\to v_\ell\in C
 \text{ is a directed path in }G^S[T]\bigr\}.
\]
The set minimized over is nonempty by \(\operatorname{An}_{G^S[T]}(C)=T\), so finiteness of \(T\) makes \(\delta(t)\) well defined.  For \(t\in C\), the length-zero path gives \(\delta(t)=0\).  For each \(t\in T\setminus C\), choose a shortest such path and denote its next vertex by \(p(t)\).  Then
\[
 t\to p(t)\text{ is an edge of }G^S[T],
 \qquad
 \delta(p(t))=\delta(t)-1.
\]
The same directed edge belongs to \(\Pi_S(G^S)[T]\) by \texttt{def:suppression-projection}.

Define \(F_0\) on vertex set \(C\) to have bidirected edges \(K_0\) and no directed edges.  Define \(F_1\) on vertex set \(T\) to have bidirected edges \(K_1\) and directed edges
\[
 \{t\to p(t):t\in T\setminus C\}.
\]
Along each selected directed edge, \(\delta\) decreases by one, so the directed part of \(F_1\) is acyclic.  Every vertex in \(T\setminus C\) has exactly one child, and no vertex in \(C\) has a child.  Hence the vertices with no children in both forests are exactly
\[
 R=C.
\]
Moreover, \(K_0\) and \(K_1\) make the respective forests single bidirected districts.  Since \(K_1[C]=K_0\) and every selected directed edge of \(F_1\) has its tail outside \(C\),
\[
 F_1[C]=F_0.
\]
Thus \(F_0\subset F_1\) are nested common-\(R\)-rooted \(C\)-forests with vertex sets \(C\) and \(T\).

It remains to prove the three incidence assertions.  By the definition of \(D\),
\[
 D=\operatorname{An}_{G^S[N_S\setminus X_N]}(Y_N)
 \subseteq N_S\setminus X_N.
\]
Since \(C=D_i\subseteq D\), this yields
\[
 C\cap X_N=\varnothing.
\]
Every directed path witnessing membership of \(C\) in the displayed ancestor set is also a path in the suppression projection, because the directed edges on \(N_S\) are unchanged.  As \(R=C\), we obtain
\[
 R\subseteq
 \operatorname{An}_{\Pi_S(G^S)[N_S\setminus X_N]}(Y_N).
\]

Finally, suppose for contradiction that \(T\cap X_N=\varnothing\).  Then \(T\subseteq N_S\setminus X_N\).  For every \(t\in T\), the equality \(\operatorname{An}_{G^S[T]}(C)=T\) supplies a directed path from \(t\) to some \(c\in C\) inside \(T\).  Because \(c\in C\subseteq D\), the definition of \(D\) supplies a directed path from \(c\) to a vertex of \(Y_N\) inside \(N_S\setminus X_N\).  Concatenating the two paths shows that \(t\in D\).  Therefore
\[
 T\subseteq D.
\]
The identity \(\operatorname{SComp}_{G^S}(T)=\{T\}\) says that any \(t\in T\) is joined to any fixed \(c\in C\) by a bidirected path in \(G^S[T\cup A_S\cup\{S\}]\).  Since \(T\subseteq D\), that path also lies in \(G^S[D\cup A_S\cup\{S\}]\).  Thus every \(t\in T\) belongs to the same member of \(\mathcal D_S(D)\) as \(c\).  That member is \(D_i=C\), whence \(T\subseteq C\), contradicting \(C\subsetneq T\).  We conclude that
\[
 T\cap X_N\ne\varnothing.
\]
All asserted graph-theoretic conclusions follow.  No step constructs or assumes a positive rational projected countermodel pair, so the final limitation in the statement is respected.
