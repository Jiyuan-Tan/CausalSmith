Assume that \(G^S\) has no bidirected edges and that \(S\) has no children.  Let \(H\subseteq N_S\).  The induced graph \(G^S[H\cup A_S\cup\{S\}]\) also has no bidirected edges, because taking an induced subgraph cannot create an edge.  A district is a maximal set connected by bidirected paths.  Hence every district of this induced graph is a singleton, and therefore Definition \(\mathrm{def:s\text{-}component}\) gives
\[
\begin{aligned}
 \operatorname{SComp}_{G^S}(H)
 &=\bigl\{K\cap H:K\in\mathcal D(G^S[H\cup A_S\cup\{S\}]),\ K\cap H\ne\varnothing\bigr\}\\
 &=\bigl\{\{h\}:h\in H\bigr\}.
\end{aligned}
\]
This includes the case \(H=\varnothing\), for which both sides are the empty partition.

We next show that a recursive S-Hedge cannot exist.  Suppose, to the contrary, that \(\operatorname{SHedge}_{G^S}(C,T)\) holds.  By Definition \(\mathrm{def:s\text{-}hedge}\),
\[
 C\subsetneq T\subseteq N_S
 \quad\text{and}\quad
 \operatorname{SComp}_{G^S}(T)=\{T\}.
\]
The declared type of \(C\) makes \(C\) nonempty, so choose \(t\in C\).  Applying the preceding singleton-partition identity with \(H=T\) yields
\[
 \operatorname{SComp}_{G^S}(T)=\bigl\{\{u\}:u\in T\bigr\}.
\]
Since \(t\in C\subseteq T\), the block \(\{t\}\) belongs to the left-hand side.  Its equality with \(\{T\}\) forces \(T=\{t\}\).  But \(\varnothing\ne C\subseteq\{t\}\) then forces \(C=\{t\}=T\), contradicting \(C\subsetneq T\).  Thus no pair \((C,T)\) satisfies the S-Hedge predicate.  A terminal recursive S-Hedge failure branch, by its stated failure certificate, would return such a pair; consequently that branch of \(\mathsf{sID}^{\pm}\) cannot occur.
