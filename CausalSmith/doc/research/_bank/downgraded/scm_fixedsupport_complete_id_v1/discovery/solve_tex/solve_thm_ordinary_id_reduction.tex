Let \(\bar G\) be the graph obtained from \(G_H^N\) by suppressing the selector vertex, its constant coordinates, and its stored gate syntax.  Let \(\bar\Theta^{+}\) denote the finite canonical response-function class on \(\bar G\), with the same recursive order and independent-root restrictions as the substantive part of \(\Theta_H\), and with strictly positive ordinary observational cells.  We prove first that suppression gives the claimed ordinary model and relation, and then that it intertwines the two recursions.

Fix \(\theta\in\Theta_H\).  Since \(H=\{s_{\emptyset}\}\), exact selector support and normalization of probability give
\[
 p_\theta(S=s_{\emptyset})=1,
 \qquad
 p_\theta(S=s)=0\quad\text{for every }s\ne s_{\emptyset}.
 \tag{1}
\]
For a selector-controlled substantive vertex \(X\in V\), the known-selector-gate assumption gives the structural equation
\[
 X=
 \begin{cases}
 f_X^{\mathrm{nat}}(\operatorname{pa}_X,U_X),&S_X^e=0,\\
 S_X^v,&S_X^e=1.
 \end{cases}
 \tag{2}
\]
Every gate is laid back on \(E_H\), and
\[
 E_H=H\cup\{s_{\emptyset}\}=\{s_{\emptyset}\}.
 \tag{3}
\]
Consequently \(s_{\emptyset,X}^e=0\), so (2) becomes, in the sole observational execution and in the target execution,
\[
 X=f_X^{\mathrm{nat}}(\operatorname{pa}_X,U_X).
 \tag{4}
\]
Thus selector-specified values are not arguments of any executed substantive mechanism.  By the definition of support-active normalization, an argument is deleted only if it is unused throughout (3), while every primitive natural-response coordinate, including a dormant coordinate, is retained.  Hence suppression removes only constant gate syntax and leaves exactly the recursive substantive response tables in (4).

There is no bidirected connection between the selector and a substantive vertex: such a connection would arise from a latent root shared by \(S\) and \(V\), which is excluded by hypothesis.  The independent-root assumption further implies that marginalizing selector-only roots leaves the declared semi-Markovian independent-root law for the substantive equations.  Therefore \(\bar G\) is the ordinary semi-Markovian expansion on \(V\), canonically isomorphic to the substantive part of \(G_H^N\).

Define \(R(\theta)\) by restricting \(\theta\) to its substantive response coordinates and substantive latent-root laws.  Equations (1)--(4) and independent-root factorization imply \(R(\theta)\in\bar\Theta^{+}\).  Conversely, given \(\bar\theta\in\bar\Theta^{+}\), define \(E(\bar\theta)\) by retaining its substantive coordinates, assigning the selector law the point mass at \(s_{\emptyset}\), reinstating the prescribed multiplexers, and filling every retained dormant selector-only simplex coordinate consistently with the stored copy equalities.  The resulting parameter is recursive, has the prescribed independent roots, obeys every known gate, and has selector support exactly \(H\).  Its admissible cells are precisely the pairs \((v,s_{\emptyset})\), and they are positive because \(p_{\bar\theta}^{\bar G}(v)>0\).  Thus
\[
 E(\bar\theta)\in\Theta_H.
 \tag{5}
\]
Recursive evaluation of the common substantive equations gives, for every substantive assignment \(v\) and outcome assignment \(y\),
\[
 \begin{aligned}
 p_\theta(V=v,S=s_{\emptyset})
   &=p_{R(\theta)}^{\bar G}(V=v),\\
 T_{a,H}(\theta)(y)
   &=p_{R(\theta)}^{\bar G}\{Y(a)=y\},
 \end{aligned}
 \tag{6}
\]
and, in the reverse direction,
\[
 \begin{aligned}
 p_{E(\bar\theta)}(V=v,S=s_{\emptyset})
   &=p_{\bar\theta}^{\bar G}(V=v),\\
 T_{a,H}\{E(\bar\theta)\}(y)
   &=p_{\bar\theta}^{\bar G}\{Y(a)=y\}.
 \end{aligned}
 \tag{7}
\]
It follows from (6) and (7), under the canonical identification \(q(v,s_{\emptyset})\leftrightarrow q(v)\), that
\[
 \Phi_H=
 \left\{
 \left(p_{\bar\theta}^{\bar G}(V),
       p_{\bar\theta}^{\bar G}\{Y(a)\}\right):
 \bar\theta\in\bar\Theta^{+}
 \right\}.
 \tag{8}
\]
The normalization-equivalence theorem identifies the same left-hand side with the attainable relation computed on \(G_H^N\).  Therefore neither retained dormant coordinates nor stored inverse-gate syntax enlarge or shrink (8).

We next compare the deterministic case function with ordinary ID.  Let
\[
 \bar p(v)=p_H(v,s_{\emptyset})
 \tag{9}
\]
and let \(\bar I=(\bar G,A,a,Y,\bar p)\) be the ordinary input, encoded by the restriction of the fixed input order to \(V\).  Couple a support-aware state with an ordinary recursive ID state by erasing the selector fields and the support ledger.  The coupling invariant is
\[
 \begin{aligned}
 &\text{the current CADMGs agree after selector suppression;}\\
 &q(x_V,S=s_{\emptyset})=\bar q(x_V)\text{ for the paired current kernels;}\\
 &\text{the outcome sets, fixed sets, pending districts, and stored factors agree.}
 \end{aligned}
 \tag{10}
\]
Equation (9) establishes (10) at initialization.  The Start case constructs the same intervention graph after suppression, hence the same ancestor set
\[
 Y^{*}=\operatorname{an}_{\bar G(a)}(Y),
 \tag{11}
\]
and the same canonically ordered districts of the induced graph on \(Y^{*}\).

For every pending substantive district \(D^{*}\), the only supported context is laid back and forces no treatment coordinate.  Therefore the context computation is exact and yields
\[
 L(D^{*})=\{s_{\emptyset}\}.
 \tag{12}
\]
In particular, the positive-context failure cannot occur and no context outside \(H\) is introduced.

Consider a substantive vertex \(W\) in any pair of successively fixed coupled CADMGs.  Selector suppression preserves all directed paths, bidirected paths, districts, and descendants among substantive vertices.  It follows directly from the definition of fixability that
\[
 \operatorname{dis}_{G}(W)\cap\operatorname{de}_{G}(W)=\{W\}
 \quad\Longleftrightarrow\quad
 \operatorname{dis}_{\bar G}(W)\cap\operatorname{de}_{\bar G}(W)=\{W\}.
 \tag{13}
\]
Induction over the entries of a proposed sequence now shows that a sequence of substantive vertices is valid on one side exactly when it is valid on the other.  Since the two searches use the same restricted canonical order, they return the same least valid substantive sequence.

The selector is isolated after (4) and the exclusion of a shared latent root.  Hence it is fixable at every stage.  If a reachable set containing a substantive district also contained \(S\), appending the fixing of this isolated selector would produce a strictly smaller reachable superset of that district.  Conversely, a substantive set is reachable in the ordinary graph exactly when the same set is reachable before suppression, with the isolated selector fixed in addition if it is random.  The computed-closure valid-sequence lemma and uniqueness of the inclusion-minimal reachable superset therefore give
\[
 \operatorname{closure}_{G_H^{[]}}(D^{*})
 =\operatorname{closure}_{\bar G}(D^{*})=:C\subseteq V,
 \qquad S\notin C.
 \tag{14}
\]

It remains to compare kernels.  Suppose (10) holds before fixing \(W\).  Finite marginalization commutes with evaluation at the sole selector value.  Thus the actual nested conditional computed by the fixing operation satisfies
\[
 q\{W\mid\operatorname{nd}_{G}(W),\operatorname{fixed}(G),S=s_{\emptyset}\}
 =
 \bar q\{W\mid\operatorname{nd}_{\bar G}(W),\operatorname{fixed}(\bar G)\}.
 \tag{15}
\]
Every denominator in (15) is a nonempty finite sum of positive admissible cells at the initial step, and after a fixing step positivity is preserved because the current positive kernel is divided by a positive conditional.  Hence all divisions in the coupled run are defined.  Dividing the two sides of the kernel equality in (10) by the equal positive conditionals in (15) proves the successor equality.  By induction along the computed valid sequence,
\[
 \left.
 \phi_T(q;G)
 \right|_{S=s_{\emptyset}}
 =
 \phi_T(\bar q;\bar G)
 \tag{16}
\]
for every fixed set \(T\) actually selected by the recursion.  The support-aware ledger merely records the positive denominators and the cross-multiplied versions of these equalities, so erasing it preserves the ordinary state.

If \(C=D^{*}\), the machine computes the valid sequence for \(V\setminus D^{*}\), evaluates at the unique context in (12), and emits
\[
 \left.
 \phi_{V\setminus D^{*}}(p_H;G_H^{[]})
 \right|_{S=s_{\emptyset}}
 =
 \phi_{V\setminus D^{*}}(\bar p;\bar G),
 \tag{17}
\]
by (16).  This is exactly the ordinary reachable district factor, so (10) is preserved.

If \(C\ne D^{*}\), the computed valid sequence for \(V\setminus C\) gives
\[
 \left.\widetilde q\right|_{S=s_{\emptyset}}
 =\phi_{V\setminus C}(\bar p;\bar G),
 \qquad
 \widetilde G[s_{\emptyset}]=\bar G_C.
 \tag{18}
\]
By (14), the case function must take the \(S\notin C\) branch.  Its context enumeration contains only (12).  Applying (13) after the first fixing sequence shows
\[
 \operatorname{fixSeq}_{\widetilde G[s_{\emptyset}]}(C\setminus D^{*})
 \ne\operatorname{none}
 \quad\Longleftrightarrow\quad
 \operatorname{fixSeq}_{\bar G_C}(C\setminus D^{*})
 \ne\operatorname{none}.
 \tag{19}
\]
When (19) holds, both procedures execute the same least valid sequence, and (16) proves equality of the emitted factors.  When (19) fails, the support-aware transition records \(\operatorname{LGSFailThicket}(D^{*},C)\); after selector suppression, the same pair \((D^{*},C)\) is precisely the ordinary hedge endpoint.  Thus the failure tag carries, rather than assumes, the ordinary hedge.  The branch \(S\in C\) is impossible by (14), so the Algorithm 2 hybrid-kernel cases are never entered.

When all district children finish, Join returns
\[
 \sum_{Y^{*}\setminus Y}\prod_{D^{*}}q_{D^{*}},
 \tag{20}
\]
with the same substitution of \(a\) as ordinary ID.  The factor equalities above make (20) exactly the ordinary ID assembly.  District splitting strictly decreases the substantive task mask, every computed fixing sequence is finite, and all remaining administrative cases descend through their finite phases.  Hence induction over the finite ordinary recursion tree, with an inner induction over each fixing sequence, proves that every branch predicate, graph, kernel, factor, and structural terminal endpoint agrees under suppression.

By input determinacy, every canonical minimum and every run prefix used in this induction is a function only of the input and current state; no published successful trace, target equality, or oracle candidate is inspected.  Finally, the cited Shpitser--Pearl formula-or-hedge result classifies the common ordinary endpoint: (20) is the identifying formula on success, while failure in (19) supplies the hedge.  The optional residual-verification processing of the recorded failure payload does not enter this specialization argument or assume general residual-candidate exhaustiveness.  Therefore \(\operatorname{SA\mbox{-}CS\mbox{-}ID}\), under singleton laid-back support and a selector with no latent root shared with \(V\), reduces canonically to the ordinary ID formula-or-hedge classification.  All displayed divisions are asserted only on the strictly positive model class \(\Theta_H\); no boundary extension is used.
