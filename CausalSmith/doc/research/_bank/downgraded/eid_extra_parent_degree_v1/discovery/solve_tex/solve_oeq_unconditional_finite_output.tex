The strongest conclusion derivable from the frozen core is the following conditional reduction.  Fix \((G,T,e)\in\mathcal G_{n,k}\) with \(d_e(G)<\infty\).  The already-established theorem \(\mathrm{thm:conditional\mbox{-}geometric\mbox{-}resolution}\) states that, if a valid source-prime chart package \(\mathfrak C_{G,e}\) is supplied for every source-consistent recorded stratum, then a randomized localized geometric-resolution algorithm returns
\[
\bigl(d_e(G),p_e,\mathcal Q_{G,e},h_{G,e}\bigr)
\]
with symbolic error probability at most \(\delta\), arithmetic time and certificate length at most
\[
(n+s)^{a(k+1)}\mathfrak d^{a}\operatorname{poly}\!\left(\log(1/\delta)\right),
\]
where \(s=s(\mathfrak C_{G,e})\) and \(\mathfrak d=\mathfrak d(\mathfrak C_{G,e})\).  In particular, if a universal \(b>0\) satisfies
\[
s\leq n^b
\qquad\text{and}\qquad
\mathfrak d\leq n^{b(k+1)},
\]
then
\[
(n+s)^{a(k+1)}\mathfrak d^{a}
\leq
(n+n^b)^{a(k+1)}n^{ab(k+1)}
\leq
2^{a(k+1)}n^{a\max\{1,b\}(k+1)+ab(k+1)}.
\]
Because \(n\geq2\), the last expression is at most \(n^{C(k+1)}\) for a universal constant \(C\) depending only on \(a\) and \(b\).  Thus bounded valid-chart construction is sufficient for the requested fixed-parameter exact finite output.

Unconditionally, the already-established theorem \(\mathrm{thm:fpt\mbox{-}minimal\mbox{-}polynomial}\) returns the correct algebraic-versus-transcendental tag.  On the algebraic branch it certifies
\[
d_e(G)\leq 2^{|D|-n+2}\leq2^{k+1},
\]
but, as its statement explicitly records, it does not compute \(d_e(G)\), \(p_e\), \(\mathcal Q_{G,e}\), or \(h_{G,e}\).  Hence the frozen core proves the chart-conditional implication and the unconditional tag, but it does not prove the requested chart-free construction.
