Let \(p_n=K_n-1\) and form the signed vectors
\[
 \widetilde X_i=(X_{i1},\ldots,X_{ip_n},-X_{i1},\ldots,-X_{ip_n})\in\mathbb R^{2p_n}.
\]
Independence and centering are inherited from the assumed score vectors.  Each signed coordinate has average variance one, so condition (M.1) in \(\texttt{lem:cck-hyperrectangle-bootstrap}\) holds with \(b=1\).  Absolute values are unchanged by signing, so the two moment inequalities and the exponential inequality in that cited lemma hold with the same \(B_n\).

Let \(S_n=n^{-1/2}\sum_iX_i\).  For every real \(t\),
\[
 \max_{K\leq p_n}|S_{nK}|\leq t
 \quad\Longleftrightarrow\quad
 n^{-1/2}\sum_i\widetilde X_i\in(-\infty,t]^{2p_n}.                            \tag{1}
\]
The set on the right is a hyperrectangle.  The centered Gaussian vector with the covariance of the signed sum is \((Z_P,-Z_P)\), because the upper-left block is \(R_P\) and signing fixes all remaining covariance blocks.  Hence its lower-orthant maximum is \(\max_K|Z_{P,K}|\).  Apply the first conclusion of the cited lemma with dimension \(2p_n\); since \(2p_n\leq2K_n\), its bound is at most the displayed \(CD_n\).

For the multiplier part, empirical centering commutes with signing:
\[
 \widetilde X_i-\overline{\widetilde X}
 =(X_i-\overline X,-X_i+\overline X).
\]
Thus the same equivalence (1) identifies the absolute multiplier maximum with a hyperrectangle event for the centered signed multiplier vector.  Apply the second conclusion of the cited lemma with \(\gamma=\gamma_n=(2nK_n)^{-1}\), which belongs to \((0,e^{-1})\) for all sufficiently large \(n\).  This gives exactly the second displayed bound in the proposed statement.  Finally,
\[
 \log^5(2nK_n)\log^2(1/\gamma_n)leq C\log^7(2nK_n),
\]
so both approximation errors vanish when \(D_n\to0\).  No part of this argument replaces oracle scores by fitted scores, proving the final scope sentence.
