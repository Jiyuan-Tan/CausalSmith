Fix a nontrivial split \(B=C\mathbin{\dot\cup}D\).  Suppose, contrary to the first conclusion, that
\[
 Z_D=h(Z_C)+\eta_D,
 \qquad \eta_D\perp\!\!\!\perp Z_C.
\]
Because \(h\) is Borel measurable, independence gives, for every \(t\in\mathbb R^{|D|}\), a version of the conditional characteristic function satisfying
\[
 \begin{aligned}
 \varphi_{D\mid C=c}(t)
 &=\mathbb E\!\left[\exp\{i\langle t,h(c)+\eta_D\rangle\}\mid Z_C=c\right]\\
 &=\exp\{i\langle t,h(c)\rangle\}\,\varphi_{\eta_D}(t)
 \end{aligned}
\]
for \(P_{Z_C}\)-almost every \(c\).  Taking absolute values and using \(|\exp(iu)|=1\) yields
\[
 |\varphi_{D\mid C=c}(t)|=|\varphi_{\eta_D}(t)|
 \quad\text{for }P_{Z_C}\text{-almost every }c.
\]
At the specified \(t_D\), the positive-probability sets \(A_1\) and \(A_2\) would therefore imply simultaneously
\[
 |\varphi_{\eta_D}(t_D)|\leq\alpha_D
 \quad\text{and}\quad
 |\varphi_{\eta_D}(t_D)|\geq\beta_D,
\]
contrary to \(\alpha_D<\beta_D\).  Thus no representation in the \(C\)-to-\(D\) direction exists.  Interchanging \(C\) and \(D\) and using \(H_1,H_2,t_C,\alpha_C,\beta_C\) gives the same contradiction for the reverse direction.  Since the argument applies to every nontrivial split and excludes all independent residuals, it in particular excludes the residual laws quantified by \(\operatorname{SmoothPos}\) in \(\mathrm{def:smooth-positive-laws}\).  This is exactly innovation atomicity.
