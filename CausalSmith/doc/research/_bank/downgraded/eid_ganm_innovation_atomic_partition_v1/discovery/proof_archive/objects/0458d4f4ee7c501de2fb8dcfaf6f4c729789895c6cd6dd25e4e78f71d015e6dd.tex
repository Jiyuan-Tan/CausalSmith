Fix \(m\ge 1\) and \(\mu\in\operatorname{SmoothPos}(m)\). By \(\mathrm{def:smooth-positive-laws}\), there is a Lebesgue density \(r:\mathbb R^m\to(0,\infty)\) such that \(\mu(A)=\int_A r\,d\lambda_m\) for every Borel set \(A\), where \(\lambda_m\) denotes \(m\)-dimensional Lebesgue measure. Moreover, \(\log r\in C^3(\mathbb R^m)\), so \(r=\exp(\log r)\) is continuous and hence Borel measurable.

Let \(O\subseteq\mathbb R^m\) be nonempty and open. Choose \(x\in O\). By openness there is \(\delta>0\) such that the Euclidean ball \(B(x,\delta)\) is contained in \(O\). Set
\[
Q=x+\left[-\frac{\delta}{2\sqrt m},\frac{\delta}{2\sqrt m}\right]^m.
\]
For every \(y\in Q\), \(\lVert y-x\rVert_2\le \delta/2<\delta\), and therefore \(Q\subseteq O\). Also \(\lambda_m(Q)=(\delta/\sqrt m)^m>0\). For each integer \(n\ge1\), define the measurable set
\[
E_n=\{y\in Q:r(y)\ge 1/n\}.
\]
Pointwise positivity of \(r\) gives \(Q=\bigcup_{n\ge1}E_n\): for each \(y\in Q\), the Archimedean property supplies \(n\) with \(n\ge 1/r(y)\). If \(\lambda_m(E_n)=0\) for every \(n\), countable subadditivity would imply \(\lambda_m(Q)=0\), contradicting the displayed positive volume. Hence \(\lambda_m(E_N)>0\) for some \(N\ge1\). Using the density representation, the inclusions \(E_N\subseteq Q\subseteq O\), and the defining lower bound on \(E_N\),
\[
\mu(O)=\int_O r\,d\lambda_m
\ge \int_{E_N}r\,d\lambda_m
\ge \frac{1}{N}\lambda_m(E_N)>0.
\]
Thus every nonempty Euclidean open set has positive \(\mu\)-probability.

It remains to prove the affine assertion. Let \(L=a+W\) be a proper affine subspace of \(\mathbb R^m\). Choose an orthonormal basis \(w_1,\ldots,w_k\) of the linear subspace \(W\). Then
\[
W=\left\{z\in\mathbb R^m:
z=\sum_{j=1}^k\langle z,w_j\rangle w_j\right\}.
\]
The right-hand side is the zero set of the continuous map \(z\mapsto z-\sum_{j=1}^k\langle z,w_j\rangle w_j\), so \(W\), and hence its translate \(L\), is closed. Because \(L\) is proper, \(L^c\) is a nonempty Euclidean open set. The first part yields \(\mu(L^c)>0\), whence
\[
\mu(L)=1-\mu(L^c)<1.
\]
Therefore \(\mu\) is not supported on \(L\). Since \(L\) was arbitrary, no member of \(\operatorname{SmoothPos}(m)\) is supported on a proper affine subspace, proving that the stated nondegeneracy follows from full density positivity and is not an additional residual-law condition.
