Partition each arm into deterministic folds \(I_{a,1}\) and \(I_{a,2}\), each of size \(m=n/2\). On pilot fold \(3-e\), let \(\widetilde p_{a,n}^{(-e)}\) be the empirical boundary-wavelet joint-density projection through \((\bar J_y,\bar J_z)\), and set \(\widetilde r_n^{(-e)}(z)=\frac12\sum_{a=0}^1\int_0^1\widetilde p_{a,n}^{(-e)}(u,z)du\). With \(T(x)=\min\{2C,\max\{c/2,x\}\}\), define \(\widehat r_n^{(-e)}(z)=T(\widetilde r_n^{(-e)}(z))/\int T(\widetilde r_n^{(-e)}(v))dv\), \(\check q_{a,n}^{(-e)}(y,z)=\widetilde p_{a,n}^{(-e)}(y,z)/\widehat r_n^{(-e)}(z)\), and \(\widehat q_{a,n}^{(-e)}(y,z)=T(\check q_{a,n}^{(-e)}(y,z))/\int_0^1T(\check q_{a,n}^{(-e)}(u,z))du\). The event \(\mathcal E_n^{(-e)}\) is \(c/2<\widetilde r_n^{(-e)}<2C\) and \(c/2<\check q_{a,n}^{(-e)}<2C\) pointwise for both arms; clipping is inactive on this event, while normalization enforces exact conditional mass. The displayed operations keep every object defined on its complement. Put \(\widehat{\bar q}_n^{(-e)}=(\widehat q_{0,n}^{(-e)}+\widehat q_{1,n}^{(-e)})/2\) and, on the oversampled zero-outcome-mean wavelet space through \(J_y^{\mathrm{op}}\), set
\[
\widehat{\mathcal G}_{n,z}^{(-e)}=
\left[P_{J_y^{\mathrm{op}}}\{-\partial_y(\widehat{\bar q}_n^{(-e)}(\cdot,z)\partial_y)\}P_{J_y^{\mathrm{op}}}+\lambda_n I\right]^{-1}P_{J_y^{\mathrm{op}}}.
\]
Define
\[
\widehat G_{R,J_y,J_z,n}^{(-e)}
=\int\Phi_{J_y,J_z}(y,z)\Phi_{J_y,J_z}(y,z)^{\top}\,dy\,\widehat r_n^{(-e)}(z)dz,
\]
\[
\widehat H_{\mathrm{form},J_y,J_z,n;\lambda\mu}^{(-e)}
=\int\Phi_\lambda(y,z)\{\widehat{\mathcal G}_{n,z}^{(-e)}\Phi_\mu(\cdot,z)\}(y)\,dy\,\widehat r_n^{(-e)}(z)dz,
\]
and the raw-moment-coordinate Hessian
\[
\widehat B_{J_y,J_z,n}^{(-e)}
=\{\widehat G_{R,J_y,J_z,n}^{(-e)}\}^{-1}
\widehat H_{\mathrm{form},J_y,J_z,n}^{(-e)}
\{\widehat G_{R,J_y,J_z,n}^{(-e)}\}^{-1}.
\]
Let \(\widehat f_n^{(-e)}(z)=W_2^2(\widehat q_{0,n}^{(-e)}(\cdot,z)dy,\widehat q_{1,n}^{(-e)}(\cdot,z)dy)\), let \(\widehat\ell_{a,n}^{(-e)}\) be its observable one-dimensional Kantorovich derivative in arm \(a\), and let \(\widehat\theta_{\mathrm{plug}}^{(-e)}=\int\widehat f_n^{(-e)}(z)\widehat r_n^{(-e)}(z)dz\). The explicit first-order score is
\[
\widehat s_{a,n}^{(-e)}(y,z)=\frac12\{\widehat f_n^{(-e)}(z)-\widehat\theta_{\mathrm{plug}}^{(-e)}\}+\widehat\ell_{a,n}^{(-e)}(y,z)-\int_0^1\widehat\ell_{a,n}^{(-e)}(u,z)\widehat q_{a,n}^{(-e)}(u,z)du.
\]
Set \(X_{a,i}^{(-e)}=\Phi_{J_y,J_z}(W_{a,i,n})-\widehat\mu_{a,J_y,J_z,n}^{(-e)}\), where \(\widehat\mu_{a,J_y,J_z,n}^{(-e)}=\int\Phi_{J_y,J_z}\widehat q_{a,n}^{(-e)}\widehat r_n^{(-e)}\). The diagonal-free correction in raw moment coordinates is
\[
\widehat U_{e,J_y,J_z,n}=\frac{1}{m(m-1)}\sum_{a=0}^1\sum_{i\ne j\in I_{a,e}}(X_{a,i}^{(-e)})^\top\widehat B_{J_y,J_z,n}^{(-e)}X_{a,j}^{(-e)}-\frac{2}{m^2}\sum_{i\in I_{1,e}}\sum_{j\in I_{0,e}}(X_{1,i}^{(-e)})^\top\widehat B_{J_y,J_z,n}^{(-e)}X_{0,j}^{(-e)}.
\]
Finally,
\[
\widehat\theta_{e,J_y,J_z,n}=\widehat\theta_{\mathrm{plug}}^{(-e)}+\sum_{a=0}^1\frac1m\sum_{i\in I_{a,e}}\widehat s_{a,n}^{(-e)}(W_{a,i,n})+\widehat U_{e,J_y,J_z,n},
\qquad
\widehat\theta^{\mathrm{an}}_{J_y,J_z,n}=\frac12\sum_{e=1}^2\widehat\theta_{e,J_y,J_z,n}.
\]
