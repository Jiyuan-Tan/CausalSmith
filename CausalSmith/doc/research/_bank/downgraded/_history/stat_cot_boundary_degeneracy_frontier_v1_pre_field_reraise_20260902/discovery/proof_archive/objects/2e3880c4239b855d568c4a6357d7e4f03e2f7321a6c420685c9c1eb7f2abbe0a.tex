Fix \(d\ge1\) and \(0<\tau<\min\{s_y,s_z\}\), and put \(a_\tau=\tau/(2\tau+d+1)\). Choose an odd integer \(K_n^{\mathrm{sm}}\asymp\log n\), with a sufficiently large fixed multiplier depending only on \((\tau,d)\), and set \(N_n^{\mathrm{sm}}=\lfloor n/K_n^{\mathrm{sm}}\rfloor\). Discard at most \(K_n^{\mathrm{sm}}-1\) observations per arm and split the remaining observations in each arm into \(K_n^{\mathrm{sm}}\) paired disjoint blocks of size \(N_n^{\mathrm{sm}}\).

On paired block \(\ell\), set
\[
J_{\tau,n}^{\mathrm{sm}}=
\left\lfloor\frac{\log_2 N_n^{\mathrm{sm}}}{2\tau+d+1}\right\rfloor
\]
and form the empirical tensor boundary-wavelet projection \(\widetilde p_{a,\ell,\tau}\) of the joint density on \([0,1]^{d+1}\) through this common isotropic resolution. Define the everywhere nonnegative normalized joint-density estimate
\[
\widehat p_{a,\ell,\tau}(y,z)=
\frac{\{\widetilde p_{a,\ell,\tau}(y,z)\}_+}
{\int\{\widetilde p_{a,\ell,\tau}(u,v)\}_+\,du\,dv},
\]
using the uniform density if the denominator is zero. Put \(\widehat r_{a,\ell,\tau}(z)=\int_0^1\widehat p_{a,\ell,\tau}(y,z)\,dy\) and \(\widehat r_{\ell,\tau}=(\widehat r_{0,\ell,\tau}+\widehat r_{1,\ell,\tau})/2\). Define
\[
\widehat q_{a,\ell,\tau}(y\mid z)=
\begin{cases}
\widehat p_{a,\ell,\tau}(y,z)/\widehat r_{a,\ell,\tau}(z),&\widehat r_{a,\ell,\tau}(z)>0,\\
1,&\widehat r_{a,\ell,\tau}(z)=0,
\end{cases}
\]
and reattach the pooled marginal:
\[
\widehat P_{a,\ell,\tau}^{\dagger}(dy,dz)
=\widehat q_{a,\ell,\tau}(y\mid z)\,dy\,\widehat r_{\ell,\tau}(z)\,dz.
\]
The block value and the final estimator are the explicit sample maps
\[
\widehat V_{\ell,\tau,n}^{\mathrm{sm}}
=\int W_2^2\!\left(\widehat P_{0,\ell,\tau}^{\dagger}(\cdot\mid z),
\widehat P_{1,\ell,\tau}^{\dagger}(\cdot\mid z)\right)
\widehat r_{\ell,\tau}(z)\,dz,
\qquad
\widehat\theta^{\mathrm{sm,med}}_{\tau,n}
=\operatorname{median}_{1\le\ell\le K_n^{\mathrm{sm}}}
\widehat V_{\ell,\tau,n}^{\mathrm{sm}}.
\]
All values lie in \([0,1]\), and every zero-denominator convention above is deterministic, so the estimator is defined on every sample.
