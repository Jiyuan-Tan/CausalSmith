Fix a raw atom \(A=\{V_{i,I}=y\}\), and let \(I_{\leq i}\) be the restriction of \(I\) to coordinates at most \(i\). By \texttt{def:ordered-evaluation}, induction on \(t=1,\ldots,i\) gives
\[
 E(f,I)_t=E(f,I_{\leq i})_t.
\]
Indeed, at coordinate \(t\) both evaluations use the same intervention entry when one is present, and otherwise they evaluate the same response map on coordinates strictly below \(t\), which agree by the induction hypothesis. Thus deleting intervention entries with index greater than \(i\) leaves the truth value of \(A\) unchanged. If \(i\in\operatorname{dom}(I)\), the same definition gives
\[
 E(f,I)_i=I(i),
 \qquad
 \mathbf 1\{V_{i,I}=y\}=\mathbf 1\{I(i)=y\},
\]
so self-intervention replacement is pointwise valid. Otherwise every retained intervention coordinate precedes \(i\). Sorting the encodings of these pairs and coalescing repeated identical pairs leaves the represented partial map unchanged and hence leaves \(E(f,I)_i\) unchanged. Simplification of truth constants preserves the Boolean value of the conjunction.

Applying these observations to every atom, in source order, proves for every \(f\in\mathfrak F\) and \(j\in\{1,\ldots,r\}\) that
\[
 \mathbf 1\{\gamma_j(f)\}
 =\mathbf 1\{\gamma_j^{\circ}(f)\}.
\]
Multiplication by \(c_j\) and summation give the pointwise score identity
\[
 \sum_{j=1}^r c_j\mathbf 1\{\gamma_j(f)\}
 =\sum_{j=1}^r c_j\mathbf 1\{\gamma_j^{\circ}(f)\}
 =g(f).
\]
Every surviving intervention coordinate is strictly below the atom's target coordinate, so the normalized list is predecessor-only.

It remains to account for preprocessing time. Build deterministic tries for the explicitly listed alphabets while reading them. Scan the raw token stream once, validate each coordinate and value in those tries, discard a later-coordinate pair when it is read, and place retained integer coordinate encodings in a deterministic binary radix trie. Reading that trie in coordinate order is a stable canonical ordering whose work is linear in the total bit length of its keys. A second scan coalesces identical adjacent pairs and simplifies constants. A deterministic binary trie on the normalized context encodings constructs the distinct set \(\mathcal H\). Each operation is linear in the number of input or emitted bits, and normalization emits no more intervention-pair or atom tokens than it reads. By the definition of \(N_{\mathrm{in}}\), the total time is \(O(N_{\mathrm{in}})\). The prescribed source order and canonical coordinate order make \(\mathsf N\) deterministic. This argument concerns only the supplied explicit unnested syntax and makes no claim for succinct nested syntax.

 w(t)=v_t\text{ for every }t\leq i\text{ in }\operatorname{dom}(w).
 \tag{1}
\]

is determined by \(v\), the named interventions, and \(i\), independently of the numerical history. By \texttt{def:prefix-partition}, it is either empty or one entire block of \(\pi_i\).

The claim about continuation is vacuous after the last coordinate, so take \(i<k\) and put \(q=i+1\). For a block \(T\in\pi_i\), define
\[
 N_T=\{w\in T:q\notin\operatorname{dom}(w)\},
 \qquad
 J_T=T\setminus N_T.
\]
All worlds in \(T\) have the same complete predecessor tuple.  y_w=w(q)\quad(w\in J_T),
 \qquad
 y_w=z_T\quad(w\in N_T)
 \tag{2}
\]
for an allowed \(z_T\in\mathcal D_q\), with \(z_T=v_q\) on the anchored block, and all entries satisfy the factual and normalized-query pins at \(q\). Distinct blocks supply distinct tuples, and the anchored assignment agrees with the factual row. This realizes every legal column.

Now take two feasible histories with the same partition \(\pi_i\). The characterization gives exactly the same set of legal numerical columns for both histories. Appending the same column splits each old block according to equality of its new entries, while distinct old blocks cannot merge because their earlier complete prefixes remain unequal. Hence the two successors have the same partition \(\pi_q\). Iterating this argument for \(q=i+1,\ldots,k\) proves equality of the support of every later column sequence subject to all later pins. Both inclusions follow because every legal selection is realizable on either history.

There are at most \(h\) such records per coordinate. Choose the default of \(\widehat f_q\) to be \(v_q\), which exists in the nonempty alphabet by Assumption~\texttt{ass:finite-alphabets}, and use it on every unlisted tuple as in \texttt{def:sparse-response-completion}. Induction over coordinates shows that it reproduces every stored retained-world column, since every natural retained-world call uses its recorded row and every intervened coordinate uses its constant. The result lies in \(\mathfrak F\), has at most \(kh\) stored rows, and uses one default per coordinate.

 \frac{\log t}{t}\leq\frac{\log3}{3},

 \prod_{j=1}^m t_j

 \prod_T(r+1)^{|T|}\leq(r+1)^h.
