For each \(t\in\{0,1\}\), define the finite restricted score measure \(\mu_{t,P}\) by \(\mu_{t,P}(E)=P_X(E\cap\mathcal A_t)\) for every Borel set \(E\subseteq\mathbb R^2\). There exists a regular conditional outcome kernel \(K_P(z,dy)\) of the observed \(Y\) given \(X=z\) such that, for each \(t\in\{0,1\}\), there is a \(\mu_{t,P}\)-null set \(N_{t,P}\subseteq\mathcal X_{t,P}\) for which, simultaneously for every \(z\in\mathcal X_{t,P}\setminus N_{t,P}\) and every \(\lambda\in\mathbb R\),
\[
 \int_{\mathbb R}|y-g_{t,P}(z)|K_P(z,dy)<\infty,
 \qquad
 \int_{\mathbb R}\{y-g_{t,P}(z)\}K_P(z,dy)=0,
\]
and
\[
 \int_{\mathbb R}\exp\!\left[\lambda\{y-g_{t,P}(z)\}\right]K_P(z,dy)
 \le \exp(\sigma^2\lambda^2/2).
\]
Here \(\sigma>0\) is fixed and known.
