Suppose \(\mathcal A_0=\mathbb R^2\setminus\mathcal A_1\). The estimator \(\widehat\tau_n\) uses neither \(\kappa\) nor the score density. Uniformly for \(\kappa\in(2,\overline\kappa]\), there are constants \(0<c<C<\infty\) such that, for all sufficiently large \(n\), \(\sup_{P\in\mathcal P_{\kappa}^{\mathrm{perv}}}\mathbb E_P[\sup_{x\in\mathcal B}|\widehat\tau_n(x)-\tau_P(x)|]\le C r_{n,\kappa}^{\mathrm{perv}}\) and \(R_n(\mathcal P_{\kappa}^{\mathrm{perv}})\ge c r_{n,\kappa}^{\mathrm{perv}}\). Its fallback event obeys \(\sup_{P\in\mathcal P_{\kappa}^{\mathrm{perv}}}P\{\exists x\in\mathcal B,\ t\in\{0,1\}:\widehat{\mathcal H}_{t,n}(x)=\varnothing\}\le Cn^3\exp\{-c n c_m h_0^{\kappa}\}\), and this event's contribution is included in the expected-risk bound.
