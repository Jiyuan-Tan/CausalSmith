Fix \(I=(M,a,X,Y,c,L,B)\in\mathfrak M_{\mathrm{exp}}\) as in the statement.  Thus the full directed graph \(G\) is acyclic, its underlying undirected graph is connected of cycle rank one, and that undirected graph has a unique simple cycle \(K\).  All domains and all local tables are finite and nonempty by \(\mathrm{ass:finite\mbox{-}signature}\) and \(\mathrm{ass:total\mbox{-}local\mbox{-}tables}\).  For a retained graph \(H\subseteq G\), write
\[
 D_H=E(G)\setminus E(H),
 \qquad
 S_Z(H)=\operatorname{Pa}_H(Z).
\]

We first reduce the causal semantics to finite constraints.  By \(\mathrm{lem:canonical\mbox{-}replay}\), a Beckers witness with retained graph \(H\in\mathcal H(G)\) is equivalent to the actual-row equalities
\[
 Q_Z^{S_Z(H)}(a_{S_Z(H)})=\{a_Z\}
 \qquad (Z\in V),                                                     \tag{1}
\]
together with an assignment \(w\in R(U\cup V)\) satisfying
\[
 w_U=a_U,qquad w_X\ne a_X,qquad w_Y\ne a_Y,                         \tag{2}
\]
and
\[
 w_Z\in Q_Z^{S_Z(H)}(w_{S_Z(H)})
 \qquad (Z\in V\setminus\{X\}).                                     \tag{3}
\]
Here \(w_U=a_U\) keeps the exogenous context fixed, and the equation at \(X\) is absent from (3) because the alternate model intervenes on \(X\).  The singleton event \(X=a_X\), with \(X\ne Y\) by \(\mathrm{ass:distinct\mbox{-}singletons}\), has no nonempty proper subevent, so the minimality clause adds no further constraint.  Thus (1)--(3) are obtained from the Beckers query by canonical replay; they are not a definition of that query.

We next characterize graphical legality.  If a directed edge \(e=p\to Z\) is not on \(K\), then its underlying undirected edge is a bridge, so there is no path at all from \(p\) to \(Z\) after deleting \(e\).  If \(e\in E(K)\), the only undirected \(p\)-to-\(Z\) path not using \(e\) is the complementary arc \(K\setminus\{e\}\).  Consequently, for every \(e=p\to Z\in D_H\),
\[
 p\leadsto_H Z
 \quad\Longleftrightarrow\quad
 K\setminus\{e\}\text{ is directed from \(p\) to \(Z\) and every edge of that arc is retained}.       \tag{4}
\]
Fix a cyclic orientation of the undirected cycle and label a directed cycle edge by the sign with which it is oriented relative to that cyclic orientation.  The complementary arc for \(e\) is directed from the tail of \(e\) to its head exactly when the sign of \(e\) is opposite to the sign of every other cycle edge.  Since a simple undirected cycle has at least three edges, two distinct edges cannot both have this property: a third edge would force the two distinguished edges to have the same sign, while either distinguished edge forces their signs to be opposite.  Hence there is at most one such edge; denote it by \(e^\star\) when it exists.

If \(e^\star\) does not exist, (4) shows that every retained subgraph is legal.  If it does exist, (4) and \(\mathrm{def:legal\mbox{-}retained\mbox{-}graph}\) give the exact equivalence
\[
 H\in\mathcal H(G)
 \quad\Longleftrightarrow\quad
 e^\star\notin D_H
 \ \text{or}\ 
 D_H\cap\bigl(E(K)\setminus\{e^\star\}\bigr)\ne\varnothing.          \tag{5}
\]
This is the only global constraint that will enter the finite programs.

We now prove the normalization.  Fix any witness \((H,w)\) satisfying (1)--(3).  For each \(Z\in V\setminus\{X\}\), membership (3) and the union in \(\mathrm{def:actualized\mbox{-}projection}\) supply a full parent row
\[
 \rho_Z\in R(\operatorname{Pa}_G(Z))
 \quad\text{such that}\quad
 w_Z\in A_Z(\rho_Z),
 \qquad
 \rho_Z|_{S_Z(H)}=w|_{S_Z(H)}.                                        \tag{6}
\]
Define the row-difference deletion set
\[
 D^0(w,\rho)
 =\{p\to Z:Z\ne X,\ \rho_{Z,p}\ne w_p\}.                             \tag{7}
\]
Equation (6) implies
\[
 D^0(w,\rho)\subseteq D_H.                                            \tag{8}
\]
If \(G\setminus D^0\) satisfies (5), set \(D=D^0\).  Otherwise \(e^\star\) exists and the failure of (5) says
\[
 e^\star\in D^0,
 \qquad
 D^0\cap\bigl(E(K)\setminus\{e^\star\}\bigr)=\varnothing.           \tag{9}
\]
The original graph \(H\) is legal and \(D^0\subseteq D_H\), so (5) and (9) imply that there is an edge
\[
 f\in D_H\cap\bigl(E(K)\setminus\{e^\star\}\bigr).                  \tag{10}
\]
In this case set \(D=D^0\cup\{f\}\).  In both cases
\[
 D\subseteq D_H
 \quad\text{and}\quad
 G\setminus D\in\mathcal H(G).                                      \tag{11}
\]
Thus at most one deletion beyond the row-difference set is used, and it is used only to repair the unique possible legality defect.

For each \(Z\in V\), put
\[
 S_Z(D)=\{p\in\operatorname{Pa}_G(Z):p\to Z\notin D\}.
\]
By (8), (10), and (11), \(D\subseteq D_H\), whence
\[
 S_Z(H)\subseteq S_Z(D).                                               \tag{12}
\]
Equation (1) and \(\mathrm{lem:local\mbox{-}hitting\mbox{-}equivalence}\) imply that \(S_Z(H)\) meets every \(\Delta\in\mathcal B_Z\).  Its superset in (12) therefore meets every such \(\Delta\), and the reverse implication of the same lemma yields
\[
 Q_Z^{S_Z(D)}(a_{S_Z(D)})=\{a_Z\}
 \qquad (Z\in V).                                                     \tag{13}
\]
For \(Z\ne X\), every parent retained under \(D\) agrees between \(\rho_Z\) and \(w\), by (7); adding the optional edge \(f\) to the deletion set only removes a matching requirement.  Hence (6) and the definition of the projected relation give
\[
 w_Z\in A_Z(\rho_Z)
 \subseteq Q_Z^{S_Z(D)}(w_{S_Z(D)})
 \qquad (Z\in V\setminus\{X\}).                                    \tag{14}
\]
Equations (2), (11), (13), and (14), followed by \(\mathrm{lem:canonical\mbox{-}replay}\), prove that \((G\setminus D,w)\) is again a Beckers witness.  Since costs are nonnegative by \(\mathrm{ass:nonnegative\mbox{-}rational\mbox{-}cost}\), (11) gives
\[
 \sum_{e\in D}c(e)\le \sum_{e\in D_H}c(e).                          \tag{15}
\]

Conversely, suppose that \(w\), rows \(\rho_Z\) for \(Z\ne X\), and a set \(D\) have the normalized form just described; suppose they obey (2), the legality condition (5),
\[
 w_Z\in A_Z(\rho_Z)\quad(Z\ne X),                                   \tag{16}
\]
and the local actual-row hitting tests
\[
 S_Z(D)\cap\Delta\ne\varnothing
 \quad(Z\in V,\ \Delta\in\mathcal B_Z).                            \tag{17}
\]
The hitting equivalence applied to (17) gives (13).  The row-difference definition (7), including the possible extra deletion \(f\), gives (14) from (16).  Condition (5) gives graphical legality.  Canonical replay therefore proves that this normalized tuple is a Beckers witness, and its deletion cost is exactly \(\sum_{e\in D}c(e)\).  This proves both directions of the normalized-certificate characterization.  Because all involved sets are finite, every nonempty feasible set of such tuples has a cost minimizer.

We expose the promised programs.  For an edge \(p\to Z\), define its base-deletion indicator by
\[
 \delta^0_{p\to Z}(\rho,w)
 =
 \begin{cases}
  \mathbf 1\{\rho_{Z,p}\ne w_p\},&Z\ne X,\\
  0,&Z=X.
 \end{cases}                                                          \tag{18}
\]
If \(e^\star\) is absent, use one unconstrained mode.  If it is present, use the following modes:
\[
\begin{array}{ll}
\text{mode \(0\):}&\delta^0_{e^\star}=0;\\[2pt]
\text{mode \(g\), \(g\in E(K)\setminus\{e^\star\}\):}
 &\delta^0_{e^\star}=\delta^0_g=1;\\[2pt]
\text{repair mode \(\bar f\), \(f\in E(K)\setminus\{e^\star\}\):}
 &\delta^0_{e^\star}=1,\quad
   \delta^0_h=0\ \text{for every }h\in E(K)\setminus\{e^\star\},
   \quad\text{and }f\text{ is additionally deleted.}
\end{array}                                                            \tag{19}
\]
There are \(1+(|E(K)|-1)+(|E(K)|-1)=2|E(K)|-1\) modes.  Mode \(0\) covers the first disjunct of (5).  If the second disjunct of (5) already holds for \(D^0\), at least one deleted complementary edge can be selected as \(g\).  The remaining case is exactly (9), and is covered by choosing its repair edge \(f\).  Thus (19) covers every normalized tuple; overlaps between modes do not affect a minimum.

For a mode \(b\), let \(f_b=f\) in repair mode \(\bar f\), and let \(f_b=\bot\) otherwise.  For an assignment of values to \(Z\) and all of its full-graph parents, define
\[
 \Phi_Z^b(w_Z,w_{\operatorname{Pa}_G(Z)})
 =
 \min_{\tau_Z}
 \left\{
  \sum_{p:p\to Z\in D_Z^b(\tau_Z,w)}c(p\to Z)
 \right\},                                                            \tag{20}
\]
where \(\tau_Z=\rho_Z\in R(\operatorname{Pa}_G(Z))\) and \(w_Z\in A_Z(\rho_Z)\) when \(Z\ne X\), while \(\tau_X=\star\) is the sole choice and no output constraint is imposed at \(X\).  The local deletion set in (20) is
\[
 D_Z^b(\tau_Z,w)
 =\{p\to Z:Z\ne X,\ \rho_{Z,p}\ne w_p\}
  \cup\{f_b:f_b=p\to Z\text{ for some \(p\)}\}.                     \tag{21}
\]
The minimum in (20) is also subject to the restrictions in (19) on indicators of edges entering \(Z\), and to the fully explicit hitting constraints
\[
 \left(\operatorname{Pa}_G(Z)
 \setminus\{p:p\to Z\in D_Z^b(\tau_Z,w)\}\right)
 \cap\Delta\ne\varnothing
 \qquad(\Delta\in\mathcal B_Z).                                     \tag{22}
\]
If these constraints admit no row, the value of (20) is \(+\infty\).  Each restriction in (19) concerns one edge indicator, so it is checked at the factor belonging to that edge's head.  The sets in (21), as \(Z\) varies, partition the deletion set by edge head; therefore the sum of the finite values in (20) counts each deleted edge exactly once.

For every \(q\in U\cup V\), define the unary potential
\[
 \psi_q(v)=
 \begin{cases}
  0,&q\in U\text{ and }v=a_q,\\
  0,&q=X\text{ and }v\ne a_X,\\
  0,&q=Y\text{ and }v\ne a_Y,\\
  0,&q\in V\setminus\{X,Y\},\\
  +\infty,&\text{otherwise}.
 \end{cases}                                                          \tag{23}
\]
The cases are disjoint because \(U\cap V=\varnothing\) and \(X\ne Y\).  Let \(C^\star(I)\) denote the minimum deletion cost among Beckers witnesses, with the empty minimum equal to \(+\infty\).  The cost-nonincreasing normalization (6)--(15) maps every witness to a feasible point of the following program, while (16)--(17) and canonical replay map every finite program point to a witness of exactly the displayed cost.  Both inequalities therefore hold, proving the identifying equality
\[
 C^\star(I)
 =
 \min_b\ \min_{w\in R(U\cup V)}
 \left\{
  \sum_{Z\in V}\Phi_Z^b(w_Z,w_{\operatorname{Pa}_G(Z)})
  +\sum_{q\in U\cup V}\psi_q(w_q)
 \right\}.                                                           \tag{24}
\]
In particular, the causal query has a positive witness if and only if the observed explicit-input functional on the right of (24) is finite.

It remains to evaluate (24) and certify the answer.  Form the bipartite factor graph with one variable vertex for every \(q\in U\cup V\), one factor vertex for every \(Z\in V\), and an edge from factor \(Z\) to each variable in \(\{Z\}\cup\operatorname{Pa}_G(Z)\).  Contracting every factor--child edge \(Z\text{--}Z\) recovers the underlying undirected graph of \(G\).  Edge contraction preserves cycle rank here, and connectedness is preserved, so this factor graph is connected of cycle rank one.  Choose a variable vertex \(q_0\) on its unique cycle.  For a fixed value \(v\in R(q_0)\), substitute \(q_0=v\) in every incident potential and delete \(q_0\); the remaining factor graph is a forest.

For any oriented edge of a rooted component of this forest, let \(N(\cdot)\) denote its neighbors and use the min-sum messages
\[
 m_{q\to Z}(x_q)
 =\psi_q(x_q)+
   \sum_{T\in N(q)\setminus\{Z\}}m_{T\to q}(x_q),                    \tag{25}
\]
and
\[
 m_{Z\to q}(x_q)
 =\min_{x_{N(Z)\setminus\{q\}}}
 \left\{
  \Phi_Z^b(x_{N(Z)})+
  \sum_{r\in N(Z)\setminus\{q\}}m_{r\to Z}(x_r)
 \right\}.                                                           \tag{26}
\]
An induction from the leaves proves that a message is exactly the minimum sum of all potentials on the sending side of the removed edge, conditional on its boundary value.  At a leaf this is (25) or (26) with an empty sum.  For the induction step, removing the receiving edge separates the sending side into the neighbor subtrees appearing in the relevant recurrence; the induction hypothesis gives each conditional subtree minimum, addition combines the disjoint subtrees, and the minimization in (26) eliminates precisely the newly internal boundary values.  Thus the component root expression is its exact conditional minimum.  Summing the component minima, adding \(\psi_{q_0}(v)\), minimizing over \(v\in R(q_0)\), and then minimizing over the modes in (19) evaluates exactly the right side of (24).

We now verify the stated resource bounds using \(\mathrm{ass:explicit\mbox{-}table\mbox{-}encoding}\).  Put \(d_Z=|R(Z)|\) and \(n_Z=|R(\operatorname{Pa}_G(Z))|\).  The encoding counts all domain entries, parent rows, parent-coordinate incidences, output incidences, edges, and vertices, so each of their totals is at most \(L\), and
\[
 \sum_{Z\in V}d_Zn_Z
 \le \left(\sum_{Z\in V}d_Z\right)
      \left(\sum_{Z\in V}n_Z\right)
 \le L^2.                                                             \tag{27}
\]
For each local assignment counted in (27), (20) enumerates at most \(L\) support rows.  For each candidate row, membership in its explicitly listed output set, all mode restrictions, and all intersections in (22) are checked by scanning at most \(L\) indexed incidences.  Thus all local potentials for one mode require at most \(O(L^4)\) elementary arithmetic or indexed-address operations, and all modes require at most \(O(L^5)\).  For a fixed mode and fixed \(q_0=v\), every message in (25)--(26) can be computed by enumerating the explicit local assignments of its factor; charging an assignment once per incident factor edge gives at most \(O(L^3)\) operations.  There are at most \(L\) values of \(q_0\) and at most \(2L\) modes.  Hence the entire computation is bounded by \(O(L^5)\), and therefore by the claimed conservative bound
\[
 O(L^7).                                                              \tag{28}
\]

Every finite local potential, message, and root value is a sum of costs of a subset of \(E(G)\); disjoint factor sides in (25)--(26) ensure that no edge cost acquires a coefficient other than zero or one.  Write the nonzero input costs as reduced fractions.  A common denominator may be chosen as the product of their denominators, whose binary length is at most the total input length \(B\).  After scaling, each summand has \(O(B)\) bits, and adding at most \(L\) summands adds at most \(\lceil\log_2(L+1)\rceil\) bits.  Reduction of a fraction cannot increase either length.  Consequently every finite rational encountered has
\[
 O(B+\log(L+1))                                                       \tag{29}
\]
bits, so comparisons and additions have polynomial bit complexity.

For a finite optimum, retain a minimizing mode, a minimizing value of \(q_0\), and one minimizing argument for every application of (20) and (26).  Backtracking supplies \(w\), every support row \(\rho_Z\), and the optional repair edge.  Equations (16), (17), and (5) verify the resulting positive witness, while the complete message tables together with (25)--(26) verify that its cost equals the minimum in (24); this is an exact optimum certificate of polynomial size.  If the value is \(+\infty\), output instead, for every oriented message edge, the finite-support set
\[
 T_{\nu\to\mu}=\{x:m_{\nu\to\mu}(x)<+\infty\}.                    \tag{30}
\]
The Boolean versions of (25)--(26) show locally that each set in (30) contains exactly the boundary values extendible through its sending-side subtree.  For every mode and every \(q_0=v\), the root combination is empty (or \(\psi_{q_0}(v)=+\infty\)); hence these tables separate every admissible boundary value from a complete feasible tuple.  Their entries and their local closure checks are indexed by the same polynomial-size tables used above, so (30) is the promised polynomial-size separating cut.

Finally, the exceptional full-graph constraint is genuinely load-bearing.  Consider the three-vertex full graph \(U\to X\to Y\) together with \(U\to Y\), binary domains, actual world zero, and deterministic tables \(X=U\) and \(Y=X\wedge U\).  The unique exceptional edge is \(e^\star=U\to Y\).  To obtain \(w_U=0\), \(w_X=1\), and \(w_Y=1\), the only supporting row for \(Y\) is \((U,X)=(1,1)\), so \(D^0\) deletes \(U\to Y\) and no complementary-cycle edge.  This violates (5).  Repair by deleting \(U\to X\) fails the hitting test at \(X\), while repair by deleting \(X\to Y\), together with the already deleted \(U\to Y\), fails the hitting test at \(Y\).  Thus every mode correctly returns infeasible.  Propagation on the endogenous chain alone would miss this obstruction, confirming that the full-graph legality state used above cannot be discarded.
