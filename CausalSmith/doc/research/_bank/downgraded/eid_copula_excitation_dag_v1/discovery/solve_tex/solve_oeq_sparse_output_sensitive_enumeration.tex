For every family \(R=(R_e)_{e\in\mathcal E}\) of positive-definite correlation matrices and every known normalized positive schedule \(d\), there is an exact-real canonical-filter variant of \(\mathsf{FiberCert}(R,d)\) that returns every support in \(\mathcal F(R,d)\) exactly once using \(O(p!\,E p^3)\) arithmetic operations. Moreover, for every such \(d\), the family \(R_e=I_p\) for all \(e\in\mathcal E\) has \(N_{\mathrm{out}}=1\), whereas naive order traversal retains all \(p!\) orders. Thus the exact-once and factorial-duplication parts of the question have affirmative answers. This partial result does not decide whether an algorithm with runtime \(2^p\operatorname{poly}(p,E)+N_{\mathrm{out}}\operatorname{poly}(p,E)\), or with polynomial delay, exists for arbitrary sparse fibers.
%%% FIELD sparse-partial-proof
Invoke the already established Theorem~\texttt{thm:sparse-fiber-exact-once-factorial-baseline}. Its first conclusion supplies an exact-real algorithm, say \(\mathcal A_{\mathrm{can}}\), such that for every input in the stated domain
\[
 \operatorname{Out}(\mathcal A_{\mathrm{can}}(R,d))
 =\mathcal F(R,d)
 \quad\text{with every member occurring once},
 \qquad
 \operatorname{ops}(\mathcal A_{\mathrm{can}})=O(p!\,E p^3).
\]
This proves the exact-once assertion and its arithmetic-complexity bound.

For the required duplication family, fix any normalized positive schedule \(d\) and set
\[
 R_e=I_p\qquad(e\in\mathcal E).
\]
The same established theorem gives, for every candidate order \(\pi\),
\[
 B^{\pi}(I_p)=0,
 \qquad
 v^{\pi}(I_p)=\mathbf 1,
 \qquad
 \Phi_e^{\pi}(I_p;d)=\operatorname{corr}(D_e)=I_p
 \quad(e\in\mathcal E).
\]
The defining equality test for the projective fiber therefore retains all \(p!\) orders, while every retained order has the empty directed support. Consequently,
\[
 \mathcal F(R,d)=\{\varnothing\},
 \qquad
 N_{\mathrm{out}}=1,
 \qquad
 \frac{\#\{\text{orders retained by naive traversal}\}}{N_{\mathrm{out}}}=p!.
\]
This is the requested factorial-duplication witness. The invoked theorem expressly supplies no \(2^p\operatorname{poly}(p,E)+N_{\mathrm{out}}\operatorname{poly}(p,E)\) bound and no polynomial-delay bound. A factorial upper bound together with a duplication witness for one traversal neither constructs either stronger algorithm nor rules one out, so the final sentence records the exact logical scope of the proved partial answer.
