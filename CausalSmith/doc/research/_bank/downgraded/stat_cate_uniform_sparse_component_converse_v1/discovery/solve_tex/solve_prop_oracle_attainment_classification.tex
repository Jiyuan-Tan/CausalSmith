%%% FIELD prop-oracle-attainment-classification-proof
By \(\mathrm{def:rate}\),
\[
\eta=\left(1+\frac{d}{2\gamma}+\frac{d}{2S}\right)^{-1}.
\]
The symbol definition of \(\rho_n^{\mathrm{or}}\) gives
\[
\rho_n^{\mathrm{or}}=n^{-q_{\mathrm{or}}},
\qquad
q_{\mathrm{or}}:=\frac{\gamma}{2\gamma+d}
=\left(2+\frac{d}{\gamma}\right)^{-1}.
\]
All of \(d\), \(S\), and \(\gamma\) are strictly positive by their declared spaces.  Hence both denominators in the preceding displays are positive, and cross-multiplication preserves the direction of each inequality.  Consequently,
\[
\begin{aligned}
\eta<q_{\mathrm{or}}
&\iff
1+\frac{d}{2\gamma}+\frac{d}{2S}
>2+\frac{d}{\gamma}\\
&\iff
\frac{d}{2S}>1+\frac{d}{2\gamma}\\
&\iff
d\gamma>S(2\gamma+d)\\
&\iff
S<\frac{d\gamma}{2\gamma+d}=S_{\star}.
\end{aligned}
\]
Thus, in the strict regime \(S<S_{\star}\), the number
\[
\delta:=q_{\mathrm{or}}-\eta
\]
is strictly positive.  By \(\mathrm{thm:sharp\mbox{-}exact\mbox{-}uniform\mbox{-}rate}\), there are constants \(0<c\le C<\infty\), independent of \(n\), such that
\[
c n^{-\eta}\le R_n\le C n^{-\eta}
\qquad(n\ge2).
\]
Since \(\rho_n^{\mathrm{or}}=n^{-q_{\mathrm{or}}}>0\), division gives the equation-by-equation comparison
\[
c n^{q_{\mathrm{or}}-\eta}
\le \frac{R_n}{\rho_n^{\mathrm{or}}}
\le C n^{q_{\mathrm{or}}-\eta},
\]
or equivalently
\[
\frac{R_n}{\rho_n^{\mathrm{or}}}\asymp n^{\delta}.
\]
Because \(\delta>0\), \(n^{\delta}\to\infty\), and therefore
\[
\frac{R_n}{\rho_n^{\mathrm{or}}}\longrightarrow\infty.
\]
In particular, the minimax risk on the same exact class is not of oracle order anywhere in the strict below-elbow regime.

It remains to evaluate the boundary allowed by \(\mathrm{ass:below\mbox{-}elbow}\).  If \(S=S_{\star}\), every equivalence above holds with equality, so
\[
\eta=q_{\mathrm{or}}=\frac{\gamma}{2\gamma+d}.
\]
Applying \(\mathrm{thm:sharp\mbox{-}exact\mbox{-}uniform\mbox{-}rate}\) once more yields
\[
c n^{-\gamma/(2\gamma+d)}
\le R_n\le
C n^{-\gamma/(2\gamma+d)}.
\]
Both sides are pure powers of \(n\); no logarithmic factor occurs.  Hence the same-class oracle benchmark is attained exactly at the elbow, whereas it is unattainable throughout the stated strict below-elbow regime.
