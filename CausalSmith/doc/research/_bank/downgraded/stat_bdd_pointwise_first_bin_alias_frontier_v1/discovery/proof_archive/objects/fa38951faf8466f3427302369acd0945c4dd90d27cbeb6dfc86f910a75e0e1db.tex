For each \(t\in\{0,1\}\), set \([\ell_t,u_t]=[0,1]\) when \(N_{t,n,\Delta}=0\).  When \(N_{t,n,\Delta}=k>0\), put
\[
 \overline Y_t=\frac{S_{t,n,\Delta}}k,
 \qquad
 r_{k,\alpha}=\sqrt{\frac{\log(4/\alpha)}{2k}},
 \qquad
 [\ell_t,u_t]=\bigl[\max\{0,\overline Y_t-r_{k,\alpha}\},\min\{1,\overline Y_t+r_{k,\alpha}\}\bigr].
\]
With \(B_{n,\Delta}=LH_{n,\Delta}\), define the closed bounded interval
\[
 C_{n,\Delta,\alpha}
 =\bigl[\ell_1-u_0-2B_{n,\Delta},\ u_1-\ell_0+2B_{n,\Delta}\bigr].
\]
