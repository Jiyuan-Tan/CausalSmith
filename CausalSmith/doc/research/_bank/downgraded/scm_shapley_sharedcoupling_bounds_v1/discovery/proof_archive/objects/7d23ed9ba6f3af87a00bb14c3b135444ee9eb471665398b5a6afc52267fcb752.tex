Let \(\mathcal C_{1-\alpha}(\widehat K)=\prod_{t,x}\mathcal C_{t,x}\) be the explicit coordinate-box product specified in the symbol definition, with cell bounds \(\ell_{t,x,y}\) and \(u_{t,x,y}\).  For each \(t\in[H]\), compute
\[
 p_t^-=\min_{k\in\mathcal C_{t,x_t}}k(y_t)
 =\max\!\left\{\ell_{t,x_t,y_t},
       1-\sum_{y\ne y_t}u_{t,x_t,y}\right\},
 \qquad
 p_t^+=\max_{k\in\mathcal C_{t,x_t}}k(y_t)
 =\min\!\left\{u_{t,x_t,y_t},
       1-\sum_{y\ne y_t}\ell_{t,x_t,y}\right\}.
\]
When \(p_t^+>0\), define for every \(x\ne x_t\)
\[
 \mathcal Q_{t,x}^{\alpha}=
 \begin{cases}
 \left\{q_x\in\Delta(\mathcal S):
   \begin{array}{l}
   \text{there is }k_x\in\mathbb R^{\mathcal S}\text{ such that }
   \sum_y k_x(y)=1,\\
   \ell_{t,x,y}\le k_x(y)\le u_{t,x,y}\text{ and }
   p_t^-q_x(y)\le k_x(y)\text{ for every }y
   \end{array}\right\},&p_t^->0,\\[6pt]
 \Delta(J_{t,x}),&p_t^-=0,
 \end{cases}
\]
where
\[
 J_{t,x}=\left\{y\in\mathcal S:
 \min\!\left(u_{t,x,y},1-\sum_{z\ne y}\ell_{t,x,z}\right)>0\right\}
 \quad\text{and}\quad
 \Delta(J)=\{q\in\Delta(\mathcal S):q(y)=0\text{ for }y\notin J\}.
\]
Set
\[
 \overline{\mathcal Q}_{\alpha}(\widehat K,\tau)
 =\left\{q:q_{t,x_t}=\delta_{y_t}\text{ and }
 q_{t,x}\in\mathcal Q_{t,x}^{\alpha}
 \text{ for every }t\in[H],\ x\ne x_t\right\}.
\]
If \(p_t^+>0\) for every \(t\), define the computable confidence-fiber endpoints by
\[
 L_i^{\alpha}=\min_{q\in\overline{\mathcal Q}_{\alpha}(\widehat K,\tau)}\Phi_i(q),
 \qquad
 U_i^{\alpha}=\max_{q\in\overline{\mathcal Q}_{\alpha}(\widehat K,\tau)}\Phi_i(q).
\]
If \(p_t^+=0\) for some \(t\), set
\(L_i^{\alpha}=-D\) and \(U_i^{\alpha}=D\).
