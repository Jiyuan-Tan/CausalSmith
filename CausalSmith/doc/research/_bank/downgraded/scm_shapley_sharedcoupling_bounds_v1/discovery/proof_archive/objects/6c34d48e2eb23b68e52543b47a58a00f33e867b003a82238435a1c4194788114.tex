Let \(\mathcal K_+(\widehat K,\tau)=\{K'\in\mathcal C_{1-\alpha}(\widehat K):K'_t(y_t\mid x_t)>0\text{ for every }t\in[H]\}\).  If \(\mathcal K_+(\widehat K,\tau)\ne\varnothing\), define
\[
 L_i^{\alpha}=\inf_{K'\in\mathcal K_+(\widehat K,\tau)}L_i(K',\tau),
 \qquad
 U_i^{\alpha}=\sup_{K'\in\mathcal K_+(\widehat K,\tau)}U_i(K',\tau),
\]
where the same values may equivalently be computed over the closure of \(\bigcup_{K'\in\mathcal K_+(\widehat K,\tau)}\mathcal B(K',\tau)\) in posterior-row space.  If \(\mathcal K_+(\widehat K,\tau)=\varnothing\), define the logical fallback \([L_i^{\alpha},U_i^{\alpha}]=[-D,D]\).
