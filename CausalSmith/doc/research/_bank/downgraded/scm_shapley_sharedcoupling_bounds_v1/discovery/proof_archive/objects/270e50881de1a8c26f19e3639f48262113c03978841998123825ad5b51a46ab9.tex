For a factual row, \(q_{t,x_t}=\delta_{y_t}\) by \(\texttt{def:posterior-row-fiber}\), so its selector is always deleted.  If \(p_t=1\) and \(x\ne x_t\), the same definition gives
\[
 q_{t,x}(y)\le K_t(y\mid x)\qquad(y\in\mathcal S).
\]
Both sides are probability mass functions, so the coordinatewise inequalities and equality of their sums imply \(q_{t,x}=K_t(\cdot\mid x)\).  Thus every row at a time outside \(J\) is a singleton.  At a time in \(J\), only the \(|\mathcal X|-1\) nonfactual rows can remain non-singleton.  Summing these counts proves
\[
 m\le\sum_{t\in J}(|\mathcal X|-1)
   =|J|(|\mathcal X|-1).
 \tag{13}
\]

Fix \(\sigma\).  Use the explicit circuit constructed in \(\texttt{thm:optimization-preserving-compiler}\), after substituting every singleton selector.  Write \(\mathcal Z_t\) for the set of remaining row selectors at time \(t\), so \(\sum_t|\mathcal Z_t|=m\).  Keep the bundled variable \(W\) live.  Starting from the fixed initial state, at stage \(t\) sum \(A_t\) and then the current state frontier, retaining \(S_{t+1}\) for the next stage; at the terminal stage also sum \(S_{H+1}\).  An induction on \(t\) gives the following scope invariant: before processing stage \(t\), the only forward message has scope contained in
\[
 \{W,S_t\}\cup\bigcup_{u<t}\mathcal Z_u.
 \tag{14}
\]
Indeed, the stage-\(t\) policy and reward factors use only \(W,S_t,A_t,S_{t+1}\), and the transition factors add only selectors in \(\mathcal Z_t\).  Summing the stage action and current state therefore produces a next message whose scope is contained in
\[
 \{W,S_{t+1}\}\cup\bigcup_{u\le t}\mathcal Z_u,
\]
which is (14) at stage \(t+1\).  This also proves the base case because \(S_1=s_1\) is fixed.

No path bucket contains more than the \(m\) active selectors and four nonglobal Markov variables; in the displayed realization it contains at most the current state, current action, and next state, but the looser four-variable count also covers retaining a neighboring frontier variable under a standard bucket convention.  After the path is summed, the \(W\)-bucket contains at most the \(m\) active selectors in addition to \(W\).  After \(W\) is summed, every decision bucket contains at most those \(m\) selectors.  Since \(w_{\mathrm c}\) is the maximum number of nonglobal bucket variables minus one, these facts give
\[
 w_{\mathrm c}(\preceq)\le (m+4)-1=m+3.
 \tag{15}
\]

Every Markov chance variable and then \(W\) is summed before any remaining row selector is maximized.  Hence whenever a chance variable shares a current factor with an uneliminated selector, that chance variable precedes the selector; the order is legal by the definition of \(\preceq\).  Applying \(\texttt{thm:optimization-preserving-compiler}\) and (15) yields
\[
 O\!\left(H^2N d^{w_{\mathrm c}(\preceq)+1}\right)
 \subseteq O\!\left(H^2N d^{m+4}\right).
\]
The proof of that theorem also shows that the maximization backpointers are indexed only by other row decisions, so they recover one shared assignment, and its gluing sampler remains unchanged.

Finally, when \(|\mathcal S|\) and \(|\mathcal A|\) are fixed, \(|\mathcal X|-1\) is fixed.  If \(|J|\le c\log H\), then (13) gives \(m\le c(|\mathcal X|-1)\log H\).  For fixed \(d\),
\[
 d^{m+4}\le d^4 H^{c(|\mathcal X|-1)\log d},
\]
after choosing the same logarithm base on both sides.  The exponent is constant on the stated family, proving polynomial complexity in \(H\) and \(N\).
