Put \(M_0=H|\mathcal X||\mathcal S|\).  For \(n_{t,x}>0\), choose an outward-rounded rational number
\[
 e_{t,x}\ge \sqrt{\frac{\log(2M_0/\alpha)}{2n_{t,x}}},
\]
and define
\[
 \mathcal C_{t,x}=\left\{k\in\Delta(\mathcal S):
 |k(y)-\widehat K_t(y\mid x)|\le e_{t,x}
 \text{ for every }y\in\mathcal S\right\}.
\]
For \(n_{t,x}=0\), set \(\mathcal C_{t,x}=\Delta(\mathcal S)\).  Then
\[
 \mathcal C_{1-\alpha}(\widehat K)=
 \prod_{t\in[H],\,x\in\mathcal X}\mathcal C_{t,x}.
\]
