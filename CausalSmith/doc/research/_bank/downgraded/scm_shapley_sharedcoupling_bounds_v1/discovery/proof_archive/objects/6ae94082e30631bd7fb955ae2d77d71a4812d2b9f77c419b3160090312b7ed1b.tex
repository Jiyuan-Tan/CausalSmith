Under \(\texttt{ass:fixed-row-multinomial-sampling}\), the explicit row-product region in \(\texttt{def:simultaneous-row-product-confidence-region}\) satisfies \(\inf_K\Pr_K\{K\in\mathcal C_{1-\alpha}(\widehat K)\}\ge1-\alpha\), without any cross-row sampling-independence requirement.  On this one event, \([L_i(K,\tau),U_i(K,\tau)]\subseteq[L_i^{\alpha},U_i^{\alpha}]\) simultaneously for every \(i\in[H]\) and every prespecified positive-probability factual trajectory and externally randomized policy pair.  For each \(t\), compute
\[
 p_t^- =\min_{k\in\mathcal C_{t,x_t}}k(y_t),
 \qquad p_t^+=\max_{k\in\mathcal C_{t,x_t}}k(y_t).
\]
If every \(p_t^+>0\), the closure of the positive-evidence confidence posterior fiber is the product of the factual rows \(\delta_{y_t}\) and, for \(x\ne x_t\),
\[
 \mathcal Q_{t,x}=\begin{cases}
 \operatorname{proj}_{q_x}\{(q_x,k_x):q_x\in\Delta(\mathcal S),\ k_x\in\mathcal C_{t,x},\ p_t^-q_x(y)\le k_x(y)\ \forall y\},&p_t^->0,\\
 \Delta(J_{t,x}),&p_t^-=0,
 \end{cases}
\]
where \(J_{t,x}=\{y:\max_{k\in\mathcal C_{t,x}}k(y)>0\}\).  If some \(p_t^+=0\), the positive-evidence union is empty and \([L_i^{\alpha},U_i^{\alpha}]=[-D,D]\). If all \(p_t^->0\), backtracking returns one common posterior-row optimizer and compatible \(K'\) and SCM witnesses attaining each confidence endpoint.  If some \(p_t^-=0<p_t^+\), the algorithm returns the exact closure infimum and supremum and a finite diagonal sequence of positive-evidence kernels and compatible SCMs converging to each endpoint; attainment by one \(K'\) is not asserted.
