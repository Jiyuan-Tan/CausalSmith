Fix \(q\in\mathbb N\) and suppose \(J=1\).  Write
\[
 \widehat\vartheta_{1,n}=E_1\widehat\theta_n
   =\begin{pmatrix}\widehat s_{1,n}\\ \widehat b_{1,n}\end{pmatrix},
 \qquad
 S_{1,n}=E_1\widetilde\Omega_nE_1^{\top}
   =\begin{pmatrix}
      \widehat V_{1,n}&\widehat u_{1,n}\\
      \widehat u_{1,n}^{\top}&\widehat v_{1,n}
    \end{pmatrix}.
\]
By the declared definition and type of the clipped label-block covariance, \(S_{1,n}=\widehat\Omega_{1,n}\in\mathbb S_{++}^{q+1}\).  Consequently its principal block \(\widehat V_{1,n}\) is positive definite and hence invertible, and its Schur complement
\[
 \widehat\sigma_{1,n}^{2}
   =\widehat v_{1,n}
     -\widehat u_{1,n}^{\top}\widehat V_{1,n}^{-1}
        \widehat u_{1,n}
\]
is strictly positive.  Thus every division and inverse below is well defined.

Consider the ordinary feasible \((q+1)\)-dimensional Wald ellipsoid in the coordinates selected by \(E_1\),
\[
 \mathcal E_{1,n}(\alpha)
 =\left\{(s,\beta)\in\mathbb R^q\times\mathbb R:
 n\begin{pmatrix}\widehat s_{1,n}-s\\
                   \widehat b_{1,n}-\beta
   \end{pmatrix}^{\!\top}
 S_{1,n}^{-1}
 \begin{pmatrix}\widehat s_{1,n}-s\\
                 \widehat b_{1,n}-\beta
 \end{pmatrix}
 \le \widehat c_n^2\right\}.
\]
This uses the same feasible covariance and critical value as Definition \(\mathrm{def:profile\text{-}intervals}\).  Indeed, when \(J=1\), the maximum in the definition of \(c_{1-\alpha}(\widetilde\Omega_n)\) contains only the label \(1\).  Conditional on the positive-definite matrix \(\widetilde\Omega_n\), the standardized vector
\[
 (E_1\widetilde\Omega_nE_1^{\top})^{-1/2}E_1Z
\]
has the \(N(0,I_{q+1})\) law when \(Z\sim N(0,\widetilde\Omega_n)\).  Hence \(\widehat c_n\) is exactly the ordinary Gaussian Wald critical value for this ellipsoid.

We now profile \(\mathcal E_{1,n}(\alpha)\) under the restriction \(s=0\).  Put
\[
 x=\widehat s_{1,n},\qquad
 y=\widehat b_{1,n}-\beta,\qquad
 \widehat\gamma_{1,n}=\widehat V_{1,n}^{-1}\widehat u_{1,n}.
\]
Direct block Gaussian elimination, equivalently multiplication of the usual block-inverse formula by \((x^{\top},y)^{\top}\), gives the identity
\[
 \begin{pmatrix}x\\y\end{pmatrix}^{\!\top}
 S_{1,n}^{-1}
 \begin{pmatrix}x\\y\end{pmatrix}
 =x^{\top}\widehat V_{1,n}^{-1}x
  +\frac{(y-\widehat u_{1,n}^{\top}
                    \widehat V_{1,n}^{-1}x)^2}
         {\widehat\sigma_{1,n}^{2}}.
\]
For completeness, this follows by the factorization
\[
 S_{1,n}
 =\begin{pmatrix}I_q&0\\
       \widehat u_{1,n}^{\top}\widehat V_{1,n}^{-1}&1
   \end{pmatrix}
   \begin{pmatrix}\widehat V_{1,n}&0\\0&\widehat\sigma_{1,n}^{2}\end{pmatrix}
   \begin{pmatrix}I_q&\widehat V_{1,n}^{-1}\widehat u_{1,n}\\0&1
   \end{pmatrix},
\]
so no external matrix result is being invoked.  By the definitions of \(Q_{1,n}\) and \(\widehat\gamma_{1,n}\), the restricted ellipsoid inequality is therefore equivalent to
\[
 Q_{1,n}
 +\frac{n}{\widehat\sigma_{1,n}^{2}}
  \left\{\beta-
  \bigl(\widehat b_{1,n}
        -\widehat\gamma_{1,n}^{\top}\widehat s_{1,n}\bigr)
  \right\}^{2}
 \le \widehat c_n^2.
\]
If \(Q_{1,n}>\widehat c_n^2\), this inequality has no solution in \(\beta\), so its profile is empty.  If \(Q_{1,n}\le\widehat c_n^2\), solving the inequality gives
\[
 \left[
 \widehat b_{1,n}-\widehat\gamma_{1,n}^{\top}\widehat s_{1,n}
 \;\mathbin{\pm}\;
 n^{-1/2}\widehat\sigma_{1,n}
       (\widehat c_n^2-Q_{1,n})^{1/2}
 \right].
\]
In the two cases this is exactly \(I_{1,n}(\alpha)\) by Definition \(\mathrm{def:profile\text{-}intervals}\).

Finally, Definition \(\mathrm{def:projected\text{-}hull}\) and \(\mathcal J=\{1\}\) yield
\[
 C_n^{\mathrm{proj}}(\alpha)
   =\operatorname{conv}\bigl(I_{1,n}(\alpha)\bigr).
\]
A nonempty \(I_{1,n}(\alpha)\) is an interval and is therefore convex, while the stipulated convex hull of the empty set is empty.  Thus
\[
 C_n^{\mathrm{proj}}(\alpha)=I_{1,n}(\alpha),
\]
which is exactly the profile of the ordinary \((q+1)\)-dimensional Gaussian Wald ellipsoid under \(s_{1,n}=0\), as claimed.
