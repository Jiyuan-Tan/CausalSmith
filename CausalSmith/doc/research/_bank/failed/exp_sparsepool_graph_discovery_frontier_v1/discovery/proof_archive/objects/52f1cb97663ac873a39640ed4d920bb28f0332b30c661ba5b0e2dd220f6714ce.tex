For each \(i\in\mathcal U\), define \(v_i=\min_{u\in\mathcal D_i}\lVert u\rVert_1\) and \(\theta_i^{\mathrm D}=\arg\min\{\lVert u\rVert_2^2/2:u\in\mathcal D_i,\ \lVert u\rVert_1\le v_i\}\), which is unique. A certified finite-tolerance output \(\widehat\theta_i\) is a feasible point for the latter quadratic program accompanied by a valid dual lower bound whose difference from \(\lVert\widehat\theta_i\rVert_2^2/2\) is at most \(\varepsilon_{\mathrm{comp}}^2/2\). When \(r_m<\delta/2\), use the explicit coordinate tolerance \(\varepsilon_{\mathrm{comp}}=(\delta-2r_m)/8\). This definition imposes no dimension-only operation or bit-complexity claim for producing the certificate.
