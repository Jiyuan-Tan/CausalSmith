Let \(\mathscr H_m\) be the finite set of compatible arm--outcome tables with row totals \(m\), and let \(\mathscr W\) be the finite set of complete weak orders on \(\mathcal R\). Extend \(L_N(H)\) by zero when \((H,N)\notin\mathfrak J\), and define
\[
 b_{H,o}(\alpha)
 =\mathbf 1\!\left\{o\in\widehat{\mathfrak O}_{\alpha}(H)\right\}
 =\mathbf 1\!\left\{\exists N'\in\mathcal N(H):
       \mathcal O(N')=o,\ p_{N'}(H)>\alpha\right\}.
\]
For every candidate count vector \(N\), put
\[
 \beta_N(\alpha)
 =\sum_{H\in\mathscr H_m}L_N(H)
       \{1-b_{H,\mathcal O(N)}(\alpha)\}.
\]
By \(\texttt{lem:deterministic-coverage-iff}\), this is exactly the design noncoverage probability of the baseline rule for a schedule with count vector \(N\); by \(\texttt{thm:exact-weak-order-coverage}\),
\[
 0\le \beta_N(\alpha)\le\alpha
 \qquad\text{for every }N.
\]
Now let \(d=(d_{H,o})\) be a binary deletion mask satisfying
\[
 d_{H,o}\in\{0,1\},
 \qquad d_{H,o}\le b_{H,o}(\alpha),
\]
and define the contained deterministic rule
\[
 \mathfrak C_d(H)
 =\{o\in\mathscr W:b_{H,o}(\alpha)=1,\ d_{H,o}=0\}.
\]
Because \(d_{H,o}\le b_{H,o}(\alpha)\), for every \(N\) and \(H\) one has the disjoint-case identity
\[
 \mathbf 1\!\left\{\mathcal O(N)\notin\mathfrak C_d(H)\right\}
 =1-b_{H,\mathcal O(N)}(\alpha)+d_{H,\mathcal O(N)}.
\]
Multiplication by \(L_N(H)\), summation over \(H\), and another application of \(\texttt{lem:deterministic-coverage-iff}\) therefore prove the exact equivalence
\[
 \mathfrak C_d\text{ has uniform coverage at least }1-\alpha
 \quad\Longleftrightarrow\quad
 \beta_N(\alpha)+
 \sum_{H\in\mathscr H_m}L_N(H)d_{H,\mathcal O(N)}
 \le\alpha
 \quad\text{for every }N. \tag{1}
\]
Consequently, after a precise lattice-consonance predicate has been expressed as a finite set \(\mathscr D_{\mathrm{con}}\) of admissible masks, existence of the requested strict contained rule is equivalent to feasibility of the finite binary system
\[
 \begin{aligned}
 &d\in\mathscr D_{\mathrm{con}},\qquad
   d_{H,o}\in\{0,1\},\qquad d_{H,o}\le b_{H,o}(\alpha),\\
 &\beta_N(\alpha)+\sum_{H\in\mathscr H_m}
     L_N(H)d_{H,\mathcal O(N)}\le\alpha
     &&\text{for every }N,\\
 &\sum_{H\in\mathscr H_{\mathrm{nd}}}\sum_{o\in\mathscr W}d_{H,o}\ge1,
 \end{aligned} \tag{2}
\]
where \(\mathscr H_{\mathrm{nd}}\) is the intended, explicitly specified set of nondegenerate tables. If strictness is required at the supplied test bed, the last line can instead be written \(\sum_o d_{H^\dagger,o}\ge1\). All coefficients in (1)--(2), apart from the externally fixed threshold \(\alpha\), are computable rational numbers: \(L_N(H)\) is a finite sum of the exact factorial masses, \(p_N(H)\) is a finite right-tail sum of the same masses, and \(b_{H,o}(\alpha)\) is obtained by finite enumeration over \(\mathcal N(H)\). Thus (2) is an exact response-table decision problem and never requires labeled-schedule enumeration.

In particular, a proposed deletion of one retained order \(o_0\) at one table \(H_0\) is uniformly valid if and only if
\[
 \max_{N:\,\mathcal O(N)=o_0}
 \{\beta_N(\alpha)+L_N(H_0)\}\le\alpha, \tag{3}
\]
with the convention \(L_N(H_0)=0\) off \(\mathfrak J\). The frontier condition \(\lambda_{H_0}(o_0)\le\alpha\) controls only the second summand in (3); it does not control the already-spent baseline size \(\beta_N(\alpha)\). Hence \(\alpha\ge\delta_{\mathrm{ord}}\) alone neither supplies a feasible deletion nor verifies consonance.
