%%% FIELD statement-sharp-finite-star-dictionary
For every \(C,D\in\mathfrak S_p\), if \(\mathsf S(C)\neq\mathsf S(D)\), then
\[
\mathcal W_2(C)\not\subseteq\mathcal M(D)
\qquad\text{or}\qquad
\mathcal W_2(D)\not\subseteq\mathcal M(C).
\]
Moreover, for every \(E_0\in\mathfrak S_p\), writing \(b_j=|\Pi^{E_0}_j|\),
\[
|\mathcal W_2(E_0)|
=\sum_{j\in V}\left(b_j+\binom{b_j}{2}\right)
=\sum_{j\in V}\binom{b_j+1}{2}
\leq\binom{p+1}{3}
\leq\frac{p^2(p-1)}{2}.
\]
The bound \(\binom{p+1}{3}\) is sharp for every \(p\geq1\): equality is attained by a transitively oriented complete directed acyclic graph whose parent partitions consist entirely of singleton blocks.
%%% FIELD proof-sharp-finite-star-dictionary
Suppose first that \(\mathsf S(C)\neq\mathsf S(D)\).  By the bounded binary-star separation theorem, there are distinct states \(E,J\in\{C,D\}\), a target \(z\in V\), and a subfamily \(\mathcal A_z\subseteq\Pi^E_z\) with \(1\leq|\mathcal A_z|\leq2\) such that the corresponding covariance \(\Sigma^{\star}\) belongs to \(\mathcal M(E)\setminus\mathcal M(J)\).  By the binary-star-library definition, the same choices imply \(\Sigma^{\star}\in\mathcal W_2(E)\).  Hence, if \(E=C\), then \(\mathcal W_2(C)\not\subseteq\mathcal M(D)\), while if \(E=D\), then \(\mathcal W_2(D)\not\subseteq\mathcal M(C)\).  This proves the separating-dictionary assertion.

It remains to count the library exactly.  Fix \(E_0\in\mathfrak S_p\), and put \(b_j=|\Pi^{E_0}_j|\).  For a target \(z\) and an admissible active subfamily \(\mathcal A_z\), let \(A_z=\bigcup_{B\in\mathcal A_z}B\).  Every block in a partition is nonempty, so \(A_z\neq\varnothing\).  Also \(z\notin A_z\), because \(A_z\subseteq\operatorname{pa}_{G_{E_0}}(z)\) and an acyclic directed graph has no self-loop.  The binary-star-library formula gives
\[
\Sigma^{\star}_{kk}
=
\begin{cases}
1+|A_z|,&k=z,\\
1,&k\neq z,
\end{cases}
\qquad
\Sigma^{\star}_{zi}=\mathbf 1\{i\in A_z\}\quad(i\neq z).
\]
Consequently \(z\) is the unique index whose diagonal entry exceeds one, and, after \(z\) is recovered,
\[
A_z=\{i\in V\setminus\{z\}:\Sigma^{\star}_{zi}=1\}.
\]
Thus the covariance recovers both its target and its active union.  Finally, because the members of \(\Pi^{E_0}_z\) are pairwise disjoint nonempty atoms, equality
\[
\bigcup_{B\in\mathcal A_z}B
=
\bigcup_{B\in\mathcal A'_z}B
\]
forces \(\mathcal A_z=\mathcal A'_z\): if \(B\in\mathcal A_z\) and \(i\in B\), then the unique partition atom containing \(i\) on the right is \(B\), so \(B\in\mathcal A'_z\), and the reverse inclusion is symmetric.  Hence the map from admissible pairs \((z,\mathcal A_z)\) to binary-star covariances is injective.  There are exactly \(\binom{b_z}{1}+\binom{b_z}{2}\) admissible subfamilies at target \(z\), including zero choices when \(b_z=0\).  Summing the disjoint, injectively represented target contributions yields
\[
|\mathcal W_2(E_0)|
=\sum_{z\in V}\left(\binom{b_z}{1}+\binom{b_z}{2}\right)
=\sum_{z\in V}\left(b_z+\binom{b_z}{2}\right)
=\sum_{z\in V}\binom{b_z+1}{2}.
\]

We next prove the uniform bound.  A finite acyclic directed graph has a topological order: indeed, every nonempty induced subgraph has a source, since otherwise repeatedly following an incoming arrow in the finite vertex set would repeat a vertex and create a directed cycle; deleting a source and iterating gives the order.  Write this order as \(v_1,\ldots,v_p\), with every arrow directed from an earlier to a later vertex.  Then
\[
|\operatorname{pa}_{G_{E_0}}(v_k)|\leq k-1.
\]
Because \(\Pi^{E_0}_{v_k}\) partitions that parent set into nonempty blocks,
\[
b_{v_k}\leq|\operatorname{pa}_{G_{E_0}}(v_k)|\leq k-1.
\]
The map \(m\mapsto\binom{m+1}{2}=m(m+1)/2\) is nondecreasing on the nonnegative integers.  Therefore
\[
|\mathcal W_2(E_0)|
=\sum_{k=1}^{p}\binom{b_{v_k}+1}{2}
\leq\sum_{k=1}^{p}\binom{k}{2}
=\binom{p+1}{3},
\]
where the last equality follows by induction from Pascal's identity \(\binom{k+1}{3}=\binom{k}{3}+\binom{k}{2}\), with both sides zero at \(p=1\).  Since \(p+1\leq3p\) for \(p\geq1\),
\[
\binom{p+1}{3}
=\frac{p(p-1)(p+1)}{6}
\leq\frac{p^2(p-1)}{2},
\]
so the former coarse bound is retained as a consequence.

For sharpness, choose any ordering \(v_1,\ldots,v_p\) of \(V\), include every arrow \(v_a\to v_b\) with \(a<b\), and let every \(\Pi^{E_0}_{v_k}\) be the singleton partition of \(\{v_1,\ldots,v_{k-1}\}\).  The graph is acyclic, these are valid parent partitions, and hence the resulting state belongs to \(\mathfrak S_p\).  It satisfies \(b_{v_k}=k-1\), so the exact identity already proved gives
\[
|\mathcal W_2(E_0)|
=\sum_{k=1}^{p}\binom{k}{2}
=\binom{p+1}{3}.
\]
Thus the global bound is attained, including the case \(p=1\), when both sides are zero.
