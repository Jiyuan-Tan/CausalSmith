Identify a row vector indexed by \((a_{\mathrm b},z_{\mathrm b})\) with its \(m\)-by-\(m\) matrix of coordinates.  Let
\[
R=\operatorname{row}(A_{\mathrm b}),
\qquad
S=\operatorname{span}\{r_{z^{\circ}}:z^{\circ}\in\mathcal A_{X_{\mathrm b}}\}.
\]
By \(\texttt{def:bow-target-coefficient}\),
\[
S=\{\mathbf 1_X t^{\mathsf T}:t\in\mathbb R^m\}.
\]
The matrices \(\mathbf 1_X\delta_i^{\mathsf T}\), \(0\le i<m\), are linearly independent, so \(\dim S=m\).  The target-row hypothesis gives \(S\subseteq R\).

Define the linear map
\[
F:R\longrightarrow\mathbb R^m/\operatorname{span}\{\mathbf 1_X\},
\qquad
F(M)=[M\mathbf 1_X].
\]
For \(M=\mathbf 1_Xt^{\mathsf T}\in S\),
\[
M\mathbf 1_X=(t^{\mathsf T}\mathbf 1_X)\mathbf 1_X,
\]
and hence \(F(M)=0\).  Thus \(F\) induces a linear map \(\overline F:R/S\to\mathbb R^m/\operatorname{span}\{\mathbf 1_X\}\).  By \(\texttt{def:bow-probe-matrix}\), the row associated with branch \(\beta_X\) is the product matrix
\[
M_{\beta_X}=\phi_{X_{\mathrm b},\beta_X}\psi_{X_{\mathrm b},\beta_X}^{\mathsf T}.
\]
Because every state is a probability vector, \(\psi_{X_{\mathrm b},\beta_X}^{\mathsf T}\mathbf 1_X=1\); therefore
\[
F(M_{\beta_X})=[\phi_{X_{\mathrm b},\beta_X}].
\]
The assumed treatment-effect span is \(\mathbb R^m\), so these quotient classes span \(\mathbb R^m/\operatorname{span}\{\mathbf 1_X\}\).  Hence \(\overline F\) is surjective and
\[
\dim(R/S)\ge m-1.
\]
Since \(S\subseteq R\), finite-dimensional dimension addition gives
\[
\operatorname{rank}(A_{\mathrm b})=\dim R
=\dim S+\dim(R/S)
\ge m+(m-1)=2m-1.
\]
The rank of a matrix cannot exceed its number of rows, which proves \(\lvert\mathcal L_{X_{\mathrm b}}\rvert\ge2m-1\).

We next verify the construction in \(\texttt{def:finite-alphabet-bow-frontier-menu}\).  Every coordinate of \(\rho_i\) is at least \(1/(2m)>0\), using \(m\ge2\), and
\[
\mathbf 1_X^{\mathsf T}\rho_i=\frac12+\frac1{2m}m=1.
\]
Thus every \(\rho_i\) is a probability state.  Each terminal coordinate vector \(e_y\) is nonnegative and has coordinate sum one, so the terminal branches also use probability states.  At \(X_{\mathrm b}\), the branch effects sum coordinatewise to
\[
\sum_{i=0}^{m-1}\frac12\delta_i
+\sum_{i=1}^{m-1}\frac1{2(m-1)}\mathbf 1_X
=\frac12\mathbf 1_X+\frac12\mathbf 1_X
=\mathbf 1_X.
\]
At \(Y_{\mathrm b}\), \(\sum_y e_y=\mathbf 1\).  Thus both instruments satisfy \(\texttt{ass:instrument-normalization}\).  The treatment effects span \(\mathbb R^m\) because they include nonzero multiples of every \(\delta_i\).  To check the states, suppose \(\sum_i\alpha_i\rho_i=0\), and put \(A=\sum_i\alpha_i\).  The \(j\)-th coordinate of this equality is
\[
\frac12\alpha_j+\frac1{2m}A=0.
\]
Summing these equations over \(j\) gives \(A=0\), and then every \(\alpha_j=0\).  Thus \(\rho_0,\ldots,\rho_{m-1}\) form a basis of \(\mathbb R^m\).  The terminal effect and state vectors are the coordinate basis \((e_y)_y\), so both terminal spans are \(\mathbb R^k\).

The first \(m\) treatment rows span
\[
U=\{u\rho_0^{\mathsf T}:u\in\mathbb R^m\},
\qquad \dim U=m,
\]
and the remaining \(m-1\) rows span
\[
V=\{\mathbf 1_Xv^{\mathsf T}:v\in\operatorname{span}(\rho_1,\ldots,\rho_{m-1})\},
\qquad \dim V=m-1.
\]
Because the \(\rho_i\) form a basis, there is a vector \(w_0\) satisfying \(\rho_0^{\mathsf T}w_0=1\) and \(\rho_i^{\mathsf T}w_0=0\) for \(1\le i<m\).  If \(M\in U\cap V\), write \(M=u\rho_0^{\mathsf T}=\mathbf 1_Xv^{\mathsf T}\).  Right multiplication by \(w_0\) gives \(u=0\), because \(v\in\operatorname{span}(\rho_1,\ldots,\rho_{m-1})\).  Hence \(M=0\), so \(U\cap V=\{0\}\).  It follows that
\[
\operatorname{rank}(A_{\mathrm b}^{\mathrm{fr}})
=\dim(U+V)=m+(m-1)=2m-1.
\]
Moreover,
\[
\mathbf 1_X\rho_0^{\mathsf T}
=2\sum_{i=0}^{m-1}\left(\frac12\delta_i\rho_0^{\mathsf T}\right)\in U,
\]
and \(\mathbf 1_X\rho_i^{\mathsf T}\in V\) for \(1\le i<m\).  Since the \(\rho_i\) are a basis, every matrix \(\mathbf 1_Xt^{\mathsf T}\), and in particular every target row \(r_{z^{\circ}}=\mathbf 1_X\delta_{z^{\circ}}^{\mathsf T}\), lies in \(U+V=\operatorname{row}(A_{\mathrm b}^{\mathrm{fr}})\).

For every terminal outcome \(y\), the construction includes terminal effect \(e_y\).  The success direction of \(\texttt{thm:bow-rowspan-iff}\), applied to each \((z^{\circ},y)\), therefore gives \(\operatorname{GID}_{\mathcal I_{\mathrm b}^{\mathrm{fr}}}(Q_{z^{\circ},y})\) on the stated primitive-positive class and supplies the explicit dual-frame-invariant arithmetic functional there.  Conversely, in any menu in the all-query class of the theorem, the only-if direction of \(\texttt{thm:bow-rowspan-iff}\) implies that every \(r_{z^{\circ}}\) belongs to \(R\); the lower-bound argument above therefore applies.  The constructed menu attains that lower bound while satisfying every completeness condition, so the minimum is exactly \(2m-1\).  Finally,
\[
m^2-(2m-1)=(m-1)^2>0
\]
for \(m\ge2\), proving non-tomography.

When \(m=k=2\),
\[
\rho_0=\frac12e_0+\frac14\mathbf 1=(3/4,1/4)=\psi^+,
\qquad
\rho_1=\frac12e_1+\frac14\mathbf 1=(1/4,3/4)=\psi^-.
\]
The treatment branches become \((\tfrac12e_0,\psi^+)\), \((\tfrac12e_1,\psi^+)\), and \((\tfrac12\mathbf 1,\psi^-)\), while the terminal branches are \((e_0,e_0)\) and \((e_1,e_1)\).  These are exactly the branches in \(\texttt{def:binary-bow-menu}\), proving \(\mathcal I_{\mathrm b}^{\mathrm{fr}}=\mathcal I_{\mathrm b}^{\dagger}\).

The effect-completeness premise is load-bearing.  If it is omitted, one normalized treatment instrument with branches \((m^{-1}\mathbf 1_X,\delta_i)\), \(0\le i<m\), has rank \(m\) and row span equal to \(S\), so it contains every target row but its effects span only \(\operatorname{span}\{\mathbf 1_X\}\).  Paired with the terminal basis instrument, \(\texttt{thm:bow-rowspan-iff}\) identifies every atomic query.  Thus the lower bound cannot be extended to menus without treatment-effect completeness.
