For the attainable bow tensor, define the column vector \(b_y\in\mathbb R^{m^2}\) by
\[
 b_y[a_{\mathrm b},z_{\mathrm b}]=B_{\mathcal M,y}(a_{\mathrm b},z_{\mathrm b}).
\]
By \texttt{lem:terminal-synthesis-invariance}, the evidence-determined synthesized response vector is
\[
 \bigl(q^{\mathrm b}_{\beta_X}(y):\beta_X\in\mathcal L_{X_{\mathrm b}}\bigr)
 =A_{\mathrm b}b_y.
\]
If \(c^{\mathsf T}A_{\mathrm b}=\widetilde c^{\mathsf T}A_{\mathrm b}=r_{z^{\circ}}^{\mathsf T}\), then ordinary associativity of finite matrix multiplication gives
\[
\begin{aligned}
 \sum_{\beta_X}c_{\beta_X}q^{\mathrm b}_{\beta_X}(y)
 &=c^{\mathsf T}A_{\mathrm b}b_y
 =r_{z^{\circ}}^{\mathsf T}b_y\\
 &=\widetilde c^{\mathsf T}A_{\mathrm b}b_y
 =\sum_{\beta_X}\widetilde c_{\beta_X}q^{\mathrm b}_{\beta_X}(y).
\end{aligned}
\]
This is the claimed coefficient invariance.
