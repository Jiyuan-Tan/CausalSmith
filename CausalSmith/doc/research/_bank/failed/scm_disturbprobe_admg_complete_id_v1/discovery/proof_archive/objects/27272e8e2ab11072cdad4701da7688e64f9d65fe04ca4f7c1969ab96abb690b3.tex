Fix an attainable bow tensor, so it is generated by some \(\mathcal M\), and fix \(y\in\mathcal A_{Y_{\mathrm b}}\).  Assumption \texttt{ass:terminal-diagonal-span} and \texttt{def:terminal-synthesis} give an admissible coefficient vector \(\lambda^y\) satisfying, pointwise in \((a_{\mathrm t},z_{\mathrm t})\),
\[
 \sum_{\beta_Y\in\mathcal L_{Y_{\mathrm b}}}
 \lambda^y_{\beta_Y}\phi_{Y_{\mathrm b},\beta_Y}(a_{\mathrm t})
 \psi_{Y_{\mathrm b},\beta_Y}(z_{\mathrm t})
 =d_y(a_{\mathrm t},z_{\mathrm t})
 =\mathbf 1\{a_{\mathrm t}=y, z_{\mathrm t}=y\}.
\]
This proves the stated pointwise sanity reduction directly; no choice of dual frame has entered.

By \texttt{lem:split-port-reduction}, for a treatment branch \(\beta_X\) and a terminal branch \(\beta_Y\),
\[
 \bar q_{\beta_X,\beta_Y}
 =\sum_{a_{\mathrm b},z_{\mathrm b},a_{\mathrm t},z_{\mathrm t}}
 W_{\mathcal M}\!\left((a_{\mathrm b},a_{\mathrm t})mid
 (z_{\mathrm b},z_{\mathrm t})\right)
 A_{\mathrm b}[\beta_X,(a_{\mathrm b},z_{\mathrm b})]
 \phi_{Y_{\mathrm b},\beta_Y}(a_{\mathrm t})
 \psi_{Y_{\mathrm b},\beta_Y}(z_{\mathrm t}).
\]
All sums are finite, so \texttt{def:terminally-synthesized-bow-response} and the pointwise synthesis equation allow the order of summation to be exchanged:
\[
\begin{aligned}
 q^{\mathrm b}_{\beta_X}(y;\lambda^y)
 &=\sum_{a_{\mathrm b},z_{\mathrm b},a_{\mathrm t},z_{\mathrm t}}
 W_{\mathcal M}\!\left((a_{\mathrm b},a_{\mathrm t})mid
 (z_{\mathrm b},z_{\mathrm t})\right)
 A_{\mathrm b}[\beta_X,(a_{\mathrm b},z_{\mathrm b})]
 \mathbf 1\{a_{\mathrm t}=y, z_{\mathrm t}=y\}\\
 &=\sum_{a_{\mathrm b},z_{\mathrm b}}
 A_{\mathrm b}[\beta_X,(a_{\mathrm b},z_{\mathrm b})]
 W_{\mathcal M}\!\left((a_{\mathrm b},y)mid(z_{\mathrm b},y)\right)\\
 &=\sum_{a_{\mathrm b},z_{\mathrm b}}
 A_{\mathrm b}[\beta_X,(a_{\mathrm b},z_{\mathrm b})]
 B_{\mathcal M,y}(a_{\mathrm b},z_{\mathrm b}).
\end{aligned}
\]
For the query, \texttt{def:atomic-query-contraction} with treatment \(X_{\mathrm b}\) and outcome \(Y_{\mathrm b}\) similarly gives
\[
\begin{aligned}
 Q_{z^{\circ},y}(\mathcal M)
 &=\sum_{a_{\mathrm b},z_{\mathrm b}}
 \mathbf 1\{z_{\mathrm b}=z^{\circ}\}
 W_{\mathcal M}\!\left((a_{\mathrm b},y)mid(z_{\mathrm b},y)\right)\\
 &=\sum_{a_{\mathrm b},z_{\mathrm b}}
 r_{z^{\circ}}[a_{\mathrm b},z_{\mathrm b}]
 B_{\mathcal M,y}(a_{\mathrm b},z_{\mathrm b}),
\end{aligned}
\]
where the last equality uses \texttt{def:bow-target-coefficient}.

If \(\widetilde\lambda^y\) is a second solution of the synthesis equations, repeating the first calculation gives the same vector \(A_{\mathrm b}B_{\mathcal M,y}\).  Hence
\[
 q^{\mathrm b}_{\beta_X}(y;\lambda^y)
 =q^{\mathrm b}_{\beta_X}(y;\widetilde\lambda^y)
\]
for every \(\beta_X\).  This common, evidence-determined coordinate is therefore well defined as \(q^{\mathrm b}_{\beta_X}(y)\).
