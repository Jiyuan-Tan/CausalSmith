Let \(P_X=\mathcal L(C\varepsilon)\). Under the population rank, source, and distinct-direction assumptions, \(J_x(C)\ne\varnothing\), \(\mathfrak F_x(P_X)\ne\varnothing\), and the sharp one-intervention observed response-vector set over the entire source-minimal observational-law fiber is
\[
\left\{\boldsymbol\theta_{\leftarrow x}(\mathcal M):\mathcal M\in\mathfrak F_x(P_X)\right\}
=\mathcal R_x^{\mathrm{vec}}(C)
=\left\{\frac{C_{-x,j}}{C_{xj}}:C_{xj}\ne0,\ \operatorname{rank}(C_{-x,-j})=p-1\right\}\subseteq\mathbb R^{p-1},
\]
where every \(-x\) on \(C\) means observed rows excluding \(x\). For every \(y\in\mathsf O\setminus\{x\}\), coordinate projection gives the sharp scalar set
\[
\left\{\theta_{y\leftarrow x}(\mathcal M):\mathcal M\in\mathfrak F_x(P_X)\right\}
=\mathcal R_{xy}(C).
\]
Every frontier point is attained by a canonical exact-representation completion \(\mathcal M_j=(n,Q_j,H_j,\varepsilon)\). The response vector is identified if and only if \(|\mathcal R_x^{\mathrm{vec}}(C)|=1\), equivalently \(|J_x(C)|=1\); the scalar response is identified if and only if \(|\mathcal R_{xy}(C)|=1\), equivalently \(\operatorname{rank}(C_{\{x,y\},J_x(C)})=1\). When either singleton condition fails, two corresponding canonical completions are exact same-law countermodels. All frontier values and one exact witness for every admissible source are certifiable in \(O(n^4)\) real-arithmetic operations; for rational \(C\), all returned structural matrices are rational.
