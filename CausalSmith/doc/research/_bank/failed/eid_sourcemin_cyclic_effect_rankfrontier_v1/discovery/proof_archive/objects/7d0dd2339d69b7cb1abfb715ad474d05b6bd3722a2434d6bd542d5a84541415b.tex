By the sharp-frontier theorem, the image of the causal target over the nonempty fiber is exactly the nonempty finite set \(\mathcal R_{xy}(C)\). Therefore the target is constant on the fiber if and only if
\[
 |\mathcal R_{xy}(C)|=1.
\]
Let \(J=J_x(C)\). Every \(C_{xj}\), \(j\in J\), is nonzero, so the first row of \(C_{\{x,y\},J}\) is nonzero and this two-row matrix has rank at least one. It has rank one if and only if all its two-by-two minors vanish:
\[
 C_{xj}C_{yk}-C_{xk}C_{yj}=0
 \qquad(j,k\in J).
\]
Division by the nonzero \(C_{xj}C_{xk}\) shows that these equalities hold if and only if
\[
 \frac{C_{yj}}{C_{xj}}=\frac{C_{yk}}{C_{xk}}
 \qquad(j,k\in J),
\]
which is equivalent to \(|\mathcal R_{xy}(C)|=1\).

If rank one fails, choose \(j,k\in J\) with a nonzero displayed minor. The two ratios are distinct. The certificate supplies \(\mathcal M_j,\mathcal M_k\in\mathfrak F_x(C,\varepsilon)\), and the intervention-ratio lemma gives
\[
 \theta_{y\leftarrow x}(\mathcal M_j)=\frac{C_{yj}}{C_{xj}}
 \ne \frac{C_{yk}}{C_{xk}}
 =\theta_{y\leftarrow x}(\mathcal M_k).
\]
Both models have observed mixing matrix \(C\) with the same supplied source vector \(\varepsilon\), so both induce exactly \(P_X=\mathcal L(C\varepsilon)\). After the shared basis extension and inverse, constructing these two models requires two rank-one shears, two complementary matchings, and two row normalizations. The matching terms dominate and cost \(O(n^3)\) arithmetic operations in total.
