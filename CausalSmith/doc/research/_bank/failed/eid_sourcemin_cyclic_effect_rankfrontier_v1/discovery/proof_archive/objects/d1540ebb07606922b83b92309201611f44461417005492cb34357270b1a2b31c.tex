Let \(A\in\mathbb R^{p\times n}\) satisfy \(A=C\Pi D\), where \(\Pi\) is a permutation matrix and \(D\) is nonsingular diagonal. If \(\pi\) is defined by \(A_{:,k}=D_{kk}C_{:,\pi(k)}\), then \(k\in J_x(A)\) if and only if \(\pi(k)\in J_x(C)\), and, whenever these conditions hold, \(A_{-x,k}/A_{xk}=C_{-x,\pi(k)}/C_{x,\pi(k)}\) and \(A_{yk}/A_{xk}=C_{y,\pi(k)}/C_{x,\pi(k)}\). Consequently \(\mathcal R_x^{\mathrm{vec}}(A)=\mathcal R_x^{\mathrm{vec}}(C)\) and \(\mathcal R_{xy}(A)=\mathcal R_{xy}(C)\).
