Let \(P_X=\mathcal L(C\varepsilon)\) under the population assumptions. Then \(J_x(C)\ne\varnothing\), and the sharp hard-intervention response-vector set over the entire irreducible source-minimal observational-law fiber is
\[
 \{\boldsymbol\theta_{\leftarrow x}(\mathcal M):\mathcal M\in\mathfrak F_x(P_X)\}
 =\mathcal R_x^{\mathrm{vec}}(C)
 =\left\{\frac{C_{-x,j}}{C_{xj}}:C_{xj}\ne0,\ \operatorname{rank}(C_{-x,-j})=p-1\right\}. \tag{17}
\]
For every \(y\in\mathsf O\setminus\{x\}\), if \(\operatorname{pr}_y(z)=z_y\), then the scalar causal target is the coordinate projection
\[
 \{\theta_{y\leftarrow x}(\mathcal M):\mathcal M\in\mathfrak F_x(P_X)\}
 =\operatorname{pr}_y\mathcal R_x^{\mathrm{vec}}(C)
 =\mathcal R_{xy}(C). \tag{18}
\]
Every point in (17), and hence every scalar value in (18), is realized by a canonical same-law completion \(\mathcal M_j=(n,Q_j,H_j,\varepsilon)\) with \(A^{\mathcal M_j}=C\). The index-to-vector map \(j\mapsto C_{-x,j}/C_{xj}\) is injective on \(J_x(C)\); consequently the response vector is identified if and only if \(|\mathcal R_x^{\mathrm{vec}}(C)|=1\), equivalently \(|J_x(C)|=1\). The scalar response is identified if and only if \(|\mathcal R_{xy}(C)|=1\), equivalently \(\operatorname{rank}(C_{\{x,y\},J_x(C)})=1\). All frontier values and one exact witness for every admissible index are certifiable by \(\operatorname{Cert}(C,x)\) in \(O(n^4)\) exact real-arithmetic operations; when \(C\) is rational, the returned structural matrices are rational.
