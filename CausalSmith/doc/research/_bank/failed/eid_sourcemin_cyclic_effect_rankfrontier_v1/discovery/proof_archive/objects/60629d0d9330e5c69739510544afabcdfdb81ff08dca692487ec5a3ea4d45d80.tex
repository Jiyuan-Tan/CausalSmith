For \(\mathcal M=(m_{\mathcal M},Q,H,\xi^{\mathcal M})\in\mathfrak F_x(P_X)\), define the one-intervention observed response vector
\[
\boldsymbol\theta_{\leftarrow x}(\mathcal M)
=\frac{(Q^{-1})_{\mathsf O\setminus\{x\},x}}{(Q^{-1})_{xx}}
\in\mathbb R^{p-1}.
\]
Only observed outcome rows are retained; this is not the vector of all completion coordinates and not a joint-multiple-intervention estimand.
