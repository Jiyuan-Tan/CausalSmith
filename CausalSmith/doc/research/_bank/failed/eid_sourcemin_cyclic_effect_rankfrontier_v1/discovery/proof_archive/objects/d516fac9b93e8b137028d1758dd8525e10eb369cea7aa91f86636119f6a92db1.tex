The full one-intervention response vector \(\boldsymbol\theta_{-x\leftarrow x}\) is identified over \(\mathfrak F_x(P_X)\) if and only if \(|J_x(C)|=1\), equivalently \(|\mathcal R_x^{\mathrm{vec}}(C)|=1\). For each \(y\ne x\), the scalar response \(\theta_{y\leftarrow x}\) is identified if and only if \(|\mathcal R_{xy}(C)|=1\), equivalently \(\operatorname{rank}(C_{\{x,y\},J_x(C)})=1\). If vector identification fails, \(\operatorname{Cert}(C,x)\) returns two same-law completions with distinct entire response vectors; if the scalar rank condition fails, it returns two with distinct \(y\)-responses. Either pair costs \(O(n^3)\) additional arithmetic operations after the shared basis inverse.
