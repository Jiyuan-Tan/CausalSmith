The set \(J_x(C)\) is nonempty. For every \(j\in J_x(C)\), \(\operatorname{Cert}(C,x)\) returns a canonical completion \(\mathcal M_j=(n,Q_j,H_j,\varepsilon)\in\mathfrak F_x(P_X)\) such that \(A^{\mathcal M_j}=C\), \(s_{\mathcal M_j}(x)=j\),
\[
 \boldsymbol\theta_{\leftarrow x}(\mathcal M_j)=\frac{C_{-x,j}}{C_{xj}},
 \qquad
 \theta_{y\leftarrow x}(\mathcal M_j)=\frac{C_{yj}}{C_{xj}}.
\]
All admissible indices and all these witnesses are computable in \(O(n^4)\) exact real-arithmetic operations. If \(C\) is rational, every returned \(Q_j\) and \(H_j\) is rational.
