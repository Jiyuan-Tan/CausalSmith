For \(\mathcal O_{nba}=\{i\in\mathcal U_{nb}:Z_{nbi}=a\}\) of observed size \(|\mathcal O_{nba}|=m_{nba}\), define
\[
\widehat{\bar R}_{nba}=\frac1{m_{nba}}\sum_{i\in\mathcal O_{nba}}\{Y_{nbi}^{\mathrm{obs}}-g_{nbi}(a)\},\qquad \widehat R_{nbi}^{c}(a)=Y_{nbi}^{\mathrm{obs}}-g_{nbi}(a)-\widehat{\bar R}_{nba},
\]
\[
\widehat\mu_{nba}=\frac1{m_{nba}}\sum_{i\in\mathcal O_{nba}}\delta_{\widehat R_{nbi}^{c}(a)},\qquad \widehat S_{nba}^2=\frac1{m_{nba}-1}\sum_{i\in\mathcal O_{nba}}\{\widehat R_{nbi}^{c}(a)\}^2.
\]
Set \(\widehat\mu_{nba}=\delta_{0_{\mathbb R}}\) and \(\widehat S_{nba}^2=0\) when \(m_{nba}=0\), and set \(\widehat S_{nba}^2=0\) when \(m_{nba}=1\). These total conventions are inactive for the endpoint theorem for all sufficiently large \(n\), because \(\min_{b,a}m_{nba}\ge q_n\) and \(q_n/\log(2B_nK)\to\infty\).
