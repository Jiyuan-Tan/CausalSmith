For every \(\alpha\in(0,1)\), assume in addition that \(\mathrm{ass:qv\text{-}stabilization}\) holds uniformly for the displayed common-parameter class \(\mathfrak D\). Then \[\liminf_{n\to\infty}\inf_{\mathbb D\in\mathfrak D}\Pr_{\mathbb D}\{\tau_n\in\mathrm{CI}_{n,1-\alpha}\}\ge1-\alpha.\] More precisely, the common leverage envelope \(\ell_n\to0\), the common residual-moment envelope \((\delta_0,C_R)\), the finite-population nondegeneracy condition \(V_n\ge v_0s_n^2\), and uniform predictable-QV stabilization imply \((\widehat\tau_n-\tau_n)/\sqrt{V_n}\Rightarrow\mathcal N(0,1)\) uniformly over \(\mathfrak D\). The exact-envelope theorem gives \(V_n\le U_n\) pathwise, and the explicit bound \(C_{\mathrm{ep}}r_n=o(1)\) permits \(U_n\) to be replaced by \(\widehat U_n\). No conditioning on the terminal adaptive path is required.
