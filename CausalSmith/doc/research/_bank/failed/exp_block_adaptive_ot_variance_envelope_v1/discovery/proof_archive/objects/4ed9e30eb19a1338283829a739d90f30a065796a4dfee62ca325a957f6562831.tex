For each \(n\), define, within this statement,
\[
 \begin{aligned}
 A_n&=\sup_{\varpi\in\mathcal P_n}\sum_{b=1}^{B_n}
 \frac{w_{nb}^2}{s_n^2(n_{nb}-1)}\left[
 \inf_{\gamma\in\mathcal I_{nb}^{h_b(\varpi)}}\int\left(\sum_ac_ax_a\right)^2d\gamma-J_{nb}^{h_b(\varpi),-}\right],\\
 C_n&=\inf_{\Xi_n\in\mathcal C_n(\boldsymbol\mu_n)}\sup_{\varpi\in\mathcal P_n}
 \sum_{b=1}^{B_n}\frac{w_{nb}^2}{s_n^2(n_{nb}-1)}\left[
 \int\left(\sum_ac_ax_a\right)^2d\gamma_{nb}^{\Xi,h_b(\varpi)}
 -\inf_{\gamma\in\mathcal I_{nb}^{h_b(\varpi)}}\int\left(\sum_ac_ax_a\right)^2d\gamma\right].
 \end{aligned}
\]
Whenever \(\mathcal C_n(\boldsymbol\mu_n)\ne\varnothing\),
\[
 \max\{A_n,C_n\}\le\Delta_n^{\mathrm{tree}}(\boldsymbol\mu_n)\le A_n+C_n,
 \qquad
 \Delta_n^{\mathrm{node}}(\boldsymbol\mu_n)\le A_n\le B_n\Delta_n^{\mathrm{node}}(\boldsymbol\mu_n).
\]
Consequently, \(\Delta_n^{\mathrm{tree}}(\boldsymbol\mu_n)\to0\) if and only if \(A_n\to0\) and \(C_n\to0\).  The first condition is the computable root-to-leaf accumulation of the single-node multi-index integrality losses; the second is exactly the additional cross-history compatibility loss from requiring one fixed potential-outcome array, common unit labels, and one predictable fitting rule.  Zero gap alone does not imply the existence of an admissible nondegenerate near-attaining completion sequence, and therefore does not imply the fixed-fraction undercoverage assertion in \(\mathrm{oeq:completion\text{-}sharpness}\).  In particular, if every nodewise centered margin is \(\delta_{0_{\mathbb R}}\), then \(A_n=C_n=\Delta_n^{\mathrm{tree}}=\Delta_n^{\mathrm{node}}=0\), but every completion has \(V_n=0\) and hence violates \(\mathrm{ass:qv\text{-}growth}\).
