For \(\Xi_n\in\mathcal C_n(\boldsymbol\mu_n)\), let \(Q_{nb}^{\Xi,h}\) be its nodewise conditional-variance contribution. With the predictable block weight already included in \(U_{nb}^{h}\) and \(Q_{nb}^{\Xi,h}\), define the normalized root-to-leaf compatibility gap
\[
\Delta_n^{\mathrm{tree}}(\boldsymbol\mu_n)=\inf_{\Xi_n\in\mathcal C_n(\boldsymbol\mu_n)}\ \sup_{\varpi\in\mathcal P_n}\frac1{s_n^2}\sum_{b=1}^{B_n}\left\{U_{nb}^{h_b(\varpi)}-Q_{nb}^{\Xi,h_b(\varpi)}\right\}.
\]
Define the single-node multi-index integrality diagnostic
\[
\Delta_n^{\mathrm{node}}(\boldsymbol\mu_n)=\sup_{b\le B_n,\,h\in\mathcal H_{n,b-1}}\frac{w_{nb}^2}{s_n^2(n_{nb}-1)}\left[\inf_{\gamma\in\mathcal I_{nb}^{h}}\int\left(\sum_{a\in\mathcal A}c_ax_a\right)^2d\gamma-J_{nb}^{h,-}\right].
\]
For a fixed \(\rho\in(0,1)\), define the reduced nodewise contribution \(U_{nb}^{h,\rho}=(1-\rho)U_{nb}^{h}\) and the corresponding root-to-leaf endpoint
\[
U_n^{\rho}(\varpi)=\sum_{b=1}^{B_n}U_{nb}^{h_b(\varpi),\rho}.
\]
The two gaps and \(U_n^{\rho}(\varpi)\) are retained only for the unresolved global history-tree compatibility problem; the fixed-fraction necessity result for uniform inference is certified separately by an explicit nonadaptive fixed-quota subclass.
