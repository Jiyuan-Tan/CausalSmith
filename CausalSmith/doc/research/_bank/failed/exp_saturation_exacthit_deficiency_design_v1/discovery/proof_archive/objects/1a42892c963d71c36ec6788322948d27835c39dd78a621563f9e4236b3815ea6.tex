Define, for a selector \(\delta\),
\[
R_A(\delta,h)=\mathbb E_h\!\left[\max_{i\in A}h_i-h_{\delta(X)}\right]. \tag{1}
\]
We first prove the subface inequality.  Fix \(S\subseteq A\) and \(M<\infty\).  By translation invariance, every class in the compact \(S\)-game has a representative \(g\) with \(\max_{i\in S}g_i=0\).  The condition \(\lVert[g]\rVert_S\leq M\) implies \(g_i\geq-2M\) for every \(i\in S\): every coordinate is within \(M\) of the reference coordinate, and the reference coordinate is itself within \(M\) of a maximizing coordinate.  Embed this compact parameter set in \(\mathbb R^A\) by setting
\[
h_i=g_i\quad(i\in S),
\qquad h_j=-2M-1\quad(j\in A\setminus S). \tag{2}
\]
Every action outside \(S\) is then strictly dominated by every action in \(S\).  Since \(\Sigma\) is diagonal, \(X_{A\setminus S}\) is independent of \(X_S\), and its law in (2) does not depend on \(g\).  Thus it supplies only randomization, which is already allowed in the class of randomized \(S\)-selectors.  Replacing an outside action by any fixed action in \(S\) cannot increase loss.  Restricting the supremum in the \(A\)-game to (2) consequently gives
\[
G_A(v_A,r_A)\geq G_{S,M}(v_S,r_S). \tag{3}
\]
Letting \(M\to\infty\) in (3) and using the declared monotone convergence \(G_{S,M}\uparrow G_S\) proves \(G_S(v_S,r_S)\leq G_A(v_A,r_A)\).  Taking the maximum of (3) at the radii \(M_S\) gives the first inequality in the statement.

We now construct the selector.  From
\[
X=h+\xi,\qquad \xi\sim N(0,\Sigma),
\]
generate independently \(E\sim N(0,\Sigma)\) and set
\[
X^{\rm s}=X+\sqrt{\frac{1-\lambda}{\lambda}}E,
\qquad
X^{\rm d}=X-\sqrt{\frac{\lambda}{1-\lambda}}E. \tag{4}
\]
Direct covariance calculation gives
\[
X^{\rm s}\sim N(h,\Sigma/\lambda),\qquad
X^{\rm d}\sim N(h,\Sigma/(1-\lambda)),\qquad
\operatorname{Cov}(X^{\rm s},X^{\rm d})=0. \tag{5}
\]
The joint characteristic function in (5) has block-diagonal quadratic exponent, so it factors; hence the two vectors are independent.  Form the nonempty screened set
\[
\widehat S=\left\{i\in A:X_i^{\rm s}\geq\max_{j\in A}X_j^{\rm s}-T\right\}. \tag{6}
\]
Conditional on \(\widehat S=S\), apply the compact \(S\)-selector to \(\sqrt{1-\lambda}\,X_S^{\rm d}\).  This observation has covariance \(\Sigma_{SS}\) and mean \(\sqrt{1-\lambda}\,h_S\).  Equations (4)--(6) therefore define a measurable randomized selector using only the original Gaussian observation and auxiliary randomization.  It is invariant under addition of a common constant.

Let \(b\) be a fixed maximizer of \(h\), put \(d_i=h_b-h_i\geq0\), and write \(\xi^{\rm s}=X^{\rm s}-h\).  Every contrast \(\xi_i^{\rm s}-\xi_j^{\rm s}\) has standard deviation at most \(a_\lambda\).  If \(b\notin\widehat S\) and \(J\) is a maximizing coordinate of \(X^{\rm s}\), then \(X_J^{\rm s}-X_b^{\rm s}>T\), while
\[
h_b-\max_{i\in\widehat S}h_i\leq d_J.
\]
For \(x>0\), integration of \(-\varphi'(u)=u\varphi(u)\) gives
\[
\Phi(-x)=\int_x^\infty\varphi(u)\,du
\leq x^{-1}\int_x^\infty u\varphi(u)\,du
=\frac{\varphi(x)}{x}. \tag{7}
\]
For a centered normal variable of standard deviation \(a\leq a_\lambda\), (7) yields
\[
d_i\Pr\{\xi_i^{\rm s}-\xi_b^{\rm s}>T+d_i\}
\leq a\varphi(T/a)
\leq \frac{a_\lambda}{\sqrt{2\pi}}
       \exp\!\left\{-\frac{T^2}{2a_\lambda^2}\right\}. \tag{8}
\]
The last inequality follows because \(a\mapsto a\exp\{-T^2/(2a^2)\}\) is increasing.  Summing (8) bounds the expected loss from deleting all true maximizers by \((d-1)a_\lambda(2\pi)^{-1/2}\exp\{-T^2/(2a_\lambda^2)\}\).

It remains to control a retained set whose true range exceeds \(2T\).  If \(i,j\in\widehat S\), then \(|X_i^{\rm s}-X_j^{\rm s}|\leq T\).  Hence, whenever \(h_j-h_i=D>2T\) and both arms are retained,
\[
\xi_i^{\rm s}-\xi_j^{\rm s}\geq D-T\geq D/2.
\]
Using (7) again,
\[
D\Pr\{\xi_i^{\rm s}-\xi_j^{\rm s}\geq D-T\}
\leq 2a_\lambda(2\pi)^{-1/2}
       \exp\!\left\{-\frac{T^2}{2a_\lambda^2}\right\}. \tag{9}
\]
The range of a bad retained set is bounded by the sum of the oriented pairwise gaps that exceed \(2T\).  Summing (9) over at most \(d(d-1)/2\) pairs and adding (8) is bounded by the stated, slightly enlarged, tail term.

On the complementary event, the true range within \(S=\widehat S\) is at most \(2T\).  Therefore
\[
\left\lVert\left[\sqrt{1-\lambda}\,h_S\right]\right\rVert_S
\leq2\sqrt{1-\lambda}\,T\sqrt{|S|-1}=M_S. \tag{10}
\]
The screen is independent of \(X^{\rm d}\), so conditioning on \(\widehat S=S\) does not change the decision observation law.  By (10) and the assumed compact certificate, the conditional within-set regret, in the original scale, is at most
\[
(1-\lambda)^{-1/2}\{G_{S,M_S}(v_S,r_S)+\eta\}. \tag{11}
\]
The events \(\{\widehat S=S\}\) partition the sample space, so averaging (11) costs the maximum over \(S\), not the sum.  Combining (8)--(11) proves the upper bound.  All constants use only \(d\) and the uniform upper bound \(\bar\sigma\), which proves uniformity on compact positive-variance cells.
