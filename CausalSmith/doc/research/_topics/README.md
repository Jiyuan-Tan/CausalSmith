# Topic-selection rounds

Working records of how research topics were chosen, one folder per selection round:
`<YYYYMMDD-HHMMSS>_<label>/` holding the slate, the search and collision checks, deep-read
notes, gate prompts and verdicts, and presolve receipts. Downloaded papers sit in a round's
`sources/` subfolder.

Git ignores this folder. Its contents are published with the run-record dataset, without
`sources/`; `scripts/fetch_runs.sh topics` brings the published rounds back. The
`causalsmith-topics` skill writes here.

`mill_2026-09/<window>/` holds the rounds of the September 2026 paper mill, one folder per
agent window.
