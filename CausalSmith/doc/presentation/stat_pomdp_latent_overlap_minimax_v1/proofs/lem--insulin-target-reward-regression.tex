\begin{proof}[Proof of \cref{obj:lem:insulin-target-reward-regression}]
Fix \(s=(g,d_1,d_2,x_1,x_2,a_1)\in\mathsf S_{\mathrm{grid}}\) and abbreviate
\[
g_e(s)
:=
\sum_{a\in\{0,1\}} e(a\mid x(s))\int p_1\,K_T(dp\mid s,a).
\]
By the definition of the target-policy reward regression, the left-hand side of the claimed identity is \(g_e(s)\). % lean: CausalSmith.Stat.PomdpLatentOverlapMinimax.rewardRegression

For each \(a\in\{0,1\}\), the embedded insulin kernel assigns the reward coordinate according to the current glucose component of \(s\). Hence its conditional reward mean is
\[
\int p_1\,K_T(dp\mid s,a)
=
r_{\mathrm{ins}}(s).
\]
Indeed, \cref{obj:def:insulin-grid} makes the reward coordinate a deterministic function of the present state, with the displayed values defining \(r_{\mathrm{ins}}\); the subsequent randomization affects the next state coordinates but not this reward coordinate. % lean: CausalSmith.Stat.PomdpLatentOverlapMinimax.insulinEmbeddedKernel_rewardMean

Substituting this identity into the regression gives
\[
g_e(s)
=
\sum_{a\in\{0,1\}} e(a\mid x(s))\,r_{\mathrm{ins}}(s)
=
\left(\sum_{a\in\{0,1\}} e(a\mid x(s))\right) r_{\mathrm{ins}}(s).
\]
The target policy in \cref{obj:def:insulin-grid} is a probability vector on \(\{0,1\}\): if \(g\ge 125\), then \(e(1\mid x(s))=1\) and \(e(0\mid x(s))=0\), while if \(g<125\), then \(e(1\mid x(s))=0\) and \(e(0\mid x(s))=1\). Therefore
\[
\sum_{a\in\{0,1\}} e(a\mid x(s))=1,
\]
and consequently \(g_e(s)=r_{\mathrm{ins}}(s)\). % lean: CausalSmith.Stat.PomdpLatentOverlapMinimax.insulinGrid_policyOverlap

This is the asserted identity. % lean: CausalSmith.Stat.PomdpLatentOverlapMinimax.insulinTargetRewardRegression
\end{proof}
