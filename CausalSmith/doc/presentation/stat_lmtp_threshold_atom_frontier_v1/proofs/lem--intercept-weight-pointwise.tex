\begin{proof}[Proof of \cref{obj:lem:intercept-weight-pointwise}]
Let
\[
N=N_x,\qquad
a=\frac{\lambda_\star N}{2}.
\]
On \(\Omega_x\), \(N>0\); together with \(\lambda_\star>0\), this gives \(a>0\).  The good-design inequality states that
\[
a\|b\|_2^2\le b^\top G_xb
\qquad\text{for every }b\in\mathbb R^{\ell+1}.
\]
% lean: GoodGramEvent

First suppose that \(i\) is active, meaning \(i\in I_2\), \(X_i=x\), and \(U_i\in[0,1]\).  Put
\[
s=v_\ell(U_i),\qquad \xi_i=G_x^{-1}s\in\mathbb R^{\ell+1}.
\]
The coercivity inequality implies the inverse bound
\[
\|G_x^{-1}s\|_2\le a^{-1}\|s\|_2 .
\]
Indeed, \(G_x\xi_i=s\), so
\[
a\|\xi_i\|_2^2\le \xi_i^\top G_x\xi_i=\xi_i^\top s\le \|\xi_i\|_2\|s\|_2,
\]
and division by \(\|\xi_i\|_2\) is harmless, with the case \(\|\xi_i\|_2=0\) immediate. % lean: coerciveMatrix_inv_mulVec_euclidean_le

By \cref{obj:lem:intercept-weight-formula},
\[
|w_{ix}|
=
\left|(G_x^{-1}s)_0\right|
\le
\|G_x^{-1}s\|_2
\le
a^{-1}\|s\|_2 .
\]
Since \(U_i\in[0,1]\),
\[
\|s\|_2^2
=
\sum_{j=0}^{\ell}U_i^{2j}
\le
\ell+1,
\]
and hence
\[
|w_{ix}|
\le
\left(\frac{\lambda_\star N_x}{2}\right)^{-1}\sqrt{\ell+1}.
\]
% lean: goodGram_interceptWeight_pointwise

If \(i\) is inactive, then the local kernel factor in the weight is zero on \(\Omega_x\), so
\[
w_{ix}=0,
\]
and the same bound follows because the right side is nonnegative. % lean: interceptWeight_eq_zero_of_inactive
\end{proof}
