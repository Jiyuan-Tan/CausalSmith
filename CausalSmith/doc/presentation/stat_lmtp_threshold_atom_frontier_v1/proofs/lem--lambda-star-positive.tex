\begin{proof}[Proof of \cref{obj:lem:lambda-star-positive}]
By \cref{obj:lem:shifted-moment-coercivity}, there is a constant
\(c=c(\ell,\kappa)>0\) such that, for every \(\rho\ge0\) and every
\(z\in\mathbb R^{\ell+1}\),
\[
c\sum_{j=0}^{\ell}z_j^2
\le
z^\top M_{\ell,\kappa,\rho}z .
\] % lean: uniform_shifted_power_moment_coercivity

Taking the infimum over all unit vectors gives
\[
c\le \lambda_{\min}(M_{\ell,\kappa,\rho})
\qquad\text{for every }\rho\ge0 .
\] % lean: lambdaStar_pos

The indexing set \(\{\rho:\rho\ge0\}\) is nonempty, so
\[
c
\le
\inf_{\rho\ge0}\lambda_{\min}(M_{\ell,\kappa,\rho}).
\] % lean: lambdaStar_pos

Because \(c_->0\) and \(c_+>0\),
\[
\lambda_\star(\ell,\kappa,c_-,c_+)
=
\frac{c_-}{c_+}\inf_{\rho\ge0}
\lambda_{\min}(M_{\ell,\kappa,\rho})
\ge
\frac{c_-}{c_+}c
>
0 .
\] % lean: lambdaStar_pos
\end{proof}
