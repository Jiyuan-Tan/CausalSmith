\begin{proof}[Proof of \cref{obj:lem:good-gram-weights}]
Write
\[
        \lambda=\lambda_\star(\ell,\kappa,c_-,c_+),
        \qquad
        N=N_x,
        \qquad
        G=G_x .
\]
On \(\Omega_x\), \(\lambda>0\), \(N>0\), and
\[
        v^\top Gv\ge \frac{\lambda N}{2}\sum_{r=0}^{\ell}v_r^2
        \qquad\text{for every }v\in\mathbb R^{\ell+1}.
\]
Thus \(G\) is nonsingular: if \(Gv=0\), the coercivity bound \(v^\top Gv\ge(\lambda N/2)\sum_r v_r^2\) with \(\lambda N>0\) forces \(\sum_r v_r^2=0\), hence \(v=0\).  The resulting monomial identity is the good-Gram reproduction statement in \cref{obj:lem:good-gram-reproduction}. % lean: coerciveMatrix_isUnit

For active observations \(i\in I_2\) with \(X_i=x\) and \(0\le U_i\le1\), the weight is
\[
        w_{ix}=e_0^\top G^{-1}v_\ell(U_i),
\]
and all inactive terms in the sum over \(I_2\) have weight \(0\).  Therefore, for \(j=0,\ldots,\ell\),
\[
\begin{aligned}
\sum_{i\in I_2} w_{ix}U_i^j
&=
e_0^\top G^{-1}
\sum_{i\in I_2}
\mathbf 1\{X_i=x,\ 0\le U_i\le1\}v_\ell(U_i)U_i^j  \\
&=
e_0^\top G^{-1}G e_j
=
\mathbf 1\{j=0\}.
\end{aligned}
\]
% lean: goodGram_reproduction

Next let \(a=\lambda N/2\).  The pointwise conclusion to be used is \cref{obj:lem:intercept-weight-pointwise}.  For an active \(i\), set \(s_i=v_\ell(U_i)\) and \(z_i=G^{-1}s_i\).  Coercivity and Cauchy--Schwarz give
\[
        a\|z_i\|_2^2
        \le z_i^\top Gz_i
        = z_i^\top s_i
        \le \|z_i\|_2\|s_i\|_2,
\]
hence
\[
        \|G^{-1}s_i\|_2\le a^{-1}\|s_i\|_2 .
\]
Since \(0\le U_i\le1\),
\[
        \|s_i\|_2^2=\sum_{r=0}^{\ell}U_i^{2r}\le \ell+1,
\]
and therefore
\[
        |w_{ix}|
        \le
        \left(\frac{\lambda N}{2}\right)^{-1}\sqrt{\ell+1}
\]
for every active \(i\), while inactive weights vanish. % lean: goodGram_interceptWeight_pointwise

The number of active indices is \(N\).  Summing the pointwise bound gives
\[
        \sum_{i\in I_2}|w_{ix}|
        \le
        N\left(\frac{\lambda N}{2}\right)^{-1}\sqrt{\ell+1}
        =
        \frac{2\sqrt{\ell+1}}{\lambda}.
\]
Squaring the same pointwise bound and summing gives
\[
        \sum_{i\in I_2}w_{ix}^2
        \le
        N\left(\frac{\lambda N}{2}\right)^{-2}(\ell+1)
        =
        \frac{4(\ell+1)}{\lambda^2N}.
\]
% lean: goodGram_weight_controls
\end{proof}
