\begin{proof}[Proof of \cref{obj:lem:latent-arm-weight-invertibility}]
Fix \(t\in\{0,1\}\). For a latent coordinate \(u\in\{1,\ldots,k\}\), set
\[
\mathsf{cell}_{u,t}:=\{U=u,\ T=t\},
\qquad
\mathsf{arm}_{t}:=\{T=t\},
\qquad
\gamma_{u,t}:=\frac{P(\mathsf{cell}_{u,t})}{P(\mathsf{arm}_t)} .
\]
By the definition of \(\Gamma_t\), this matrix is diagonal and its \(u\)th diagonal entry is \(\gamma_{u,t}\). % lean: latentArmWeights

We first show that every diagonal entry is bounded below by the positivity margin. By \cref{obj:ass:latent-arm-positivity},
\[
\pi_0\le P(\mathsf{cell}_{u,t}).
\]
Moreover \(\mathsf{cell}_{u,t}\subseteq \mathsf{arm}_t\), so monotonicity gives
\[
P(\mathsf{cell}_{u,t})\le P(\mathsf{arm}_t).
\]
Together with \(\pi_0>0\), this implies
\[
0<P(\mathsf{arm}_t).
\]
Since \(P\) is a probability law,
\[
P(\mathsf{arm}_t)\le 1.
\]
Hence, using \(\pi_0>0\),
\[
\pi_0 P(\mathsf{arm}_t)
\le \pi_0
\le P(\mathsf{cell}_{u,t}).
\]
Dividing by the positive number \(P(\mathsf{arm}_t)\) yields
\[
\pi_0
\le
\frac{P(\mathsf{cell}_{u,t})}{P(\mathsf{arm}_t)}
=
\gamma_{u,t}.
\]
In particular \(\gamma_{u,t}>0\), so \(\gamma_{u,t}\ne0\). % lean: latentArmWeight_lower

Now let \(x,y\in\mathbb R^k\) and suppose \(\Gamma_t x=\Gamma_t y\). Taking the \(u\)th coordinate and using diagonality gives
\[
\gamma_{u,t}x_u=\gamma_{u,t}y_u .
\]
Since \(\gamma_{u,t}\ne0\), cancellation gives
\[
x_u=y_u .
\]
This holds for every latent coordinate \(u\), and therefore \(x=y\). Thus the linear map induced by \(\Gamma_t\) is injective. % lean: latentArmWeights_injective
\end{proof}
