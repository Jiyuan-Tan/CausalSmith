\section{Confidence sets, cluster reports, and ordered weights}

The root-\(n\) law estimators from \cref{obj:thm:collision-uniform-root-n} lead directly to confidence reporting for the quotient law of latent-class average treatment effects. The first construction keeps two complementary objects in view: an exact repaired-image set of nearby feasible summaries through the repaired summary map, and a lattice-centered finitely represented exact-real \(W_1\) outer set with an atom-floor restriction. The exact-real operation model is fixed-dimensional and unit-cost, with arithmetic, comparison, singular-value, polar-decomposition, and fixed-degree root-isolation primitives counted as the operations certified in \cref{obj:synth_16,obj:prop:polynomial-net-law-estimator}. This follows the econometric logic of confidence sets obtained by inverting sample restrictions \citep{RobinsVanDerVaart2006}, with the reporting metric adapted to discrete laws as in Wasserstein approaches to mixture uncertainty \citep{DeoRandrianarisoa2023}.

\begin{algorithmv}{def:wasserstein-confidence-set}[Wasserstein confidence set \(\mathcal C^{\mathrm{alg}}_{n,\alpha}\)]
The inputs are fixed \(k,d_x,d_z,n\in\mathbb N\), constants \(L,\pi_0,\sigma_0,\alpha,C_0,C_{\mathrm{lat}}\in\mathbb R\), an observed sample \(\omega\in O_{d_x,d_z}^n\) with empirical summary \(\widehat S_n\), repair data \((\overline F,\Pi)\) on \(\mathcal K\), and a prescribed structured-lattice estimator.
\begin{enumerate}
\item The fixed constants satisfy
\[
0<k,\qquad 0<n,\qquad 1\le L,\qquad
0<\pi_0\le (2k)^{-1},\qquad
0<\alpha<\frac12,\qquad
1\le C_0,\qquad 0<C_{\mathrm{lat}}.
\]
Define the effect-support radius and assume its nonnegativity:
\[
L_\tau:=\frac{4L\sqrt{d_z}}{\sigma_0},\qquad 0\le L_\tau.
\]
\item Define the simultaneous concentration radius by
\[
r_{n,\alpha}:=C_0L\sqrt{\frac{\log(C_0/\alpha)}{n}}.
\]
\item The repair data satisfy: \(\overline F\) is continuous on \(\mathcal K\) and extends the summary-to-quotient-law map on model summaries; \(\Pi\) is measurable; if \(\mathcal K\ne\varnothing\), then
\[
\Pi(s)\in\operatorname*{argmin}_{q\in\mathcal K}d_S(q,s);
\]
if \(\mathcal K=\varnothing\), then
\[
\Pi(s)=0;
\]
and the induced repaired estimator is measurable.
\item Let \(\widehat\lambda_n\) be the valid \(k\)-atomic law returned at \(\omega\) by the measurable prescribed structured-lattice estimator at support radius \(L_\tau\), generated by an exhaustive duplicate-free lexicographically ordered list of well-formed \(H_n,q_n\) lattice candidates and the first lexicographic minimizer of \(J_n(\vartheta;\widehat S_n)\) with threshold
\[
\frac{\pi_0\sigma_0^2}{2}.
\]
\item Define the original summary-inversion confidence set by
\[
\mathcal C_{n,\alpha}:=
\begin{cases}
\{\overline F(q):q\in\mathcal K,\ d_S(q,\Pi(\widehat S_n))\le2r_{n,\alpha}\},&\mathcal K\ne\varnothing,\\
\{\delta_0\},&\mathcal K=\varnothing.
\end{cases}
\]
\item Define the atom-floor constant and computable radius by
\[
m_\star:=\pi_0,\qquad
R_{n,\alpha}:=C_{\mathrm{lat}}\left(r_{n,\alpha}+(\sqrt n)^{-1}\right).
\]
\item Define the atom-floor subclass by
\[
\mathcal P_{\le k,m_\star}([-L_\tau,L_\tau])
:=
\{\xi\in\mathcal P_{\le k}([-L_\tau,L_\tau]):
\operatorname{AtomFloor}(m_\star,\xi)\}.
\]
\item Output the computable Wasserstein confidence set
\[
\mathcal C^{\mathrm{alg}}_{n,\alpha}
:=
\{\xi\in\mathcal P_{\le k}([-L_\tau,L_\tau]):
\operatorname{AtomFloor}(m_\star,\xi),\
W_1(\xi,\widehat\lambda_n)\le R_{n,\alpha}\}.
\]
\end{enumerate}
\end{algorithmv}

\Cref{obj:def:wasserstein-confidence-set} defines the exact repaired-image summary-inversion set \(\mathcal C_{n,\alpha}\) and the lattice-centered outer set \(\mathcal C^{\mathrm{alg}}_{n,\alpha}\). The radius \(R_{n,\alpha}\) combines the concentration scale \(r_{n,\alpha}\) with the lattice mesh scale, while the atom floor \(m_\star=\pi_0\) carries the latent-arm positivity margin into the represented-law class. The lattice-centered set is finitely represented by the empirical lattice center, the transport metric, and fixed finite-dimensional constraints in the exact-real model.

The computational guarantee is an exact-real finite-representation statement. In the fixed-dimensional unit-cost model used in \cref{obj:synth_16,obj:prop:polynomial-net-law-estimator}, the lattice search has polynomial candidate growth and exact evaluation over the stated primitive operations. The constrained representation of \(\mathcal C^{\mathrm{alg}}_{n,\alpha}\) gives finite atom, mass, and transport-plan constraints for membership and endpoint formulations. The exact repaired-image set \(\mathcal C_{n,\alpha}\) is represented through \(\overline F\) on the compact repaired summary image, and \cref{obj:oeq:constructive-total-repair} records the polynomial-time exact-image problem for that original repaired set.

\begin{algorithmv}{def:cluster-report}[Cluster report \(\mathfrak R_{n,\alpha}\)]
The cluster report is computed from \(\widehat S_n\), \(S(P)\), \(r_{n,\alpha}\), \(R_{n,\alpha}\), \(m_\star\), \(\widehat\lambda_n\), and \(\mathcal C^{\mathrm{alg}}_{n,\alpha}\) as follows.
\begin{enumerate}
\item Define the simultaneous concentration event and association radius by
\[
E_P:=\{d_S(\widehat S_n,S(P))\le r_{n,\alpha}\},
\qquad
\rho_{n,\alpha}:=\frac{R_{n,\alpha}}{m_\star}.
\]
\item Merge repeated atoms of \(\widehat\lambda_n\). Join two distinct support points whenever their distance is at most \(4\rho_{n,\alpha}\), and define
\[
\widehat{\mathscr K}_{n,\alpha}
\]
as the set of connected components of the resulting graph.
\item For each \(C\in\widehat{\mathscr K}_{n,\alpha}\), define the associated true and candidate support sets by
\[
K_C(P):=\{x\in\operatorname{supp}(\nu_P):\operatorname{dist}(x,C)\le\rho_{n,\alpha}\},
\qquad
K_C(\xi):=\{x\in\operatorname{supp}(\xi):\operatorname{dist}(x,C)\le\rho_{n,\alpha}\}.
\]
\item Define the mass interval by
\[
I_C:=\left[
\inf_{\xi\in\mathcal C^{\mathrm{alg}}_{n,\alpha}}\xi(K_C(\xi)),
\sup_{\xi\in\mathcal C^{\mathrm{alg}}_{n,\alpha}}\xi(K_C(\xi))
\right].
\]
In the ordered-support and transport-plan representation of \(\mathcal C^{\mathrm{alg}}_{n,\alpha}\), each endpoint is the value of a finite union of fixed-dimensional mixed-integer constrained programs. For each \(1\le r\le k\), introduce binary variables
\[
z_a\in\{0,1\},\qquad 1\le a\le r,
\]
with
\[
z_a=1\quad\Longleftrightarrow\quad \min_{c\in C}|x_a-c|\le\rho_{n,\alpha},
\]
and minimize or maximize
\[
\sum_{a=1}^r w_a z_a
\]
subject to the ordered-support, atom-floor, simplex, and transport constraints defining \(\mathcal C^{\mathrm{alg}}_{n,\alpha}\).
\item Output the report
\[
\mathfrak R_{n,\alpha}
:=
\left\{
\left(
C,\,
[\min C-\rho_{n,\alpha},\max C+\rho_{n,\alpha}],\,
I_C
\right):
C\in\widehat{\mathscr K}_{n,\alpha}
\right\}.
\]
For each component \(C\), define the external true-support gap by
\[
\Delta_C(P):=\inf\{|x-y|:x\in K_C(P),\ y\in\operatorname{supp}(\nu_P)\setminus K_C(P)\},
\]
with value \(+\infty\) when \(\operatorname{supp}(\nu_P)\setminus K_C(P)=\emptyset\).
\end{enumerate}
\end{algorithmv}

The cluster report has a sample-facing layer and a theorem-side validation layer. The sample-facing output is formed from the observed \(\widehat S_n\), the supplied constants, the lattice center \(\widehat\lambda_n\), and the constrained class \(\mathcal C^{\mathrm{alg}}_{n,\alpha}\): it merges empirical support points at threshold \(4\rho_{n,\alpha}\), expands each component by \(\rho_{n,\alpha}\), and computes mass endpoints over the same constrained class. The true-law symbols \(S(P)\), \(E_P\), \(K_C(P)\), and \(\Delta_C(P)\) name the concentration event, associated true support block, and external separation scale used to state coverage and width.

\Cref{obj:thm:honest-root-n-confidence} establishes simultaneous coverage for both confidence constructions over the uniformly conditioned model class. The statement also gives samplewise nonemptiness and \(W_1\)-diameter bounds, so the reported law-level uncertainty has root-\(n\) scale under the same constants that control the estimator in \cref{obj:prop:polynomial-net-law-estimator}.

The mechanism is the combination of summary concentration and the gap-free modulus. On the event that \(\widehat S_n\) lies within \(r_{n,\alpha}\) of \(S(P)\), the feasible-summary set includes a summary whose image is \(\nu_P\), and the structured-lattice center lies within the radius used to form \(\mathcal C^{\mathrm{alg}}_{n,\alpha}\). The transport representation in the theorem gives a finite-dimensional constrained problem over atom locations, masses, and couplings.

Law-level confidence sets can be difficult to read directly when nearby support points are statistically unresolved. The next construction converts the \(W_1\) set into a component report: estimated support points are connected at threshold \(4\rho_{n,\alpha}\), and the mass attached to each empirical component is summarized by an interval over the same constrained confidence class.

\begin{algorithmv}{def:labeled-weight-estimator}[Ordered-weight estimator \(\widehat p_n^{\uparrow}\)]
The input is the positive estimated atomic law \(\widehat\nu_n\) on \([-L_\tau,L_\tau]\).

\begin{enumerate}
\item Write \(\widehat\nu_n\) uniquely in increasing support order as
\[
\widehat\nu_n
=
\sum_{\ell=1}^{\widehat s_n}
\widehat w_{\ell,n}\delta_{\widehat\tau_{\ell,n}},
\qquad
\widehat\tau_{1,n}<\cdots<\widehat\tau_{\widehat s_n,n},
\qquad
\widehat w_{\ell,n}>0 .
\]

\item Output the ordered-weight estimator
\[
\widehat p_n^{\uparrow}
=
\begin{cases}
(\widehat w_{1,n},\ldots,\widehat w_{k,n}), & \widehat s_n=k,\\[2mm]
(1/k,\ldots,1/k), & \widehat s_n<k .
\end{cases}
\]
\end{enumerate}

Ordering the finitely many support points and extracting their jump sizes are Borel operations, so \(\widehat\nu_n\mapsto\widehat p_n^{\uparrow}\) is a total Borel map into \(\Delta^{k-1}\).
\end{algorithmv}

The report \(\mathfrak R_{n,\alpha}\) replaces individual estimated atoms by empirical components formed at connection threshold \(4\rho_{n,\alpha}\). For each component \(C\), the support interval expands the component by \(\rho_{n,\alpha}\), and the mass interval \(I_C\) ranges over all laws in \(\mathcal C^{\mathrm{alg}}_{n,\alpha}\) whose atoms can be transported to the lattice center within \(R_{n,\alpha}\). The external gap \(\Delta_C(P)\) is the separation scale relevant to the component's aggregate mass.

\begin{theoremv}{thm:honest-root-n-confidence}[Honest root-\(n\) confidence]
Fix integers \(k,d_x,d_z\) and constants \(\pi_0,\sigma_0\) such that
\[
2\le k,\qquad k\le d_x,\qquad k\le d_z,\qquad
0<\pi_0\le {1\over 2k},\qquad 0<\sigma_0\le 1 .
\]
There exists a simultaneous-concentration constant \(C_0\ge 1\) such that, for every boundedness radius \(L\ge 1\), there is a constant \(C_{\mathrm{mod}}>0\) for which the prescribed structured-lattice constant \(C_{\mathrm{lat}}\) is positive and the following holds.  For every sample size \(n\ge 1\), there exist:
\begin{itemize}
\item \textbf{(Structured lattice estimator.)} a measurable estimator \(\widehat\lambda_n\) taking values in \(\mathcal P_k([-L_\tau,L_\tau])\), generated by a finite exhaustive list of well-formed structured-lattice candidates, ordered lexicographically, with \(\widehat\lambda_n\) equal to the effect law of the first lexicographic minimizer of the structured-lattice criterion;
\item \textbf{(Summary repair data.)} a continuous extension \(\overline F\) on the summary closure \(\mathcal K\), a measurable nearest-summary selector \(\Pi\) with its empty-closure fallback, and the associated measurable repaired summary-to-law map.
\end{itemize}
For every miscoverage level \(\alpha\) satisfying
\[
0<\alpha< {1\over 2},
\]
let \(\mathcal C_{n,\alpha}\), \(R_{n,\alpha}\), and \(\mathcal C^{\mathrm{alg}}_{n,\alpha}\) be the confidence-set objects of \cref{obj:def:wasserstein-confidence-set} formed from this repair data and this structured-lattice estimator, with \(m_\star=\pi_0\) and center \(\widehat\lambda_n\).  Then, on every sample, both \(\mathcal C_{n,\alpha}\) and \(\mathcal C^{\mathrm{alg}}_{n,\alpha}\) are nonempty, and \(\mathcal C^{\mathrm{alg}}_{n,\alpha}\) has the finite constrained transport representation
\[
\nu\in\mathcal C^{\mathrm{alg}}_{n,\alpha}
\quad\Longleftrightarrow\quad
\operatorname{AtomFloor}(\pi_0,\nu)\ \text{and there exists a transport plan }\gamma\text{ from }\nu\text{ to }\widehat\lambda_n
\text{ with cost at most }R_{n,\alpha}.
\]
Moreover, for every full-data probability law \(P\in\mathcal M\) in \cref{obj:def:model-class},
\[
1-\alpha
\le
Q_P^{(n)}
\left\{
\nu_P\in\mathcal C_{n,\alpha}\cap\mathcal C^{\mathrm{alg}}_{n,\alpha}
\right\}.
\]
Finally, on every sample,
\[
\operatorname{diam}_{W_1}(\mathcal C_{n,\alpha})
\le
4C_{\mathrm{mod}}\, r_{n,\alpha},
\qquad
\operatorname{diam}_{W_1}(\mathcal C^{\mathrm{alg}}_{n,\alpha})
\le
2R_{n,\alpha}.
\]
\end{theoremv}

\Cref{obj:thm:cluster-adaptive-report} establishes the coverage and width properties of the component report on the concentration event. Every true support point is assigned to a unique empirical component, the reported support interval contains the associated true atom, and the reported mass interval contains the true aggregate component mass. When a component is separated from the remaining true support by \(\Delta_C(P)\), the mass-interval length contracts at the displayed inverse-gap scale.

The report is adaptive because transport cost controls how much mass can cross a gap. If estimated support points connected to nearby true atoms fall within the \(4\rho_{n,\alpha}\) component threshold, the construction pools them and reports aggregate mass. When a component is externally separated, moving mass across that separation consumes \(W_1\) budget, and the interval width reflects the ratio between the available radius and the external gap.

The final object in this section returns to effect-ordered latent weights. The quotient law treats coincident class-average effects as a single atom, while the ordered-weight target attaches masses to effect ranks on a gap-local stratum. The estimator below applies the repaired law construction and then orders the labelled representative when all labelled atoms are positive and distinct.

\begin{theoremv}{thm:cluster-adaptive-report}[Cluster-adaptive report validity]
Let \(k,d_x,d_z\in\mathbb N\), \(\pi_0\in\mathbb R\), and \(\sigma_0\in\mathbb R\).  Suppose that
\begin{itemize}
\item \textbf{(Dimensions.)} \(2\le k\), \(k\le d_x\), and \(k\le d_z\).
\item \textbf{(Latent mass.)} \(0<\pi_0\le 1/(2k)\).
\item \textbf{(Rank margin.)} \(0<\sigma_0\le 1\).
\end{itemize}
Then there is a simultaneous-concentration constant \(C_0\ge 1\) such that, for every \(L\ge 1\), if
\[
L_\tau=\frac{4L\sqrt{d_z}}{\sigma_0},
\]
and
\[
\begin{gathered}
s_0=\pi_0\sigma_0^2,\qquad
c_V=4\sqrt{d_xk},\qquad
K_D=\frac{4\sqrt{k}LL_\tau}{\sigma_0},\\
A_D=\frac{8}{3s_0}+\frac{32L}{s_0^2},\qquad
K_f=\frac{16\sqrt{d_x}kL^2}{\sigma_0^2},\\
c_D=2K_Dc_V+\frac{4k\sqrt{k}LL_\tau}{\sigma_0^2}
      +\frac{2\sqrt{k}L}{\sigma_0}+\frac{kL_\tau}{\sigma_0},\\
c_m=2\sqrt{k}Lc_V+k+kL,\qquad
c_b=k+2\sqrt{k}Lc_V,\\
c_{\mathrm{grid}}=c_D+c_m+c_b,\qquad
B_{\mathrm{lat}}=2(A_D+1)+c_{\mathrm{grid}},
\end{gathered}
\]
then the prescribed structured-lattice stability constant
\[
C_{\mathrm{lat}}
=
\max\left\{
\frac{8L_\tau}{s_0},
\,
(L_\tau+K_D+LK_f)B_{\mathrm{lat}}
\right\}
\]
is positive.  For every \(n\ge 1\), there exist a measurable structured-lattice estimator
\(\widehat\lambda_n\) and repair data consisting of a continuous extension on \(\mathcal K\) and a Borel nearest-summary selector, such that \(\widehat\lambda_n\) is obtained from an exhaustive lexicographically ordered finite list of well-formed structured-lattice candidates by choosing the first minimizer of \(J_n(\vartheta;\widehat S_n)\).

For every \(\alpha\) with \(0<\alpha<1/2\), the estimator has atom floor \(\pi_0\).  Moreover, for every \(P\in\mathcal M\) in \cref{obj:def:model-class} and every sample,
\[
W_1\!\left(\widehat\lambda_n,\nu_P\right)
\le
C_{\mathrm{lat}}
\left\{
d_S\!\left(\widehat S_n,S(P)\right)+\frac{1}{\sqrt n}
\right\}.
\]
Define
\[
r_{n,\alpha}
=
C_0L\sqrt{\frac{\log(C_0/\alpha)}{n}},
\qquad
R_{n,\alpha}
=
C_{\mathrm{lat}}\left(r_{n,\alpha}+\frac{1}{\sqrt n}\right),
\qquad
\rho_{n,\alpha}=\frac{R_{n,\alpha}}{\pi_0},
\]
with \(\widehat S_n\) as in \cref{obj:def:empirical-summary}, and set
\[
E_P=\left\{\omega:
d_S\!\left(\widehat S_n(\omega),S(P)\right)\le r_{n,\alpha}
\right\}.
\]
Then
\[
Q_P^{(n)}(E_P)\ge 1-\alpha.
\]
For every sample \(\omega\in E_P\), the cluster report \(\mathfrak R_{n,\alpha}\) centered at \(\widehat\lambda_n(\omega)\) satisfies the following properties for the representative atomic law \(\nu_P\):
\begin{itemize}
\item \textbf{(Partition.)} Each support point \(x\in\operatorname{supp}(\nu_P)\) belongs to a unique empirical component \(C\in\widehat{\mathscr K}_{n,\alpha}\) with \(x\in K_C(P)\).
\item \textbf{(Association.)} For every \(C\in\widehat{\mathscr K}_{n,\alpha}\), the set \(K_C(P)\) is nonempty and is contained in \(\operatorname{supp}(\nu_P)\).
\item \textbf{(Support interval.)} If \(C\in\widehat{\mathscr K}_{n,\alpha}\) and \(x\in K_C(P)\), then \(x\) lies in the reported support interval for \(C\).
\item \textbf{(Mass interval.)} If \(C\in\widehat{\mathscr K}_{n,\alpha}\), then the reported mass interval \(I_C\) contains \(\nu_P(K_C(P))\).
\item \textbf{(Singleton width.)} If \(C\in\widehat{\mathscr K}_{n,\alpha}\) and \(\operatorname{card}(K_C(P))=1\), then the reported support interval for \(C\) has length at most \(4\rho_{n,\alpha}\), and
\[
\operatorname{length}(I_C)
\le
\frac{8}{\pi_0}
\min\left\{1,\frac{R_{n,\alpha}}{\delta(P)}\right\}.
\]
\item \textbf{(External-gap width.)} If \(C\in\widehat{\mathscr K}_{n,\alpha}\) and \(\Delta_C(P)=+\infty\), then \(\operatorname{length}(I_C)=0\).  For every \(C\in\widehat{\mathscr K}_{n,\alpha}\),
\[
\operatorname{length}(I_C)
\le
\frac{8}{\pi_0}
\min\left\{1,\frac{R_{n,\alpha}}{\Delta_C(P)}\right\},
\]
with the displayed right side read as zero when \(\Delta_C(P)=+\infty\).
\item \textbf{(Constrained representation.)} The computable class
\(\mathcal C^{\mathrm{alg}}_{n,\alpha}\) has the finite constrained-program representation
\[
\xi\in\mathcal C^{\mathrm{alg}}_{n,\alpha}
\quad\Longleftrightarrow\quad
\operatorname{AtomFloor}(\pi_0,\xi)
\ \text{and}\ 
\exists\gamma\ \text{with transport cost at most } R_{n,\alpha}
\text{ from }\xi\text{ to }\widehat\lambda_n(\omega).
\]
\end{itemize}
\end{theoremv}

\Cref{obj:def:labeled-weight-estimator} defines \(\widehat p_n^{\uparrow}\) as a simplex-valued ordered-weight rule derived from the repaired quotient-law estimator. Its target is \(p^{\uparrow}(P)\) from \cref{obj:def:ordered-mass-target}, so the relevant population domain is the gap-local stratum \(\mathcal M(g)\) in \cref{obj:def:gap-stratum}.

\begin{theoremv}{thm:labeled-weight-upper}[Ordered-weight upper bound]
Let \(k,d_x,d_z\in\mathbb N\) and \(L,\pi_0,\sigma_0\in\mathbb R\).  Assume:
\begin{itemize}
\item \textbf{(Latent size.)} \(2\le k\).
\item \textbf{(Proxy dimensions.)} \(k\le d_x\) and \(k\le d_z\).
\item \textbf{(Envelope.)} \(1\le L\).
\item \textbf{(Latent-arm margin.)} \(0<\pi_0\le (2k)^{-1}\).
\item \textbf{(Rank margin.)} \(0<\sigma_0\le 1\).
\end{itemize}
Then there is a constant \(C=C(k,d_x,d_z,L,\pi_0,\sigma_0)>0\) such that, for every \(n\ge1\), one can choose the simplex-valued measurable ordered-weight estimator \(\widehat p_n^{\uparrow}\) from \cref{obj:def:labeled-weight-estimator} so that, for every gap scale \(g\) satisfying \(0<g\le1/4\) and every full-data probability law \(P\in\mathcal M(g)\),
\[
E_{Q_P^{(n)}}\!\left[\left\|\widehat p_n^{\uparrow}-p^{\uparrow}(P)\right\|_1\right]
\le
C\min\left\{1,\left(\sqrt n\,g\right)^{-1}\right\}.
\]
\end{theoremv}

\Cref{obj:thm:labeled-weight-upper} gives the ordered-weight risk bound on the separated gap-local class. The rate is clipped at one and improves as the product \(\sqrt n\,g\) grows, capturing the scale at which effect ordering becomes informative for latent-stratum masses.

The contrast with the preceding law results is the statistical role of the gap. For the quotient law \(\nu_P\), \cref{obj:thm:honest-root-n-confidence} and \cref{obj:thm:cluster-adaptive-report} report uncertainty in \(W_1\) and in aggregate component masses, with collisions represented by shared atoms. For ordered weights, \cref{obj:thm:labeled-weight-upper} works on \(\mathcal M(g)\), where distinct effects and the gap window make the effect order a stable object at the scale shown in the bound.
