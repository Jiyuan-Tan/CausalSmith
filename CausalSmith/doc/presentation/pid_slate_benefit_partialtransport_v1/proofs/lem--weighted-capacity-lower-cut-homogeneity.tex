\begin{proof}[Proof of \cref{obj:lem:weighted-capacity-lower-cut-homogeneity}]
Fix a cell \(x\).  Write \(\omega=w_x\), so \(\omega\ge 0\).  By \cref{obj:def:threshold-cuts}, the lower cut can be written as the finite maximum over the dummy alternative and the threshold alternatives:
\[
B_L(x)
=
\max\Bigl(
\{0\}\cup
\bigl\{
\ell_{\le t}(x)-h_{\le t}(x)+\min\{\Delta q(x),0\}:t\in\mathcal Y
\bigr\}
\Bigr).
\]
The same formula applied to \(c^w\) gives \(B_L^w(x)\).  Since multiplication by \(\omega\ge0\) commutes with a finite maximum,
\[
\omega B_L(x)
=
\max\Bigl(
\{0\}\cup
\bigl\{
\omega\bigl(\ell_{\le t}(x)-h_{\le t}(x)+\min\{\Delta q(x),0\}\bigr):t\in\mathcal Y
\bigr\}
\Bigr).
\]
Thus it remains to compare the dummy term and each threshold term. % lean: weightedCapacities_benefitLower

For the dummy alternative the equality is immediate, because the term is \(0\) on both sides:
\[
0=\omega\cdot 0 .
\]
Now fix \(t\in\mathcal Y\).  The weighted prefix sums satisfy
\[
\ell_{\le t}^w(x)
=\sum_{i\le t}\omega\ell_i(x)
=\omega\sum_{i\le t}\ell_i(x)
=\omega\ell_{\le t}(x),
\]
and similarly
\[
h_{\le t}^w(x)=\omega h_{\le t}(x).
\]
The weighted capacity-total gap is
\[
\Delta q^w(x)
=
\sum_{j\in\mathcal Y}\omega h_j(x)
-
\sum_{i\in\mathcal Y}\omega\ell_i(x)
=
\omega\bigl(q_1(x)-q_0(x)\bigr)
=
\omega\Delta q(x).
\]
Because \(\omega\ge0\),
\[
\min\{\Delta q^w(x),0\}
=
\min\{\omega\Delta q(x),0\}
=
\min\{\omega\Delta q(x),\omega\cdot0\}
=
\omega\min\{\Delta q(x),0\}.
\]
Combining these identities,
\[
\ell_{\le t}^w(x)-h_{\le t}^w(x)+\min\{\Delta q^w(x),0\}
=
\omega\bigl(\ell_{\le t}(x)-h_{\le t}(x)+\min\{\Delta q(x),0\}\bigr).
\]
The dummy term and all threshold terms therefore agree with the corresponding \(\omega\)-scaled unweighted terms inside the same finite maximum.  Hence
\[
B_L^w(x)=\omega B_L(x)=w_xB_L(x).
\]
% lean: weightedCapacities_benefitLower
\end{proof}
